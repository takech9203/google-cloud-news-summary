📋 概要

Google Cloud Database Migration Service が、MySQL の同種マイグレーション (Homogeneous Migration) において MySQL 9.7 をサポートするようになりました。MySQL 9.7 を使用するオンプレミス環境や他のクラウド環境から Cloud SQL for MySQL 9.7 への移行が可能になります。

MySQL 9.7 は MySQL Innovation Release の最新バージョンであり、パフォーマンスの向上やセキュリティ機能の強化が含まれています。最新バージョンの MySQL を使用している組織でも、Database Migration Service を活用したシームレスなクラウド移行が可能になりました。

❌ Before (アップデート前)

  • MySQL 9.7 環境では DMS による直接移行ができなかった
  • 手動でのダンプ・リストア作業やサードパーティツールが必要
  • ダウングレードしてからの移行を検討する必要があった

✅ After (アップデート後)

  • MySQL 9.7 から Cloud SQL for MySQL 9.7 への直接移行が可能
  • 多様なソース (AWS, Azure, オンプレミス) からの移行に対応
  • 継続的レプリケーションによる最小ダウンタイム移行が実現

🏗️ アーキテクチャ図

✅ メリット

💼 ビジネス面

✓コスト不要: 同種マイグレーションは DMS 追加料金なし
✓最小ダウンタイム: 継続的レプリケーションによりビジネスへの影響を最小化

🔬 技術面

✓サーバーレス: インフラ管理不要でスケーラブル
✓最新バージョン対応: MySQL 9.7 の新機能をそのまま活用可能
✓セキュアな移行: SSL/TLS + CMEK によるデータ保護

⚠️ デメリット・制約事項

⚠️ 制限事項:
  • 後のマイナーバージョンから前のマイナーバージョンへの移行は非推奨
  • 完全にリージョナルなプロダクト - ソース・デスティネーション・接続プロファイル・ジョブはすべて同一リージョンに配置が必要
  • ソースデータベースのプラグインは移行不可
💡 考慮すべき点:
  • 長時間実行トランザクションは移行中に避けることが推奨される
  • AWS Aurora 以外からの移行では、リードレプリカからの移行が推奨される場合がある

💰 料金

同種マイグレーション (MySQL to Cloud SQL for MySQL) は、Database Migration Service の追加料金なしで利用可能です。関連リソースには通常の料金が適用されます。
