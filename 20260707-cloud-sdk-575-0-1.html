🔒 Cloud SDK 575.0.1

CVE-2026-34182 セキュリティ修正パッチ

2026-07-07
Security Patch GA Windows

📋 概要

Google Cloud CLI バージョン 575.0.1 がリリースされました。Windows 版 gcloud CLI にバンドルされている Python を 3.14.6 にアップデートし、セキュリティ脆弱性 CVE-2026-34182 (OpenSSL 関連) を修正するパッチリリースです。

本リリースは機能追加を含まないセキュリティのみの修正であり、Cloud SDK 575.0.0 (2026-06-30 リリース) に対するホットフィックスとして提供されています。

💡 補足: CVE-2026-34182 は Container-Optimized OS のリリースノートにおいても OpenSSL v3.5.7 / v3.0.21 へのアップグレードで修正対象として挙げられている共通の脆弱性です。

🔄 Before / After

❌ アップデート前の課題

  • バンドル Python 3.14.5 に CVE-2026-34182 が存在
  • 暗号化通信において脆弱性の影響を受ける可能性
  • 手動での Python アップデートではバンドル版との整合性が保てない

✅ アップデート後の改善

  • バンドル Python が 3.14.6 にアップデート済み
  • 標準アップデート手順で自動的にセキュリティ修正が適用
  • Windows 環境での暗号化通信の安全性が確保

🛠️ 設定方法

前提条件: Google Cloud CLI がインストール済みであること。Windows 環境が主要対象。

ステップ 1: 現在のバージョンを確認 Bash 
gcloud version

バージョンが 575.0.1 未満であることを確認します。

ステップ 2: Cloud SDK をアップデート Bash 
gcloud components update

最新バージョン (575.0.1) に自動的にアップデートされます。

ステップ 3: アップデートの確認 Bash 
gcloud version

Google Cloud SDK 575.0.1 と表示されることを確認してください。

📦 パッチリリースとしての提供

バージョン番号: 575.0.1 (575.0.0 からのパッチ)。機能変更なし、セキュリティ修正のみ。

✅ メリット

💼 ビジネス面

✓ コンプライアンス対応: 既知の CVE に対する修正を迅速に適用でき、セキュリティ監査要件を満たせる
✓ 運用負荷の軽減: 標準的な gcloud components update コマンドで適用可能

⚙️ 技術面

✓ 脆弱性の解消: CVE-2026-34182 による暗号化通信のリスクを排除
✓ バンドル管理: Python ランタイムの管理が gcloud CLI のアップデートプロセスに統合

⚠️ デメリット・制約事項

制限事項
  • Windows 環境のみが本パッチの直接対象。Linux / macOS ユーザーは別途対応が必要な場合がある
  • パッケージマネージャー (apt / yum) 経由でインストールした場合、gcloud components update は使用不可。パッケージマネージャー経由でアップデートが必要
考慮すべき点
  • バンドル Python を使用せず独自の Python を利用している場合は、別途 Python のアップデートが必要
  • アップデート適用後、既存のスクリプトやワークフローへの影響はないが、念のため動作確認を推奨

💡 ユースケース

🏭 ユースケース 1: CI/CD パイプラインでの gcloud CLI 使用

シナリオ: Windows ベースの CI/CD 環境で gcloud CLI を使用してデプロイを行っている場合

PowerShell 
# CI/CD パイプラインの初期化ステップ
gcloud components update --quiet
gcloud version

効果: パイプラインのセキュリティベースラインを維持し、脆弱性のある Python ランタイムでの実行を防止

👨‍💻 ユースケース 2: 開発者のローカル環境

シナリオ: Windows 上で日常的に gcloud CLI を使用して Google Cloud リソースを管理している開発者

効果: 開発環境のセキュリティを最新状態に保ち、認証情報や API リクエストの暗号化通信の安全性を確保
