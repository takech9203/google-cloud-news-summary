# Gemini Code Assist: 初月ライセンスクレジットの提供終了

**リリース日**: 2026-08-20

**サービス**: Gemini Code Assist

**機能**: 初月利用分クレジット (最大 50 ライセンス) の提供終了

**ステータス**: Announcement

📊 [このアップデートのインフォグラフィックを見る](https://takech9203.github.io/google-cloud-news-summary/20260820-gemini-code-assist-first-month-credits-discontinued.html)

## 概要

Google Cloud は 2026 年 8 月 20 日、Gemini Code Assist の初月利用分クレジット (first-month credits) の提供を終了したことを発表しました。このクレジットは、Gemini Code Assist のサブスクリプションを一度も持ったことがない請求先アカウントを持つ新規顧客に対して提供されていた特典で、エディション (Standard / Enterprise) を問わず、初月に最大 50 ライセンス分のクレジットが自動適用されるものでした。

このクレジット制度は 2025 年 1 月 30 日に導入され、新規顧客が初期コストなしで Gemini Code Assist をチームに展開して評価できる仕組みとして機能していました。今回の発表により、今後新規に Gemini Code Assist のサブスクリプションを購入する顧客にはこのクレジットは適用されません。

なお、**現在すでにこのクレジットを受け取っている顧客は今回の変更の影響を受けません**。これから導入を検討している組織は、初月から通常の料金が発生する前提でコスト計画を立てる必要があります。

**アップデート前の課題 (変更前の状態)**

- 2025 年 1 月 30 日以降、Gemini Code Assist のサブスクリプションを持ったことがない請求先アカウントの新規顧客には、エディションを問わず初月に最大 50 ライセンス分のクレジットが自動適用されていた
- 新規顧客は初月のライセンス費用を抑えた形で、チーム規模での試用・評価が可能だった

**アップデート後の変更**

- 初月クレジットの新規提供が終了し、今後の新規サブスクリプション購入では初月から通常料金が適用される
- 既存のクレジット受領者への影響はなく、すでに適用されているクレジットはそのまま有効
- 新規導入時のコスト評価では、初月無料分を前提としない見積もりが必要になった

## サービスアップデートの詳細

### 変更のポイント

1. **初月クレジットの提供終了**
   - 対象だったのは「請求先アカウントを持ち、Gemini Code Assist のサブスクリプションを一度も持ったことがない新規顧客」
   - エディション (Standard / Enterprise) を問わず、初月に最大 50 ライセンス分のクレジットが自動適用されていた
   - 今回の発表により、この特典の新規適用が終了

2. **既存顧客への影響なし**
   - 現在クレジットを受け取っている顧客は、この変更の影響を受けない

3. **本体機能への影響なし**
   - Gemini Code Assist の機能・エディション構成・ライセンス管理の仕組み自体に変更はない
   - 純粋に課金上の特典 (プロモーション) の終了であり、技術的な移行作業は不要

## 技術仕様

### 終了したクレジット制度の概要

| 項目 | 詳細 |
|------|------|
| 特典内容 | 初月利用分として最大 50 ライセンスのクレジットを自動適用 |
| 対象者 (従来) | 請求先アカウントを持ち、Gemini Code Assist サブスクリプション未購入の新規顧客 |
| 対象エディション | Standard / Enterprise (エディション不問) |
| 導入日 | 2025 年 1 月 30 日 |
| 終了発表日 | 2026 年 8 月 20 日 |
| 既存受領者への影響 | なし (現在受領中の顧客は影響を受けない) |

### サブスクリプションの基本仕様 (参考)

| 項目 | 詳細 |
|------|------|
| サブスクリプション単位 | 請求先アカウントごとに 1 サブスクリプション |
| 購入に必要な権限 | `consumerprocurement.orders.place` (roles/billing.admin または roles/consumerprocurement.orderAdmin に含まれる) |
| Enterprise の最小ライセンス数 | 10 ライセンス |
| 契約期間 | 月次または年次 (年次は割引レートで月次請求) |
| ライセンス割り当て | 自動割り当て (デフォルト) または手動割り当て |

## メリット・影響

### 新規導入を検討する組織への影響

- **初月からフルコストが発生**: 従来は最大 50 ライセンス分が初月無料だったが、今後は初月から通常料金での予算確保が必要
- **評価方法の見直し**: チーム規模での無料試用に頼らず、少人数のライセンスから始めて段階的に拡大するアプローチや、年次契約割引の活用を検討する価値がある

### 既存顧客への影響

- **影響なし**: 現在クレジットを受け取っている顧客は、この変更による請求への影響はない

## 考慮すべき点

- 導入を検討中の組織は、初月クレジットを前提としたコスト試算を修正する必要がある
- ライセンスは自動割り当てがデフォルトのため、意図しないライセンス消費 (= 課金) を避けたい場合は、手動割り当てへの変更や `cloudaicompanion.licenses.selfAssign` 権限の管理を検討する
- ライセンス数の削減やエディションのダウングレードは即時反映されず、契約期間の終了時に適用される点にも注意が必要

## 料金

Gemini Code Assist Standard / Enterprise の現在の料金 (1 ユーザーあたり月額、USD) は以下のとおりです。

### 料金例

| エディション | 月次契約 | 年次契約 (12 か月コミットメント) |
|--------------|----------|----------------------------------|
| Standard | $22.80 / 月 | $19.00 / 月 |
| Enterprise | $54.00 / 月 | $45.00 / 月 |

- Enterprise エディションは最小 10 ライセンスからの購入となります
- 年次契約は割引レートが適用され、一括払いではなく月次で請求されます
- 最新の料金は [Gemini for Google Cloud の料金ページ](https://cloud.google.com/products/gemini/pricing) を参照してください

## 関連サービス・機能

- **Gemini for Google Cloud**: Gemini Code Assist を含む Google Cloud 向け AI 支援製品ポートフォリオ
- **Admin for Gemini (Google Cloud コンソール)**: サブスクリプションの購入・編集・ライセンス割り当てを行う管理画面
- **Cloud Billing**: サブスクリプションは請求先アカウントに紐づくため、請求管理の権限設計と密接に関連
- **Gemini CLI**: Gemini Code Assist のライセンスに含まれるクォータで利用可能な CLI ツール
