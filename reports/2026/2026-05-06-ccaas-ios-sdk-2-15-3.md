# Google Cloud CCaaS: iOS Mobile SDK v2.15.3 パッチ (チャット終了時クラッシュ修正)

**リリース日**: 2026-05-06

**サービス**: Google Cloud Contact Center as a Service (CCaaS) / CCAI Platform

**機能**: Mobile SDK for iOS version 2.15.3 patch - crash fix

**ステータス**: Announcement

📊 [このアップデートのインフォグラフィックを見る](https://takech9203.github.io/google-cloud-news-summary/20260506-ccaas-ios-sdk-2-15-3.html)

## 概要

Google Cloud Contact Center as a Service (CCaaS) の iOS Mobile SDK バージョン 2.15.3 パッチがリリースされた。本パッチは、エンドユーザーが「End chat」ボタンをタップした際にアプリがクラッシュする重大な不具合を修正するものである。

CCAI Platform の iOS SDK は、iPhone や iPad アプリ内で音声およびチャットサポート体験を提供するためのツールキットである。今回の不具合はチャットセッション終了時に発生するクラッシュであり、ユーザーがサポートチャットを正常に終了できない状態を引き起こしていた。本パッチの適用により、チャット終了操作が正常に処理されるようになる。

**アップデート前の課題**

- 「End chat」ボタンをタップするとアプリがクラッシュしていた
- エンドユーザーがチャットセッションを正常に終了できなかった
- アプリのクラッシュにより、チャット後アンケートや正常な画面遷移が実行されなかった

**アップデート後の改善**

- 「End chat」操作時のクラッシュが解消され、チャットセッションが正常に終了するようになった
- チャット終了後のライフサイクル (post-chat survey、画面遷移) が意図通りに動作する
- アプリの安定性が向上し、エンドユーザーが安心してチャットサポートを利用できるようになった

## サービスアップデートの詳細

### 修正内容

1. **チャット終了時クラッシュの修正**
   - 「End chat」ボタンタップ時に発生していたクラッシュを修正
   - チャットセッション終了処理のロジックが正常に動作するようになった

2. **対象プラットフォーム**
   - iOS SDK v2.15.3 のみが対象
   - iOS 12.0 以降をサポートする既存のバージョン要件に変更なし
   - Android SDK は本不具合の影響を受けない

## 技術仕様

### 影響範囲

| 項目 | 詳細 |
|------|------|
| 対象 SDK | CCAI Platform iOS Mobile SDK v2.15.3 |
| 修正種別 | クラッシュ修正 (Crash Fix) |
| 影響を受ける機能 | チャットセッション終了操作 (「End chat」ボタン) |
| 対象 OS | iOS 12.0 以降 |
| Android への影響 | なし |
| 前バージョン | v2.15.2 (Android 向けパッチ、2026-04-02 リリース) |

### 関連する iOS SDK イベント

CCAI Platform iOS SDK では `NSNotificationCenter` を通じてセッション関連イベントが通知される。今回の修正は、ユーザーが「End chat」をタップした後に発行される `UJETEventSessionDidEnd` イベント周辺の処理に関連している。

- `UJETEventSessionDidEnd`: セッション終了時に発行 (ended_by: "end_user")
- `UJETEventSdkDidTerminate`: SDK 終了時のイベント

## メリット

### ビジネス面

- **カスタマー体験の安定化**: チャット終了時のクラッシュが解消され、サポート体験全体の信頼性が向上する
- **サポート問い合わせの削減**: クラッシュに起因する二次的な問い合わせやネガティブなフィードバックが減少する

### 技術面

- **アプリの安定性向上**: クラッシュの解消により、アプリ全体の crash-free rate が改善される
- **セッション完了率の向上**: チャットセッションが正常に終了できることで、post-chat survey の回収率や分析データの精度が向上する

## 関連サービス・機能

- **CCAI Platform Android SDK**: Android 版の SDK。v2.15.2 で minSdkVersion の引き上げと依存ライブラリ更新が行われた
- **CCAI Platform Web SDK**: Web 版の SDK。同様のチャットサポート機能を Web サイト上で提供する
- **CCAI Platform SmartActions**: チャット中にユーザー認証や写真リクエストなどを実行する機能
