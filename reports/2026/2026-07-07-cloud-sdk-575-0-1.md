# Cloud SDK: バージョン 575.0.1 セキュリティ修正 (CVE-2026-34182 対応)

**リリース日**: 2026-07-07

**サービス**: Google Cloud CLI (Cloud SDK)

**機能**: Windows バンドル Python のセキュリティアップデート

**ステータス**: GA (一般提供)

📊 [このアップデートのインフォグラフィックを見る](https://takech9203.github.io/google-cloud-news-summary/20260707-cloud-sdk-575-0-1.html)

## 概要

Google Cloud CLI バージョン 575.0.1 がリリースされました。本リリースは、Windows 版 gcloud CLI にバンドルされている Python を 3.14.6 にアップデートし、セキュリティ脆弱性 CVE-2026-34182 を修正するパッチリリースです。

CVE-2026-34182 は OpenSSL に関連するセキュリティ脆弱性であり、Container-Optimized OS のリリースノートにおいても OpenSSL v3.5.7 および v3.0.21 へのアップグレードで修正対象として挙げられています。Windows 環境で gcloud CLI を使用しているユーザーは、本バージョンへのアップデートが推奨されます。

本リリースは機能追加を含まないセキュリティのみの修正 (パッチリリース) であり、Cloud SDK 575.0.0 (2026-06-30 リリース) に対するホットフィックスとして提供されています。

**アップデート前の課題**

- Windows 版 gcloud CLI にバンドルされた Python 3.14.5 に CVE-2026-34182 (OpenSSL 関連脆弱性) が存在
- gcloud CLI を利用する際に、暗号化通信において脆弱性の影響を受ける可能性があった
- 手動での Python アップデートではバンドル版との整合性が保てない

**アップデート後の改善**

- バンドル Python が 3.14.6 にアップデートされ CVE-2026-34182 が修正済み
- gcloud CLI の標準アップデート手順で自動的にセキュリティ修正が適用される
- Windows 環境での暗号化通信の安全性が確保される

## サービスアップデートの詳細

### 主要機能

1. **Windows バンドル Python アップデート**
   - Python バージョンを 3.14.5 から 3.14.6 へ更新
   - CVE-2026-34182 (OpenSSL 関連脆弱性) の修正を含む

2. **パッチリリースとしての提供**
   - バージョン番号: 575.0.1 (575.0.0 からのパッチ)
   - 機能変更なし、セキュリティ修正のみ

## 設定方法

### 前提条件

1. Google Cloud CLI がインストール済みであること
2. Windows 環境であること (本パッチの主要対象)

### 手順

#### ステップ 1: 現在のバージョンを確認

```bash
gcloud version
```

バージョンが 575.0.1 未満であることを確認します。

#### ステップ 2: Cloud SDK をアップデート

```bash
gcloud components update
```

最新バージョン (575.0.1) に自動的にアップデートされます。

#### ステップ 3: アップデートの確認

```bash
gcloud version
```

`Google Cloud SDK 575.0.1` と表示されることを確認してください。

## メリット

### ビジネス面

- **コンプライアンス対応**: 既知の CVE に対する修正を迅速に適用でき、セキュリティ監査要件を満たせる
- **運用負荷の軽減**: 標準的な gcloud components update コマンドで適用可能なため、追加の運用手順が不要

### 技術面

- **脆弱性の解消**: CVE-2026-34182 (OpenSSL 関連) による暗号化通信のリスクを排除
- **バンドル管理**: Python ランタイムの管理が gcloud CLI のアップデートプロセスに統合されており、個別管理が不要

## デメリット・制約事項

### 制限事項

- Windows 環境のみが本パッチの直接対象。Linux / macOS ユーザーは別途対応が必要な場合がある
- パッケージマネージャー (apt / yum) 経由でインストールした場合、`gcloud components update` は使用不可。パッケージマネージャー経由でアップデートが必要

### 考慮すべき点

- バンドル Python を使用せず独自の Python を利用している場合は、別途 Python のアップデートが必要
- アップデート適用後、既存のスクリプトやワークフローへの影響はないが、念のため動作確認を推奨

## ユースケース

### ユースケース 1: CI/CD パイプラインでの gcloud CLI 使用

**シナリオ**: Windows ベースの CI/CD 環境で gcloud CLI を使用してデプロイを行っている場合

**実装例**:
```powershell
# CI/CD パイプラインの初期化ステップ
gcloud components update --quiet
gcloud version
```

**効果**: パイプラインのセキュリティベースラインを維持し、脆弱性のある Python ランタイムでの実行を防止

### ユースケース 2: 開発者のローカル環境

**シナリオ**: Windows 上で日常的に gcloud CLI を使用して Google Cloud リソースを管理している開発者

**効果**: 開発環境のセキュリティを最新状態に保ち、認証情報やAPIリクエストの暗号化通信の安全性を確保
