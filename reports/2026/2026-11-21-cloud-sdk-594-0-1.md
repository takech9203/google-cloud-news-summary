# Cloud SDK: gcloud CLI 594.0.1 パッチリリース (General bug fixes)

**リリース日**: 2026-11-21

**サービス**: Cloud SDK (Google Cloud CLI)

**機能**: バージョン 594.0.1 - 一般的なバグ修正 (General bug fixes)

**ステータス**: GA (パッチリリース)

📊 [このアップデートのインフォグラフィックを見る](https://takech9203.github.io/google-cloud-news-summary/20261121-cloud-sdk-594-0-1.html)

## 概要

2026 年 11 月 21 日、Google Cloud CLI (gcloud) バージョン 594.0.1 がリリースされた。公式リリースノートに記載されている変更内容は「General bug fixes. (一般的なバグ修正)」のみであり、新機能の追加や Breaking Changes は含まれていないパッチリリースである。修正されたバグの具体的な内容は公表されていない。

本リリースは、2026 年 11 月 17 日にリリースされた 594.0.0 に続くパッチである。594.0.0 には `gcloud auth`、`gcloud billing accounts`、`gcloud compute shared-vpc` の各コマンド群におけるフラグと位置引数の優先順位に関する 3 件の Breaking Changes が含まれていた (詳細は [2026-11-17 のレポート](2026-11-17-cloud-sdk-594-breaking-changes.md) を参照)。594.0.1 のリリースノートにはこれらの Breaking Changes を元に戻す記載はないため、594.0.0 の動作変更はそのまま有効である。

594.0.0 へのアップグレードを保留していたユーザーは、本パッチ適用済みの 594.0.1 を対象に、Breaking Changes の影響確認とあわせてアップグレードを計画するとよい。

**アップデート前の課題**

- 594.0.0 に何らかのバグが存在していた (具体的な内容は公表されていない)

**アップデート後の改善**

- 一般的なバグ修正が適用され、594.x 系の安定性が向上した

## 設定方法

### 前提条件

1. Google Cloud CLI がインストール済みであること
2. 593.x 以前からアップグレードする場合は、594.0.0 の Breaking Changes の影響を事前に確認していること

### 手順

#### ステップ 1: 現在のバージョンを確認

```bash
gcloud version
```

#### ステップ 2: Cloud SDK をアップデート

```bash
gcloud components update
```

最新バージョン (594.0.1) にアップデートされる。パッケージマネージャー (apt / yum) 経由でインストールした場合は `gcloud components update` は使用できないため、パッケージマネージャーでアップデートする。

#### ステップ 3: アップデートの確認

```bash
gcloud version
```

`Google Cloud SDK 594.0.1` と表示されることを確認する。

## デメリット・制約事項

### 考慮すべき点

- 修正されたバグの具体的な内容が公表されていないため、特定の不具合が解消されたかどうかはアップデート後の動作確認で判断する必要がある
- 593.x 以前から直接 594.0.1 にアップグレードする場合、594.0.0 の Breaking Changes (位置引数とフラグの優先順位変更、位置引数の必須化) の影響を受けるため、事前にスクリプトの棚卸しが必要

## ユースケース

### ユースケース 1: 594.0.0 へのアップグレードを保留していた環境の更新

**シナリオ**: 594.0.0 の Breaking Changes の影響調査のためにアップグレードを保留していた CI/CD 環境やローカル環境で、バグ修正済みの 594.0.1 を適用する。

**実装例**:
```bash
# 影響を受けるコマンドパターンをスクリプトから検索 (594.0.0 の Breaking Changes 対応)
grep -rnE "gcloud (auth (print-access-token|print-identity-token|login|application-default login|activate-service-account)|billing accounts (get-iam-policy|set-iam-policy|add-iam-policy-binding|remove-iam-policy-binding)|compute shared-vpc)" .

# 問題がなければ 594.0.1 へ更新
gcloud components update
```

**効果**: Breaking Changes の影響確認と、バグ修正済みパッチの適用を 1 回のアップグレードで完了できる。
