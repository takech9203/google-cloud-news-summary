🗄️ Firestore with MongoDB compatibility Preview

💬 Conversational Analytics で
自然言語によるデータ分析が可能に

Gemini を活用した「チャットでデータと対話する」体験を MongoDB 互換データベースへ
📅 リリース日: 2026-11-09

📝 概要

Firestore with MongoDB compatibility で Conversational Analytics (会話型分析) が Preview として利用可能になりました。 Conversational Analytics API (geminidataanalytics.googleapis.com) を基盤とし、Firestore に格納されたオペレーショナルデータに自然言語で質問して回答を得られます。

コレクションなどのナレッジソースに紐づけたデータエージェントを作成し、カスタムメタデータ、同義語・ビジネス用語、キーフィールド、フィルタリング/グルーピングのデフォルト設定といったコンテキストを付与できます。 会話は永続化され、フィールド名を意識せずに日常的な言葉でマルチターンの質問が可能です。応答にはテキスト、コード、チャート、エージェントの推論過程が含まれます。

これまでデータベース系データソースは AlloyDB for PostgreSQL、Spanner、Cloud SQL (MySQL / PostgreSQL) に限られていましたが、Firestore with MongoDB compatibility (Enterprise edition) のユーザーも BI ツールや MQL の知識なしに運用データから洞察を得られるようになります。

❌ Before: アップデート前の課題

  • データ分析には MQL (MongoDB Query Language) の記述か、BigQuery などの分析基盤へのデータ移動が必要だった
  • Conversational Analytics API のデータベース系データソースは AlloyDB、Spanner、Cloud SQL に限られ、Firestore は対象外だった
  • 2026 年 10 月 Preview の QueryData はシングルターンの NL → MQL 生成が中心で、永続化されたマルチターンの会話型分析体験はなかった

✅ After: アップデート後の改善

  • コンソールの Conversations ページからデータエージェントを作成し、自然言語でのマルチターン会話による分析が可能に
  • Guided (ノーコード) と Advanced (Gemini CLI / IDE) の 2 つのコンテキスト作成オプションで回答精度を調整可能に
  • コンソールで作成したエージェントを API 経由でも呼び出せるため、自社アプリケーションへの組み込みが容易に

ユーザーの自然言語の質問を、コンテキストを持つデータエージェントが解釈して Firestore へのクエリに変換・実行し、テキストやチャートを含む回答を返します。

⚡ 主要機能

💬 1. データエージェントによる自然言語クエリ

✓コレクションなどのナレッジソースに紐づくデータエージェントを作成し、自然言語で質問できる
✓フィールド名を正確に指定しなくても、日常的な言葉やビジネス用語で質問できる
✓応答にはテキスト、コード、チャートに加えて推論過程と会話メタデータが含まれる

🛠️ 2. 2 つのコンテキスト作成オプション

✓Guided: Google Cloud コンソール上でコードを書かずにエージェントを構築
✓Advanced: Gemini CLI や IDE を使い、エージェントの品質をより細かく制御
✓カスタムメタデータ、同義語・ビジネス用語、キーフィールド、フィルタリング/グルーピングのデフォルトを設定可能

🔄 3. 永続化されたマルチターン会話

✓会話は保存され、文脈を引き継いだ複数ターンの質問が可能
✓Conversations ページで、サンプルエージェント、下書き/公開済みエージェント、共有されたエージェントを管理できる

🔌 4. API 経由のアプリケーション統合

✓コンソールで作成したエージェントは Conversational Analytics API からも呼び出せる
✓データソースへの直接会話 (エージェントコンテキストなし) も可能だが、精度重視の場合はエージェントの利用が推奨

🚀 設定方法

✅ 前提条件

✓Firestore Enterprise edition (MongoDB compatibility) のデータベースが作成済みであること
✓Conversational Analytics API (Data Analytics API with Gemini) が有効化されていること
✓利用者に Conversational Analytics API の適切な IAM ロールが付与されていること

📑 手順

  1. データエージェントの作成
    コンソールの Firestore の Conversations ページから、対象のナレッジソース (コレクション) を選択してデータエージェントを作成
  2. コンテキストと指示の追加 (任意)
    まずは自動生成コンテキストで開始し、必要に応じて同義語・ビジネス用語、キーフィールド、フィルタリング/グルーピングのデフォルトなどをカスタマイズ。高度な制御には Gemini CLI / IDE の Advanced オプションを利用
  3. 会話の開始
    エージェントとの会話を開始し、自然言語でデータについて質問。コンソールで作成したエージェントは API 経由でアプリケーションからも呼び出し可能

👍 メリット

💼 ビジネス面

✓データ活用の民主化: MQL や BI ツールの知識がない業務担当者でも、自然言語で運用データから洞察を得られる
✓意思決定の迅速化: ダッシュボード作成やクエリ開発を待たずに、その場で質問して回答を得られる
✓追加コストなしで試用可能: Preview 期間中は機能自体への追加課金がなく、低リスクで評価できる

⚙️ 技術面

✓データ移動が不要: オペレーショナルデータベースに直接分析クエリを実行でき、ETL パイプラインの構築が不要
✓コンテキストによる精度向上: ビジネス用語やキーフィールドを教え込むことで、組織固有の質問にも正確に回答できる
✓API 統合: コンソールで作成・検証したエージェントをそのまま API 経由でアプリケーションに組み込める

⚠️ デメリット・制約事項

🚧 制限事項

✗Preview (Pre-GA) のため、Pre-GA Offerings Terms が適用され、サポートが限定される場合がある
✗Firestore Enterprise edition (MongoDB compatibility) が前提であり、Standard edition では利用できない
✗Dynamic Shared Quota のため、需要が高い時間帯には一時的に 429 Resource Exhausted エラーが発生する可能性がある (短い待機後のリトライが推奨)

🤔 考慮すべき点

⚠️ 注意:
  • Gemini の出力はもっともらしく見えても事実と異なる場合があるため、利用前に回答の検証が推奨される
  • エージェントコンテキストを使わない直接会話は精度が下がる可能性があるため、精度が重要な場合はエージェントの作成を推奨
  • 会話型分析のクエリには通常の Firestore コンピュート課金が発生するため、大規模コレクションへの探索的な質問はコストに注意

🎯 ユースケース

🛒 ユースケース 1: EC サイトの注文データの即席分析

シナリオ: Firestore with MongoDB compatibility に注文・顧客・商品データを格納している EC サイトで、マーケティング担当者が「先月最も売れた商品カテゴリは?」「リピート購入率が高い地域は?」といった質問をしたい。

実装例:

Text 実装の流れ 
1. 注文 (orders)・顧客 (customers) コレクションをナレッジソースとしてデータエージェントを作成
2. 「売上」「リピート率」などのビジネス用語とフィールドの対応をコンテキストに追加
3. コンソールの Conversations ページ、または自社管理画面 (API 統合) から自然言語で質問
✅ 効果: BI チームへの依頼や SQL/MQL の習得なしに、業務担当者が自律的にデータから洞察を得られる。

💻 ユースケース 2: SaaS アプリケーションへの分析チャットの組み込み

シナリオ: Firestore をバックエンドに持つ SaaS アプリケーションで、エンドユーザー向けに「自分のデータについて質問できる」チャット機能を提供したい。

✅ 効果: コンソールで作成・検証したデータエージェントを Conversational Analytics API 経由で呼び出すことで、分析エンジンを自前で開発することなく、会話型分析機能を製品に組み込める。

💰 料金

💡 Preview 期間中、Conversational Analytics 機能自体への追加料金はありません。
ただし、エージェントの作成時および会話中に実行されるクエリに対しては、通常の Firestore のコンピュート料金が発生します。
