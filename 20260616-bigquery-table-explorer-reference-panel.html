📊 BigQuery: Table Explorer の Reference パネルへの統合

BigQuery Announcement
2026-06-16

🔍 概要

BigQuery の Table Explorer 機能が Reference パネル に統合されることが発表されました。この移行は 2026年7月以降 に実施される予定で、データ探索からクエリ作成までのワークフローがクエリエディタ内で完結するようになります。

💡 ポイント: Table Explorer の視覚的データ探索機能が、クエリエディタ内のサイドパネルとして生まれ変わり、よりシームレスなワークフローを実現します。

🔄 Before / After 比較

❌ Before (Table Explorer)

  • Table Explorer とクエリエディタが分離
  • データ探索とクエリ作成を別インターフェースで実施
  • 生成クエリをエディタにコピーする追加手順が必要
  • テーブル情報参照時にコンテキストスイッチが発生

✅ After (Reference パネル)

  • クエリエディタ内でスキーマ確認とクエリ構築が一体化
  • フィールド名クリックでクエリに直接挿入可能
  • 操作ステップの大幅削減
  • Gemini Cloud Assist との連携で AI 支援も利用可能

🚀 主要機能

Table Explorer (移行元)

🔢 フィールド選択

テーブルフィールドを最大 10 個選択してデータを視覚的に探索

📊 インタラクティブカード

各フィールドの上位 10 件の値をインタラクティブカードとして表示

⚡ クエリ自動生成

選択に基づいたデータ探索クエリの自動生成

🗂️ 多様なソース対応

BigQuery テーブル、BigLake テーブル、外部テーブル、ビューに対応

Reference パネル (移行先)

📑 動的スキーマ表示

クエリエディタ内でテーブル・ビューのスキーマ情報を動的に表示

⭐ クイックアクセス

最近使用したテーブルやスター付きテーブルへの即座のアクセス

✏️ 直接挿入

フィールド名のクリックによるクエリへの直接挿入、スニペット挿入機能

🔍 テーブル検索

パネル内でテーブルを検索し、複数テーブル間を自由に切り替え可能

🤖 Gemini Cloud Assist 連携

AI によるデータ分析支援

Reference パネルへの移行に伴い、Gemini Cloud Assist との連携が利用可能に。Table Explorer の基本的なクエリ生成を超えた高度な分析支援を提供します。

💡 データインサイト

データに関するより深いインサイトの取得が可能に

🧠 SQL AI 支援

SQL クエリの AI 支援による生成・補完・説明

✅ メリット

🎯 ワークフロー効率化

データ探索からクエリ作成までをクエリエディタ内で一貫して実施。分析者の生産性が向上。

🤖 AI 支援の活用

Gemini Cloud Assist との統合により、より高度なデータ分析やクエリ最適化が可能に。

🔄 コンテキスト保持

クエリエディタとデータ参照を同一画面で行えるため、コンテキストスイッチが不要に。

📈 対応リソース拡大

スナップショットやマテリアライズドビューなど、従来非対応だったリソースも参照可能に。

⚠️ 考慮事項・制約

注意すべきポイント:
  • Table Explorer の「フィールド値の出現頻度をカード表示する」機能の代替方法は詳細未発表
  • 既存の Table Explorer を活用したワークフローやトレーニング資料の更新が必要になる可能性あり
  • 移行時期は「2026年7月以降」とされており、具体的な日付は未定

💰 料金

Table Explorer は選択したフィールドと値に基づいてクエリを実行するため、BigQuery のコンピュート料金が発生します。Reference パネルへの移行後も、クエリの実行には同様のコンピュート料金が適用されます。

📌 料金体系: 料金体系自体に変更はないと見られます。詳細は BigQuery 料金ページ を参照してください。

🔒 権限要件

→ テーブルデータの参照には対象テーブルへの読み取り権限が必要
→ 列レベルのアクセス制御 (ACL) が設定されている場合は、選択した全フィールドへの読み取りアクセスが必要

🎯 ユースケース

📊 データアナリストの日常作業

テーブルスキーマを確認しながらクエリを構築する場面で、Reference パネルを活用することでエディタを離れずに作業が完結。生産性の大幅な向上が期待される。

🔍 新しいデータセットの探索

初めて扱うデータセットのスキーマやフィールド情報をサイドパネルで即座に確認し、クエリスニペットを挿入しながら効率的に理解を深められる。

🤖 AI 支援による高度な分析

Gemini Cloud Assist と連携して、データに関するインサイト取得やクエリの自動生成・最適化を行う。Table Explorer の基本機能を超えた分析が可能に。
