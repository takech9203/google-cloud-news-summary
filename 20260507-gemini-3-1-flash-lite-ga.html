⚡ 主要機能

🎯 Gemini 2.5 Flash 相当の応答品質

前世代の Flash-Lite モデルから大幅な品質向上を実現。Gemini 2.5 Flash と同等のパフォーマンスを主要ベンチマークで達成し、コスト効率を維持しながら、より高品質な出力を生成します。

📝 改善されたインストラクション・フォロー

複雑なチャットボットや指示の多いワークフローに対応。Gemini 2.5 Flash からの移行パスとして信頼性を確保し、構造化出力 (JSON スキーマ) への準拠精度が向上しています。

🧠 拡張されたシンキング (思考) サポート

from google.genai import types

    model="gemini-3.1-flash-lite",
    contents="Hello, how are you?",
)
print(response.text)

Python 
response = client.models.generate_content(

    config=types.GenerateContentConfig(
        thinking_config=types.ThinkingConfig(thinking_level="medium")
    ),
)
print(response.text)

ステップ 4: 構造化出力 (JSON)

Python 
from pydantic import BaseModel, Field

class ReviewAnalysis(BaseModel):
    aspect: str = Field(description="The feature mentioned")
    sentiment_score: int = Field(description="1 to 5 (1=worst, 5=best)")
    is_return_risk: bool = Field(description="True if return mentioned")

response = client.models.generate_content(
    model="gemini-3.1-flash-lite",
    contents=["Analyze this review", "Great product but shipping was slow"],
    config={
        "response_mime_type": "application/json",
        "response_json_schema": ReviewAnalysis.model_json_schema(),
    },
)
print(response.text)
