📋 概要

2026 年 11 月 17 日、Google Cloud は Apigee の更新バージョン 1-18-0-apigee-10 をリリースしました。 セキュリティ速報 GCP-2026-082 (Bug ID: 586658318) に記載された脆弱性 CVE-2026-114938 に対応するセキュリティアップデートです。 Apigee ランタイム全体が対象であり、JavaCallout ポリシーで実行される顧客提供の Java コードも緩和策に含まれます。

CVE-2026-114938 は OpenJDK 17.0.6 以降に存在するリモートコード実行 (RCE) の脆弱性で、深刻度は Critical です。 AVX-512 VBMI 対応の x86-64 プロセッサ上で、HotSpot の AVX-512 VBMI Base64 デコーダ intrinsic における整数アンダーフローにより、 不正な形式の Base64 入力 (Base64.getDecoder() / Base64.getUrlDecoder()) のデコード時にヒープ領域外書き込みが発生します。 C2 JIT コンパイラがデコードパスをコンパイルした後は、認証不要のリモート攻撃者が細工した Base64 入力を送るだけで JVM 内で任意コードを実行できる可能性があります。

💡 ポイント: セキュリティアップデートのため、影響バージョンを実行しているインスタンスは メンテナンスウィンドウを構成しているインスタンスも含めて、通常より早い優先スケジュールでパッチが適用されます。 顧客側で Java コールアウトのコードを変更する必要はありません。

⚠️ アップデート前の課題

  • Apigee ランタイム (Java ベースの Message Processor など) は OpenJDK 上で動作しており、影響バージョンでは不正な Base64 入力を介した任意コード実行のリスクがあった
  • JavaCallout ポリシーの顧客提供 Java コード内の Base64.getDecoder() / Base64.getUrlDecoder() 呼び出しも攻撃面となり得た
  • マネージドサービスのため、顧客自身では Apigee ランタイムの JVM にパッチや緩和フラグ (-XX:UseAVX=2 など) を適用できなかった

✅ アップデート後の改善

  • 1-18-0-apigee-10 へのアップデートにより、Apigee ランタイム (JavaCallout の顧客提供 Java コードを含む) で CVE-2026-114938 が緩和
  • 顧客は Java コールアウトのコードを変更する必要がなく、Google 側のロールアウトのみで保護が適用される
  • メンテナンスウィンドウ構成済みインスタンスも対象とする優先スケジュールにより、Critical 脆弱性への暴露期間を最小化

⚖️ メリットと制約事項

💼 ビジネス面のメリット

✓Critical 脆弱性への迅速な対応: 認証不要の RCE という深刻なリスクが、顧客の運用負荷なしで解消される
✓コンプライアンス対応の簡素化: 脆弱性管理の報告ではセキュリティ速報とバージョン確認結果を根拠にできる

🔩 技術面のメリット

✓顧客コードの変更不要: JavaCallout の JAR を再ビルド・再デプロイすることなく緩和が適用される
✓メンテナンスウィンドウをバイパスする優先適用: 通常は適用タイミングを制御する構成下でも優先適用され、暴露期間が最小化される

⚠️ 考慮すべき点

•優先スケジュールでの適用により、想定外のタイミングでインスタンスの更新 (ローリングアップデート) が発生する可能性がある
•自組織のインスタンスがパッチ済みバージョンかは、セキュリティ速報の手順に従って自身で確認する必要がある
•Apigee 以外で自己管理している Java ワークロード (GKE、Cloud Run、Compute Engine 上の OpenJDK 17.0.6+ など) は本リリースの対象外。GCP-2026-082 記載の緩和策 (JDK_JAVA_OPTIONS="-XX:+IgnoreUnrecognizedVMOptions -XX:UseAVX=2" の設定とパッチ済み JDK へのアップグレード) を別途実施する必要がある

📋 ユースケース 2: 組織全体の CVE-2026-114938 対応の棚卸し

効果: Apigee は Google 側の優先ロールアウトで対応されるため確認のみでよく、自己管理の Java ワークロードに JDK_JAVA_OPTIONS の暫定緩和策とパッチ済み JDK / ベースイメージへの更新を集中して実施できる。
