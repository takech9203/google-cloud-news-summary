⚓ Apigee Operator for Kubernetes 1.1.2

Netty ほか依存ライブラリのセキュリティ修正リリース
Apigee Operator for Kubernetes 一般提供 (GA) 🔒 セキュリティアップデート
リリース日: 2026-11-04

📋 概要

Google Cloud は Apigee Operator for Kubernetes バージョン 1.1.2 をリリースしました。 このオペレーターは、kubectl や Helm などの Kubernetes ネイティブなツールで API プロダクトやオペレーション定義といった API 管理タスクを実行でき、 GKE クラスタと Apigee ランタイムを APIM リソース経由で同期させる仕組みを提供します。

1.1.2 はセキュリティ修正を中心としたメンテナンスリリースです。 Java 系依存ライブラリ群が一括更新され、合計 61 件の CVE に対処しています。 本番 GKE クラスタで運用中のチームには早期適用が推奨されます。

❌ Before (1.1.1 以前)

  • Netty、Jackson、Jetty、Vert.x、Guava の旧バージョンに起因する多数の既知脆弱性 (CVE) が残存
  • Artifact Analysis や社内スキャナーで依存ライブラリ由来の検出が多数報告される状態
  • ネットワーク処理 (Netty) や JSON 処理 (Jackson) など通信経路のコンポーネントに未修正の脆弱性

✅ After (1.1.2)

  • Netty 4.1.137.Final へ更新し、CVE-2026-33870 / 33871 など 35 件を修正
  • Jackson 2.21.7 (16 件)、Jetty 12.0.36 (7 件)、Vert.x 4.5.35 (2 件)、Guava 33.7.2-jre (1 件) で残りも一括解消
  • Helm チャートを 1.1.2 に上げて再デプロイするだけでまとめて適用可能

GKE クラスタ上で稼働する Apigee Operator for Kubernetes の依存ライブラリ 5 種がバージョン 1.1.2 で一括更新され、 合計 61 件の CVE が修正されます。適用は Helm チャートのバージョン更新のみで完結します。

⚙️ 主要機能 (アップデートの詳細)

1️⃣ Apigee Operator for Kubernetes 1.1.2 の提供開始

2026 年 11 月 4 日のリリースノートで、新バージョン 1.1.2 が利用可能になったことが発表されました。機能追加ではなく、依存ライブラリのセキュリティ修正を目的としたメンテナンスリリースです。

2️⃣ Netty のアップグレード (4.1.137.Final) — 35 件の CVE 修正

オペレーターの非同期ネットワーク処理を担う Netty を 4.1.137.Final に更新。

対処 CVE: CVE-2026-33870、CVE-2026-33871、CVE-2026-41417、CVE-2026-42578〜42581、CVE-2026-42583〜42585、CVE-2026-42587、CVE-2026-44249、CVE-2026-45416、CVE-2026-45673、CVE-2026-45674、CVE-2026-47244、CVE-2026-47691、CVE-2026-48043、CVE-2026-50010、CVE-2026-50020、CVE-2026-50560、CVE-2026-55831、CVE-2026-55833、CVE-2026-56745、CVE-2026-56746、CVE-2026-56819、CVE-2026-59898〜59901、CVE-2026-59903、CVE-2026-59921、CVE-2026-73508、CVE-2026-75595、CVE-2026-75596 (計 35 件)

3️⃣ Jackson のアップグレード (2.21.7) — 16 件の CVE 修正

JSON 処理ライブラリ Jackson を 2.21.7 に更新。

対処 CVE: CVE-2026-18401、CVE-2026-19032、CVE-2026-54512〜54515、CVE-2026-59888、CVE-2026-59889、CVE-2026-68494、CVE-2026-68497、CVE-2026-77310、CVE-2026-83557、CVE-2026-89407、CVE-2026-89425、CVE-2026-91776、CVE-2026-91777 (計 16 件)

4️⃣ Jetty / Vert.x / Guava のアップグレード — 計 10 件の CVE 修正

→Jetty 12.0.36: CVE-2025-11143、CVE-2026-1605、CVE-2026-2332、CVE-2026-6790、CVE-2026-8384、CVE-2026-10050、CVE-2026-10051 の 7 件に対処
→Vert.x 4.5.35: CVE-2026-1002、CVE-2026-6860 の 2 件に対処
→Guava 33.7.2-jre: CVE-2026-102554 の 1 件に対処

ステップ 1: 現在のインストール状態を確認

Bash 
# 現在のチャートバージョンを確認
helm list -n apim

# オペレーター Pod の稼働状態を確認
kubectl get pods -n apim

既存リリース (例: 1.1.1) のチャート名とリリース名を確認します。

ステップ 2: CRD とオペレーターを 1.1.2 に更新

Bash 
# CRD チャートを 1.1.2 に更新
helm upgrade apigee-apim-crds -n apim \
  oci://us-docker.pkg.dev/apigee-release/apigee-k8s-tooling-helm-charts/apigee-apim-operator-crds \
  --version 1.1.2 \
  --atomic

# オペレーター本体を 1.1.2 に更新 (既存の values 設定を引き継ぐ)
helm upgrade apigee-apim-operator -n apim \
  oci://us-docker.pkg.dev/apigee-release/apigee-k8s-tooling-helm-charts/apigee-apim-operator-helm \
  --version 1.1.2 \
  --reuse-values \
  --atomic
✅ ポイント: --atomic を指定すると、アップグレード失敗時に自動でロールバックされます。

ステップ 3: 更新後の動作確認

Bash 
# チャートバージョンが 1.1.2 になったことを確認
helm list -n apim

# オペレーター Pod が Running / READY 1/1 であることを確認
kubectl get pods -n apim

✓脆弱性スキャンのノイズ削減: コンテナイメージスキャンで検出されていた依存ライブラリ由来の指摘が解消され、本当に対処が必要な検出に集中できる

🚧 制限事項

⚠️ 注意:
  • 本リリースはセキュリティ修正が中心であり、適用を先送りすると既知脆弱性が残存するため、計画的な早期適用が望ましい
  • アップグレード時はオペレーター Pod が再作成されるため、変更管理プロセスに沿ったメンテナンス計画 (dry-run の実施、--atomic によるロールバック確保) を推奨

🎯 ユースケース

🔍 ユースケース 1: 定期脆弱性スキャンへの対応

シナリオ: セキュリティチームがコンテナイメージの定期スキャンを実施しており、Apigee Operator for Kubernetes のイメージから Netty や Jackson の CVE が多数検出されている。

Bash 
# dry-run で影響を確認してから適用
helm upgrade apigee-apim-operator -n apim \
  oci://us-docker.pkg.dev/apigee-release/apigee-k8s-tooling-helm-charts/apigee-apim-operator-helm \
  --version 1.1.2 --reuse-values --atomic --dry-run=server

効果: 1 回のチャート更新で 61 件の CVE 検出が解消され、脆弱性対応の SLA を満たせる。

🔄 ユースケース 2: GKE 上の API 管理基盤の定期メンテナンス

シナリオ: GKE Gateway + Apigee Operator for Kubernetes で API ポリシー適用基盤を運用しており、四半期ごとのメンテナンスウィンドウでコンポーネントを更新している。

効果: メンテナンスウィンドウ内で 1.1.2 への更新を組み込むことで、機能面の変更リスクを抑えつつセキュリティ水準を最新に保てる。

🔗 関連サービス・機能

→Apigee: オペレーターが同期先とする API 管理プラットフォーム。ポリシー決定ポイント (PDP) として機能する

📝 まとめ

Apigee Operator for Kubernetes 1.1.2 は、Netty 4.1.137.Final へのアップグレードを筆頭に、 Jackson、Jetty、Vert.x、Guava を含む依存ライブラリの合計 61 件の CVE を修正するセキュリティリリースです。 機能面の変更はないため適用リスクは小さく、GKE 上でオペレーターを運用しているすべての環境で、 Helm チャートを 1.1.2 へ早期に更新することを推奨します。
