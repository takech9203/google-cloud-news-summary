📋 概要

Gemini Enterprise Agent Platform において、Gemini 3.1 Flash Image Preview および Gemini 3 Pro Image Preview に複数の改善が導入されました。画像生成ワークフローの効率化とレイテンシ削減を目的としたアップデートです。

❌ Before

  • 4K 画像出力の効率性に改善の余地
  • 思考画像が複数生成されレスポンス時間に影響
  • 512 解像度パラメータは限定的な表記のみ対応
  • デフォルト思考レベルがレイテンシ面で非最適

✅ After

  • 4K 出力品質と処理効率が向上
  • 思考画像の最大数が 1 枚に制限
  • "512", "512p", "512P", "512PX", "512px" が利用可能に
  • デフォルト思考レベルが Minimal に変更

⚡ 主要機能

🖼️ 4K 出力品質と効率性の向上

Gemini 3.1 Flash Image Preview および Gemini 3 Pro Image Preview の両方で 4K 出力 (4096x4096px) の生成効率が向上。より高品質な出力が可能になりました。

🧠 思考画像 (Thought Image) の制限

両モデルで思考画像の最大数が 1 枚に制限。以前はモデルが最大 2 枚の中間画像を生成していましたが、1 枚に制限されたことでレスポンス時間の短縮とトークン消費の削減が実現。

📐 512 解像度パラメータの拡張 (Flash Image のみ)

image_size パラメータで以下の値が利用可能に:

"512" "512p" "512P" "512PX" "512px"

0.5MP (512px) 解像度の出力画像を生成。サムネイルやプレビュー用途に最適。

⏱️ デフォルト思考レベルの変更 (Flash Image のみ)

デフォルト thinkingLevel が Minimal に変更。完全に思考を無効化するのではなく、最低限の思考プロセスを維持。サポートされる値: minimal (デフォルト) / high

💻 コードサンプル

512px 解像度で生成 (低レイテンシ)

Python 
from google import genai
from google.genai import types

client = genai.Client()

# Gemini 3.1 Flash Image - 512px 解像度で生成
response = client.models.generate_content(
    model="gemini-3.1-flash-image-preview",
    contents="A minimalist logo design for a coffee shop",
    config=types.GenerateContentConfig(
        response_modalities=["IMAGE"],
        response_format={"image": {"image_size": "512px"}},
        thinking_config=types.ThinkingConfig(
            thinking_level="minimal",
            include_thoughts=False
        ),
    )
)

for part in response.parts:
    if part.text is not None:
        print(part.text)
    elif image := part.as_image():
        image.save("logo_512.png")

4K 高品質生成 (思考レベル High)

Python 
# Gemini 3.1 Flash Image - 4K 高品質生成
response = client.models.generate_content(
    model="gemini-3.1-flash-image-preview",
    contents="A detailed architectural visualization of a modern glass building",
    config=types.GenerateContentConfig(
        response_modalities=["IMAGE"],
        response_format={"image": {"image_size": "4K"}},
        thinking_config=types.ThinkingConfig(
            thinking_level="High",
            include_thoughts=True
        ),
    )
)

ビジネス面

✓ レスポンス時間短縮: Minimal 思考 + 思考画像 1 枚制限でインタラクティブ体験向上

技術面

✓ 柔軟なパラメータ指定: 512 解像度の複数表記対応で互換性向上
✓ 予測可能なレイテンシ: 思考画像 1 枚制限でレスポンス時間のばらつき軽減
✓ 効率的なトークン消費: 4K 出力の効率改善で同じ予算で高品質な結果

⚠️ デメリット・制約事項

制限事項:
  • Preview ステータスのため、SLA や非推奨ポリシーの対象外
  • 思考画像 1 枚制限で複雑なプロンプトの構図試行が減少する可能性
  • image_size の指定には大文字 "K" が必要 (例: "1K", "2K", "4K")。小文字はエラー
  • 512 解像度は Flash Image のみ (Pro Image は非対応)
💡 考慮すべき点:
  • 品質重視のユースケースでは明示的に thinkingLevel: "High" を指定
  • 思考トークンは includeThoughts の設定に関わらず課金対象
  • thought_signature フィールドをマルチターン会話で正しく返却する必要あり
