ビジュアルリフレッシュ

UI 刷新・音声概要の出力言語選択・Fast Research など 6 つの変更が GA に
📅 リリース日: 2026-10-30
☁️ Google Cloud Release Notes

📌 概要

Gemini Notebook Enterprise の UI と機能群を刷新する 「Visual refresh」アップデートが GA になりました。 Gemini Notebook Enterprise は、PDF、Google ドキュメント/スライド、Web サイト URL などのソースを「ノートブック」として集約し、 AI がソースにグラウンディングした回答・要約・コンテンツ生成を行うエンタープライズ向け AI リサーチ/ライティングツールです。 データは常に自社の Google Cloud プロジェクト内に保持され、VPC-SC、CMEK、データレジデンシーなどのコンプライアンス機能を備えています。

今回のアップデートでは、コンシューマー版/Google Workspace 版の Gemini Notebook と統一されたカラースキーム/スタイルへの UI 刷新に加え、 音声概要 (Audio overview) の出力言語選択、インフォグラフィックのスタイルプレビュー、要約カスタマイズ、高速リサーチ機能「Fast Research」など、 6 つの変更・新機能がまとめて GA になりました。

💡 ポイント: コンシューマー版 Gemini Notebook (NotebookLM) に慣れたユーザーがエンタープライズ版でも同じ操作感で利用できるようになるため、 組織内での利用定着を進めたい管理者や、多言語チームでノートブックを活用するユーザーに有益なアップデートです。

❌ Before (アップデート前の課題)

  • UI がコンシューマー版/Workspace 版の Gemini Notebook とデザインが異なり、両方を使うユーザーに操作感の差異があった
  • 音声概要の出力言語をノートブックの言語と別に選択する設定が UI になかった
  • インフォグラフィック生成時、ビジュアルスタイルの実際の見た目を事前確認せずに選択する必要があった
  • ノートブック要約は自動生成されたものを使う前提で、独自の要約に置き換える手段がなかった
  • Web からのソース探索は「Discover sources」機能と「I'm feeling curious」ボタンで提供されていた

✅ After (アップデート後の改善)

  • UI のカラースキームとスタイルがコンシューマー版/Workspace 版と統一され、一貫した利用体験に
  • 「Settings > Output language」から音声概要の出力言語を選択でき、ノートブックの言語と異なる言語で音声を生成可能に
  • インフォグラフィック作成時に、ビジュアルスタイルの例を事前確認してから選択可能に
  • 「More options > Customize notebook」から、自動生成要約を独自のカスタム要約に置き換え可能に
  • Web 上の情報探索は「Web」と「Fast Research」に置き換えられ、より高速なリサーチが可能に (Discover sources と I'm feeling curious は廃止)

🚀 主要機能 (6 つの変更・新機能)

🎨 1. UI デザインの刷新 (Refreshed UI design)

→カラースキームとスタイルが更新され、コンシューマー版および Google Workspace 版の Gemini Notebook とデザインが統一
→個人利用とエンタープライズ利用で一貫した操作体験を提供

🔊 2. 音声概要の出力言語選択 (Audio overview language selection)

→音声概要の出力言語を選択可能に。ノートブックの言語と異なる言語で音声出力を生成できる
→設定場所: 「Settings > Output language」

🖼️ 3. インフォグラフィックの更新 (Infographic update)

→インフォグラフィック生成前に、ビジュアルスタイルの例を確認してから選択できるように

📝 4. ノートブック要約のカスタマイズ (Customize the notebook summary)

→自動生成された要約を独自のカスタム要約に置き換え可能に
→操作: 「More options (その他のオプション) > Customize notebook」を選択

🔗 5. ノートブック共有の変更 (Sharing notebooks)

✕ノートブック共有時の通知で、ウェルカムノート (welcome note) を書くオプションが廃止

🔍 6. Web 上の Fast Research (Fast Research on the web)

→「Web」と「Fast Research」が従来の「Discover sources」を置き換え
✕「I'm feeling curious」ボタンは利用不可に

🔌 音声概要の API (参考)

音声概要は UI に加えて API (Preview) でも生成でき、languageCode パラメータで言語を指定できます。

Bash 音声概要の生成 (言語指定付き) 
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  "https://ENDPOINT_LOCATION-discoveryengine.googleapis.com/v1alpha/projects/PROJECT_NUMBER/locations/LOCATION/notebooks/NOTEBOOK_ID/audioOverviews" \
  -d '{
    "sourceIds": [{ "id": "SOURCE_ID" }],
    "episodeFocus": "EPISODE_FOCUS",
    "languageCode": "LANGUAGE_CODE"
  }'

👍 メリット

💼 ビジネス面

✓利用定着の促進: コンシューマー版 Gemini Notebook と統一された UI により、個人で使い慣れたユーザーがエンタープライズ版へスムーズに移行でき、社内教育コストを削減できる
✓多言語チームでの活用: 音声概要の出力言語を選択できるため、英語ドキュメントのノートブックから日本語の音声概要を生成するなど、グローバルチームでの情報共有が容易になる

🛠️ 技術面

✓成果物品質の事前確認: インフォグラフィックのビジュアルスタイル例を事前に確認できるため、生成のやり直しを減らせる
✓ナレッジの文脈付与: 自動生成要約をカスタム要約に置き換えられるため、ノートブックの目的や注意事項をチームに正確に伝えられる
✓リサーチの高速化: Web と Fast Research により、Web 上の情報ソース探索が従来の Discover sources より整理された形で利用できる

⚠️ デメリット・制約事項

🚧 制限事項

✕ノートブック共有の通知時にウェルカムノートを書くオプションが廃止されたため、共有時のメッセージ添付はできなくなった
✕「Discover sources」と「I'm feeling curious」ボタンは廃止され、従来のソース探索フローに依存していた場合は新しい「Web / Fast Research」への移行が必要
✕ノートブックの共有は同一 Google Cloud プロジェクト内のユーザーに限定され、パブリック共有はできない (従来からの仕様)

🤔 考慮すべき点

⚠️UI の刷新により画面の配色・スタイルが変わるため、社内マニュアルやトレーニング資料のスクリーンショット更新が必要になる場合がある
⚠️音声概要などの生成系機能には 1 日あたりの利用上限 (音声概要 20 回/ユーザー、インフォグラフィック 15 回/ユーザーなど) がある

💰 料金

今回のアップデート自体に伴う追加料金はありません。 Gemini Notebook Enterprise はサブスクリプション (ライセンス) ベースの課金で、スタンドアロン製品として、 または Gemini Enterprise (Standard / Plus) の一部として購入できます。

詳細は Gemini Enterprise の料金ページ および ライセンス設定ドキュメント を参照してください。
