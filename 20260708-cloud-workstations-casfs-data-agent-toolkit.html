🛠️ 設定方法

CASFS/ABFS の利用確認

最新のベースイメージを使用している場合、CASFS カーネルモジュールは自動的に利用可能です。

Bash 
# ワークステーション構成一覧を取得
gcloud workstations configs list \
  --cluster=CLUSTER_NAME \
  --region=REGION

# ワークステーション内で CASFS モジュールの存在を確認
lsmod | grep casfs

Data Agent Toolkit Extension の利用

Data Agent Toolkit Extension はデフォルトでインストール済みのため、ワークステーション起動後すぐに利用可能です。

⚠️ 制限事項・注意点

⚠️ 制限事項
✗Data Agent Toolkit は Preview ステータス - 本番環境での使用に注意
✗AlloyDB/Cloud SQL 接続は IAM 認証のみ対応 (Auth Proxy 非対応)
✗オーケストレーションパイプラインの自動デプロイは GitHub Actions のみ対応
✗CASFS/ABFS は Android ビルドシステムとの組み合わせが前提 (汎用 FS ではない)
💡 考慮すべき点
→Extension プリインストールによりコンテナイメージサイズがわずかに増加する可能性
→CASFS は自動ロードだが、Android ビルドツールの追加セットアップは別途必要
→Preview のため、Data Agent Toolkit の機能や API は今後変更される可能性あり
