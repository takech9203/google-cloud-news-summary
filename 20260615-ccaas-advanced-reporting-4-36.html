📊 CCaaS Advanced Reporting Dashboards v4.36

Google Cloud CCaaS Feature Release
2026-06-15

☁️ 概要

Google Cloud Contact Center as a Service (CCaaS) の Advanced Reporting Dashboards がバージョン 4.36 にアップデートされました。コンタクトセンターの管理者やスーパーバイザー向けに、キュー管理の柔軟性向上、リアルタイムメトリクスの拡充、CRM 連携強化、リピートコンタクト分析機能が追加されています。

🔄 Before / After 比較

❌ Before (v4.35 以前)

  • 子キュー含めたフィルタリング不可、手動集計が必要
  • リアルタイムのエージェント通話状態を確認不可
  • CSAT スコア確認に CRM へ別途ログインが必要
  • コールバック関連メトリクスや CSAT 平均値なし
  • インタラクションタイプ別フィルタなし
  • Repeat Contact % が 100% 超過するバグ

✅ After (v4.36)

  • Child Queues チェックボックスで一括フィルタリング
  • 通話中/待機中エージェント数をリアルタイム把握
  • CSAT ダッシュボードから直接 CRM へリンク
  • コールバック指標と CSAT 平均値が追加
  • Interaction Type フィルタで詳細分析可能
  • バグ修正でレポート精度・信頼性向上

🚀 主要機能

🔗 Child Queues フィルタ

Queue Name フィルタを持つ全ダッシュボードに「Child Queues」チェックボックスを追加。「Yes」選択で親キュー配下の全子キューを一括表示。Explore にも対応。

📡 リアルタイムメトリクス

Agent & Queue Status (Live) Explore に新指標を追加:

  • In Call: 通話中エージェント数
  • Available/Waiting: 待機中エージェント数
  • Contacts in Queue: キュー内コール数

🔗 CSAT CRM リンク

CSAT - Calls / Chats ダッシュボードの CSAT Interactions テーブルに CRM リンクを追加。Session ID から CRM 内の CSAT スコアに直接遷移可能。

📞 Queue Monitoring 新タイル

Real-time Queue Monitoring - Calls に追加:

  • Total Rolled Over Pending Callbacks
  • Total Rolled Over Completed Callbacks
  • Avg CSAT Calls

📈 Queue Performance 改善

Interaction Type フィルタ追加、Queue Detailed Table に Interaction Type カラム追加、Queue Summary Table に Total Repeat Contacts / Repeat Contact % カラム追加。

🐛 バグ修正 (6 件)

Repeat Contact % 100% 超過問題、Date フィルタ問題、言語ラベル欠落、Chat ID 誤表示、disposition code 欠落などを修正。

🐛 バグ修正詳細

🔧 Queue Performance - Calls の Queue Summary Table で Repeat Contact % が 100% を超える問題を修正
🔧 Explores で「is on or after」を絶対日付に設定した際に結果が返らない Date フィルタの問題を修正
🔧 Agent Availability ダッシュボードから Total Logged in Time メトリクスタイルを削除
🔧 Advanced Reporting ダッシュボードで言語ラベルが欠落する問題を修正
🔧 All Interactions - Chats ダッシュボードで Chat ID フィルタ使用時に Virtual Agent Chats テーブルに誤った Chat ID が表示される問題を修正
🔧 Call Agent Metrics (Historical) ダッシュボードでアウトバウンドコールの disposition code が欠落/空白になる問題を修正

💡 ユースケース

🏢 ユースケース 1: 階層的キュー構造の一括パフォーマンス分析

シナリオ: 大規模コンタクトセンターで製品カテゴリごとに親キュー配下に複数の子キュー (言語別、スキル別) を設定している場合

効果: Child Queues フィルタを「Yes」に設定することで、親キュー配下の全子キューのデータを集約して表示。組織全体のパフォーマンスを素早く把握可能。

⚡ ユースケース 2: リアルタイムでのリソース再配分判断

シナリオ: ピーク時間帯にキュー待ち時間が増加、スーパーバイザーがエージェント再配分を判断する必要がある場合

効果: Agent & Queue Status (Live) の新メトリクス (In Call / Available / Contacts in Queue) により、即座にルーティング変更やエージェント再配分の判断が可能。

🔍 ユースケース 3: 低 CSAT スコアの迅速な原因調査

シナリオ: CSAT スコアが低下しているキューを発見、具体的なインタラクション詳細を CRM で確認したい場合

効果: CSAT ダッシュボードの Session ID リンクから直接 CRM の該当セッションにジャンプ。従来の CRM 検索操作が不要になり調査時間を大幅短縮。

🔄 ユースケース 4: リピートコンタクト率の改善

シナリオ: 初回解決率 (FCR) を改善するため、リピートコンタクトが多いキューを特定し原因分析を行いたい場合

効果: Queue Summary Table の Total Repeat Contacts / Repeat Contact % でリピートが多いキューを特定。Interaction Type フィルタと組み合わせて改善施策を立案。

✅ メリット

ビジネス面

  • 運用可視性向上: リアルタイムメトリクスで迅速な意思決定
  • 顧客満足度管理効率化: CRM 直接リンクで調査時間短縮
  • リピートコンタクト分析: FCR 改善のデータドリブン施策
  • 階層的キュー管理: 組織構造に沿った分析

技術面

  • リアルタイム監視強化: 60 秒間隔の包括的キュー監視
  • データ精度向上: バグ修正でレポート信頼性向上
  • フィルタリング柔軟性: より精密なデータ分析が可能

⚠️ 制限事項・注意点

  • Advanced Reporting は 7 リージョンのみで利用可能
  • 有効化するとレガシーダッシュボードは利用不可になる
  • 日付フィルタの最大期間は 45 日間
  • Agent ロールのユーザーはダッシュボードにアクセス不可
  • CSAT CRM リンクには CRM 側の CSAT 投稿設定が必要
  • リアルタイムダッシュボードは 60 秒間隔 (完全なリアルタイムではない)
  • 有効化/無効化時にカスタムロールの権限設定に影響の可能性あり
