🎬 Gemini Omni Flash がステートフル・ストリーミング動画生成に対応

Interactions API で store: true / stream: true の動画生成が Preview 提供開始
📅 リリース日: 2026-09-17

📌 概要

Gemini Enterprise Agent Platform の動画生成モデル Gemini Omni Flash が、Interactions API における ステートフル (store: true) および SSE ストリーミング (stream: true) の動画生成に Preview 対応しました。生成した動画とインタラクション状態をサーバー側に一時保存し、ステータス更新や最終出力を SSE 接続経由でストリーミング受信できるほか、完了した非同期インタラクションを unary またはストリーミングの GET リクエストで取得できます。

動画生成は完了までに 1 分以上かかることがあるため、ワークフローに応じたインタラクションモードの選択が重要です。 「同期・ステートフル」「同期・ステートフルストリーミング」「非同期 (background)」を組み合わせられるようになり、 動画生成アプリケーションの応答性と柔軟性が大きく向上します。

🎯 対象ユーザー: Gemini Omni Flash を使った会話型の動画生成・編集アプリケーションを構築する開発者、 長時間の生成処理をバックエンドで扱う AI アプリケーション開発者

❌ Before: アップデート前の課題

✗動画生成は完了まで 1 分以上かかることがあり、クライアントは単一のリクエストで応答を待ち続ける必要があった
✗生成の進行状況 (モデルの思考過程やステータス) をリアルタイムに把握する手段が限られていた
✗インタラクション状態がサーバーに保存されず、結果の後取得やインタラクション ID を参照した継続処理が難しかった

✅ After: アップデート後の改善

✓store: true で動画と状態をサーバー側に一時保存 (最大 7 日間)。後からの結果取得やインタラクション ID を参照したマルチターン動画編集が可能に
✓stream: true で SSE 接続によりモデルの思考 (thought) を逐次受信し、その後に出力動画を受信。体感レイテンシと進捗の可視性が改善
✓完了した非同期インタラクション (background: true) を unary GET またはストリーミング GET (?stream=true) で柔軟に取得可能に

⚡ 主要機能

🗄️ 1. ステートフル動画生成 (store: true)

→生成された動画とインタラクション状態をサーバー側に一時保存
→保存されたインタラクションと非同期インタラクションは最大 7 日間保持
→インタラクション ID (previous_interaction_id) を参照して、マルチターンの動画編集に活用可能

📡 2. SSE ストリーミング動画生成 (stream: true)

→store と stream の両方を true にすると、モデルの思考 (thought summary) を逐次受信し、その後に出力動画が届く
→イベントシーケンス: interaction.created → interaction.status_update → step.start / step.delta / step.stop → interaction.completed → done
→step.delta イベントには思考テキストのほか、出力動画の mime_type と URI (Cloud Storage 出力時) が含まれる

🔄 3. 非同期インタラクションの柔軟な取得

→background: true でバックグラウンド実行した動画生成を、後からインタラクション ID で取得
→unary GET リクエストのほか、?stream=true を付与したストリーミング GET で保存済みインタラクションと生成動画をストリーミング取得可能

ステップ 1: ステートフルストリーミングで動画生成をリクエスト

Bash 動画生成リクエスト (SSE ストリーミング) 
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d @request.json \
  "https://aiplatform.googleapis.com/v1beta1/projects/PROJECT_ID/locations/global/interactions"

store: true と stream: true を含む request.json を送信すると、SSE イベント (interaction.created、step.delta、interaction.completed など) が順次返されます。

ステップ 2: 保存済みインタラクションを後から取得

Bash ストリーミング GET で保存済みインタラクションと動画を取得 
# ストリーミング GET で保存済みインタラクションと動画を取得
curl -X GET \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  "https://aiplatform.googleapis.com/v1beta1/projects/PROJECT_ID/locations/global/interactions/INTERACTION_ID?stream=true"

レスポンスに含まれるインタラクション ID を使い、unary またはストリーミングの GET リクエストで完了済みインタラクションを取得できます。
