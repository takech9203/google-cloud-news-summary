📋 概要

BigQuery の Conversational Analytics (会話型分析) に 2 つの重要なアップデートが追加されました。

🤖 AI.AGG 関数 (Preview)
Vertex AI の Gemini モデルを活用して、自然言語の指示に基づくデータ集約を行う関数。テキストや画像データを処理して単一の文字列結果を返す。「レビューを要約して」「最も多い話題は何か」といった集約型の質問に対し、最適な SQL を自動生成。
🏥 HIPAA コンプライアンス対応 (GA)
電子保護対象健康情報 (ePHI) を含むデータセットに対しても、BigQuery の会話型分析機能を適切な構成の下で利用可能に。医療機関やヘルスケア企業がデータ分析の民主化を進める際の規制面での障壁が解消。

🔄 Before / After 比較

❌ Before (アップデート前)

  • 集約型の質問には AI.GENERATE 等の汎用関数で手動バッチ処理が必要
  • Gemini コンテキストウィンドウ超過時は複雑なマルチレベルバッチ処理が必要
  • HIPAA 対象ワークロードでは会話型分析が利用不可
  • ヘルスケアアナリストには SQL 専門知識が必須

✅ After (アップデート後)

  • AI.AGG 関数で集約型質問に最適化された SQL を自動生成
  • マルチレベル集約が自動実行され大規模データも対応
  • BAA の下で ePHI データへの会話型分析が利用可能
  • SQL 知識なしにデータインサイトを取得可能

💻 SQL コードサンプル

SQL レビューの感情分析と要約 
-- レビューの感情分析と要約
SELECT
  product_category,
  AI.AGG(
    review_text,
    'Summarize the overall sentiment and common themes in these reviews.'
  ) AS review_summary
FROM `project.dataset.product_reviews`
GROUP BY product_category;
SQL Conversational Analytics エージェント経由の利用例 
-- ユーザーが「各著者の記事トピックを要約して」と質問すると
-- エージェントが以下のような SQL を自動生成:
SELECT
  t.by,
  AI.AGG(
    t.text,
    'Tell me what topics the user talks about the most. Keep it concise.'
  ) AS common_topic
FROM `bigquery-public-data.hacker_news.full` AS t
WHERE t.text IS NOT NULL AND t.type = 'story'
GROUP BY t.by;

🔧 設定方法

前提条件

1.Google Cloud プロジェクトで BigQuery API、Vertex AI API、Gemini Data Analytics API を有効化
2.適切な IAM ロールの付与 (bigquery.user、geminidataanalytics.dataAgentCreator)
3.HIPAA ワークロードの場合: Google Cloud との BAA 締結
4.Cloud リソース接続の作成 (エンドユーザー認証を使用しない場合)

Step 1: API の有効化

Bash API 有効化コマンド 
gcloud services enable bigquery.googleapis.com --project=PROJECT_ID
gcloud services enable aiplatform.googleapis.com --project=PROJECT_ID
gcloud services enable geminidataanalytics.googleapis.com --project=PROJECT_ID
gcloud services enable cloudaicompanion.googleapis.com --project=PROJECT_ID

Step 2: データエージェントの作成

BigQuery Studio のエージェントカタログからデータエージェントを作成し、対象テーブルをナレッジソースとして追加する。

Step 3: AI.AGG を活用した会話の開始

💡 質問例:
  • 「このデータの主要トレンドを要約して」
  • 「レビューの全体的な感情を分析して」
  • 「ユーザーが最も議論しているトピックは何か」

Step 4: HIPAA 対応の構成 (医療ワークロードの場合)

Bash VPC Service Controls の設定 
# VPC Service Controls の設定 (推奨)
gcloud access-context-manager perimeters create PERIMETER_NAME \
    --resources="projects/PROJECT_NUMBER" \
    --restricted-services="bigquery.googleapis.com" \
    --title="BigQuery HIPAA Perimeter"

US または EU の Multi-Region Processing (MREP) ロケーションを使用し、データレジデンシー要件を満たす構成にする。

⚠️ デメリット・制約事項

制限事項

  • AI.AGG 関数は Preview ステータス - 本番環境利用には注意 (Pre-GA サービス利用規約適用)
  • クエリあたり推奨最大 2,000 万行、1,000 グループ超過でタイムアウトの可能性
  • 出力はグループあたり 10,000 トークンに制限
  • 1 行あたり 10 MiB を超えるデータはエラーの可能性
  • 10 以上の画像を含む単一入力行はスキップされる場合あり
  • Thinking Budget を必要とする Gemini モデルは使用不可

考慮すべき点

  • バッチ処理により、ソースデータのトークン数より多くのトークンが Gemini に送信 - コスト増加の可能性
  • HIPAA 対応には BAA の締結が前提 - 技術的設定だけでは不十分
  • Assured Workloads パッケージには含まれない (FedRAMP High 等には非対応)
  • Preview 期間中のサポートは bqml-feedback@google.com への連絡が必要
  • Workforce Identity Federation 使用時に長時間クエリが失敗する場合あり

💡 ユースケース

🏥 ユースケース 1: 医療機関における患者フィードバック分析

シナリオ: 病院の品質改善チームが、患者満足度調査の自由記述回答を分析し、部門別の改善ポイントを特定

SQL 患者フィードバック分析 
-- データエージェントへの質問:
-- 「各部門の患者フィードバックを要約し、改善すべき点を教えて」
SELECT
  department,
  AI.AGG(
    feedback_text,
    'Summarize patient feedback sentiment and identify top improvement areas.'
  ) AS feedback_summary
FROM `hospital_data.patient_surveys`
WHERE survey_date >= '2026-01-01'
GROUP BY department;

効果: HIPAA 準拠環境で ePHI を含むフィードバックデータを安全に分析し、SQL を書かずに部門別インサイトを取得

🛒 ユースケース 2: EC サイトのレビュー傾向分析

シナリオ: マーケティングチームが製品カテゴリごとのレビュー傾向を把握し、顧客が最も重視する製品特性を特定

SQL EC レビュー傾向分析 
-- データエージェントへの質問:
-- 「各製品カテゴリで顧客が最も議論しているポイントは何か」
SELECT
  category,
  AI.AGG(
    STRUCT(review_title, review_body),
    'What are the top 3 aspects customers discuss most? Are they positive or negative?'
  ) AS review_insights
FROM `ecommerce.product_reviews`
GROUP BY category;

効果: 数十万件のレビューを自動バッチ処理・集約し、カテゴリ別インサイトを一文で取得

🖼️ ユースケース 3: マルチモーダルデータの分類・要約

シナリオ: 小売企業が Cloud Storage の商品画像を分析し、カテゴリ分類の精度を検証

SQL 商品画像の分類分析 
-- データエージェントへの質問:
-- 「商品画像の主要カテゴリを分析して」
SELECT
  AI.AGG(
    STRUCT(OBJ.GET_ACCESS_URL(ref, 'r')),
    'What are the major categories of these product images?'

効果: テキストだけでなく画像データも含めたマルチモーダルな集約分析を自然言語一つで実行
