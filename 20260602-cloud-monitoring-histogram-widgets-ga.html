カスタムダッシュボード機能拡張

☁️ 概要

Cloud Monitoring のカスタムダッシュボードにおける Histogram ウィジェット が一般提供 (GA) として発表されました。複数の時系列データの最新値を範囲 (ビン) にグループ化し、値の相対的な頻度分布をグラフィカルに表現できます。

SRE チーム、インフラ管理者、アプリケーション開発者にとって、インフラストラクチャやアプリケーションのパフォーマンス分布を一目で理解し、異常値やパターンの特定が容易になります。

❌ Before (これまで)

  • テーブル、ゲージ、スコアカードのみで分布把握が困難
  • 値の集中範囲を確認するには外部ツールが必要
  • プレビュー段階で SLA 適用なし

✅ After (今回のアップデート)

  • GA で SLA 対象、本番環境で安心利用
  • 頻度分布をダッシュボード上で直接可視化
  • ビンサイズ・軸範囲の詳細カスタマイズ対応
  • API によるプログラマティック構成に対応

⚡ 主要機能

📊 分布可視化

各時系列から最新値を抽出し、ビンにグループ化。X軸がビン (値の範囲)、Y軸がカウント (時系列数) を表示し、相対頻度分布を直感的に把握可能。

🎛️ 柔軟なビン設定

ビン数指定 (Count: 推奨 5-50、最大 1000) またはビンサイズ指定 (Size) を選択可能。デフォルトではデータに基づき自動決定。

📐 軸のカスタマイズ

X軸の最小値・最大値を指定可能。Y軸スケーリングは Linear (線形) または Logarithmic (対数) を選択可能。

🔌 API による構成

Cloud Monitoring API の XyChart 構造を使用。plotType を STACKED_BAR に設定し、dimensions で metric_value を指定して構成。

🔧 技術仕様

項目 詳細
ウィジェットタイプ XyChart (Histogram モード)

💻 API 構成サンプル

Cloud Monitoring API を使用した Histogram ウィジェットの構成例:

JSON Histogram Dashboard API 構成 
{
  "displayName": "Histogram Dashboard Example",
  "mosaicLayout": {
    "columns": 48,
    "tiles": [{
      "height": 16,
      "width": 24,
      "widget": {
        "title": "VM Instance - CPU utilization [MEAN]",
        "xyChart": {
          "dataSets": [{
            "dimensions": [{ "column": "metric_value" }],
            "minAlignmentPeriod": "60s",
            "plotType": "STACKED_BAR",
            "targetAxis": "Y1",
            "timeSeriesQuery": {
              "timeSeriesFilter": {
                "filter": "metric.type=\"compute.googleapis.com/instance/cpu/utilization\" resource.type=\"gce_instance\"",
                "aggregation": {
                  "alignmentPeriod": "60s",
                  "perSeriesAligner": "ALIGN_MEAN"
                }
              }
            }
          }],
          "yAxis": { "scale": "LINEAR" }
        }
      }
    }]
  }
}

ビンサイズ詳細制御

JSON ビン範囲・サイズの指定 
{
  "dimensions": [{
    "column": "metric_value",
    "xMin": 0,
    "xMax": 1.0,
    "maxBinCount": 20
  }]
}

🚀 設定方法

📋 前提条件: Cloud Monitoring が有効 / roles/monitoring.editor ロール / カスタムダッシュボード作成権限
  1. Google Cloud コンソールの Monitoring > Dashboards からカスタムダッシュボードを開き、編集モードにする
  2. 「Add widget」をクリックし、ウィジェットタイプから「Histogram」を選択
  3. 表示したいメトリクスタイプを選択（デフォルトのビン設定で Histogram が表示される）
  4. ビン設定のカスタマイズ: Count (ビン数) / Size (ビンサイズ) / X-axis range / Y-axis scale を必要に応じて設定
  5. 「Apply」をクリックしてウィジェット変更を適用し、「Save」でダッシュボードを保存

CLI を使用した代替方法

Bash gcloud CLI でダッシュボード作成 
# JSON 設定ファイルからダッシュボードを作成
gcloud monitoring dashboards create --config-from-file=dashboard.json

🎯 ユースケース

🖥️ VM インスタンスの CPU 使用率分布分析

100 台以上の VM の CPU 使用率分布を把握し、リソース最適化を実施。大半が低使用率に集中していればオーバープロビジョニング、右側に偏っていればスケールアップの必要性を示し、コスト最適化やキャパシティプランニングに直接活用。

⏱️ API レスポンスタイムの分布分析

マイクロサービスのレスポンスタイム分布を監視し、レイテンシ異常を検出。バイモーダル分布 (2 つのピーク) が見られる場合、特定条件下でのパフォーマンス劣化を示唆し、根本原因の調査ポイントを特定。

💾 ディスク I/O パフォーマンスの監視

データベースクラスタの各ノードにおけるディスク書き込みバイト数の分布を監視。特定ノードだけが極端に高い I/O を示している場合を即座に視覚化でき、データの偏りやパーティション設計の問題を早期発見。

✅ メリット

💼 ビジネス面

運用効率向上: 異常の早期検出と対応時間短縮
意思決定の迅速化: リソース利用状況を視覚的に把握
GA の信頼性: SLA 適用で本番環境に安心利用

🔬 技術面

分布パターンの直感的理解: 平均値やパーセンタイルだけでは見えないパターンを可視化
IaC 連携: API 互換で Terraform 等と連携容易
既存ダッシュボード統合: 他ウィジェットと同一画面に配置可能

⚠️ 制限事項・注意点

  • ダッシュボードあたり最大ウィジェット数: 100 個
  • ビン数の最大値: 1000 (推奨 5-50)
  • 最新値のみ表示 -- 時系列の推移は表示不可 (Line Chart を使用)
  • Distribution 型の値をそのまま表示する場合は Heatmap が適切
  • 時系列数が少ない場合 (5 未満) はテーブルやスコアカードの方が適切な場合がある
  • ビン設定が不適切だと分布の特徴を見逃す可能性あり

💰 料金情報

Histogram ウィジェット自体の利用に追加料金なし。料金はメトリクスのデータ取り込み量に基づきます。

項目 料金
Google Cloud 非課金メトリクス 無料
カスタムダッシュボード作成・利用 無料
Histogram ウィジェット利用 無料
API 読み取り呼び出し 最初の 100 万時系列/請求アカウント/月は無料
カスタムメトリクス 課金対象 (料金ページ参照)

🌍 利用可能リージョン

🌐 グローバル対応: Cloud Monitoring はグローバルサービスとして提供されており、Histogram ウィジェットを含むカスタムダッシュボード機能はすべてのリージョンで利用可能です。モニタリング対象のリソースがどのリージョンに配置されていても、Histogram ウィジェットでデータを可視化できます。
