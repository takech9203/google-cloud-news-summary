Gemini Enterprise 提供開始 (Feature)
📅 リリース日: 2026-08-20

🚀 Antigravity for IDEs が
AI developer tools で利用可能に

VS Code / JetBrains / Visual Studio / Zed に自律型 AI エージェントを拡張機能で組み込み、エンタープライズガバナンス下で利用

📋 概要

Gemini Enterprise の AI developer tools に Antigravity for IDEs が追加されました。 Google の自律型 AI エージェントプラットフォーム Antigravity のエージェント機能を、開発者が普段使う IDE に 拡張機能として直接組み込めるようになります。

対象は Gemini Enterprise の Standard / Plus / Pay-as-you-go エディションで、 月次請求書 (invoice) が発行される Cloud Billing アカウントにリンクされたプロジェクトで利用できます。 サイドパネルでのエージェント対話、インライン差分レビュー、インタラクティブなプラン確認を、 Gemini Enterprise のガバナンス (IAM・モデル認可・コスト管理) のもとで利用可能です。

😣 Before: アップデート前の課題

  • Antigravity のエージェント機能を使うには専用環境 (Google Antigravity) か CLI が必要で、既存 IDE 中心のワークフローとの統合が限定的だった
  • VS Code や JetBrains を標準とする開発者は、エージェント利用のために環境を切り替える必要があった

😊 After: アップデート後の改善

  • 使い慣れた IDE に拡張機能を追加するだけで、自律型 AI エージェント (マルチステップ実行・コード編集・レビュー支援) を直接利用可能
  • 「Sign in with Gemini Enterprise」で企業 ID (BYOID / Workforce Identity Federation) によるサインインとプロジェクト・リージョン選択が可能
  • 管理者は認可モデル制御・ファイルアクセスポリシー・IAM ロール・支出上限を IDE 利用時にも適用できる
🎯 対象ユーザー: Gemini Enterprise 導入組織のソフトウェア開発チームと、エンタープライズのセキュリティ・コンプライアンス要件下で AI コーディングエージェントを展開したいプラットフォーム管理者。

開発者は既存 IDE 内の Antigravity 拡張機能から Gemini Enterprise にサインインし、エディションに紐づくクレジットと 管理者が設定したポリシー (IAM ロール、認可モデル、支出上限) のもとで AI エージェントを利用します。

⚡ 主要機能

🤖 1. IDE 内での自律型 AI エージェント

→専用サイドパネルでエージェントと対話し、マルチステップのタスク (機能実装、リファクタリング、API 移行、テスト生成など) を委任
→インライン差分レビュー、インタラクティブなプラン、ウォークスルーやスクリーンショットなどのアーティファクトで変更を検証
→Tab 補完、MCP、スキル、ルール、ワークフロー、プラグイン、フックなどのカスタマイズに対応

🖥️ 2. 対応 IDE

💻 Visual Studio Code

VS Code Marketplace の拡張機能 (macOS / Linux / Windows)

🟣 Visual Studio 2026 Preview

VSIX 拡張機能、.NET ソリューション向け

🧩 JetBrains Preview

IntelliJ IDEA、PyCharm、WebStorm、GoLand、CLion、Rider など (Enterprise サポートは Preview)

⚡ Zed Preview

ネイティブのエージェント編集 (Enterprise サポートは Preview)

🔐 3. エンタープライズ向けの認証とガバナンス

→「Sign in with Gemini Enterprise」で企業 ID (BYOID / Workforce Identity Federation) によるサインイン
→コード・プロンプト・エージェントのトランスクリプトは Google の基盤モデルの学習に使用されない
→IAM ポリシー、VPC Service Controls、リージョン境界を尊重した動作

Antigravity for IDEs New既存の IDE に自律型 AI エージェント機能を組み込む拡張機能

🔧 技術仕様: 利用要件

項目詳細
対象エディションGemini Enterprise Standard / Plus / Pay-as-you-go
請求要件月次請求書が発行される invoiced Cloud Billing アカウントへのリンクが必須
必要ロールGemini Enterprise Admin (roles/discoveryengine.agentspaceAdmin) または Gemini Enterprise User (roles/discoveryengine.agentspaceUser)
利用可能モデルGoogle 製モデルのみ (管理者が「Antigravity authorized models」設定で認可モデルを制御可能)
リージョンデータレジデンシーの制限はロケーションドキュメントを参照

🛠️ 設定方法

✅ 前提条件

✓Gemini Enterprise Standard / Plus / Pay-as-you-go のサブスクリプションを保有していること
✓プロジェクトが invoiced Cloud Billing アカウントにリンクされ、月次請求書が発行されていること
✓利用者に Gemini Enterprise Admin または Gemini Enterprise User ロールが付与されていること

📝 導入 3 ステップ

STEP 1⚙️ 管理者が AI developer tools を有効化・設定
→
STEP 2🧩 IDE に Antigravity 拡張機能をインストール
→
STEP 3🔑 Gemini Enterprise でサインイン

⚙️ ステップ 1: 管理者が AI developer tools を有効化・設定する

Gemini Enterprise の設定で AI developer tools を有効化し、認可モデルやファイルアクセスポリシーを構成します。初回設定時、作業フォルダ外のファイルアクセスポリシーはデフォルトで「Deny」になるため、確認を挟みたい場合は明示的に「Always ask」へ変更します。

🧩 ステップ 2: IDE に Antigravity 拡張機能をインストールする

各 IDE のマーケットプレイス (VS Code Marketplace、JetBrains ワンクリックインストール、Visual Studio VSIX、Zed) から Antigravity 拡張機能をインストールします。

🔑 ステップ 3: Gemini Enterprise でサインインする

IDE のアクティビティバーで Antigravity アイコンを選択し、「Sign in with Gemini Enterprise」から企業 ID でサインインします。その後、Google Cloud プロジェクトとリージョンを選択すると、エディションのクレジット・クォータ・ポリシーが適用されます。

⚖️ メリットと制約事項

👍 メリット

💼 ビジネス面
✓ツール切り替えコストの削減: 既存 IDE を変更せずエージェント型 AI 開発を導入でき、組織のツール標準化を維持したまま展開
✓統制されたコスト管理: エディションのクレジット範囲で利用でき、超過分は Overages 設定と月次支出上限で制御
🔧 技術面
✓ガバナンスの一貫適用: IAM ロール、認可モデル制御、VPC Service Controls、データレジデンシー境界が IDE 内でも有効
✓データ保護: コード・プロンプト・トランスクリプトが基盤モデルの学習に使用されない
✓統一された認証: IDE 拡張機能、CLI、デスクトップアプリで認証が統一され、モデル利用資格・クォータ・プライバシーポリシーが一元管理

⚠️ 制約・考慮点

🚧 制限事項
✗invoiced Cloud Billing アカウントが必須 (セルフサーブアカウント不可)
✗JetBrains と Zed の Enterprise サポートは Preview 段階
✗Access Transparency、FedRAMP (Moderate/High)、IL4/IL5、ISO 27001/42001、ITAR、SOC 1/2/3 などのコンプライアンス認証に未対応
✗利用できるのは Google 製モデルのみ
💡 考慮すべき点
  • 必要な API を有効化する前にサブスクリプションを購入すると失敗する場合がある (API 有効化後、約 5 分待ってから購入)
  • バックグラウンドタスクに Gemini Flash Lite、画像生成に Gemini 3 Pro Image を使用するため、これらのモデル利用が課金対象になり得る
  • 認可モデル設定と Agent Platform の組織ポリシーが不一致だと、クォータ超過分の Pay-as-you-go リクエストが失敗する可能性

💡 ユースケース

🏢 ユースケース 1: 既存 IDE 標準を維持したままの全社 AI エージェント展開

シナリオ: JetBrains IDE を標準としている開発組織が、開発環境を変えずに自律型 AI エージェントを導入したい。

✨ 効果: Antigravity 拡張機能を配布し、Gemini Enterprise サインインを利用することで、既存ワークフローを保ったまま、IAM とモデル認可ポリシーに準拠した形でエージェント型開発を展開できる。

🤝 ユースケース 2: エージェントへのマルチステップタスクの委任

シナリオ: レガシーモジュールのリファクタリングやテストスイートの生成といった複数ステップの作業を、IDE 内でエージェントに委任したい。

✨ 効果: エージェントがプランを提示し、インライン差分で変更をレビューしながら進められるため、大規模な変更でも人間の確認を挟みつつ効率的に完了できる。

💰 料金

Antigravity for IDEs は Gemini Enterprise Standard / Plus / Pay-as-you-go エディションの AI developer tools に含まれます。

→Standard / Plus: Antigravity、Antigravity for IDEs、Android Studio 向けの月次クレジット (ドル建て) が含まれ、クォータ超過分は Overages を有効化した場合に Agent Platform の料金レートで課金
→Pay-as-you-go: 利用量に応じた従量課金
🛡️ コスト保護: 意図しない課金を防ぐため、Cloud Billing の予算機能でプロジェクト単位の月次支出上限を設定でき、上限到達時には超過利用が自動停止されます。

🎯 まとめ

Antigravity for IDEs の追加により、Gemini Enterprise 契約組織は開発者の使い慣れた IDE をそのままに、 エンタープライズガバナンス下で自律型 AI エージェントを展開できるようになりました。 すでに Standard / Plus / Pay-as-you-go エディションを invoiced アカウントで利用している組織は、 AI developer tools の設定 (認可モデル、ファイルアクセスポリシー、支出上限) を確認したうえで、 対象 IDE への拡張機能導入を検討することを推奨します。
