# Google Cloud News Summary v0.3.0

*Released: 2026-03-07*

---

## English

### 🚀 What's New

This release adds a configurable lookback period (`--days`), simplifies agent prompts with extracted tool lists, and improves stability with an SDK race condition workaround.

### 📝 Changes

#### Added
- ✨ Configurable `--days` parameter for the news lookback period
- 🛠️ Extracted tool lists and simplified agent prompts to use the Skill tool
- 🛡️ Workaround for the Claude Agent SDK race condition (Issue #584)

#### Changed
- 📝 Translated `run.py` comments and docstrings to Japanese

#### Fixed
- 🐛 Use `secrets` instead of `vars` for `AWS_ROLE_ARN` in CI configuration

---
