# Google Cloud News Summary v0.1.0

*Released: 2026-02-15*

---

## English

### 🚀 What's New

Initial release of Google Cloud News Summary — a Claude Agent SDK skill that collects Google Cloud news and generates detailed Japanese reports, featuring a subagent architecture for parallel report generation.

### ✨ Features

- **Report Generation Skill**: Collects Google Cloud news and generates detailed Japanese reports with the Claude Agent SDK
- **Subagent Architecture**: Parallel report generation via subagents with documentation
- **OIDC Authentication Guide**: Comprehensive SETUP.md for CI/CD authentication
- **Scheduled Runs**: Daily runs at 05:00 JST

### 📝 Changes

#### Added
- ✨ Initial project setup (skill definition, orchestrator, parsers, CI/CD)
- ✨ Subagent architecture documentation and implementation
- 📝 Comprehensive OIDC authentication guide in SETUP.md

#### Changed
- 🔄 Made GitHub repository parameter optional in IAM deployment script
- ⏰ Adjusted schedule to 05:00 JST

#### Fixed
- 🛡️ Removed exposed API key from MCP configuration
- 🐛 Reset `.mcp.json` before git rebase in CI to avoid conflicts

## 日本語

### 🚀 新機能

Google Cloud News Summary の初期リリースです。Google Cloud のニュースを収集し、日本語の詳細レポートを生成する Claude Agent SDK スキルです。サブエージェントアーキテクチャによる並列レポート生成を備えています。

### ✨ 機能

- **レポート生成スキル**: Claude Agent SDK で Google Cloud のニュースを収集し、日本語の詳細レポートを生成
- **サブエージェントアーキテクチャ**: サブエージェントによる並列レポート生成とドキュメント
- **OIDC 認証ガイド**: CI/CD 認証のための包括的な SETUP.md
- **スケジュール実行**: 毎日 05:00 JST に実行

### 📝 変更内容

#### 追加
- ✨ プロジェクト初期セットアップ (スキル定義、オーケストレーター、パーサー、CI/CD)
- ✨ サブエージェントアーキテクチャのドキュメントと実装
- 📝 SETUP.md に包括的な OIDC 認証ガイドを追加

#### 変更
- 🔄 IAM デプロイスクリプトの GitHub リポジトリパラメータをオプション化
- ⏰ スケジュールを 05:00 JST に調整

#### 修正
- 🛡️ MCP 設定から露出していた API キーを削除
