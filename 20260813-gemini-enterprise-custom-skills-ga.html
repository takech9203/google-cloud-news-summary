☁️ Gemini Enterprise ✅ GA (一般提供)

🧩 カスタムスキルの作成・アップロード・共有が GA に

📅 リリース日: 2026-08-13

📋 概要

Gemini Enterprise で、エンドユーザーがカスタムスキルを作成・アップロード・共有できる機能が一般提供 (GA) になりました。 スキルとは、アシスタントに特定のタスクを実行させるための「再利用可能なカスタム指示」です。 契約書のレビューやブランドボイスに沿った文章作成など、ドメイン固有の反復タスクをスキル化して組織内で再利用できます。

スキルは agentskills.io が管理するオープン標準に準拠し、skill.md というプロンプトファイルを中核とするパッケージ形式です。 スクリプト (Python / Bash)、参照ファイル、背景コンテキストを同梱でき、アシスタントは質問やタスクに関連するスキルを自動的に呼び出します。

😣 Before: アップデート前の課題

  • 「GA with allowlist」のため、アカウントマネージャーへの連絡と許可リスト登録が必要だった
  • Feature Management に「Enable skills」トグルがなく、管理者がセルフサービスで有効化できない期間があった
  • ドメイン固有タスクは肥大化したシステムプロンプトや Agent Designer での個別エージェント作成に頼る必要があった

😊 After: アップデート後の改善

  • 許可リスト不要の GA に。管理者のトグル操作だけでスキル機能と共有機能を有効化できる
  • エンドユーザーが Web アプリで自然言語 / Markdown 編集によりスキルを作成、Markdown / ZIP のインポートや共有が可能に
  • 共有リクエストの承認フロー、一時停止・無効化・削除といったエンタープライズ向けガバナンスが利用可能に

管理者が Feature Management でスキル機能を有効化すると、エンドユーザーはスキルの作成・インポート・共有が可能になり、アシスタントは会話の中で関連スキルを自動または手動で呼び出します。共有には管理者の承認フローを挟むことができます。

⚡ 主要機能

📝 1. スキルの作成 (エンドユーザー)

→Web アプリの「Skills」→「+ New skill」で作成
→スキル名 (組織内で一意)・説明・指示を設定。説明にトリガー指示を含めるとアシスタントの使用判断に利用される
→チャットボックスでの自然言語入力、または Markdown の直接編集で指示を記述可能

📦 2. スキルのインポート (アップロード)

→既存スキルを Markdown または ZIP ファイルとしてインポート可能
→ZIP には skill.md (ルートに必須) に加え、Python / Bash コードを含む scripts/ ディレクトリを同梱可能
→名前・説明・指示はアップロードファイルから自動抽出

🔗 3. スキルの共有と管理者承認フロー

→作成したスキルを他のユーザーと共有可能
→「Enable skill sharing without admin approval」が無効の場合、共有リクエストは管理者の承認 (Approve) / 却下 (Deny) を経て反映

🛡️ 4. 管理者によるガバナンス

→Feature Management の 3 つのトグルで機能の開放範囲を制御
→ユーザー作成スキルの一覧表示、一時停止 (Suspended)・無効化 (Disabled)・却下 (Private に戻す)・削除が可能

🎁 6. Google 提供のデフォルトスキル

→Brand Voice (ブランドガイドライン準拠)、Contract Creation (契約書ドラフト作成)、Contract Review (契約書レビュー)、Customer Briefing (顧客ブリーフィング)、Project Updates (プロジェクト状況の集約)
→Google 管理スキルは直接編集不可だが、「Duplicate to edit」で複製して編集可能

⚙️ Feature Management のトグル

トグル説明
Enable skillsユーザーによるスキルの作成・使用を許可
Enable skill sharingユーザーによるスキル共有を許可 (Enable skills が前提)。承認なし共有を有効にしない限り、管理者が共有リクエストを承認する必要がある
Enable skill sharing without admin approval管理者承認なしでの即時共有・利用を許可 (上記 2 つのトグルが前提)

🛠️ 設定方法

📌 前提条件:
  • Gemini Enterprise の Standard / Plus / Pay-as-you-go / Frontline のいずれかのエディションのライセンス
  • 管理操作には Gemini Enterprise Admin IAM ロール (roles/discoveryengine.agentspaceAdmin) が必要

  1. 管理者がスキル機能を有効化

    Google Cloud コンソールの「Gemini Enterprise」ページ → 対象アプリ → 「Configurations」→「Feature Management」タブで、用途に応じて「Enable skills」「Enable skill sharing」「Enable skill sharing without admin approval」のトグルをオンにする。

    ⚠️ スキル機能はデフォルトで無効のため、この設定が必須。

  2. エンドユーザーがスキルを作成またはインポート

    Gemini Enterprise Web アプリにサインインし、ナビゲーションメニューの「Skills」→「+ New skill」で新規作成 (一意の名前・説明・指示を入力)、または「Import」で Markdown / ZIP をインポート。作成・インポートしたスキルはデフォルトで有効化される。

  3. 管理者が共有リクエストをレビュー (承認制の場合)

    コンソールの「Gemini Enterprise」ページで対象アプリの「Skills」を開き、Pending の共有ステータスを持つスキルの「Review share request」をクリック。共有先ユーザーを選択し「Approve」(承認) または「Deny」(却下) をクリック。

💡 メリット

💼 ビジネス面

✓組織ナレッジの再利用: 契約書レビューの観点、ブランドガイドライン、報告書フォーマットなど部門固有のノウハウをスキル化して全社で共有・再利用
✓セルフサービスでの導入: 許可リスト申請が不要になり、管理者のトグル操作のみで即座に全社導入
✓統制されたシェアリング: 管理者承認フローにより、品質・コンプライアンス上問題のあるスキルの拡散を防止

⚙️ 技術面

✓プロンプトの肥大化を回避: モジュール化された指示でアシスタントにドメイン知識を追加
✓オープン標準準拠: agentskills.io 標準準拠のため、他のエージェント環境のスキル資産を Markdown / ZIP でインポートして再利用しやすい
✓自動呼び出し: 説明とトリガー指示に基づき関連スキルを動的に選択。ユーザーがスキルの存在を意識しなくても恩恵を受けられる
✓段階的なガバナンス: 一時停止 (所有者はテスト継続可) → 無効化 → 却下 → 削除と、粒度に応じたライフサイクル管理

⚠️ デメリット・制約事項

🚧 制限事項

✗スキルはエージェント (Agent Designer などで作成) では利用不可。コアアシスタントとの会話でのみ有効
✗スクリプト実行は Python と Bash のみサポート
✗Web アプリのエディタで作成できるのは単一の skill.md を持つスキルのみ。スクリプト付きの複雑なスキルは ZIP でのインポートが必要
✗カスタム MCP サーバーとスキルは連携できない
✗自然言語でのスキル作成では、会話コンテキストやコネクタの内容を入力として利用できない
✗応答生成にスキルが使われても、UI 上でどのスキルが使用されたかは明示されない

🤔 考慮すべき点

  • スキル機能はデフォルトで無効。管理者による Feature Management での有効化が必須
  • 自動選択は期待どおりにトリガーされない場合がある (既知の問題)。確実に使わせたい場合は @メンションや直接依頼を推奨
  • ZIP に複数ファイルを含めた場合、UI に表示されるのは skill.md のみ (他ファイルは内部的に実行時利用)
  • 却下 (Reject) 時の理由はスキル所有者に表示されないため、別途フィードバック手段を用意するとよい
  • Google 管理スキルは管理者コントロールで全ユーザーに対して一時停止・無効化できない (エンドユーザーが個別にオフにすることは可能)

🎯 ユースケース

⚖️ ユースケース 1: 法務部門の契約書レビュー観点の標準化

法務部門が契約書レビューチェックリスト (準拠法、責任制限条項、解約条件など) をスキル化し、営業部門やパートナー管理部門に共有。各部門の担当者は法務に都度依頼せずに一次レビューを実施できる。

Markdown skill.md (契約書一次レビュースキル) 
# skill.md (契約書一次レビュースキル)
name: 契約書一次レビュー
description: 契約書ドラフトのレビュー依頼時に使用。責任制限・準拠法・
  解約条件・自動更新条項をチェックし、リスクを 3 段階で評価する。

## 指示
1. アップロードされた契約書から以下の条項を抽出する
   - 責任制限 (上限額・除外事由)
   - 準拠法・裁判管轄
   - 契約期間・自動更新・解約予告期間
2. 自社標準 (別紙ガイドライン) との差分を表形式で提示する
3. リスクを High / Medium / Low で評価し、法務エスカレーションの要否を示す
✨ 効果: レビュー観点が組織全体で標準化され、法務部門への一次確認依頼が削減。共有時に管理者承認を挟むことで、ガイドライン改訂時の品質統制も維持できる。

🎨 ユースケース 2: ブランドボイスに沿ったコンテンツ作成の全社展開

マーケティング部門がトーン & マナー、用字用語、禁止表現をまとめたブランドボイススキルを作成し全社に共有。各部門はプレスリリース、提案書、社外メールの作成時に @ブランドボイス で呼び出す。

✨ 効果: 対外文書の品質・トーンが統一され、マーケティング部門の最終チェックの手戻りが減少。Google 提供の Brand Voice スキルを複製 (Duplicate to edit) してカスタマイズすれば、ゼロから作成する手間も省ける。

🔄 ユースケース 3: 既存のスキル資産の移行・再利用

開発チームが agentskills.io 標準に準拠して他のエージェント環境向けに作成済みのスキル (skill.md + scripts/ の ZIP パッケージ) を、Gemini Enterprise にインポートしてビジネスユーザーにも開放する。

✨ 効果: オープン標準準拠のため、スキル資産を書き直すことなく Gemini Enterprise で再利用可能。Python / Bash スクリプトを含む高度なスキルも ZIP インポートで展開できる。

💰 料金

スキル機能自体の追加料金に関する個別の記載はなく、Gemini Enterprise のエディション (Standard / Plus / Pay-as-you-go / Frontline) のライセンスに含まれる機能として提供されます。 Gemini Enterprise はユーザー単位・月単位のサブスクリプション課金です。

🌍 利用可能リージョン

スキルに固有のロケーション制限はありません。ただし、スキルが利用できるかどうかはチャット会話で選択されているモデルに依存します。 詳細は Gemini Enterprise の既知の制限 を参照してください。

🔗 関連サービス・機能

🎨 Agent Designer (Gemini Enterprise)

ノーコードでエージェントを構築するツール。スキルが「再利用可能な部品としての反復タスク」に適するのに対し、承認を伴う複雑な複数ステップのワークフローにはエージェントが適する。

⚙️ Feature Management (Gemini Enterprise 管理)

スキルのほか、エージェント共有やモデル選択など Web アプリのエンドユーザー機能を管理者が制御する仕組み。

🗂️ Gemini Enterprise Agent Platform (Skill Registry)

開発者向けに API / SDK でスキルを登録・管理する仕組み。CreateSkill API で ZIP パッケージ化したスキルをプログラマティックに登録できる。

🛡️ Agent Registry

スタンドアロンスキルの登録・バージョン管理・公開元検証を行うガバナンス基盤。エンタープライズレベルのスキル管理を補完する。

📝 まとめ

Gemini Enterprise のカスタムスキルが許可リスト不要の GA となり、エンドユーザー主導でのスキル作成・アップロード・共有と、管理者による承認・ガバナンスの両輪が揃いました。 組織のドメイン知識をオープン標準準拠のスキルとして資産化できる重要なアップデートです。

🚀 推奨アクション: まずは管理者が Feature Management で「Enable skills」を有効化し、承認フロー付きの共有設定でスモールスタートすることを推奨します。
