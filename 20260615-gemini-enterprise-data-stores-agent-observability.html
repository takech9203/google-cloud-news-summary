📋 概要

Gemini Enterprise に 2 つの重要なアップデートが同時にリリースされました。

🔗 新規データストアコネクタ: AirOps、Airtable、Calendly、Dynamics 365、Freshservice、Google Stitch、Intercom、MailerLite、Zoho CRM の 9 つのサードパーティデータストアが Public Preview で追加。さらに Smartsheet、Wrike、Zoho Projects に書き込みアクションを追加。
🔍 エージェント個別オブザーバビリティ: Agent Designer で作成した従業員製エージェントに対して個別にオブザーバビリティ設定を構成可能に。Metrics Explorer / Trace Explorer でエージェント単位のモニタリングが実現。

❌ Before

  • AirOps、Airtable、Calendly 等の SaaS データを直接検索不可
  • Smartsheet/Wrike/Zoho Projects は検索のみでアクション不可
  • オブザーバビリティはアプリレベル (Core Assistant) のみ
  • 複数エージェント環境で問題切り分けが困難

✅ After

  • 9 つの新しいコネクタで幅広い SaaS ツールと連携可能
  • Smartsheet/Wrike/Zoho Projects でタスク作成・更新が可能
  • Agent Designer エージェントごとに個別オブザーバビリティ設定
  • 特定エージェントの問題特定・パフォーマンス最適化が容易

💻 ステップ 3: REST API による有効化

Bash 
curl -X PATCH -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  -H "X-Goog-User-Project: PROJECT_ID" \
  "https://ENDPOINT_LOCATION-discoveryengine.googleapis.com/v1alpha/projects/PROJECT_ID/locations/LOCATION/collections/default_collection/engines/APP_ID/assistants/default_assistant/agents/AGENT_ID?updateMask=observabilityConfig" \
  -d '{
    "observabilityConfig": {
      "observabilityEnabled": true,
      "sensitiveLoggingEnabled": false
    }
  }'
⚠️ 注意: PROJECT_ID、LOCATION (global / us / eu)、APP_ID、AGENT_ID を環境に合わせて置き換えてください。

💻 技術面

✓きめ細かな監視: エージェント単位でのメトリクス収集。特定エージェントの問題を迅速に特定・解決
✓OpenTelemetry 標準準拠: ベンダー非依存な標準テレメトリ形式で、既存監視エコシステムとの統合が容易
✓フェデレーテッド検索: データをコピーせず検索可能。データガバナンスとセキュリティを維持

⚠️ デメリット・制約事項

🚫 制限事項

✗新規データストアは全て Public Preview (Pre-GA Offerings Terms 適用)
✗データストアは global、us、eu の 3 リージョンのみでサポート
✗1 つのアプリに対して同一コネクタタイプのデータストアは 1 つのみ推奨
✗エージェントオブザーバビリティは Agent Designer で作成した従業員製エージェントのみ対象 (カスタム/サードパーティエージェントは非対応)
✗VPC Service Controls のパーミッター適用は既存データストアでは非対応 (再作成が必要)

💡 考慮すべき点

  • "Enable logging of prompt inputs and response outputs" 有効時は PII データがログに記録されるため、アクセス制御を適切に設定
  • フェデレーテッド検索ではクエリがサードパーティ API に送信 — 各サービスの利用規約・プライバシーポリシーが適用
  • メトリクスデータは Cloud Monitoring に保存され、デフォルトで 6 週間保持
