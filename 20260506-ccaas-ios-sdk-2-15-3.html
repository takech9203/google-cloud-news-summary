📱 CCaaS iOS Mobile SDK v2.15.3 パッチリリース

チャット終了時クラッシュ修正

CCAI Platform Crash Fix Patch Released
2026-05-06

📋 概要

Google Cloud Contact Center as a Service (CCaaS) の iOS Mobile SDK v2.15.3 パッチがリリースされました。本パッチは、エンドユーザーが「End chat」ボタンをタップした際にアプリがクラッシュする重大な不具合を修正するものです。

CCAI Platform の iOS SDK は、iPhone や iPad アプリ内で音声およびチャットサポート体験を提供するためのツールキットです。今回の不具合はチャットセッション終了時に発生するクラッシュであり、ユーザーがサポートチャットを正常に終了できない状態を引き起こしていました。

🔄 Before / After

❌ Before (v2.15.2 以前)

  • 「End chat」ボタンをタップするとアプリがクラッシュ
  • チャットセッションを正常に終了できない
  • チャット後アンケートや正常な画面遷移が実行されない

✅ After (v2.15.3)

  • 「End chat」操作時のクラッシュが解消
  • チャット終了後のライフサイクルが正常に動作
  • アプリの安定性が向上し安心して利用可能

⚙️ 関連する iOS SDK イベント

CCAI Platform iOS SDK では NSNotificationCenter を通じてセッション関連イベントが通知されます。今回の修正は、ユーザーが「End chat」をタップした後に発行される UJETEventSessionDidEnd イベント周辺の処理に関連しています。

📤 UJETEventSessionDidEnd

セッション終了時に発行 (ended_by: "end_user")

🔌 UJETEventSdkDidTerminate

SDK 終了時のイベント

💡 ポイント: 今回のクラッシュは UJETEventSessionDidEnd の発行に伴うセッション終了処理のロジックに起因していたと考えられます。v2.15.3 で当該処理が修正されています。
