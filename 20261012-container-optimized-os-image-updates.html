Container-Optimized OS Security Fixed dev チャネル
📅 リリース日: 2026-10-12

📝 概要

Google Cloud は COS の新しい dev チャネルイメージ cos-dev-138-20198-0-0 を公開。 リリースノートの要点は (1) Lustre クライアントドライバ v2.14.0_p262-r1 のサポート追加、 (2) sys-libs/binutils-libs の CVE-2026-18220 修正、 (3) sys-apps/pv の v1.12.0 アップグレード の 3 点。 同イメージには Linux カーネル v6.18.55、runc v1.5.2、glibc の CVE-2026-5450 修正、 ARM64 向け Arm CCA Confidential VM のゲスト認証サポート (CONFIG_ARM_CCA_GUEST) なども含まれる。

対象は Compute Engine VM や GKE ノードで COS を使うユーザー、特に次期マイルストーン COS 138 を dev チャネルで検証しているユーザー。Lustre ドライバ更新は Managed Lustre を使う AI/ML・HPC ワークロードに関係する。

⚙️ 主要機能

📦 Lustre クライアントドライバ v2.14.0_p262-r1 のサポート追加 Fixed

→ net-fs/lustre-client-drivers パッケージの新リビジョン v2.14.0_p262-r1 をサポート

→ Lustre は AI/ML・HPC 向けの高性能並列ファイルシステム。COS は Google Cloud Managed Lustre のクライアントとしても利用される

→ 同イメージでは v2.14.0_p262 のサポートも併せて追加

🔒 CVE-2026-18220 の修正 Security

→ sys-libs/binutils-libs (GNU Binutils の共有ライブラリ群) の脆弱性 CVE-2026-18220 を修正

→ binutils-libs はオブジェクトファイルやバイナリ操作に使われる基盤ライブラリ。OS イメージの更新で修正が適用される

🔧 sys-apps/pv の v1.12.0 へのアップグレード Fixed

→ パイプラインを流れるデータの進捗を監視するユーティリティ pv (Pipe Viewer) を v1.12.0 に更新

🧩 同一イメージ (cos-dev-138-20198-0-0) に含まれるその他の主な変更

  • Linux カーネルを v6.18.55 に更新
  • app-containers/runc / runc-test を v1.5.2 にアップグレード
  • sys-libs/glibc の CVE-2026-5450 を修正
  • ARM64 向けに CONFIG_ARM_CCA_GUEST を有効化し、Arm CCA Confidential VM のゲスト認証をサポート
  • cos-gpu-installer のデフォルトバージョンを v2.7.9 に更新
  • idpf ドライバに watchdog_timeout モジュールパラメータを追加
  • expat v2.8.5、libgcrypt v1.12.4、libpcre2 v10.49、oauthlib v4.0.0、xemu v0.0.11、google-guest-configs 20260928.00、oslogin 20260924.00 などのパッケージ更新

🛠️ 設定方法

✅ 前提条件

✓Compute Engine または GKE で Container-Optimized OS イメージを使用していること
✓cos-dev ファミリは検証用チャネル。本番環境では LTS ファミリ (cos-[MILESTONE]-lts) を使用すること

ステップ 1: 最新 dev イメージの確認

Bash cos-dev ファミリの最新イメージを確認 
gcloud compute images describe-from-family cos-dev \
  --project=cos-cloud

ステップ 2: 新イメージで検証用 VM を作成

Bash cos-dev-138-20198-0-0 で VM を作成 
gcloud compute instances create my-cos-dev-instance \
  --image=cos-dev-138-20198-0-0 \
  --image-project=cos-cloud \
  --zone=us-central1-a
💡 ヒント: dev チャネルは次期マイルストーンの機能をいち早く検証するためのチャネル。 今回の修正内容は、今後の beta / LTS リリースにも順次取り込まれていく。

✓次期 LTS への移行準備: dev チャネル (COS 138) で最新カーネル・ランタイム構成を事前検証でき、将来の LTS 移行をスムーズに進められる

🔧 技術面のメリット

✓Lustre クライアントの最新化: v2.14.0_p262-r1 サポートにより、Managed Lustre を使う AI/ML・HPC ワークロードで最新のクライアントリビジョンを利用可能
✓ユーティリティの更新: pv v1.12.0 への更新でデータ転送監視ユーティリティが最新化

⚠️ 制限事項

✗cos-dev ファミリは検証用であり、本番ワークロードでの使用は推奨されない
✗CVE-2026-18220 の深刻度・影響範囲の詳細は、リリースノート上では未公開

🤔 考慮すべき点

→COS イメージ更新には VM の再作成 (GKE の場合はノードの再作成) が伴うため、計画的なロールアウトが必要
→GKE から Managed Lustre を利用する場合はドライバの手動インストールは不要。Managed Lustre CSI ドライバ経由での利用が推奨 (COS ノードは GKE 1.33.2-gke.1111000 以降の x86_64、1.34.1-gke.2541000 以降の ARM でサポート)

🎯 ユースケース

🛡️ ユースケース 1: 脆弱性スキャン指摘への対応

シナリオ: セキュリティチームの脆弱性スキャンで、COS ノードの binutils-libs に CVE-2026-18220 が検出された。

効果: 修正を含む COS イメージへ更新することで該当 CVE が解消され、スキャンアラートをクローズできる。dev チャネル利用環境では cos-dev-138-20198-0-0 以降を使用する。

🤖 ユースケース 2: Lustre を使う AI/ML ワークロードの事前検証

シナリオ: Managed Lustre をストレージとして使う AI/ML 基盤を運用しており、次期 COS マイルストーン (COS 138) での動作を事前に確認したい。

効果: 最新の Lustre クライアントドライバ (v2.14.0_p262-r1) とカーネル v6.18 系を含む dev イメージで互換性検証を行い、将来の LTS 昇格時の移行リスクを低減できる。

🔗 関連サービス・機能

🗄️ Google Cloud Managed Lustre

COS に含まれる Lustre クライアントドライバで接続する高性能並列ファイルシステム。AI/ML・HPC ワークロード向け。

🚢 Google Kubernetes Engine (GKE)

COS は GKE ノードのデフォルトイメージ。Managed Lustre CSI ドライバにより、COS ノードから手動のドライバインストールなしで Lustre ボリュームをマウントできる。

🖥️ Compute Engine

COS イメージ (cos-cloud プロジェクト) を直接指定して VM を作成できる。
