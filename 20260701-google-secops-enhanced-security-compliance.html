📋 概要

Google SecOps の Advanced BigQuery Export 機能に、エンタープライズレベルのセキュリティ・コンプライアンス強化と新しいデータセットのサポートが追加されました。

VPC Service Controls、Customer-Managed Encryption Keys (CMEK)、Data Residency (DRZ) のネイティブサポートにより、規制要件の厳しい業界 (金融、医療、政府機関) でも Advanced BigQuery Export の活用が可能になります。

🔄 Before / After

❌ Before (従来の制限)

  • CMEK 有効インスタンスでは利用不可
  • VPC-SC との統合に個別構成が必要
  • Entity Graph / Ingestion Metrics はエクスポート対象外
  • MSSP の一元管理の仕組みがない
  • 重複排除に複雑な SQL が必要

✅ After (今回の改善)

  • VPC-SC / CMEK / DRZ がネイティブサポート
  • Entity Graph / Ingestion Metrics がエクスポート対象に追加
  • Fine-Grained DML マージで自動重複排除
  • MSSP ハブ・アンド・スポーク型管理
  • Access Transparency ログの Cloud Logging 配信

🔐 セキュリティ機能の詳細

🛡️ VPC Service Controls (VPC-SC)

サービス境界内でのデータアクセス制御により、データ流出リスクを軽減。Advanced BigQuery Export は VPC-SC 準拠機能としてネイティブサポート。

🔑 Customer-Managed Encryption Keys (CMEK)

顧客が Cloud KMS で管理する暗号鍵によるデータ保護。Multi-region (eu, us) および全サポートリージョンで対応。

🌍 Data Residency (DRZ)

データの保存場所を特定リージョンに制限。データ主権要件を満たすための地理的制御を提供。

📋 Access Transparency

Federated Resource Identification Service を使用して、顧客向け監査ログを Cloud Logging ワークスペースに直接配信。

⚙️ 設定方法

💡 前提条件:
  • Google SecOps Enterprise Plus ライセンスを保有
  • Advanced BigQuery Export の有効化をリクエスト済み (Public Preview)
  • Google SecOps インスタンスにリンクされた Google Cloud プロジェクトが存在

Step 1: リンクされたデータセットの確認

BigQuery コンソールの Explorer パネルで secops_linked_data データセットを確認します。

SQL アクセス確認テストクエリ 
-- アクセス確認のテストクエリ
SELECT *
FROM `PROJECT_ID.secops_linked_data.events`
LIMIT 10;

Step 2: VPC Service Controls の構成

VPC-SC を使用する場合、Google SecOps をサービス境界に含め、適切な Ingress/Egress ルールを設定します。

Step 3: CMEK の構成

Cloud KMS で暗号鍵を作成し、Google SecOps インスタンスに適用します。全サポートリージョンで利用可能です。

💡 ユースケース

🏦 コンプライアンスが厳格な金融機関でのセキュリティ分析

金融業界の規制要件 (データ主権、暗号化管理) を満たしながら、BigQuery 上でセキュリティデータの高度な分析を実行。CMEK と VPC-SC の下でニアリアルタイム脅威検出が可能。

SQL 不審なネットワークアクティビティ検出クエリ 
-- VPC-SC 境界内のリンクされたデータセットから
-- 不審なネットワークアクティビティを検出
SELECT
  metadata.event_timestamp,
  principal.hostname,
  target.ip,
  network.dns.questions.name
FROM `PROJECT_ID.secops_linked_data.events`
WHERE hour_time_bucket >= TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 24 HOUR)
  AND network.dns.questions.name IS NOT NULL
ORDER BY metadata.event_timestamp DESC;

🌐 MSSP による複数顧客テナントの一元分析

MSSP が複数の顧客テナントのセキュリティデータを単一のハブプロジェクトから横断的に分析し、脅威の傾向を把握。プログラマティックなサブスクリプションにより新規顧客のオンボーディングを迅速化。

📈 データ品質管理と取り込みモニタリング

Ingestion Metrics のエクスポートにより、ログの取り込み状況、パースエラー、データ品質を BigQuery 上で可視化し、BI ツール (Power BI, Looker) と連携してセキュリティデータパイプラインの健全性を監視。

⚠️ 制限事項・注意点

⚠️ 主要な制限事項
  • Enterprise Plus 必須 - 他のライセンスティアでは利用不可
  • Public Preview - リクエストベースでの有効化が必要
  • Entity Graph データ鮮度 - 約 4 時間 (バッチプロセス)
  • BigQuery カラム制限 - UDM スキーマは 27,000+ フィールドだが、BigQuery のソフトリミットは 10,000 列
  • データ保持期間 - SecOps プロジェクトと同期、個別設定不可
  • 履歴データ - 有効化時点からのみエクスポート開始
  • 再エンリッチ UDM - エクスポート対象外
💡 考慮すべき点:
  • 移行期間中は既存パイプラインとの二重運用
  • Pre-GA のため変更が互換性を保たない可能性あり
  • 大規模クエリの分析コストに注意

🌏 利用可能リージョン

Google SecOps がサポートするすべてのリージョンで利用可能。CMEK は Multi-region (eu, us) および全サポートリージョンで対応。

💡 注意: Multi-region を選択した場合、追加のリージョン固有の CMEK 設定が必要です (eu の場合は europe-west1、us の場合は us-central1)。
