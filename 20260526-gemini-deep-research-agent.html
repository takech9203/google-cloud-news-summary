🤖 Gemini Deep Research Agent

Gemini Enterprise Agent Platform Preview
2026-05-26

📋 概要

🤖 Gemini Deep Research Agent とは:
Google が開発したマネージド AI エージェント。複雑なマルチステップのリサーチワークフローを自律的に計画・実行・統合し、包括的な引用付きレポートを生成します。公開ウェブとプライベートなエンタープライズデータの両方にアクセスして調査を行います。

単なる検索エンジンや Q&A システムとは異なり、人間のリサーチアナリストのように振る舞います。ユーザーが調査テーマを入力すると、エージェントがリサーチプランを策定し、数百件の検索クエリを自律実行しながら情報を収集・分析し、最終的に引用付きの包括的レポートと音声サマリーを生成します。

Gemini Enterprise アプリ内のプリビルトエージェントとして提供されるほか、Interactions API や Discovery Engine API を通じてプログラマティックにアクセスすることも可能です。

🔄 Before / After

❌ Before (従来の課題)

  • 複数の情報ソースを手動で横断調査 (数日~数週間)
  • 公開情報と社内機密データの統合分析に複数ツールが必要
  • 引用元追跡やエビデンス整理に多大な手作業
  • 情報の取りこぼしによる意思決定の質のばらつき

✅ After (改善)

  • 単一プロンプトから自律的にリサーチ実行 (数時間に短縮)
  • 公開ウェブ + エンタープライズデータを単一エージェントで統合調査
  • すべての情報に引用が自動付与
  • Collaborative Planning でリサーチ方向性を制御可能

💡 ポイント: ユーザー入力の評価後、自律的にリサーチプランを策定し、公開ウェブとエンタープライズデータの両方から情報を収集する反復ループを実行。十分な情報が収集されると統合・分析フェーズに移行し、引用付きレポートと音声サマリーを生成します。

⚡ 主要機能

📝 1. 自律的リサーチプラン策定

→ユーザーのクエリを分析し、調査が必要なトピックを自動特定
→マルチステップのリサーチ計画を策定し、研究の方向性を決定
→Collaborative Planning 有効化でプランをレビュー・編集してから実行開始

🔍 2. マルチソース情報収集

→Google Search を活用した公開ウェブからの情報収集
→エンタープライズデータコネクタ経由でアクセス制御された社内データへアクセス
→対応: Google Workspace, Microsoft (OneDrive, SharePoint), ServiceNow, Jira, Confluence 等
→1 タスクあたり最大 80~160 件の検索クエリを自律実行

📡 3. リアルタイムストリーミング

→リサーチの進行状況をリアルタイムでストリーミング表示
→調査中のトピックと回答が逐次的にユーザーに共有
→Thinking Summaries 機能で中間推論ステップの可視化が可能

📄 4. 包括的レポート生成

→引用付きの構造化されたレポートを自動生成
→各情報にドキュメント ID、URI、タイトル、ドメインなどのメタデータを付与
→1~2 分の音声サマリーを自動生成
→ビジュアライゼーション (チャート・画像) の自動生成オプション

🔌 5. API によるプログラマティックアクセス

→Interactions API (Gemini API) および Discovery Engine API でのアクセスが可能
→バックグラウンド実行モードにより、長時間リサーチを非同期処理
→REST、Python SDK、JavaScript SDK に対応

🔧 技術仕様

エージェント設定パラメータ

パラメータ 型 デフォルト 説明
type string 必須 "deep-research" を指定
thinking_summaries string "none" "auto" で中間推論ステップのストリーミングを有効化
visualization string "auto" "auto" でチャート・画像の自動生成を有効化
collaborative_planning boolean false true でリサーチ開始前のプランレビューを有効化

モデルバリアント

モデル 用途 推定トークン使用量
deep-research-preview-04-2026 標準的なリサーチタスク 入力 ~250k / 出力 ~60k トークン
deep-research-max-preview-04-2026 深い競合分析やデューデリジェンス 入力 ~900k / 出力 ~80k トークン

💻 API リクエスト例

Python Interactions API を使用した Deep Research 
from google.cloud import discoveryengine_v1 as discoveryengine

# Interactions API を使用した Deep Research
agent_config = {
    "type": "deep-research",
    "thinking_summaries": "auto",
    "visualization": "auto",
    "collaborative_planning": False,
}

interaction = client.interactions.create(
    agent="deep-research-preview-04-2026",
    input="Research the competitive landscape of cloud GPUs.",
    agent_config=agent_config,
    background=True,
)
Bash Discovery Engine API - リサーチセッション開始 
curl -X POST \

    "query": { "text": "Research query here" },
    "agentsSpec": {
      "agentSpecs": { "agentId": "deep_research" }

        }
      },
      "webGroundingSpec": {}
    }
  }'

✅ メリット

ビジネス面

🚀リサーチ時間の大幅短縮: 従来数日~数週間 → 数時間に短縮。経営判断のスピードが向上
🎯情報の網羅性向上: 数百件の検索を自律実行し、人間では見落としがちな情報源もカバー
💰コスト削減: 専門リサーチャーやコンサルタントへの外注コストを削減。1 タスクあたり $1~$7
🌐ナレッジの民主化: 自然言語のプロンプトで高品質なリサーチレポートを取得可能

技術面

☁️マネージドサービス: インフラ管理不要。Google がスケーリングと可用性を管理
🔒エンタープライズデータ統合: 既存データコネクタと連携し、アクセス制御を維持
🔌API ファースト設計: REST / Python SDK / JavaScript SDK に対応
📡ストリーミングレスポンス: リアルタイムで進行状況確認が可能

⚠️ デメリット・制約事項

制限事項

❌Preview ステータスのため、SLA が適用されない可能性
❌Gemini Enterprise Frontline エディションでは利用不可
❌API アクセスは許可リスト (allowlist) 制 - 事前申請が必要
❌コストが可変 ($1~$7/タスク)、リサーチの深さに応じて変動
⚠️ 考慮すべき点:
  • エージェントの自律的判断がリサーチの方向性と異なる場合がある (Collaborative Planning 推奨)
  • 大規模リサーチではトークン 900k 以上になりコスト管理に注意
  • Preview 期間中の料金体系は変更される可能性
  • エンタープライズデータへのアクセスにはコネクタのセットアップとインデックス作成が必要

💡 ユースケース

📈 ユースケース 1: 競合分析レポートの自動生成

シナリオ: 新規市場参入を検討中の事業部門が、競合他社の製品戦略・価格設定・市場シェアの包括的分析を必要としている。

効果: 従来 2~3 週間の競合分析を数時間で完了。外部・内部の両方のデータソースから網羅的に情報を収集し、表形式の比較や視覚化を含む包括的レポートを自動生成。

🔬 ユースケース 2: 社内ナレッジベースを活用した技術調査

シナリオ: エンジニアリングチームが新しいアーキテクチャ設計を検討する際に、社内の過去のポストモーテムレポート・設計ドキュメント・外部ベストプラクティスを統合的に調査したい。

効果: Google Drive や Confluence の社内ドキュメントと公開ウェブの技術記事を横断検索し、過去の障害・成功事例を踏まえた最適なアーキテクチャパターンを提案。

📜 ユースケース 3: 規制・コンプライアンス調査

シナリオ: 法務部門が新しい市場での事業展開に際して、各国の規制要件・データ保護法・業界コンプライアンス要件を調査する必要がある。

効果: 複数法域の規制情報を公開ソースから収集し、社内ポリシードキュメントとの整合性を分析。引用付き規制マッピングレポートを生成。

💰 料金

従量課金制 (Pay-as-you-go)。1 リクエストが計画・検索・読み取り・推論の自律ループをトリガーするため、通常のチャットよりトークン使用量が大きくなります。

モデル 典型的な使用量 推定コスト
deep-research-preview-04-2026 (標準) ~80 検索、~250k 入力トークン (50-70% キャッシュ)、~60k 出力 $1.00 ~ $3.00
deep-research-max-preview-04-2026 (Max) ~160 検索、~900k 入力トークン (50-70% キャッシュ)、~80k 出力 $3.00 ~ $7.00
⚠️ 注意: Preview 期間中の推定料金であり、変更される可能性があります。
