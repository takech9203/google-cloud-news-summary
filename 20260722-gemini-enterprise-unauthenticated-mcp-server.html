☁️ Gemini Enterprise: 認証不要カスタム MCP サーバーデータストア

Gemini Enterprise Public Preview
2026-07-22

📋 概要

Gemini Enterprise のカスタム MCP (Model Context Protocol) サーバーデータストアの設定において、認証が不要な MCP サーバーに接続する際に「No authentication (認証なし)」オプションを選択できるようになりました。

これにより、社内向けの読み取り専用 MCP サーバーや、ネットワークレベルのセキュリティで保護された MCP サーバーへの接続が大幅に簡素化されます。従来は OAuth 2.0 認証の設定が必須でしたが、URL を入力するだけで接続が完了します。

❌ Before (アップデート前)

  • OAuth 2.0 認証の設定が必須
  • 認証不要サーバーにも OAuth 構成が必要
  • 不要な OAuth インフラの構築が必要
  • PoC/プロトタイピングに時間がかかる

✅ After (アップデート後)

  • 「No authentication」を選択可能
  • URL 入力のみで接続完了
  • OAuth インフラ不要で簡素化
  • 迅速な PoC/プロトタイピング

⭐ 主要機能

🔓 認証なしオプション

MCP サーバーが認証を必要としない場合に選択可能。必要な入力は MCP サーバー URL のみ。HTTPS URL が必須 (例: https://mcp.example.com/mcp)

🌐 StreamableHTTP トランスポート

StreamableHTTP トランスポートのみをサポート。旧来の Server-Sent Events (SSE) トランスポートは非対応。URL は通常 /mcp で終わる形式。

⚙️ アクション管理

接続後、MCP サーバーのツールはデータストアの「アクション」としてインポート。デフォルトでは全アクション無効。管理者が個別に有効化 (最大 100 個)。

🏷️ ツールアノテーション対応

readOnlyHint で読み取り専用操作の確認スキップ。destructiveHint でデータ変更操作は確認を維持。

🛠️ 設定方法

前提条件

✓Organization Policy Administrator ロール (roles/orgpolicy.policyAdmin)
✓Discovery Engine Editor ロール (roles/discoveryengine.editor)
✓MCP サーバー FQDN がエグレスポリシーで許可されていること

手順

  1. 組織ポリシーのオーバーライド
    「Disable custom MCP server connector for Gemini Enterprise」ポリシーを「Not enforced」に設定
  2. データストアの作成
    Gemini Enterprise > Data stores > Create data store > Custom MCP Server を選択
  3. 認証方式の選択
    「No authentication」を選択し、MCP サーバー URL を入力
  4. データストアの構成
    MCP Server Description、ロケーション、データコネクタ名を入力して作成
  5. アクションの有効化
    データストアが Active になったら、Actions > Reload > 有効化するアクションを選択

✓PoC の迅速化: 認証設定なしですぐにテスト可能

🔧 技術面

✓柔軟な認証モデル: VPN/FW との組み合わせが容易

⚠️ デメリット・注意事項

⚠️ 制限事項:
  • Preview 段階のため、本番ワークロードでの使用は推奨されない
  • StreamableHTTP トランスポートのみ対応 (SSE 非対応)
  • Private Service Connect (PSC) 非対応
  • VPC Service Controls 非対応
💡 考慮すべき点:
  • 認証なし MCP サーバーはネットワークレベルのセキュリティ (VPN、IAP、FW) で保護を強く推奨
  • データストア経由のトラフィックは Agent Gateway を経由しないため、Agent Gateway ポリシーは適用されない
  • 組織ポリシーのオーバーライドはプロジェクト単位で行うこと (組織全体への適用は避ける)

🎯 ユースケース

📚 ユースケース 1: 社内ナレッジベースへの接続

シナリオ: 社内 Wiki や技術ドキュメントが MCP サーバーとして公開されており、VPN 内からのアクセスに認証が不要な場合。

設定例 
MCP サーバー URL: https://wiki.internal.corp.example.com/mcp
認証: No authentication
有効化アクション: search_documents, get_page_content
アノテーション: readOnlyHint: true

効果: 従業員が Gemini Enterprise を通じて社内ナレッジに自然言語でアクセスでき、情報検索の効率が向上。

🔄 ユースケース 2: レガシー API のラッパー

シナリオ: レガシーシステムの REST API を MCP プロトコルでラップし、Gemini Enterprise から利用可能にする。API はネットワークファイアウォールで保護。

効果: レガシーシステムの改修なしに、AI エージェント経由でのデータアクセスが実現。

🧪 ユースケース 3: 開発・検証環境での PoC

シナリオ: 新しい MCP サーバーの開発中に、認証なしで素早く Gemini Enterprise との統合をテストしたい場合。

効果: OAuth 設定なしで迅速に統合テストを実施でき、開発サイクルが短縮。

💰 料金

カスタム MCP サーバーデータストアの料金は、Gemini Enterprise のライセンス体系に含まれます。データストア作成時に「General pricing」または「Configurable pricing」を選択できます。

🔗 関連サービス

Agent Registry

MCP サーバーの一元管理カタログ。カスタム MCP サーバー以外は Agent Registry から追加可能。

Agent Gateway

MCP サーバーへのトラフィック制御とランタイムポリシー適用 (直接設定のカスタム MCP サーバーには適用されない)。

Organization Policy Service

カスタム MCP サーバーの有効化/無効化を組織ポリシーで制御。

Discovery Engine

Gemini Enterprise のデータストア基盤。

📝 まとめ

Gemini Enterprise のカスタム MCP サーバーデータストアに「認証なし」オプションが追加されたことで、OAuth 設定が不要な社内 MCP サーバーへの接続が大幅に簡素化されました。ネットワークレベルでセキュリティが確保された社内システムや PoC 環境での活用に特に有効です。

Preview 段階であるため本番運用には注意が必要ですが、MCP プロトコルを活用した社内データ統合を検討している組織は、まず開発環境でこの機能を試し、Gemini Enterprise と社内ツールの統合パターンを検証することを推奨します。
