📋 概要

SAP on Google Cloud において、ABAP SDK for Google Cloud v1.14 と BigQuery Connector for SAP v2.14 の 2 つのコンポーネントが一般提供 (GA) となった。ABAP SDK v1.14 は Cloud Storage コンテンツリポジトリの署名検証に関するバグ修正と SPRO 設定メニューのクリーンアップを含む保守リリース。BigQuery Connector v2.14 はカスタムカレンダータイプを使用した日付フィールドのレプリケーションサポートを追加し、SAP 固有の非標準日付形式を BigQuery へ正確に複製できるようになった。

Before (アップデート前の課題)

  • Cloud Storage コンテンツリポジトリで署名検証エラーが発生
  • SPRO 設定メニューに未参照のノードが残存
  • カスタムカレンダータイプの日付フィールドが BigQuery へ正しくレプリケーションできない

After (アップデート後の改善)

  • 署名検証が正常に機能し、ドキュメント保存の信頼性向上
  • SPRO メニューから未参照ノード削除、構成管理が簡潔に
  • カスタムカレンダー日付フィールドが正確にレプリケーション可能

🏗️ アーキテクチャ図

ABAP SDK v1.14 は Cloud Storage コンテンツリポジトリとの通信における署名検証を修正し、BigQuery Connector v2.14 は SAP から BigQuery へのデータレプリケーションにおいてカスタムカレンダータイプの日付フィールドをサポートする。

🚀 主要機能

1. ABAP SDK v1.14 - 署名検証の修正
🔐 Cloud Storage コンテンツリポジトリ機能で発生していた署名検証の問題を解決。SAP ArchiveLink サービス経由でのドキュメント保存・取得が安定的に動作するようになった。
→ PDF、画像等のビジネスオブジェクト添付ドキュメントの保管やアーカイブに影響
2. ABAP SDK v1.14 - SPRO 設定メニューのクリーンアップ
🧹 未参照のノードを SPRO 設定メニューから削除。SDK の設定管理がより直感的になり、管理者の操作性が向上。
3. BigQuery Connector v2.14 - カスタムカレンダー日付フィールドのサポート
📅 SAP のカスタムカレンダータイプを使用した日付フィールドのレプリケーションに対応。標準範囲外の値をカスタム形式で格納する日付データを正確に BigQuery へ複製。
→ 会計年度カレンダー、工場カレンダーなど業種固有のカレンダーを使用する環境で特に有効

セキュリティ設定 (v2.14 新規)

BigQuery Connector for SAP v2.14 では、設定テーブルにカスタム認可グループ ZSGC が割り当てられる。

設定テーブル認可グループ

🔧 設定方法

前提条件

✓SAP NetWeaver Application Server (ABAP) が稼働していること
✓ABAP SDK for Google Cloud の既存バージョンがインストール済み
✓BigQuery Connector for SAP の既存バージョンがインストール済み (BigQuery 連携使用時)

ステップ 1: ABAP SDK v1.14 へのアップデート

ABAP 
トランザクション /GOOG/SDK_IMG を実行
→ ABAP SDK for Google Cloud > Basic Settings で設定を確認

ステップ 2: BigQuery Connector v2.14 へのアップデート

BigQuery Connector のアップデートは公式ドキュメントの手順に従って実施する。

ステップ 3: 認可グループの設定 (BigQuery Connector v2.14)

ABAP 
トランザクション PFCG を使用
→ 該当ロールに認可グループ ZSGC を追加
→ ユーザーマスターレコードを更新
⚠️ 注意: v2.14 へのアップデート後、認可グループ ZSGC をユーザーロールに追加しないと、既存ユーザーが設定テーブルにアクセスできなくなります。アップデート計画に必ず含めてください。

🎯 ユースケース

🏭 ユースケース 1: 製造業における工場カレンダーデータの BigQuery 分析

シナリオ: 製造業の SAP 環境では、工場カレンダー (Factory Calendar) を使用して稼働日・非稼働日を管理している。これらのカレンダーは標準の日付範囲外のカスタム形式で値を格納しており、従来は BigQuery への正確なレプリケーションが困難だった。

効果: BigQuery Connector v2.14 により、工場カレンダーに基づく生産計画データや納期データが正確に BigQuery へレプリケーションされ、生産効率分析や需要予測に活用できるようになる。

📄 ユースケース 2: SAP ドキュメントの Cloud Storage アーカイブ

シナリオ: 企業が SAP のビジネスオブジェクトに添付された請求書 PDF や契約書をコンプライアンス要件に基づき Cloud Storage にアーカイブしている。署名検証の問題により一部のドキュメント操作でエラーが発生していた。

効果: ABAP SDK v1.14 の修正により、SAP ArchiveLink を通じた Cloud Storage へのドキュメント保存・取得が安定し、規制対応のためのアーカイブ運用が信頼性高く実施できる。
