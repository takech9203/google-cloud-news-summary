📋 概要

Knowledge Catalog (旧 Dataplex Universal Catalog) において、Oracle および MySQL データソースからメタデータを自動インポートするためのプリビルトコネクタが Preview として公開された。BigQuery Data Transfer Service を活用して外部データソースに接続し、技術メタデータ、運用メタデータ、ビジネスメタデータを自動抽出して Knowledge Catalog に統合する。

🔄 Before / After 比較

❌ Before (従来)

  • カスタムコネクタを自前で開発が必要
  • Managed Service for Apache Spark 上で実行
  • Workflows パイプラインの構築・運用が必要
  • 外部データソースのメタデータが統合されておらず、発見可能性が低い

✅ After (アップデート後)

  • GUI からコネクタを設定するだけで自動インポート
  • スケジュール設定で定期的にメタデータ同期
  • カスタムコネクタの開発・運用が不要
  • 導入までの時間とコストが大幅に削減

🏗️ アーキテクチャ図

BigQuery Data Transfer Service がコネクタの実行基盤として機能し、Oracle・MySQL からメタデータを抽出して Knowledge Catalog のエントリグループにインポートする。各インポート実行時にはエントリグループ内のエントリが完全に上書きされ、ソースに存在しなくなったオブジェクトは削除される。

⚡ 主要機能

🔌 プリビルトコネクタ

Oracle・MySQL に対するプリビルトコネクタを提供。カスタム開発なしに GUI ベースでメタデータインポートを開始可能。オンプレミス、Cloud SQL、他クラウドに対応。

📊 3種類のメタデータ収集

技術メタデータ: DB/スキーマ/テーブル/ビュー定義
運用メタデータ: 作成日時・更新日時
ビジネスメタデータ: オーナー・アノテーション

🕐 スケジュール同期

定期的なメタデータ同期スケジュール設定に対応。オンデマンド実行も可能。フルオーバーライト方式で常に最新状態を維持。

🔐 セキュアなネットワーク接続

Private Service Connect 経由の Network Attachment でプライベート IP に安全接続。TLS (PEM証明書) にも対応。パブリック IP は Attachment 不要。

⚠️ 制約事項・注意点

Preview 段階の制限:
  • SLA の対象外 - 本番環境での使用には注意が必要
  • 対応データソースは Oracle と MySQL の 2 種類のみ
  • フルオーバーライト方式 - 差分のみの更新には非対応
  • CMEK は一時データの暗号化のみに使用 (Knowledge Catalog 内のメタデータには適用されない)
💡 考慮すべき点:
  • プライベート IP のデータベースは Network Attachment の事前設定が必要
  • サービスエージェントへの権限付与を忘れないこと
  • Preview 期間中のフィードバック: dataplex-discuss@google.com

🎯 ユースケース

🏢 ハイブリッド環境のデータガバナンス統合

シナリオ: オンプレミスの Oracle Database と Cloud SQL for MySQL の両方を運用し、データアセットの全体像を把握したい企業。

効果: 両方のデータソースのメタデータが Knowledge Catalog に自動集約。セマンティック検索でデータ発見、リネージ追跡、品質監視対象が拡大。

🚚 データマイグレーション計画の支援

シナリオ: オンプレミスの Oracle Database を BigQuery にマイグレーションする計画があり、対象テーブルの全体像と依存関係を把握したい。

効果: Oracle のメタデータをインポートし、テーブル・ビュー・スキーマの全体構造を可視化。マイグレーション計画策定を効率化。

🔒 コンプライアンス対応のためのデータインベントリ

シナリオ: GDPR 等のデータ保護規制に対応するため、全データベースの個人情報を含むテーブルを特定したい。

効果: 分散した Oracle・MySQL のメタデータを集約し、ビジネスメタデータと組み合わせて個人情報アセットの特定とインベントリ作成が容易に。

📌 まとめ

Knowledge Catalog の Oracle・MySQL コネクタにより、オンプレミスや他クラウドに分散したデータベースのメタデータを Google Cloud のデータカタログに統合管理することが大幅に容易になった。カスタムコネクタ開発が不要になり、GUI ベースの設定で完結する。

推奨アクション: マルチクラウド・ハイブリッド環境のデータガバナンスを検討している組織は、Preview 段階で評価を開始し、GA 時にスムーズに本番適用できるよう準備を進めること。
