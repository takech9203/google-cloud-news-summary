🏪 Cloud Marketplace Partners: レポート配信の高速化

Google Cloud Marketplace GA

📋 概要

Google Cloud Marketplace のパートナー向け Customer Insights レポート の配信が大幅に高速化されました。これまでデータ処理と配信に 2 日 (D+2) を要していたレポートが、1 日 (D+1) で配信されるようになります。

この改善により、パートナーは顧客の利用状況データをこれまでより 1 日早く入手でき、ビジネス上の意思決定や顧客対応の迅速化が期待できます。

💡 ポイント: パートナー側での設定変更は不要。BigQuery エクスポート、CSV エクスポート (Google Drive / Cloud Storage) のいずれの配信方法を利用している場合も、自動的に高速化が適用されます。

🔄 Before / After 比較

❌ Before (D+2)

  • Customer Insights レポートは太平洋時間基準で 2 日遅れ (D+2) で配信
  • 6月1日のデータは6月3日に配信
  • 顧客の利用状況把握に最短 2 日間必要
  • データの鮮度に課題

✅ After (D+1)

  • 日次レポートの配信が D+1 に短縮
  • 6月1日のデータは6月2日に配信
  • より新鮮な顧客データに基づく意思決定が可能
  • Incremental Insights も同様に高速化

💻 コードサンプル

BigQuery で D+1 配信されたレポートデータを確認するクエリ例:

SQL 
-- Customer Insights レポートの確認
SELECT
  report_date,
  date,
  company,
  domain,
  external_account_id,
  sku_id,
  usage,
  unit
FROM
  `marketplace_report.insights`
WHERE
  _PARTITIONDATE = '2026-05-27'  -- D+1: 5月26日のデータが5月27日に配信
ORDER BY
  date DESC;

前日比で利用量が急落した顧客を検知するクエリ:

SQL 
-- BigQuery で前日の利用状況を確認するクエリ (D+1 で実行可能に)
SELECT
  company,
  external_account_id,
  SUM(usage) AS total_usage,
  LAG(SUM(usage)) OVER (PARTITION BY external_account_id ORDER BY date) AS prev_day_usage
FROM
  `marketplace_report.insights`
WHERE
  _PARTITIONDATE >= DATE_SUB(CURRENT_DATE(), INTERVAL 7 DAY)
GROUP BY
  company, external_account_id, date
HAVING
  total_usage < prev_day_usage * 0.5  -- 利用量が前日比50%以下に低下
ORDER BY
  date DESC;

🔧 設定方法

✅ 自動適用: 今回のアップデートはパートナー側での設定変更を必要としません。既存のレポート配信設定が自動的に D+1 スケジュールに移行されます。

推奨設定

Step 1: レポート配信状況の確認

URL 
https://console.cloud.google.com/producer-portal/partner-report?project=YOUR_PUBLIC_PROJECT_ID

Step 2: Incremental Insights レポートの有効化 (推奨)

BigQuery Export が有効な場合は自動的に有効。CSV Export の場合は Producer Portal で "Customer incremental insights" チェックボックスを有効にする。

Step 3: レポート通知の設定 (推奨)

Bash 
# Essential Contacts API を有効化
gcloud services enable essentialcontacts.googleapis.com --project=YOUR_PROJECT_ID

レポートの遅延や再生成が発生した場合に通知を受け取るための設定です。

💡 ユースケース

🖥️ ユースケース 1: SaaS パートナーの顧客利用状況モニタリング

シナリオ: SaaS 製品を Cloud Marketplace で提供するパートナーが、顧客の日次利用状況をモニタリングし、利用量の急激な変化を検知してカスタマーサクセスチームに通知する。

効果: 以前は D+2 の遅延により顧客の利用量低下に気づくまでに最短 3 日 (利用日 + D+2) かかっていたが、D+1 により最短 2 日で検知可能に。

📊 ユースケース 2: VM 製品パートナーの収益ダッシュボード

シナリオ: VM ベースの製品を提供するパートナーが、リアルタイムに近い収益ダッシュボードを運用し、経営陣にデイリーレポートを提供する。

効果: ダッシュボードのデータ鮮度が 1 日改善され、前日までの収益状況をより正確に把握可能に。経営判断のスピード向上と四半期目標の進捗追跡がより正確に。
