📋 概要

Google SecOps Marketplace のレスポンスインテグレーションに 9 件の更新が公開されました。新機能 (Feature) は 2 件で、SAP ERP インテグレーション (v1.0) の新規追加と、Google Threat Intelligence (v23.0) への新アクション「Ask Threat Intelligence Agent」の追加です。残り 7 件は既存インテグレーションの修正・改善 (Changed) です。

SAP ERP インテグレーションの追加により、Google SecOps SOAR から SAP ERP を対象としたオーケストレーションが可能になり、基幹業務システムである SAP をセキュリティ運用のレスポンス対象に組み込めるようになります。修正系の更新には、Microsoft Graph Mail 系コネクタの無限再処理ループ防止や、Chronicle Alerts Connector の取り込み停止問題の修正など、アラート取り込みの信頼性に直結する改善が含まれており、該当インテグレーションを運用中の組織はバージョン更新が推奨されます。

❌ Before: アップデート前の課題

  • SAP ERP 向けレスポンスインテグレーションが存在せず、SAP を対象とした SOAR オーケストレーションができなかった
  • GTI に Threat Intelligence エージェントへ問い合わせるアクションがなかった
  • Microsoft Graph Mail / Delegated コネクタで、オーバーフローアラートが ID 未保存・未読のままスキップされ、無限再処理ループ・状態喪失が発生し得た
  • Chronicle Alerts Connector で、複合検出の読み込み失敗やページネーション停滞時にアラート取り込みが停止することがあった
  • Tools「Get Integration Instances」でアンパサンド (&) を含む環境名が正しくフィルタリングされなかった
  • Wiz の双方向同期ジョブで、クローズ理由マッピングに不具合があった
  • M365 Defender「Execute Custom Query」に時間範囲の絞り込みパラメータがなかった

✅ After: アップデート後の改善

  • SAP ERP インテグレーション (v1.0) が新規追加され、SOAR から SAP ERP を連携対象にできるようになった
  • GTI (v23.0) に「Ask Threat Intelligence Agent」アクションが追加された
  • Microsoft Graph Mail (v50.0) / Delegated (v27.0) でオーバーフローアラートの ID 保存・既読化が行われ、無限再処理ループと状態喪失を防止
  • Google Chronicle (v99.0) で、複合検出の読み込み失敗やページネーション停滞時にも取り込みが止まらないよう修正
  • Okta (v19.0) で OAuth 認証スコープが更新され、ユーザー管理系アクションをサポート
  • M365 Defender (v34.0) に Time Frame / Start Time / End Time パラメータが追加され、時間ベースのクエリフィルタリングが可能に

⭐ 主要機能

🏢 1. SAP ERP インテグレーション v1.0 の新規追加 Feature

→Google SecOps Marketplace に SAP ERP 向けインテグレーションが Version 1.0 として登場
→SAP を利用する組織が、Google SecOps SOAR のプレイブックから SAP ERP を連携対象にできるようになる
→SIEM 側の「Google SecOps for SAP」(Preview、SAP ログの取り込み・検出) と組み合わせることで、SAP 環境の「検出から対応まで」をカバーする構成に近づく
→レポート作成時点では、個別ドキュメント (アクション一覧・設定パラメータ) は未公開

💬 2. GTI v23.0:「Ask Threat Intelligence Agent」アクション追加 Feature

→Google Threat Intelligence インテグレーションに新アクション「Ask Threat Intelligence Agent」が追加
→プレイブックや手動アクションから Threat Intelligence エージェントへの問い合わせを組み込めるようになる
→本アクションの詳細パラメータはレポート作成時点で公式ドキュメント未反映

📧 3. Microsoft Graph Mail / Delegated: オーバーフローアラート処理の修正 Changed

→両コネクタ (v50.0 / v27.0) で、オーバーフローしたアラートが ID を保存せず・メールを既読にせずスキップされる問題を修正
→同じメールが繰り返し再処理される無限ループや、コネクタの状態 (処理済み ID) の喪失を防止

🔍 4. Google Chronicle v99.0: Alerts Connector の取り込み停止問題を修正 Changed

→複合検出 (composite detections) の読み込み失敗や、ページネーションが進行しない場合に、アラート取り込みが停止し得る問題を修正
→SecOps SIEM のアラートを SOAR ケースへ取り込む基幹コネクタのため、取り込み欠落リスクの低減に直結

🧩 5. その他の改善 Changed

→Tools v85.0:「Get Integration Instances」でアンパサンド (&) を含む環境名のフィルタリングを修正。MSSP などで記号を含む環境名を使用している場合に影響
→Wiz v11.0: 双方向同期ジョブのクローズ理由マッピングを修正し、Add Comment To Issue、Get Blue Agent Analysis、Get Issue Details、Ignore Issue、List Resource Vulnerability Findings、Reopen Issue、Resolve Issue の定義済みウィジェットを更新
→Okta v19.0: OAuth 認証スコープを更新し、ユーザー管理アクションに対応
→Microsoft 365 Defender v34.0:「Execute Custom Query」に Time Frame / Start Time / End Time パラメータを追加し、時間ベースのクエリフィルタリングに対応

💡 メリット

💼 ビジネス面

✓SAP 環境のセキュリティ対応を SOC に統合: 基幹システムである SAP を SOAR のプレイブックに組み込めるようになり、SAP 固有の運用チームに依存しないインシデント対応が可能になる
✓アラート欠落・重複対応の削減: メール系コネクタと Chronicle Alerts Connector の修正により、アラートの取りこぼしや同一メールの重複処理が防止され、SOC 運用の信頼性が向上する

🔬 技術面

✓エージェントへの問い合わせをプレイブックに組み込み可能:「Ask Threat Intelligence Agent」アクションにより、GTI のエージェントへの問い合わせを自動化フローの一部として実行できる
✓コネクタ状態管理の堅牢化: オーバーフローアラートの ID 保存・既読化により、コネクタ再起動や高負荷時でも処理状態が維持される
✓時間指定クエリ: M365 Defender の Execute Custom Query で対象期間を明示的に指定でき、クエリ結果の再現性とパフォーマンスが向上する

⚠️ デメリット・制約事項

🚧 制限事項

✗SAP ERP インテグレーション (v1.0) の個別ドキュメント (アクション一覧・パラメータ) はレポート作成時点で未公開
✗「Ask Threat Intelligence Agent」アクションの詳細パラメータもレポート作成時点でドキュメント未反映
✗修正・新機能を利用するには、各インテグレーションを今回のバージョンへ更新する必要がある

🤔 考慮すべき点

→Okta v19.0: OAuth 認証スコープが更新されているため、OAuth 認証を使用している場合はスコープ設定 (Okta 側のアプリケーション設定) の見直しが必要になる可能性がある
→Wiz v11.0: クローズ理由マッピングの挙動が修正されているため、双方向同期ジョブを運用している場合はクローズ理由の同期結果の確認を推奨
→メール系コネクタ: 修正は「オーバーフロー時」の挙動変更のため、オーバーフローが頻発している場合は Max Emails/Alerts 系パラメータの設定自体の見直しも検討する

🎯 ユースケース

🏢 ユースケース 1: SAP を含むインシデント対応プレイブックの構築

シナリオ: SAP ERP を基幹システムとして運用する企業の SOC が、SAP に関連する不審なアクティビティの検出後、SOAR プレイブックで SAP 側の情報確認や対応を自動化したい。

Text 実装例 
1. Content Hub から SAP ERP インテグレーション (v1.0) をインストール
2. SAP ERP インスタンスを構成
3. 既存のインシデント対応プレイブックに SAP ERP のアクションを追加
✨ 効果: SAP 環境をセキュリティ対応フローに直接組み込めるようになり、SAP チームへの手動エスカレーションに依存した対応時間を短縮できる。

💬 ユースケース 2: プレイブックからの脅威インテリジェンス問い合わせ

シナリオ: アナリストがケース調査の過程で、Google Threat Intelligence のエージェントに追加の調査質問を行いたい。従来は GTI のコンソールに切り替えて調査していた。

Text 実装例 
Google Threat Intelligence インテグレーションを v23.0 に更新し、
プレイブックまたは手動アクションとして「Ask Threat Intelligence Agent」を実行
✨ 効果: ケース対応の文脈から離れずに Threat Intelligence エージェントへの問い合わせを実行でき、調査のコンテキストスイッチを削減できる。

📧 ユースケース 3: メールアラート取り込みの安定化

シナリオ: Microsoft Graph Mail Connector でフィッシング報告メールボックスを監視しているが、高負荷時にオーバーフローしたアラートが再処理ループに陥り、同じメールが繰り返し処理されていた。

✨ 効果: v50.0 (Delegated は v27.0) への更新により、オーバーフローアラートの ID が保存され、メールが既読化されるため、無限再処理ループと状態喪失が防止される。

🔗 関連サービス・機能

🏢 Google SecOps for SAP (SIEM 側、Preview)

SAP の Security Audit Log や Change Documents などを Google SecOps SIEM に取り込み、キュレーション済み YARA-L ルールで検出する機能。今回の SOAR 向け SAP ERP インテグレーションと組み合わせることで、SAP 環境の検出から対応までをカバーできる。

🌐 Google Threat Intelligence

「Ask Threat Intelligence Agent」が追加されたインテリジェンスソース。エンティティエンリッチメントや IOC 調査、ダークウェブアラートの取り込み (GTI Alerts Connector) などを提供。

🔍 Google Chronicle - Chronicle Alerts Connector

Google SecOps SIEM のアラートを SOAR ケースに取り込む基幹コネクタ。今回の修正で複合検出関連の取り込み停止リスクが低減された。
