🤖 Gemini Enterprise Agent Platform:
Supervised Fine-tuning アップデート

Vertex AI Preview Supervised Fine-tuning Multimodal
2026-05-20

📋 概要

Gemini Enterprise Agent Platform の Supervised Fine-tuning に 2 つの重要なアップデートが追加されました。

🆕 Gemini 3.1 Flash Lite 対応

最もコスト効率の高い Gemini モデルに対する Supervised Fine-tuning が Preview として利用可能に。低レイテンシかつ低コストなモデルでドメイン固有のカスタマイズが実現。

🎯 Part-level mediaResolution

ファインチューニングデータセットにおいて Part ごとの解像度制御が可能に。MEDIA_RESOLUTION_ULTRA_HIGH を含む細粒度の設定をサポート。

🧠 ポイント: マルチモーダルなファインチューニングのユースケースを大幅に拡張し、コスト最適化とモデル品質の両立を実現するアップデートです。

🔄 Before / After 比較

❌ Before (アップデート前)

  • Gemini 3.1 Flash Lite に対して Supervised Fine-tuning を実行できなかった
  • メディア解像度はデータセット全体で統一する必要があった
  • MEDIA_RESOLUTION_ULTRA_HIGH はファインチューニングで利用不可
  • 高解像度/低解像度が混在するデータセットではトークンコストが増大

✅ After (アップデート後)

  • Gemini 3.1 Flash Lite の Supervised Fine-tuning が us-central1 / europe-west4 で実行可能
  • Part-level で mediaResolution を宣言でき、画像ごとに異なる解像度を設定可能
  • MEDIA_RESOLUTION_ULTRA_HIGH (2240 トークン) が Part-level でサポート
  • 推論は us / eu マルチリージョンエンドポイントで提供

⚙️ 主要機能

🚀 Gemini 3.1 Flash Lite の Supervised Fine-tuning (Preview)

  • モデル: gemini-3.1-flash-lite
  • チューニングリージョン: us-central1 / europe-west4
  • 推論エンドポイント: us / eu マルチリージョン
  • マルチモーダル対応: テキスト、画像、音声、動画、ドキュメント

🎛️ Part-level mediaResolution 宣言

  • 個々の Part ごとに mediaResolution を設定可能
  • 対象: 画像、動画、PDF
  • 従来のグローバル設定に加え、Part 単位の細粒度制御が可能
  • MEDIA_RESOLUTION_ULTRA_HIGH レベルが利用可能

🔬 MEDIA_RESOLUTION_ULTRA_HIGH

  • 画像に対して最大 2240 トークンを割り当て
  • スクリーン録画の静止画、高解像度写真の分析に最適
  • Part-level 宣言でのみ使用可能 (グローバル設定では不可)

💻 設定方法

Part-level mediaResolution の設定例

JSON Part-level mediaResolution 宣言 
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "fileData": {
            "mimeType": "image/jpeg",
            "fileUri": "gs://my-bucket/high-detail-image.jpeg"
          },
          "mediaResolution": {
            "level": "MEDIA_RESOLUTION_ULTRA_HIGH"
          }
        },
        {
          "fileData": {
            "mimeType": "image/jpeg",
            "fileUri": "gs://my-bucket/context-image.jpeg"
          },
          "mediaResolution": {
            "level": "MEDIA_RESOLUTION_LOW"
          }
        },
        {
          "text": "Compare the details in these two images."
        }
      ]
    }
  ]
}

チューニングジョブの作成 (REST API)

Bash curl でチューニングジョブを作成 
curl -X POST \
  "https://us-central1-aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/us-central1/tuningJobs" \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  -d '{
    "baseModel": "gemini-3.1-flash-lite",
    "supervisedTuningSpec": {
      "trainingDatasetUri": "gs://my-bucket/train.jsonl",
      "validationDatasetUri": "gs://my-bucket/validation.jsonl"
    },
    "tunedModelDisplayName": "my-tuned-flash-lite"
  }'

✅ メリット

💼 ビジネス面

コスト最適化: Flash Lite は最もコスト効率の高いモデル。ファインチューニングにより高価なモデルに匹敵する特化性能を低コストで実現。

柔軟なトークンコスト管理: Part-level mediaResolution により重要な画像のみ高解像度を割り当て、全体コストを最適化。

EU データレジデンシ対応: europe-west4 チューニング + eu エンドポイント推論で EU データレジデンシ要件に対応。

🔧 技術面

細粒度の解像度制御: 同一データセット内で異なるメディアに異なる解像度を設定。品質とコストのトレードオフを最適化。

ULTRA_HIGH 解像度: 2240 トークンにより OCR や細かいディテール認識など高精度タスクのチューニング品質が向上。

低レイテンシ推論: Flash Lite ベースのチューニング済みモデルは高速推論でリアルタイムアプリケーションに最適。

⚠️ デメリット・制約事項

制限事項:
  • Preview (限定サポート) であり、SLA の対象外
  • チューニングリージョンは us-central1 と europe-west4 のみ
  • 推論は us / eu マルチリージョンエンドポイントのみ
  • ULTRA_HIGH は画像の Part-level 宣言でのみ利用可能 (動画・PDF 非対応)
  • 動画チューニングの最大ファイルサイズは 100MB
  • 動画の最大長: MEDIUM で 5 分、LOW で 20 分
💡 考慮すべき点:
  • Preview 期間中は機能変更や制限追加の可能性あり
  • アジア太平洋リージョンは現時点で非対応
  • controlled generation との組み合わせで品質低下の可能性
  • チューニング済みモデルでは thinking 予算をオフまたは最低値に設定推奨

🎯 ユースケース

📄 高精度ドキュメント分析

シナリオ: 金融機関が契約書や報告書のスキャン画像から重要情報を抽出。細かい文字やロゴの認識が必要な画像は ULTRA_HIGH、全体レイアウト確認のみは LOW を設定。

効果: トークンコストを抑えつつ、重要部分のみ最高解像度で学習。コスト効率と精度を両立した専用モデルを構築。

🛒 カスタマーサポート自動化

シナリオ: EC サイトが商品画像と顧客問い合わせに基づく自動回答チャットボットを Flash Lite ベースで構築。大量リクエストを低コストで処理。

効果: 推論コストを大幅に削減しつつ、ドメイン固有の知識 (商品カタログ、返品ポリシーなど) を学習した高品質な応答を実現。

💰 料金

Supervised Fine-tuning の料金はトレーニングトークン数に基づいて計算されます。トレーニングトークン数 = データセット内トークン数 x エポック数。

チューニング後の推論コストは、各安定版 Gemini モデルと同一の料金が適用されます。

📎 詳細: Gemini Enterprise Agent Platform の料金ページを参照。
