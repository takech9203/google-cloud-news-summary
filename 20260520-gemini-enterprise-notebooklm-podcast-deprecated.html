🎙️ Podcast API の非推奨化

Gemini Enterprise NotebookLM Enterprise Deprecated
2026-05-20

📋 概要

Google Cloud は、NotebookLM Enterprise の Podcast API を非推奨 (Deprecated) としました。今後、新規顧客へのアローリスト追加は行われず、新たな利用開始は不可能となります。

Podcast API は、ソースドキュメントに基づいてポッドキャスト形式の音声コンテンツを自動生成する API であり、NotebookLM Enterprise ノートブックや Gemini Enterprise ライセンスなしで、バッチ処理として大量にポッドキャストを生成できることが特徴でした。

⚠️ 重要: 既存のアローリスト顧客にも将来的な影響を与える可能性があるため、早期の移行計画の策定が推奨されます。

❌ アップデート前

  • Podcast API でスタンドアロンでポッドキャスト生成可能
  • テキスト/画像/音声/動画入力 → MP3 出力
  • バッチ処理での大量コンテンツ変換が可能
  • ノートブック・ライセンス不要

→ アップデート後

  • 新規顧客はアローリスト追加不可
  • Podcast API の新規利用が不可能に
  • 既存顧客も将来的な移行が必要
  • 代替: Audio Overview API (v1alpha) または NotebookLM UI

📝 非推奨化の詳細

🚫 新規アローリスト追加の停止

Google は新規顧客をアローリストに追加しない方針を決定。既存のアローリスト顧客への即時的な影響は現時点では未発表。

⚙️ Podcast API の特徴 (非推奨前)

→スタンドアロン API として動作 (ノートブック、ライセンス、データストア不要)
→Discovery Engine API の有効化と roles/discoveryengine.podcastApiUser ロールのみが必要
→テキスト、画像、音声、動画を含むマルチモーダル入力に対応
→入力コンテンツの合計は 100,000 トークン未満が条件

🎵 出力仕様

→MP3 形式でのポッドキャスト出力
→SHORT (4-5分) または STANDARD (約10分) の長さ指定が可能
→BCP47 言語コードによる多言語対応

非推奨: Podcast API (今後利用不可)

Bash 
# 今後利用不可となる API 呼び出し
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  "https://discoveryengine.googleapis.com/v1/projects/PROJECT_ID/locations/global/podcasts" \
  -d '{
    "podcastConfig": {
      "focus": "FOCUS_TOPIC",
      "length": "SHORT",
      "languageCode": "ja"
    },
    "contexts": [
      { "text": "TEXT_CONTENT" }
    ],
    "title": "PODCAST_TITLE",
    "description": "PODCAST_DESCRIPTION"
  }'

代替: Audio Overview API (v1alpha)

Bash 
# Audio Overview API の呼び出し例
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  "https://ENDPOINT_LOCATION-discoveryengine.googleapis.com/v1alpha/projects/PROJECT_NUMBER/locations/LOCATION/notebooks/NOTEBOOK_ID/audioOverviews" \
  -d '{
    "sourceIds": [{ "id": "SOURCE_ID" }],
    "episodeFocus": "EPISODE_FOCUS",
    "languageCode": "ja"
  }'
⚠️ 注意: Audio Overview API は現在 Preview ステータスであり、Pre-GA Offerings Terms が適用されます。SLA の保証はありません。

🔄 移行ガイダンス

代替手段 1: Audio Overview API (v1alpha)

ノートブックに関連付けられた音声オーバービューを生成する API。Podcast API とは異なり、ノートブックとデータソースの事前準備が必要ですが、類似した音声コンテンツ生成機能を提供します。

1
NotebookLM Enterprise ノートブックを作成

Gemini Enterprise ライセンスが必要

2
データソースを追加

ノートブックにソースコンテンツを登録

3
Audio Overview API を呼び出し

v1alpha エンドポイントで音声オーバービューを生成

4
出力を取得 (WAV/MP4)

ノートブックごとに1つの音声オーバービューのみ保持可能

代替手段 2: NotebookLM Enterprise UI

💡 手動生成: エンドユーザー向けの NotebookLM Enterprise UI からは、引き続きポッドキャスト/音声オーバービューの手動生成が可能です。バッチ処理には不向きですが、少量のコンテンツ生成には有効です。

移行時の考慮事項

⚠️Audio Overview API はノートブックごとに1つの音声オーバービューのみ保持可能
⚠️Audio Overview API は v1alpha であり、今後の仕様変更の可能性あり
⚠️バッチ処理のワークフローの再設計が必要 (ノートブック作成→ソース追加→音声生成→削除)

⚠️ デメリット・制約事項

影響を受けるユースケース

❌大量の書籍・記事に対するバッチポッドキャスト生成
❌ノートブック不要のスタンドアロンでのポッドキャスト生成
❌Gemini Enterprise ライセンスなしでの音声コンテンツ生成

考慮すべき点

→既存の Podcast API ベースのワークフローは将来的に完全に停止する可能性
→Audio Overview API は Preview であり、SLA の保証がない
→移行にはノートブックとデータソースの管理が追加で必要
→バッチ処理自動化には追加ステップ (ノートブック作成/ソース追加/音声生成/削除) が必要

🎯 ユースケース (影響分析)

📚 ユースケース 1: 教育コンテンツのバッチ生成

シナリオ: 教育機関が数百のコース教材からポッドキャストを自動生成

影響: 自動化パイプラインは新規構築不可。既存利用者も将来的に移行が必要。

代替: Audio Overview API を使用する場合、各コース教材ごとにノートブックを作成し、ソースを追加した上で音声オーバービューを生成する必要あり。ワークフローが複雑化。

📰 ユースケース 2: メディア企業の記事音声化

シナリオ: メディア企業が記事をポッドキャスト形式に変換してリスナーに配信

影響: スタンドアロンで利用できた Podcast API が使えなくなり、NotebookLM Enterprise のフル構成が必要に。

代替: NotebookLM Enterprise ライセンスの取得、ノートブック管理の実装、Audio Overview API の活用を組み合わせた新しいパイプラインの構築が必要。
