⚡ 主要機能

📐 Mermaid Chart データストア

Mermaid Chart からダイアグラムをレンダリングおよび検索可能。Mermaid コードを使用したダイアグラムの直接取得に対応。

→エンティティタイプ: Diagrams
→用途: 技術文書の可視化

🔗 Blockscout データストア

複数のブロックチェーンネットワークにわたる深層ブロックチェーン分析を実行可能。パブリックブロックチェーンデータへのアクセスを提供。

→エンティティタイプ: Blockchain entities
→用途: オンチェーン分析

🧬 Open Targets データストア

Open Targets Platform からの薬剤・ターゲット・疾患データの検索および取得が可能。創薬研究のためのデータアクセスを統合。

→エンティティタイプ: Drugs, Targets, Diseases
→用途: 医薬品研究

🌐 Apollo GraphOS MCP Tools データストア

Apollo GraphOS の仕様およびドキュメントへの直接アクセスを提供。MCP (Model Context Protocol) ツールとしての統合。

→エンティティタイプ: GraphQL specifications
→用途: API 管理

→Data セクションで検索対象のエンティティを選択

Step 3: 構成の設定

→Multi-region リストからロケーションを選択 (Global / US / EU)

→Billing セクションで General pricing を選択して Create をクリック
→状態が Creating から Active に変わるまで待機

Step 5: アプリへの接続

→既存のアプリにデータストアを接続、または新しいアプリを作成して接続

⚠️ デメリット・制約事項

制限事項
✗Public Preview 段階 - サポートが限定的、Pre-GA Offerings Terms が適用
✗VPC Service Controls を既存データストアに適用するには削除・再作成が必要
✗対応ロケーションは Global, US, EU のみ
✗フェデレーション方式のため検索品質がインジェスト方式より低い可能性
セキュリティ上の考慮点
!クエリ文字列がサードパーティの検索バックエンドに送信される
!LLM クエリ書き換えでセッション履歴の一部がサードパーティに送信される可能性
!複数フェデレーテッドデータソースが有効な場合、全データソースにクエリが送信される可能性
!サードパーティに到達したデータはそのシステムの利用規約に準拠

💡 ユースケース

📐 技術文書とアーキテクチャ図の統合検索

シナリオ: エンジニアリングチームが技術文書作成時に、Mermaid Chart のアーキテクチャ図と Apollo GraphOS の API スキーマ情報を同時に検索し、整合性のあるドキュメントを作成。

効果: 複数のツールを切り替えることなく、Gemini Enterprise 上で必要な情報を統合的に取得でき、ドキュメント作成の効率が向上。

🔗 ブロックチェーンプロジェクトのデータ分析

シナリオ: Web3 開発チームが Blockscout コネクタを使用して、複数のブロックチェーンネットワークにわたるトランザクションデータやスマートコントラクトの情報を直接分析。

効果: 個別のブロックチェーンエクスプローラーにアクセスすることなく、統合インターフェースからオンチェーンデータを検索・分析。

🧬 創薬研究における標的探索

シナリオ: 製薬企業の研究者が Open Targets コネクタを使用して、特定の疾患に関連する薬剤ターゲットや既存薬剤の情報を社内データソースと組み合わせて検索。

効果: Open Targets Platform のデータと社内リサーチデータを統合的に検索でき、創薬研究の意思決定が迅速化。

💰 料金

料金体系: General pricing (従量課金制) が適用されます。データストア作成時に Billing セクションで General pricing を選択する必要があります。

詳細な料金情報については、Gemini Enterprise の料金ページおよびライセンス情報を参照してください。
