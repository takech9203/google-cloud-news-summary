📋 概要

Gemini Enterprise Agent Platform において、Gemini 3.1 Flash Image (コードネーム: Nano Banana 2) と Gemini 3 Pro Image (コードネーム: Nano Banana Pro) が GA (一般提供) となった。テキストと画像の両方を入出力として扱えるマルチモーダル画像生成モデルであり、高品質な画像生成・編集・テキストレンダリングが可能である。

さらに 4K (4096x4096) 解像度での画像出力を Preview としてサポート。Gemini 3.1 Flash Image は動画入力 (Preview) にも対応し、動画からサムネイルや代表画像を生成するユースケースが新たに可能となった。加えて Anthropic の Claude Opus 4.8 が Model Garden に追加された。

❌ Before

  • 両モデルは Preview 段階で SLA 保証なし
  • 最大 2K (2048x2048) 解像度に限定
  • 動画を直接入力してサムネイル自動生成が不可
  • Claude 最新モデルは Agent Platform 上で利用不可

✅ After

  • GA となり SLA に基づいた本番利用が可能
  • 4K (4096x4096) 出力が Preview で利用可能
  • 動画から直接サムネイル・代表画像を生成
  • Claude Opus 4.8 が Model Garden で利用可能

💻 API 呼び出し例

4K 画像生成のコード例。統合 generateContent API で画像生成・編集・テキスト生成を一貫して実行可能。

Python 4K 画像生成の例 
from google import genai
from google.genai.types import GenerateContentConfig, Modality

client = genai.Client()

# 4K 画像生成の例
response = client.models.generate_content(
    model="gemini-3.1-flash-image",
    contents="東京タワーの夜景を幻想的な雰囲気で生成してください",
    config=GenerateContentConfig(
        response_modalities=[Modality.TEXT, Modality.IMAGE],
        response_format={
            "image": {
                "aspect_ratio": "16:9",
                "image_size": "4K",
            }
        },
    ),
)

for part in response.candidates[0].content.parts:
    if part.text:
        print(part.text)
    elif part.inline_data:
        # 画像データを保存
        with open("output.png", "wb") as f:
            f.write(part.inline_data.data)

ステップ 3: テキスト+画像インターリーブ出力

Python インターリーブ出力例 
from google import genai
from google.genai.types import GenerateContentConfig, Modality
from PIL import Image
from io import BytesIO

client = genai.Client()

# テキストと画像のインターリーブ出力
response = client.models.generate_content(
    model="gemini-3-pro-image",
    contents="料理レシピをステップごとに画像付きで説明してください",
    config=GenerateContentConfig(
        response_modalities=[Modality.TEXT, Modality.IMAGE],
    ),
)

for i, part in enumerate(response.candidates[0].content.parts):
    if part.text:
        print(part.text)
    elif part.inline_data:
        image = Image.open(BytesIO(part.inline_data.data))
        image.save(f"step-{i}.png")

⚠️ デメリット・制約事項

制限事項
  • 4K 出力は Preview 段階であり、SLA の対象外
  • 動画入力は Gemini 3.1 Flash Image のみのサポートで Preview 段階
  • Function Calling、Code Execution、ファインチューニング、コンテキストキャッシュが非サポート
  • 出力画像数は 32,768 出力トークンの制約を受ける
  • 安全でないコンテンツと判断された場合、画像生成が拒否される

考慮すべき点

⚡画像生成あたりのトークン消費量が大きい (Flash Image で最大 2,520 トークン) ため、コスト計画に注意
⚡Gemini 3 Pro Image の推奨言語は限定的 (ja-JP を含む 15 言語)
⚡複数画像の生成数は正確にコントロールできない場合がある
⚡テキストを含む画像生成時は、先にテキストを生成してから画像に組み込むプロンプト設計が推奨

🎬 動画コンテンツのサムネイル自動生成

シナリオ: 動画配信プラットフォームで、アップロードされた動画からクリック率の高いサムネイル画像を自動生成。

効果: 動画コンテンツの公開までのリードタイムを短縮し、視聴者の注目を集めるサムネイルを効率的に生成。

Python 動画サムネイル生成 
import base64

# 動画ファイルを読み込み
with open("video.mp4", "rb") as f:
    video_data = base64.b64encode(f.read()).decode()

response = client.models.generate_content(
    model="gemini-3.1-flash-image",
    contents=[
        {"mime_type": "video/mp4", "data": video_data},
        "この動画から最もインパクトのあるシーンを選び、"
        "YouTubeサムネイルとして適した画像を生成してください"
    ],
    config=GenerateContentConfig(
        response_modalities=[Modality.IMAGE],
        response_format={"image": {"aspect_ratio": "16:9", "image_size": "2K"}},
    ),
)
