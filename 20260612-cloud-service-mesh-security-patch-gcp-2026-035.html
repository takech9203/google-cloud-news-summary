🛡️ Cloud Service Mesh: セキュリティパッチロールアウト

Cloud Service Mesh 深刻度: 高 ロールアウト中
2026-06-12

📋 概要

Google Cloud は Managed Cloud Service Mesh の全リリースチャネルに対して、セキュリティパッチを含む新しいサイドカープロキシバージョンのロールアウトを開始しました。 このロールアウトは、CVE-2026-47774 (セキュリティ速報 GCP-2026-035) への修正を含む緊急対応です。

🚨 脆弱性の概要: Envoy の HTTP/2 ダウンストリームリクエスト処理における脆弱性で、認証されていないリモートクライアントが過剰なメモリ消費を引き起こし、Envoy プロセスの OOM (Out of Memory) 終了とサービス拒否 (DoS) を発生させる可能性があります。

Before / After 比較

❌ Before (パッチ適用前)

  • HTTP/2 リクエストを介した DoS 攻撃のリスクが存在
  • 認証不要でリモートクライアントが Envoy の OOM を引き起こせる
  • 6月3日予定の通常ロールアウトでは脆弱性修正が含まれない
  • 全バージョンの Cloud Service Mesh に影響

✅ After (パッチ適用後)

  • CVE-2026-47774 が修正され、HTTP/2 DoS 攻撃リスクが解消
  • Managed CSM ユーザーは自動パッチ適用で手動対応不要
  • 全リリースチャネルに同時ロールアウトで迅速な修正展開
  • Gateway API 向け Security Proxy も同時更新

🔧 設定方法

Managed Cloud Service Mesh (自動適用)

✅ 対応不要: Managed Cloud Service Mesh を利用している場合、パッチは自動的にロールアウトされるため、ユーザー側での操作は不要です。
Bash 
# 現在のサイドカーバージョンを確認
kubectl get pods -n <NAMESPACE> -o jsonpath='{.items[*].spec.containers[?(@.name=="istio-proxy")].image}'

# 名前空間のリリースチャネルを確認
kubectl get namespace <NAMESPACE> -o jsonpath='{.metadata.labels.istio\.io/rev}'

In-cluster Cloud Service Mesh (手動アップグレード)

⚠️ 手動対応必要: インクラスタ版を利用している場合は、手動でのアップグレードが必要です。
Bash 
# パッチ済みバージョンへのアップグレード
# v1.28 系: 1.28.7-asm.4 へ更新
# v1.27 系: 1.27.9-asm.5 へ更新
# v1.26 系: 1.26.8-asm.11 へ更新
# 公式ドキュメントのアップグレード手順に従ってください

ロールアウト状況の確認

Bash 
# Pod のサイドカーバージョンを確認
kubectl get pods -n <NAMESPACE> -o json | \
  jq '.items[] | {name: .metadata.name, proxy: (.spec.containers[] | select(.name=="istio-proxy") | .image)}'

# ロールアウトの進行状況を確認 (Pod の再起動状態)
kubectl get pods -n <NAMESPACE> -w

✓Gateway API 向け Security Proxy も同時更新で包括的な保護を実現

デメリット・制約事項

!ロールアウト中は Pod の再起動が発生し、一時的な接続断が発生する可能性
!In-cluster CSM (v1.25 以前) は EOL のため CVE 修正がバックポートされず、v1.26 以降へのアップグレードが必須
!全クラスタへの適用完了まで数日を要する場合がある
!6月3日告知の通常ロールアウトが今回のセキュリティパッチに置き換えられる

💡 ユースケース

🚨 即座に対応が必要

公開 HTTP/2 エンドポイント: 攻撃者が直接リクエストを送信できるため、最優先でパッチ適用を確認

マルチテナント環境: テナント間でのリソース枯渇攻撃を防止

☁️ Managed CSM 利用中

対応不要: 自動ロールアウトにより段階的にパッチ適用

確認推奨: ロールアウト完了後にサイドカーバージョンを検証

🔧 In-cluster CSM 利用中

手動アップグレード必須: v1.28.7-asm.4 / v1.27.9-asm.5 / v1.26.8-asm.11 への更新が必要

v1.25 以前: サポート終了のため v1.26 以降への移行が必須

💰 料金

💡 追加料金なし: Cloud Service Mesh のセキュリティパッチ適用に追加料金は発生しません。Cloud Service Mesh は GKE Enterprise のコンポーネントとして提供されており、GKE Enterprise の料金に含まれます。

🌍 利用可能リージョン

Managed Cloud Service Mesh がサポートされている全リージョンでロールアウトが行われます。ロールアウトは段階的に展開されるため、リージョンによって適用タイミングが異なる場合があります。

📝 まとめ

今回のロールアウトは、CVE-2026-47774 (Envoy HTTP/2 DoS 脆弱性、深刻度: 高) に対するセキュリティパッチを全リリースチャネルに展開するものです。

✓Managed CSM: 自動パッチ適用。ユーザー操作不要
!In-cluster CSM: 速やかに対象バージョンへのアップグレードを実施
✓Gateway API: Security Proxy も合わせて更新、メッシュ全体のセキュリティを包括的に強化
