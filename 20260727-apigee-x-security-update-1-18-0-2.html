📋 概要

2026 年 7 月 27 日、Apigee の更新バージョン 1-18-0-apigee-2 がリリースされました。 本リリースはセキュリティ修正を中心としたアップデートで、Java Callout ポリシーのセキュリティ問題の修正 (Bug ID: 534852923) と、 Apigee インフラストラクチャに対するセキュリティ修正が含まれます。

Java Callout ポリシーは、Apigee の標準ポリシーではカバーできないカスタムロジックを Java コードで実装するための機能であり、 API プロキシフロー内でユーザー提供の JAR を実行する仕組みです。 適用のための操作は不要で、Google 側のロールアウトにより自動的に反映されます。
