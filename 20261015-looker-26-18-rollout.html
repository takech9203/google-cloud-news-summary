📝 概要

2026 年 10 月 15 日、Looker (Google Cloud core) インスタンスに対して Looker 26.18 の機能有効化が開始されました。 26.18 のバイナリ自体は 2026 年 9 月 29 日から Rapid / No Channel チャネルへの展開が始まっていましたが、 今回のアナウンスにより 26.18 で導入された新機能が順次利用可能になります。

Looker 26.18 は、ClickHouse 26+ と Dremio 26.0+ (Arrow Flight SQL) の新ダイアレクト対応、 AI 支援機能「Starter questions」の GA、LookML リポジトリの診断・修復ツール、 CI の Style Validator、Conversational Analytics のスケジュール型エージェントワークフロー (Preview)、 Looker Data Apps (Preview) など、AI・開発者体験の両面で多くの機能強化を含むリリースです。

Looker (original) インスタンスでは 2026 年 10 月 5 日から 26.18 機能の自動有効化が先行して開始されており、 今回が Looker (Google Cloud core) 向けの正式な有効化開始の発表にあたります。

❌ Before (アップデート前の課題)
  • 26.18 の新機能は Looker (original) では 2026-10-05 から有効化が始まっていた一方、Looker (Google Cloud core) では未有効だった
  • Looker (Google Cloud core) ではバイナリ展開 (9/29 開始) と機能有効化のタイミングが分離されており、新機能を利用できなかった
✅ After (アップデート後の改善)
  • Looker (Google Cloud core) インスタンスでも 26.18 の新機能 (新ダイアレクト対応、AI 機能、開発ツール群) が順次利用可能に
  • Looker (original) と Looker (Google Cloud core) の両プラットフォームで 26.18 の機能セットが揃う

⚡ Looker 26.18 の主要機能

公式リリースノート (2026 年 10 月 9 日付) で確認できる、Looker (Google Cloud core) と Looker (original) の両方に適用される主な機能です。

🗄️ ClickHouse 26+ ダイアレクト対応 NEW
  • 近代化された JDBC ドライバーを使用する ClickHouse 26 以降への接続をサポート
  • 対称集計 (symmetric aggregates) に対応
🏹 Dremio 26.0+ (Arrow Flight SQL) ダイアレクトの組み込みサポート NEW
  • バンドルされた Apache Arrow Flight SQL JDBC ドライバーを使用
  • カスタム JDBC ドライバー JAR ファイルを個別にインストールする必要がなくなった
🤖 AI-Assisted Quick Starts (Starter questions) GA
  • 新しい Explore エクスペリエンスにおける「Starter questions」機能が一般提供 (GA) に昇格
🔧 Diagnose & Repair ツール NEW
  • LookML プロジェクトリポジトリを 8 つの診断テストで評価 (個人開発環境・共有本番環境の両方に対応)
  • 古いロックファイルの削除、ファイル権限の修正、破損したオブジェクトインデックスの修復などを自動実行
  • 未コミットの変更を専用のリカバリブランチに退避しつつ、破損したリポジトリの再構築が可能
🧹 Looker CI の Style Validator NEW
  • Looker Continuous Integration (CI) に Style Validator が追加
  • LookML のコーディング標準、命名規則、構造的ベストプラクティスを強制
  • デフォルトの組み込みルールセットのほか、lkmlstyle.yaml 設定ファイルでルールの重大度、ファイル除外、カスタムルールなどをカスタマイズ可能
📬 Conversational Analytics のスケジュール型エージェントワークフロー Preview
  • 従来のトリガー型に加えてスケジュール型エージェントワークフローをサポート
  • 自然言語を使って、AI 生成のインサイトサマリー、データテーブル、可視化、PDF レポートをメールや Slack に定期配信可能
  • 受信者はワークフロー通知の「Investigate」からデータエージェントとのプライベートな会話を開始できる
  • 管理者は新しい Workflow Executions 管理ページでスケジュール実行の監視とトラブルシューティングが可能
🎨 Looker Data Apps Preview
  • Looker Data Apps は、Gemini CLI、Claude Code、Cursor などのローカル AI コーディングエージェントが自然言語プロンプトから構築するフリーフォームキャンバスダッシュボード
  • 絶対配置、要素の重ね合わせ、カスタム Web コンポーネントなど完全なビジュアルレイアウト制御が可能
  • Looker のガバナンスされた LookML セマンティックレイヤーとユーザー権限に準拠

⚠️ デメリット・制約事項

🔐 API 認証方式の変更 (Breaking Change): Looker 26.18 のリリースに伴い、Looker 言語 SDK と Looker API の /login エンドポイントは、認証情報を HTTP リクエストボディでのみ受け付けるようになり、URL クエリパラメータでの受け渡しはサポートされなくなります (2026 年 3 月 23 日に事前アナウンス済み)。 URL クエリパラメータで認証情報を渡しているスクリプトやアプリケーションは失敗するため、SDK をバージョン 26.4 以降にアップグレードし、カスタムスクリプトを修正する必要があります。
🔁 レガシーワークフローの再作成: Looker 26.14 より前のバージョンで作成された Conversational Analytics ワークフローは「Legacy Workflows」タブに表示され、再作成が必要です。
⏳ 機能の有効化は順次実施: 「有効化が開始された」段階であり、すべての Looker (Google Cloud core) インスタンスで即座に利用可能になるわけではありません。
