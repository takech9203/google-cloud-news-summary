🗄️ Oracle Database@Google Cloud

Database Connections — API / gcloud / MCP から Oracle に SQL 実行
Oracle Database@Google Cloud GA (一般提供) MCP 対応
📅 リリース日: 2026-11-03

📝 概要

Database Connections が GA になりました。Database Connection は、特定の Oracle データベースとデータベースユーザーへの「再利用可能でセキュアなポインタ」として機能する Google Cloud リソースです。一度作成すれば、oracledatabase.googleapis.com API、gcloud CLI、さらには MCP (Model Context Protocol) サーバー経由で、ODB Network 上の Oracle データベースに接続して SQL 文を実行できます。

接続対象は Autonomous AI Database、Exadata VM Cluster 上のデータベース、DB システム。パスワードや Oracle Wallet は Secret Manager で管理され、SQL 実行の認可は IAM 権限 (oracledatabase.databaseConnections.executeSql) で制御されるため、アプリ・自動化スクリプト・AI エージェントからのアクセスを Google Cloud のセキュリティモデルに統合できます。

❌ Before (アップデート前の課題)

  • SQL 実行には ODB Network に到達可能なネットワーク内に Oracle クライアント環境の構築が必要だった
  • パスワードや Wallet などの認証情報の管理・配布を各クライアント側で行う必要があった
  • AI エージェントや自動化ツール向けの Google Cloud API / MCP ベースの標準手段がなかった

✅ After (アップデート後の改善)

  • 接続を一度作成すれば gcloud / REST API / MCP 経由で SQL (SELECT / DML / DDL) を直接実行できる
  • パスワードと Wallet を Secret Manager で一元管理し、サービスエージェントが実行時に安全に参照
  • SQL 実行権限を IAM で分離し、「SQL 実行のみ」「接続管理のみ」の最小権限設計が可能に
  • MCP ツール (database_connection_executesql など) で AI エージェントからの操作を公式サポート

⚡ 主要機能

🔗 1. Database Connection リソース

→Oracle データベースと DB ユーザーへの再利用可能でセキュアなポインタ
→接続文字列は Oracle Easy Connect 形式または TNS 記述子をサポート (例: hostname.domain.com:1521/SERVICE_NAME)
→パスワードは Secret Manager のシークレットバージョンで指定。mTLS/TLS 接続には base64 エンコードした Oracle Wallet ZIP をシークレットとして指定可能
→作成・更新・テスト・削除の管理操作に対応 (接続テスト用の test 操作あり)

▶️ 2. SQL 実行 (executeSql)

→SELECT に加え、DML・DDL 文の実行をサポート (自動コミット)
→バインド変数 (params) をサポート。SQL インジェクション対策として文字列連結ではなくバインド変数の使用が推奨
→gcloud (gcloud oracle-database database-connections execute-sql) と REST API (:executeSql) の両方で利用可能

🤖 3. MCP サーバー統合

→https://oracledatabase.googleapis.com/mcp エンドポイントで MCP ツールを提供
→create_database_connection / list_database_connections / get_database_connection / database_connection_executesql などで AI エージェントから接続管理と SQL 実行が可能
→database_connection_executesql は destructive_hint: true としてマークされており、エージェント利用時は読み取り専用 / 最小権限の DB ユーザーの使用が推奨

⚙️ SQL 実行の仕様と制限

項目詳細
トランザクション各呼び出しが独立したトランザクション (自動コミット)。複数呼び出しにまたがるトランザクションは不可
API エラー認証失敗・DB 利用不可・ネットワークエラー・タイムアウトは HTTP 4xx/5xx として返却
ORA エラー無効なクエリ (例: ORA-00942) は HTTP 200 で成功しつつ metadata.status: ERROR となるため、metadata.status と metadata.message の確認が必要
結果サイズ上限レスポンスあたり 10 MB (10,485,760 バイト)。超過時は切り捨てられ status: PARTIAL が返る
タイムアウトSQL 文は 30 秒、API デッドラインは 60 秒。超過時は QUERY_TIMEOUT
接続対象ODB Network 経由で到達可能な Autonomous AI Database、Exadata VM Cluster データベース、DB システム

🔑 必要な IAM 権限

権限用途
oracledatabase.databaseConnections.create / update / delete / get / list / testDatabase Connection の管理
oracledatabase.databaseConnections.executeSqlSQL 文の実行 (データアクセス権限。接続に設定された DB ユーザーの権限の範囲で読み取り・変更が可能)
oracledatabase.odbNetworks.use / getODB Network の利用・参照
💡 最小権限のカスタムロール設計: roles/oracledatabase.admin にはすべての必要権限が含まれますが、最小権限の原則に従い以下のカスタムロール作成が推奨されています。
  • SQL ランナー (アプリ/エージェント向け): databaseConnections.get / list / executeSql
  • 接続マネージャー: databaseConnections.* + odbNetworks.use / odbNetworks.get

🔐 サービスエージェントへのシークレットアクセス付与

接続の作成・更新・テスト・SQL 実行時には、Google 管理のサービスエージェント (service-PROJECT_NUMBER@gcp-sa-oci.iam.gserviceaccount.com) が Secret Manager からパスワードシークレットと Wallet シークレットを読み取ります。各シークレットに roles/secretmanager.secretAccessor の付与が必要です。

Bash サービスエージェントへの権限付与 
gcloud secrets add-iam-policy-binding SECRET_ID \
  --member="serviceAccount:service-PROJECT_NUMBER@gcp-sa-oci.iam.gserviceaccount.com" \
  --role="roles/secretmanager.secretAccessor" \
  --project=SECRET_PROJECT_ID

ステップ 1: Database Connection を作成

Bash gcloud で Database Connection を作成 
gcloud oracle-database database-connections create my-connection \
  --location=us-east4 \
  --connection-string="your-db-host.example.com:1521/YOUR_SERVICE_NAME" \
  --username=APP_USER \
  --password-secret-version=projects/PROJECT_ID/secrets/db-password/versions/1 \
  --odb-network=projects/PROJECT_ID/locations/us-east4/odbNetworks/my-odb-network
💡 ヒント: mTLS 接続 (Autonomous Database など) の場合は --wallet-secret-version で Wallet シークレットを指定します。

ステップ 2: SQL 文を実行

Bash gcloud で SQL を実行 (バインド変数対応) 
# シンプルなクエリ
gcloud oracle-database database-connections execute-sql my-connection \
  --location=us-east4 \
  --sql-statement="SELECT 1 FROM DUAL"

# バインド変数付きのクエリ
gcloud oracle-database database-connections execute-sql my-connection \
  --location=us-east4 \
  --sql-statement="SELECT * FROM employees WHERE department_id = :dept_id AND status = :status" \
  --params='name=dept_id,value=10' \
  --params='name=status,value="ACTIVE"'
Bash REST API (:executeSql メソッド) での実行 
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  "https://oracledatabase.googleapis.com/v1/projects/PROJECT_ID/locations/REGION/databaseConnections/CONNECTION_ID:executeSql" \
  -d '{ "sqlStatement": "SELECT * FROM employees WHERE department_id = :dept_id", "params": [{ "name": "dept_id", "value": "10" }] }'

⚖️ メリットと制約事項

👍 メリット

💼 ビジネス面
  • AI エージェント活用の加速: MCP サーバー統合により、Oracle のデータを安全に参照・操作するエージェンティックなワークフローを構築できる
  • 運用負荷の軽減: 接続情報と認証情報を Google Cloud リソースとして一元管理。クライアントごとの接続設定・認証情報配布が不要に
🔧 技術面
  • IAM による統一的なアクセス制御: 「SQL ランナー」「接続マネージャー」のような最小権限のカスタムロール設計が可能
  • Secret Manager との統合: 認証情報がクライアントに露出しない
  • バインド変数サポート: SQL インジェクションを防ぐパラメータ化クエリを gcloud / API / MCP すべてでサポート

⚠️ 制限事項・考慮点

🚧 制限事項
  • 各 SQL 実行は自動コミット。マルチステートメントトランザクションは不可
  • 結果サイズは 10 MB が上限。超過分は切り捨て (status: PARTIAL)
  • SQL 30 秒 / API 60 秒のタイムアウトがあり、長時間クエリやバッチ処理には不向き
🤔 考慮すべき点
  • executeSql は DB ユーザー権限の範囲でデータの読み取り・変更が可能なため、権限付与は慎重に
  • MCP ツールは DML/DDL を自動コミット実行可能。プロンプトインジェクションによるデータ変更・削除リスクを考慮し、エージェント用接続には読み取り専用 / 最小権限の DB ユーザーを推奨
  • ORA エラーは HTTP 200 で返却されるため、アプリ側で metadata.status の確認実装が必要
  • Shared VPC で ODB Network と接続が別プロジェクトの場合、両プロジェクトのサービスエージェントにシークレットアクセス権の付与が必要

🔗 関連サービス・機能

🔐 Secret Manager: データベースパスワードと Oracle Wallet (mTLS 用) の保管に使用。サービスエージェントが実行時に参照する
🔑 IAM: Database Connection の管理権限と SQL 実行権限 (executeSql) を制御。カスタムロールによる最小権限設計が可能
🛜 ODB Network: Oracle Database@Google Cloud のデータベースへのプライベートネットワーク接続を提供。Database Connection の接続経路として必須
🤖 MCP (Model Context Protocol) サーバー: oracledatabase.googleapis.com/mcp 経由で接続管理・SQL 実行ツールを AI エージェントに提供
