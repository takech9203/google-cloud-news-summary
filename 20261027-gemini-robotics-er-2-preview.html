🤖 Gemini Robotics ER 2

Gemini Enterprise Agent Platform で身体性推論 (Embodied Reasoning) モデルが Preview 提供開始
📅 リリース日: 2026-10-27
Gemini Enterprise Agent Platform Preview
🧠 Embodied Reasoning 🦾 Robotics 👁️ VLM (ビジョン言語モデル) ⚡ Gemini 3.5 Flash ベース

📋 概要

Gemini Enterprise Agent Platform で、ロボティクス向けの身体性推論モデル Gemini Robotics ER 2 (gemini-robotics-er-2-preview) が Preview として利用可能になりました。Gemini 3.5 Flash をベースに構築された VLM で、 ロボットが物理世界を正確に認識・推論するための機能に特化しています。

空間推論 (ポインティング / 物体追跡 / バウンディングボックス / 軌道生成)、 エージェント型コード実行 (ズーム・クロップ / 計器読み取り)、 タスクオーケストレーション (カスタムロボット API との連携)、 動画理解 (モーメント検出 / 進捗分類) をサポート。 Google Gen AI SDK から enterprise=True で初期化し、自社の Google Cloud プロジェクトと認証情報で呼び出せます。

😣 Before (アップデート前)

  • 旧世代モデル Gemini Robotics ER 1.6 は 2026 年 8 月 31 日に非推奨 (deprecated) となり、後継モデルへの移行が必要だった
  • 空間推論、動画のモーメント検出・進捗分類、複数ロボットのオーケストレーション、複数ステップのツール利用には改善の余地があった

😊 After (アップデート後)

  • Gemini 3.5 Flash ベースの新モデルにより、空間推論・動画モーメント検出・進捗分類・マルチロボットオーケストレーション・マルチステップツール利用が改善
  • 自社プロジェクトの Google Cloud 認証情報でロボティクス特化モデルを呼び出し可能に
  • Thinking、構造化出力、コンテキストキャッシュ、Function Calling、コード実行、Grounding、Computer Use (Preview) と組み合わせ可能
💡 ポイント: Generative AI Preview 提供のため Pre-GA Offerings Terms および Additional Terms for Generative AI Preview Products が適用されますが、 顧客は本 Preview を本番・商用目的で利用することを選択できます。

カメラ画像・映像・自然言語指示を入力として受け取った Gemini Robotics ER 2 が、コード実行ツールを活用しながら 空間推論・動画理解を行い、カスタムロボット API を通じて実際のロボット (VLA モデル) をオーケストレーションする構成です。

⚡ 主要機能

📍 空間推論 (Spatial Reasoning)

  • 画像・動画内の物体へのポインティング (0-1000 に正規化された [y, x] 座標で返答)
  • 動画フレーム間での物体追跡
  • 2D バウンディングボックスによる物体検出
  • ロボットアームの動作を導く軌道 (ウェイポイント列) の生成

🛠️ エージェント型コード実行

  • コード実行ツールで画像のズーム / クロップなどの画像操作を行い、認識精度を向上
  • 計器 (インストゥルメント) の読み取りに対応
  • シーンへの注釈付けに対応

🧩 タスクオーケストレーション

  • 空間推論とカスタムロボット API (Function Calling) を組み合わせ、長時間 (long-horizon) タスクを遂行
  • VLA モデルを用いたロボットのエージェント的なオーケストレーション
  • マルチロボットオーケストレーションに対応

🎞️ 動画理解 (Video Understanding)

  • 連続した動画フィードからのモーメント検出 (moment finding)
  • 進捗分類 (progress classification)
  • タスクの進捗理解や成功判定 (success detection) を含むロボット映像の理解

ステップ 1: Agent Studio / Model Garden で試す

Google Cloud コンソールの Agent Studio でモデル gemini-robotics-er-2-preview を選択してプロンプトを試行できます。 Model Garden からもモデル情報を確認できます。

ステップ 2: Google Gen AI SDK から呼び出す

Python 空間推論 (ポインティング) の呼び出し例 
from google import genai
from google.genai import types

# Gemini Enterprise Agent Platform のガイドでは enterprise=True で初期化し、
# Google Cloud 認証情報で認証する
client = genai.Client(enterprise=True)

with open("my-image.png", "rb") as f:
    image_bytes = f.read()

prompt = """
Point to no more than 10 items in the image.
The answer should follow the json format:
[{"point": [y, x], "label": <label1>}, ...].
The points are in [y, x] format normalized to 0-1000.
"""

response = client.models.generate_content(
    model="gemini-robotics-er-2-preview",
    contents=[
        types.Part.from_bytes(data=image_bytes, mime_type="image/png"),
        prompt,
    ],
    config=types.GenerateContentConfig(
        thinking_config=types.ThinkingConfig(thinking_level="high")
    ),
)
print(response.text)
💡 ヒント: 空間推論タスクでは thinking_level を指定して推論の深さを制御できます (公式例では pointing に high、バウンディングボックス検出に low を使用)。

💪 メリット

💼 ビジネス面

  • 本番・商用利用が可能な Preview: 顧客は本番・商用目的での利用や生成出力の第三者開示を選択でき、Cloud Data Processing Addendum に基づく個人データの処理も可能
  • エンタープライズ基盤での利用: 自社の Google Cloud プロジェクト・認証情報・課金体系 (Standard PayGo) の下でロボティクス特化モデルを利用できる

⚙️ 技術面

  • ロボティクス特化の推論能力: 汎用 VLM では難しい、正規化座標でのポインティング、軌道生成、動画からの進捗分類・成功判定といった身体性推論に特化
  • プラットフォーム機能との統合: Thinking、構造化出力、コンテキストキャッシュ、Function Calling、コード実行などを組み合わせた長時間タスクのオーケストレーションが可能

⚠️ デメリット・制約事項

🚧 制限事項

✗Preview 提供のため「as is」での提供となり、サポートが限定される場合がある (Pre-GA Offerings Terms 適用)
✗RAG Engine、チューニング、Agentic video understanding、Live API、Interactions API、Chat Completions API は非対応
✗Provisioned Throughput、バッチ推論、固定クォータは利用不可 (Standard PayGo のみ)

🤔 考慮すべき点

🔒 プライバシー通知: Robotics モデルは動作のために映像・音声データを利用します。 識別可能な人物の個人データ (音声、画像、肖像) が収集されうる運用を行う場合、 事前の通知と同意の取得が必要で、顔のぼかしなどのデータ最小化手法の利用が求められます。
📡 ストリーミング版について: Gemini Developer API 側にはリアルタイムストリーミング向けの gemini-robotics-er-2-streaming-preview が存在しますが、Gemini Enterprise Agent Platform で Preview 提供されるのは gemini-robotics-er-2-preview (Live API 非対応) です。
🔁 移行が必要: Gemini Robotics ER 1.6 は 2026 年 8 月 31 日に非推奨となっているため、 利用中の場合はモデル ID を gemini-robotics-er-2-preview に置き換えて移行してください。

🎯 ユースケース

1️⃣ ロボットアームによるピック & プレース

シナリオ: 作業台上の物体をカメラで認識し、ロボットアームで指定の場所に移動させる。

Text プロンプト例 (公式ドキュメントより) 
"Generate a trajectory for the robotic arm to pick up the red pen
 and place it in the organizer. Return a list of waypoints as JSON:
 [{"step": <int>, "point": [y, x], "action": <description>}, ...]
 where coordinates are normalized to 0-1000."

✨ 効果: 対象物体の位置特定から中間ウェイポイントを含む軌道生成までをモデルが行い、 ロボット制御系に渡せる構造化データ (JSON) を取得できる。

2️⃣ ロボット作業映像の進捗監視・成功判定

シナリオ: ロボットの作業映像を継続的に解析し、タスクの進捗状況を分類して完了 (成功) を検出する。

✨ 効果: 動画理解 (モーメント検出・進捗分類) により、長時間タスクの監視や成功判定を自動化できる。

3️⃣ カスタムロボット API を使った長時間タスクのオーケストレーション

シナリオ: 空間推論と Function Calling (カスタムロボット API) を組み合わせ、 複数ステップにまたがるタスクを計画・実行する。複数ロボットの連携 (マルチロボットオーケストレーション) も対象。

✨ 効果: モデルがタスクを分解し、適切な順序でロボット API を呼び出すことで、 long-horizon タスクの自動遂行が可能になる。
