🗄️ Flex Unified サービスレベルが
europe-west8 (ミラノ) で利用可能に

📅 リリース日: 2026-10-15

📌 概要

Google Cloud NetApp Volumes の Flex Unified サービスレベルが、 カスタムパフォーマンス機能を含めて europe-west8 (ミラノ、イタリア) リージョンで利用可能になりました。

Flex Unified は NetApp Volumes の中で最も柔軟性の高いサービスレベルで、 容量とパフォーマンスを独立してプロビジョニングできる「カスタムパフォーマンス」をサポートします。 小規模な 1 GiB のボリュームから大容量プールまで幅広く対応し、Default モードと ONTAP モードの 2 つの動作モードを提供します。

⚠️ 注意: 2026 年 9 月 15 日以降、従来の Flex File ストレージプールの新規作成は不可となっており、Flex Unified が後継の位置付けです。

今回のリージョン拡大により、イタリア国内にワークロードやデータを配置する必要があるユーザー (データレジデンシー要件のある企業など) が、ミラノリージョンで Flex Unified の機能をフル活用できるようになりました。

❌ Before (アップデート前)

  • europe-west8 (ミラノ) では Flex Unified を利用できず、他のサービスレベルを選択するか、別リージョン (europe-west1、europe-west3 など) を利用する必要があった
  • イタリア国内のデータレジデンシー要件を満たしつつ、容量とパフォーマンスを独立して設定できるストレージ構成を取ることが難しかった

✅ After (アップデート後)

  • europe-west8 で Flex Unified ストレージプールを作成可能に
  • カスタムパフォーマンス機能も同時にサポートされ、容量とは独立してスループット・IOPS をプロビジョニング可能に
  • ミラノリージョンで低レイテンシーなファイルストレージ (NFS/SMB など) を Flex Unified で構成可能に

⚙️ Flex Unified サービスレベルの主な特徴

📦 1. 柔軟な容量設定

✓ストレージプール: 1 TiB 〜 425 TiB (1 GiB 単位で増加可能)
✓ボリューム: 1 GiB 〜 300 TiB (1 GiB 単位で増減可能)

⚡ 2. カスタムパフォーマンス

✓プールのパフォーマンスを容量とは独立して設定可能
✓デフォルト: プールあたり 64 MiBps / 1,024 IOPS
✓スループットは 1 MiBps 単位で最大 5 GiBps まで引き上げ可能 (1 MiBps ごとに 16 IOPS が付与)
✓IOPS はプールあたり最大 160,000 IOPS までプロビジョニング可能
✓プール内の全ボリュームでパフォーマンスを共有 (小さいボリュームが余剰パフォーマンスを利用可能)

🔀 3. 2 つの動作モード

✓Default モードと ONTAP モードを選択可能
✓手動 QoS、オートティアリング (ホットティア自動拡張付き)、ゾーン/リージョナルの高可用性構成に対応

🎯 まとめ

Flex Unified サービスレベル (カスタムパフォーマンス含む) が europe-west8 (ミラノ) に拡大され、 イタリア国内でのデータレジデンシー要件を満たしつつ、容量とパフォーマンスを独立してプロビジョニングできる 柔軟なファイルストレージが利用可能になりました。 ミラノリージョンでファイルストレージを検討している場合は、Flex Unified の採用を検討してください。
