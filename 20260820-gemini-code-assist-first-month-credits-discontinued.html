Gemini Code Assist Announcement 料金・ライセンス

💳 Gemini Code Assist
初月ライセンスクレジットの提供終了

リリース日: 2026-08-20
Google Cloud Release Notes

📌 概要

Google Cloud は 2026 年 8 月 20 日、Gemini Code Assist の初月利用分クレジット (first-month credits) の提供を終了したことを発表しました。 このクレジットは、Gemini Code Assist のサブスクリプションを一度も持ったことがない請求先アカウントの新規顧客に対し、 エディション (Standard / Enterprise) を問わず初月に最大 50 ライセンス分が自動適用される特典でした。

2025 年 1 月 30 日に導入されたこの制度は、新規顧客が初期コストなしでチームに展開・評価できる仕組みとして機能していましたが、 今後新規にサブスクリプションを購入する顧客には適用されません。

✅ 既存顧客は安心: 現在すでにこのクレジットを受け取っている顧客は、今回の変更の影響を受けません。 これから導入を検討している組織は、初月から通常料金が発生する前提でコスト計画を立てる必要があります。

🔄 Before / After

❌ Before (変更前の状態)
  • 2025 年 1 月 30 日以降、サブスクリプション未購入の請求先アカウントの新規顧客に、エディションを問わず初月に最大 50 ライセンス分のクレジットが自動適用
  • 新規顧客は初月のライセンス費用を抑えた形で、チーム規模での試用・評価が可能だった
✅ After (変更後)
  • 初月クレジットの新規提供が終了し、今後の新規サブスクリプション購入では初月から通常料金が適用
  • 既存のクレジット受領者への影響はなく、すでに適用されているクレジットはそのまま有効
  • 新規導入のコスト評価では、初月無料分を前提としない見積もりが必要に

🔍 変更のポイント

1️⃣ 初月クレジットの提供終了
  • 対象だったのは「請求先アカウントを持ち、Gemini Code Assist のサブスクリプションを一度も持ったことがない新規顧客」
  • エディション (Standard / Enterprise) を問わず、初月に最大 50 ライセンス分のクレジットが自動適用されていた
  • 今回の発表により、この特典の新規適用が終了
2️⃣ 既存顧客への影響なし
  • 現在クレジットを受け取っている顧客は、この変更の影響を受けない
3️⃣ 本体機能への影響なし
  • Gemini Code Assist の機能・エディション構成・ライセンス管理の仕組み自体に変更はない
  • 純粋に課金上の特典 (プロモーション) の終了であり、技術的な移行作業は不要

💡 メリット・影響

🏢 新規導入を検討する組織への影響

✖ 初月からフルコストが発生: 従来は最大 50 ライセンス分が初月無料だったが、今後は初月から通常料金での予算確保が必要
➜ 評価方法の見直し: チーム規模での無料試用に頼らず、少人数のライセンスから始めて段階的に拡大するアプローチや、年次契約割引の活用を検討する価値がある

👥 既存顧客への影響

✔ 影響なし: 現在クレジットを受け取っている顧客は、この変更による請求への影響はない

⚠️ 考慮すべき点

⚠️ 導入を検討中の組織は、初月クレジットを前提としたコスト試算を修正する必要がある
⚠️ ライセンスは自動割り当てがデフォルトのため、意図しないライセンス消費 (= 課金) を避けたい場合は、手動割り当てへの変更や cloudaicompanion.licenses.selfAssign 権限の管理を検討する
⚠️ ライセンス数の削減やエディションのダウングレードは即時反映されず、契約期間の終了時に適用される点にも注意が必要

📝 まとめ

Gemini Code Assist の初月クレジット (最大 50 ライセンス) の新規提供が終了し、今後の新規サブスクリプションでは初月から通常料金が適用されます。 既存のクレジット受領者への影響はありませんが、これから導入を検討する組織は、初月無料分を前提としないコスト試算と、 年次契約割引や段階的なライセンス展開の活用を検討することを推奨します。
