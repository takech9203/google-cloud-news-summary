📞 Google Cloud CCaaS 4.30

IVR グリーティングスキップ、キューステータス API、高度なコールスケジューリング

2026-05-19
GA CCaaS

📋 概要

Google Cloud CCaaS 4.30 がリリースされた。このバージョンでは、IVR グリーティングメッセージのスキップオプション、ヘッドレス Web SDK における高度なコールスケジューリングのデフォルト有効化、リアルタイムのキューステータスエンドポイントの新設、および HubSpot 連携でのコール転送機能の追加が含まれる。

特に注目すべきは、新しいキューステータスエンドポイント (GET /apps/api/v1/queues/status) であり、音声 AI システムがリアルタイムでキューの状態を把握し、ライブエージェントへのエスカレーションやスケジュールコールバックの提案を動的に判断できるようになる。

🔄 Before / After 比較

❌ Before (4.29 以前)

  • IVR グリーティングは常に再生され、不要な待ち時間が発生
  • 高度なコールスケジューリングは明示的に true 設定が必要
  • キューのリアルタイムステータスを一括取得する API がない
  • HubSpot 連携でのコール転送機能が限定的

✅ After (4.30)

  • IVR グリーティングをスキップし迅速にキューへ接続可能
  • 高度なコールスケジューリングがデフォルトで有効
  • 新 API でリアルタイムデータに基づく動的ルーティング判断
  • HubSpot 連携でのコール転送機能が拡張

⚡ 主要機能

🎙️ IVR グリーティングスキップ

Settings > Languages & Messages > IVR-specific Messages セクションに新しい「Skip IVR Greeting」オプションを追加。通話開始時のグリーティングメッセージを省略し、発信者をより迅速にキューへルーティング可能に。

✓ 単一キュー構成のコールフローで特に有効
✓ グローバル設定として全 IVR コールに適用

🔌 キューステータスエンドポイント

新エンドポイント GET /apps/api/v1/queues/status でリーフキューのリアルタイムデータを提供。

✓ 推定待ち時間 (EWT)
✓ エージェント可用性
✓ コールバックスロット容量
✓ 営業時間・祝日情報

📅 高度なコールスケジューリング (デフォルト有効)

useAdvancedCallScheduling パラメータがデフォルトで true に設定。追加設定なしで高度な機能を利用可能。

✓ 設定可能な日数先までのタイムスロット表示
✓ タイムスロット容量の設定
✓ 既存スケジュールコールの再スケジュール/キャンセル

🔗 HubSpot 連携コール転送機能

HubSpot CRM 連携においてコール転送時の追加機能を提供。5 月 12 日のプレリリースで予告されていた機能の正式リリース。

✓ エージェントステータス継承
✓ チケットオーナーの自動更新
✓ エージェント同期

キューステータスの取得

Bash 
# キューステータスの取得
curl -X GET "https://YOUR_CCAAS_HOST/apps/api/v1/queues/status" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json"

音声 AI によるインテリジェントルーティング実装例

Python 
import requests

# キューステータスを取得
response = requests.get(
    f"https://{CCAAS_HOST}/apps/api/v1/queues/status",
    headers={"Authorization": f"Bearer {token}"}
)
queue_data = response.json()

# ルーティング判断
if queue_data["available_agents"] > 0 and queue_data["ewt"] < 120:
    # エージェントへエスカレーション
    escalate_to_agent(call_id)
elif queue_data["callback_slot_capacity"] > 0:
    # コールバック予約を提案
    offer_callback(call_id, queue_data["available_slots"])
else:
    # キュー待機
    hold_in_queue(call_id)

⚠️ 制限事項・注意点

! キューステータスエンドポイントはリーフキュー (最下層キュー) のみが対象。親キュー (ブランチキュー) のステータスは含まれない。
! IVR グリーティングスキップはグローバル設定であり、特定のキューのみに適用する場合はキューレベルの設定との組み合わせが必要。
! useAdvancedCallScheduling のデフォルト値変更により、既存のヘッドレス SDK 実装で意図しない動作変更が発生する可能性あり。明示的に false 未設定の場合は動作確認を推奨。
! IVR グリーティングスキップ時、発信者への最初のコンテキスト情報 (会社名など) が失われるため、他の手段で補完する検討が必要。
