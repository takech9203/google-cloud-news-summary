📞 CCaaS: Agent Assist Hub パネルへの移行

CCaaS Agent Desktop 予定 (2026 Q3)
2026-06-30

📋 概要

Google Cloud CCaaS (Contact Center as a Service) の Agent Desktop において、従来の Knowledge Assist パネルが新しい Agent Assist Hub パネルに置き換えられる。Hub パネルは複数の Agent Assist モジュールを統合管理するハブとして機能し、Knowledge Assist はその中の一つのモジュールとして提供される。

Agent Assist Hub は、Knowledge Assist、Generative Knowledge Assist、Sentiment Analysis、Session Summarization など、これまで個別に提供されていた Agent Assist の各機能を統合的に管理するためのハブパネルである。

💡 ポイント: 移行は自動的に行われ、管理者による設定変更は不要。ただし、移行時にサインイン中のエージェントは再サインインが必要。

🔄 Before / After 比較

❌ Before (移行前)

  • Knowledge Assist が独立したパネルとして提供
  • 他の Agent Assist 機能と分離されていた
  • 複数の機能へアクセスするには異なるパネルを切り替え
  • 各機能が個別管理で統一的な操作体験なし

✅ After (移行後)

  • Agent Assist Hub パネルで各機能がモジュールとして統合管理
  • Knowledge Assist は Hub 内で他の機能と統合
  • 統一的なアクセスポイントから全機能を利用
  • 設定変更不要で自動移行、管理者負担を最小化

⚡ 主要機能

🏠 Agent Assist Hub パネル

Agent Assist の各機能を統合的に管理するハブパネル。デスクトップレイアウト内で Knowledge Assist パネルの位置を自動的に置き換え、複数の Agent Assist モジュールへの統一的なアクセスポイントを提供する。

📚 Knowledge Assist モジュール

従来の Knowledge Assist パネルと 1:1 で同等の機能を提供。会話中にリアルタイムで関連ドキュメントを提案し、エージェントがナレッジベースを手動で検索する機能やエンドユーザーへのドキュメント共有機能を維持。

🔄 自動移行

管理者による設定変更は不要。デスクトップレイアウトの既存設定は自動的に新パネルに移行される。移行時にサインイン中のエージェントのみ再サインインが必要。

📝 移行手順

前提条件

✓ CCAI Platform インスタンスで Agent Desktop エクステンションが有効化されていること
✓ Agent Assist が設定済みであること (サービスアカウント、会話プロファイル含む)

ステップ

移行前の確認

CCAI Platform ポータルで Settings > Operation Management に移動し、Agent Desktop ペインで Manage Desktop Layout Lists をクリック。Knowledge Assist ウィジェットを使用しているレイアウトを確認する。

自動移行の適用 (管理者操作不要)

2026年Q3早期 (7月中旬〜下旬) に自動的に移行が実施される。デスクトップレイアウトの既存設定が Agent Assist Hub パネルに自動変換される。

エージェントの再サインイン

更新時にサインイン中のエージェントに対し、Agent Desktop からサインアウト後に再度サインインを依頼。Agent Assist Hub パネル内の Knowledge Assist モジュールの正常動作を確認する。

⚠️ 注意: 更新時にサインイン中のエージェントは、Knowledge Assist モジュールが動作しなくなる。サインアウト / サインインで解決する。

⚠️ 制約事項・注意点

制限事項

✗ 更新時にサインインしているエージェントの Knowledge Assist モジュールが一時的に動作停止する
✗ エージェントの再サインインが必要なため、通話中やチャット対応中のエージェントには即時適用できない

考慮すべき点

→移行のタイミング (7月中旬〜下旬) に向けて、エージェントへの事前通知を計画する必要がある
→繁忙時間帯を避けてエージェントの再サインインを計画することが望ましい
→カスタムパネルを使用している場合、Agent Assist Hub パネルとの位置関係を確認する

🎯 ユースケース

📞 ユースケース 1: コンタクトセンターの通常運用

シナリオ: 音声通話やチャットで顧客対応を行うエージェントが、会話中にリアルタイムで Knowledge Assist の提案を受け取る。

効果: 移行後も従来と同じ方法でドキュメント提案を受け取ることができる。Agent Assist Hub パネル内の Knowledge Assist モジュールは、従来の Knowledge Assist パネルと同じ操作感を提供する。

🗓️ ユースケース 2: 移行タイミングの運用管理

シナリオ: 管理者がエージェントのシフト切り替えタイミングに合わせて、再サインインを促す運用を計画する。

効果: 通話中のエージェントへの影響を最小限に抑えつつ、全エージェントが新しい Agent Assist Hub パネルに円滑に移行できる。
