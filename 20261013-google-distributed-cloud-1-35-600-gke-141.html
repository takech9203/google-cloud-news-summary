☁️ Google Distributed Cloud (software only)
1.35.600-gke.141 パッチリリース

📅 リリース日: 2026-10-13 | VMware 版 / ベアメタル版
Google Distributed Cloud VMware 版 ベアメタル版 🔒 脆弱性修正 Announcement / Fixed

📋 概要

GDC (software only) の VMware 版・ベアメタル版の両プラットフォームで、パッチリリース 1.35.600-gke.141 がダウンロード可能になりました。 両バージョンとも Kubernetes v1.35.8-gke.100 上で動作します。

本リリースは、前日 (2026-10-12) に公開された 1.35.600-gke.140 に続くフォローアップのパッチリリースです。 .140 がバグ修正を多く含んでいたのに対し、.141 の修正内容は「脆弱性修正一覧に記載されたセキュリティ脆弱性の修正」のみで、 新機能の追加や機能的なバグ修正は含まれません。1.35 系を運用するオンプレミス環境のセキュリティを最新の状態に保つためのリリースです。

❌ Before (アップデート前の課題)

✗ 1.35.600-gke.140 以前のバージョンには、脆弱性修正一覧 (Vulnerability fixes) に記載された既知のセキュリティ脆弱性が未修正のまま残っていた

✅ After (アップデート後の改善)

✓ 脆弱性修正一覧に記載されたセキュリティ脆弱性が、VMware 版・ベアメタル版の両プラットフォームで修正された

🗓️ リリースの流れと利用可能タイミング

📦 1.35.600-gke.140 2026-10-12 リリース バグ修正 + 脆弱性修正
→
🔒 1.35.600-gke.141 2026-10-13 リリース (本リリース) 脆弱性修正のみ
→
🖥️ GKE On-Prem API クライアント コンソール / gcloud CLI / Terraform 約 7〜14 日後に利用可能
💡 ポイント: ダウンロード (gkectl / bmctl) は即時可能ですが、GKE On-Prem API クライアント経由での利用はリリース後約 7〜14 日かかります。

⚙️ サービスアップデートの詳細

1️⃣ 1.35.600-gke.141 のリリース (両プラットフォーム共通)

  • → VMware 版・ベアメタル版ともに Kubernetes v1.35.8-gke.100 上で動作 (.140 から変更なし)
  • → サードパーティストレージベンダーを利用している場合は、認定済みストレージパートナーの一覧で対応状況の確認が必要

2️⃣ 🔒 脆弱性修正

  • → 脆弱性修正一覧 (VMware 版 / ベアメタル版) に記載されたセキュリティ脆弱性を修正
  • → 本リリースの Fixed 項目は脆弱性修正のみ。機能的なバグ修正 (audit-proxy、プリフライトチェック、CA ローテーションなど) は前リリース 1.35.600-gke.140 を参照

💻 設定方法 (アップグレード手順)

アップグレード手順は 1.35.600-gke.140 と同様です。アップグレード先バージョンと同じバージョンのツール (gkectl / bmctl 1.35.600-gke.141) を使用してください。

Bash ベアメタル版の例: bmctl 1.35.600-gke.141 をダウンロードしてアップグレード 
# ベアメタル版の例: bmctl 1.35.600-gke.141 をダウンロードしてアップグレード
gcloud storage cp gs://anthos-baremetal-release/bmctl/1.35.600-gke.141/linux-amd64/bmctl ./bmctl
chmod +x ./bmctl
# クラスタ構成ファイルの anthosBareMetalVersion を 1.35.600-gke.141 に更新後
./bmctl upgrade cluster -c CLUSTER_NAME --kubeconfig ADMIN_KUBECONFIG

詳細な手順はプラットフォームごとのアップグレードガイド (VMware 版 / ベアメタル版) を参照してください。

✓ セキュリティリスクの低減: 既知の脆弱性が修正され、オンプレミス環境のコンプライアンス要件への対応が容易になる
✅ 技術面のメリット
✓ 最新パッチへの集約: .140 のバグ修正と .141 の脆弱性修正を 1 回のアップグレードでまとめて適用できる (1.35.500 以前からのアップグレードの場合)
⚠️ 制限事項
  • GKE On-Prem API クライアント (コンソール、gcloud CLI、Terraform) で利用可能になるまで、リリース後約 7〜14 日かかる
  • サードパーティストレージベンダー利用時は、本リリースに対する認定状況を事前に確認する必要がある
  • クラスタのダウングレードはサポートされない
💡 考慮すべき点
  • .140 へのアップグレードを計画中だった場合は、脆弱性修正を含む .141 を直接適用する方が効率的
  • アップグレードはメンテナンスウィンドウの計画が必要

GDC (software only) 1.35.600-gke.141 は、前日リリースの .140 に続く脆弱性修正のみのフォローアップパッチです。 1.35 系へのアップグレードを計画している場合は、.140 ではなく本バージョンを直接適用することで、バグ修正と最新の脆弱性修正をまとめて取り込めます。 セキュリティ要件の厳しいオンプレミス環境では早期の適用を推奨します。
