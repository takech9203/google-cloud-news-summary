🔗 Gemini Enterprise: ServiceNow データストア GA

Gemini Enterprise GA ServiceNow
2026-06-16

📋 概要

Gemini Enterprise において、ServiceNow データストアのフェデレーション検索およびアシスタントアクション機能が一般提供（GA）となりました。自然言語を使って ServiceNow のデータに直接アクセスし、インシデント・変更リクエスト・タスク・ナレッジベース記事の検索・閲覧が可能になります。

さらに、インシデントの作成や更新といったアクションも Gemini Enterprise アプリから直接実行できるようになり、IT サービスマネジメント（ITSM）業務のコンテキストスイッチを大幅に削減します。

🎯 対象ユーザー: IT サポートチーム、サービスデスク担当者、変更管理者、ナレッジマネージャー

🔄 Before / After 比較

❌ Before (アップデート前)

  • Gemini Enterprise と ServiceNow 間で画面切り替えが必要
  • インシデント作成・更新に ServiceNow UI への直接アクセスが必須
  • パブリックプレビュー段階で本番利用に制限
  • データソース間の統合的な検索が不可

✅ After (アップデート後)

  • 自然言語で ServiceNow データを直接検索・閲覧
  • インシデント作成・更新を Gemini Enterprise 内で完結
  • GA により SLA ベースのサポートと本番利用が可能
  • 他データソースと統合的に結果を表示

🏗️ アーキテクチャ図

Gemini Enterprise がユーザーの自然言語クエリを受け取り、LLM がクエリを書き換えた後、ServiceNow API に直接送信します。フェデレーション検索では ServiceNow からのリアルタイム結果が他のデータソースと統合されます。

⚡ 主要機能

🔍 フェデレーション検索

→ServiceNow データをリアルタイムで直接検索（取り込み不要）
→インシデント・変更リクエスト・タスク・ナレッジベースを横断検索
→他の接続データソースと統合表示
→Authorization Code グラントフローによるセキュア認証

🤖 アシスタントアクション

→インシデントの新規作成
→既存インシデントの更新（システム ID 使用）
→自然言語コマンドによる操作
→追加の読み取り専用アクションも利用可能

📡 2 つのコネクタタイプ

🌐 フェデレーション検索

方式: データ取り込みなし

特徴: リアルタイムにレコードにアクセス

認証: Authorization Code グラントフロー

用途: リアルタイム検索 + アクション実行

📥 データ取り込み（Data Ingestion）

方式: ローカルデータストアに同期

特徴: インデックス化して高速検索

認証: ROPC（+ Authorization Code）

用途: 高速検索 + オフライン対応

🔐 アクセス制御

💡 アクセス制御のポイント:
  • admin、incident_manager、change_manager ロール: 全インシデント閲覧可能
  • その他のユーザー: 自身が関連付けられたインシデントのみ閲覧可能
  • ServiceNow の itil や sn_incident_read ロールは Gemini Enterprise では適用されない

⚠️ 制限事項・注意点

⚠️ 制限事項:
  • 対応リージョンは global、us、eu のみ
  • アクション付きデータストアは 1 コネクタタイプにつき 1 データストアのみ推奨
  • 既存データストアへの VPC Service Controls ペリメーター適用は不可（再作成が必要）
  • ServiceNow の itil/sn_incident_read ロールによる広範な閲覧権限は Gemini Enterprise では適用外
  • LLM クエリ書き換え時、セッション履歴の一部が ServiceNow API に送信される可能性
🔒 プライバシーに関する考慮:
  • フェデレーション検索ではクエリ文字列が ServiceNow API に送信される
  • 複数のフェデレーション検索データソースが有効な場合、クエリが全データソースに送信される可能性
  • データが ServiceNow に到達した後は、ServiceNow の利用規約・プライバシーポリシーが適用
