ステップ 1: 現在使用中のモデルエンドポイントを確認

Bash 
# アプリケーションコード内で廃止モデルを検索

ステップ 2: モデル ID を GA 版に更新

Python 
# 変更前 (エラーが発生する)

# 変更後 (推奨)
model = "gemini-2.5-flash"  # または "gemini-3.5-flash"

Bash 
# API エンドポイントの形式 (グローバルエンドポイント)

  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts": [{"text": "Hello"}]}]
  }'

💡 メリット

🕐 長期サポート

GA モデルはリリースから最低 12 ヶ月の利用期間が保証。gemini-3.1-flash-lite は 2027 年 5 月以降まで。

💰 コスト最適化

gemini-3.1-flash-lite は高品質ながら最もコスト効率の高いモデルとして設計。

🧠 品質向上

GA 版は Preview 版のフィードバックを反映し、性能と品質が改善。

⚙️ 追加機能

Thinking 機能、ファインチューニング、Provisioned Throughput など Preview 版にはなかった機能を完全サポート。

🔒 セキュリティ

Data residency、CMEK、VPC-SC、AXT など enterprise-grade のセキュリティ機能を完全サポート。

⚠️ デメリット・制約事項

制限事項:
  • 廃止は即時 - 既にエンドポイントへのアクセスは不可能 (移行猶予期間なし)
  • Preview モデルで作成したファインチューニング済みモデルは GA モデルで再トレーニングが必要
  • 一部の応答特性 (トーン、出力フォーマットなど) が Preview 版と GA 版で異なる場合がある
💡 考慮すべき点:
  • gemini-2.5-flash / gemini-2.5-flash-lite は 2026 年 10 月 16 日に退役予定 - 中長期的には gemini-3.1-flash-lite または gemini-3.5-flash への移行を推奨
  • モデル移行時はプロンプトの最適化が必要な場合あり (特に Thinking 機能のレベル設定)
  • Provisioned Throughput を利用する場合、新しいモデルでの再契約が必要

💬 ユースケース 1: チャットボットアプリケーションの移行

シナリオ: gemini-2.5-flash-preview-05-2025 を使用した顧客対応チャットボットでエンドポイント廃止により API エラーが発生。

効果: gemini-3.1-flash-lite は instruction following が改善されており、複雑なチャットボットワークフローでの信頼性が向上。

Python 
import vertexai
from vertexai.generative_models import GenerativeModel

# プロジェクト初期化
vertexai.init(project="your-project-id", location="global")

# 移行後のモデル指定
model = GenerativeModel("gemini-3.1-flash-lite")

# Thinking レベルを設定してレスポンス品質を調整
response = model.generate_content(
    "顧客の問い合わせに回答してください",
    generation_config={
        "temperature": 0.7,
        "max_output_tokens": 2048,
    }
)
