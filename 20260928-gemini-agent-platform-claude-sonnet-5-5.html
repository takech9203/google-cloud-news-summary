📌 概要

Anthropic の最新モデル Claude Sonnet 5.5 が、Gemini Enterprise Agent Platform の Model Garden で一般提供 (GA) されました。モデル ID は claude-sonnet-5-5。 コーディング、エージェント、大規模なプロフェッショナルワーク向けに設計され、 Claude Sonnet 5 (2026-06-30 リリース) の機能をすべて継承しつつ、新しい思考制御オプションが追加されています。

最大の変更点は、thinking.type に新しい値 between_tools が追加されたことです。 これは本モデルで利用できる最も低い思考設定で、拡張思考 (extended thinking) を行わず、 ツール呼び出しの間にモデルが書く短い進捗報告が思考ブロックとして返されます。

⚠️ 注意: Claude Sonnet 5.5 は thinking: {"type": "disabled"} をサポートしません。 思考をオフ (に最も近い状態) にしたい場合は between_tools を使用します。 適応的思考 (Adaptive thinking) はオン・オフの切り替えが可能です。

❌ Before (アップデート前の課題)

  • Sonnet クラスの最新は Claude Sonnet 5 (2026-06-30 GA) で、それ以降のモデル改善 (コーディング、エージェント、プロフェッショナルワーク) を Google Cloud 上で利用できなかった
  • ツール呼び出し中心のワークロードで思考量を最小限に抑える between_tools のような専用の思考設定が存在しなかった

✅ After (アップデート後の改善)

  • Anthropic の最新 Sonnet モデルを Model Garden から GA として直ちに利用可能
  • 新しい思考設定 between_tools により、拡張思考なしでツール呼び出し間の短い進捗報告のみを受け取る、低思考コストの運用が可能
  • Claude Sonnet 5 と同じ料金・同じトークン上限 (入力 1M / 出力 128K) で、Provisioned Throughput や Shared Model Lineage Quota にも対応
