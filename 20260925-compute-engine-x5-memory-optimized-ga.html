📌 概要

Compute Engine の新しいメモリ最適化マシンシリーズ「X5」が一般提供 (GA) になりました。 従来の X4 の上限だった 32 TB メモリの壁を打ち破り、最大 48 TB (49,152 GB) の超大容量構成を提供。 CPU には Intel Granite Rapids を採用し、最大 2,064 vCPU を利用できます。

主な対象は、単一ノード (スケールアップ構成) でミッションクリティカルなデータベースを拡張したい 最大規模の SAP HANA および RISE with SAP のユーザーです。 前日 (2026-09-24) には X5 が SAP HANA スケールアップ (OLAP / OLTP) と SAP NetWeaver 向けに SAP 認定を取得しており、 超大規模 SAP システムを Google Cloud で本番稼働させる基盤が正式に整いました。

🔙 Before: X4 まで (〜32 TB)

  • メモリ最適化ベアメタルの最大は X4 (Sapphire Rapids、1,920 vCPU / 32 TB) で、32 TB 超のインメモリ DB を単一ノードで稼働できない
  • 32 TB 超の SAP HANA はスケールアウト分割やデータ削減 (アーカイブ、ティアリング) の検討が必要
  • Granite Rapids 世代の CPU をメモリ最適化ベアメタルで使う選択肢がない

✅ After: X5 GA (〜48 TB)

  • 最大 48 TB / 2,064 vCPU の X5 ベアメタルが GA。X4 比で +50% のメモリを単一ノードで利用可能
  • 超大規模 SAP HANA をスケールアウト分割せずシンプルなスケールアップ構成のまま拡張できる
  • RISE with SAP の大規模ユーザーも最大構成 (x5-2064-48T-metal) を SAP 管理ワークロードとして利用可能

X4 シリーズではメモリ上限 32 TB を超えるデータベースの単一ノード稼働が不可能でしたが、 X5 シリーズの GA により最大 48 TB のスケールアップ構成が可能になりました。

⚡ 主要機能

1️⃣ 最大 48 TB メモリの超大容量構成

✓最上位の x5-2064-48T-metal は 2,064 vCPU / 49,152 GB (48 TB) メモリを提供
✓X4 シリーズの最大構成 (32 TB) から 50% のメモリ容量増
✓12 TB / 16 TB / 24 TB / 32 TB / 48 TB の 5 つの事前定義マシンタイプを用意

2️⃣ Intel Granite Rapids CPU プラットフォーム

✓X4 (Intel Sapphire Rapids、第 4 世代 Xeon) より新しい世代の CPU を採用
✓vCPU 数も最大 1,920 → 2,064 に増加

3️⃣ SAP HANA / RISE with SAP 向けの単一ノードスケールアップ

✓最大規模の SAP HANA / RISE with SAP ユーザーが、ミッションクリティカルな DB を単一ノードで容易にスケールアップ可能
✓最大構成の x5-2064-48T-metal は、RISE with SAP プログラムで SAP が管理するワークロード向けに提供

👍 メリット

💼 ビジネス面

✓超大規模基幹システムのクラウド移行を実現: 32 TB 超のインメモリ DB をオンプレ大型アプライアンスから構成変更なしで移行可能
✓RISE with SAP 戦略との整合: 最大 48 TB 構成が RISE with SAP に対応し、SAP マネージドのクラウド移行戦略の受け皿に
✓データ成長への長期的な備え: 32 TB 近辺で稼働中のシステムに +50% のスケールアップ余地を確保

⚙️ 技術面

✓単一ノードスケールアップで運用簡素化: スケールアウト分割に伴うテーブル分散設計・ノード間通信チューニングが不要
✓最新世代 CPU による性能向上: Granite Rapids は X4 の Sapphire Rapids より新世代、vCPU も最大 2,064 に増加
✓Hyperdisk による柔軟なストレージ性能: IOPS / スループットをワークロードに合わせて独立に調整可能

⚠️ デメリット・制約事項

🚫 制限事項

✗ブロックストレージは Hyperdisk のみ (Persistent Disk は利用不可、ブートボリュームも Hyperdisk が必要)
✗提供リージョン / ゾーンが限定される
✗事前定義マシンタイプのみで、カスタムマシンシェイプは利用不可
✗対応 OS イメージが限定される (SAP HANA の場合は SLES for SAP 15 SP7 以降または RHEL for SAP 10.0 以降)
✗最大構成の x5-2064-48T-metal は、RISE with SAP プログラムで SAP が管理するワークロード向け

🤔 考慮すべき点

⚠️ベアメタルの一般的な特性 (ライブマイグレーション非対応、起動時間が長いなど、X4 と同様の挙動) を事前に検証すること
⚠️ベアメタルの料金・発注は Google Cloud アカウントチームへの確認が推奨される (X4 と同様の提供モデル)
⚠️SAP で利用する場合は、SAP 認定状況 (2026-09-24 発表) と SAP Note の最新情報を確認すること

🎯 ユースケース

📦 ユースケース 1: 32 TB 超の SAP HANA (S/4HANA) の単一ノード移行

シナリオ: オンプレミスの大型アプライアンスで稼働する 32 TB 超の S/4HANA データベースを、スケールアウト分割せずに Google Cloud に移行したい。

構成例 実装イメージ 
# データベース層: RISE with SAP 経由で x5-2064-48T-metal (48 TB)
# ストレージ: Hyperdisk Extreme (data / log)、Hyperdisk Balanced (boot / shared)
# アプリケーション層: SAP NetWeaver 認定マシンタイプ
✅ 効果: スケールアップ構成を維持したまま移行でき、データ分割やアプリケーション改修の工数を回避できる。

📈 ユースケース 2: X4 上の大規模 SAP HANA の基盤刷新とスケールアップ余地の確保

シナリオ: X4 (32 TB) の上限近くで稼働する SAP HANA について、データ増加に備えて基盤を刷新したい。

✅ 効果: Granite Rapids 世代への CPU 刷新と同時に、メモリ上限が 48 TB へ拡大。スケールアウト移行を回避しつつ数年分のデータ成長に対応できる。

💰 料金 / 🌏 利用可能リージョン

💰 料金: X5 ベアメタルの公開料金は執筆時点で確認できません。同種の X4 ベアメタルと同様に、料金・発注は Google Cloud アカウントチームへの問い合わせが案内されています。 最新情報は Compute Engine の料金 / 確約利用割引 (CUD) を参照。
🌏 リージョン: X5 マシンシリーズは一部のゾーン / リージョンでのみ利用可能です。最新の提供状況は 利用可能なリージョンとゾーン を参照してください。

📝 まとめ

X5 シリーズの GA により、Compute Engine のメモリ最適化ベアメタルは 最大 48 TB メモリ / 2,064 vCPU (Intel Granite Rapids) へと拡大し、 X4 の 32 TB 上限を 50% 上回る単一ノードスケールアップが可能になりました。

32 TB 超の SAP HANA を運用中、またはデータ増加を見込む企業は、提供リージョン・対応 OS・SAP 認定状況を確認のうえ、 移行や基盤刷新の候補として評価することを推奨します。 48 TB 構成 (x5-2064-48T-metal) は RISE with SAP プログラムでの利用が前提となる点に注意してください。
