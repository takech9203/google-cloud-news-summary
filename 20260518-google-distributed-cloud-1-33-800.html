☁️ Google Distributed Cloud v1.33.800-gke.75

Google Distributed Cloud Patch Release Security Fix
2026-05-18

📋 概要

Google Distributed Cloud (software only) for VMware および bare metal のバージョン 1.33.800-gke.75 がリリースされました。Kubernetes v1.33.11-gke.100 上で動作し、セキュリティ脆弱性の修正と VMware 環境における重要なバグ修正が含まれています。

Google Distributed Cloud (software only) は、Google Cloud のインフラストラクチャとサービスをオンプレミスのデータセンターに拡張するソフトウェア製品です。VMware vSphere 環境またはベアメタル上で GKE ベースの Kubernetes クラスタを作成・管理・アップグレードできます。

🔄 Before / After 比較

❌ Before (修正前の課題)

  • Advanced Admin Cluster が管理する非 Advanced ユーザークラスタに対して gkectl diagnose cluster / gkectl diagnose snapshot が実行できなかった
  • バンドル Ingress を無効にし ingressVIP を空白にした構成で gkectl check-config が失敗
  • 既知のセキュリティ脆弱性が存在

✅ After (修正後の改善)

  • 混在環境でもヘルスチェックと診断情報収集が正常に動作
  • バンドル Ingress 無効構成での preflight チェックが正しく通過
  • セキュリティ脆弱性が修正済み

⚡ 主要機能

🔒 セキュリティ脆弱性の修正

Vulnerability fixes に記載された複数の脆弱性が修正されました。VMware 版・bare metal 版の両方に適用されます。

🩺 クラスタヘルスチェック・診断情報収集の修正 (VMware)

Advanced Admin Cluster が管理する非 Advanced ユーザークラスタに対して、gkectl diagnose cluster および gkectl diagnose snapshot が正常に動作するようになりました。バージョン 1.32 以降で追加された Advanced クラスタでの診断サポートが、混在環境でも安定的に利用可能になります。

✅ preflight チェックの修正 (VMware)

バンドル Ingress が無効で loadBalancer.vips.ingressVIP が空白の構成において、gkectl check-config が正常に通過するようになりました。外部 Ingress Controller を使用する環境での構成検証が適切に動作します。

🎯 ユースケース

📡 ユースケース 1: Advanced/非 Advanced 混在環境での運用監視

大規模オンプレミス環境で段階的に Advanced Cluster へ移行を進めている組織向け。Advanced Admin Cluster で複数の非 Advanced User Cluster を管理し、定期的なヘルスチェックを自動化している環境で、本アップデートによりすべてのクラスタに対して一貫した監視が可能になります。

Bash 
# 全ユーザークラスタのヘルスチェックスクリプト
for cluster in $(kubectl get clusters --kubeconfig=admin-kubeconfig -o jsonpath='{.items[*].metadata.name}'); do
  echo "Checking cluster: $cluster"
  gkectl diagnose cluster --kubeconfig=admin-kubeconfig --cluster-name=$cluster
done

🔧 ユースケース 2: カスタム Ingress 構成の検証自動化

Istio や NGINX Ingress Controller を使用するため、バンドル Ingress を無効にした構成を採用している組織向け。CI/CD パイプラインで構成変更時に gkectl check-config による事前検証を実施することで、人的ミスによるデプロイ失敗を防止できます。
