📋 概要

Anthropic の最新モデル Claude Sonnet 5 が、Gemini Enterprise Agent Platform の Model Garden でパートナーモデルとして一般提供 (GA) を開始。コーディング、エージェント、プロフェッショナルワークに特化した Anthropic の中規模モデルの最新バージョン。

🧠 主な特徴: 入力として Text / Image / PDF をサポート。最大 100 万トークンのコンテキスト長と 128,000 トークンの最大出力。Computer Use、Web Search、Function Calling、Memory Tool など幅広い機能に対応。

Before / After 比較

  • Claude Sonnet 4.6 が最新で、それ以降の進化を Google Cloud 上で活用不可
  • より高い性能には Opus ラインの高コストモデルが必要
  • Memory Tool は一部モデルでのみ利用可能

✅ After

  • Sonnet ライン最新の Claude Sonnet 5 が利用可能に
  • Computer Use / Web Search / Memory Tool を含む全機能セットに対応
  • 共有リネージクォータで追加のクォータ申請が不要

🚀 設定方法

前提条件:
  • Agent Platform API (aiplatform.googleapis.com) が有効化されていること
  • パートナーモデルの使用に必要な権限が付与されていること
  • Model Garden で Claude Sonnet 5 のモデルカードから「Enable」をクリックし、利用規約に同意していること

Step 1: モデルの有効化

Google Cloud Console で Model Garden にアクセスし、Claude Sonnet 5 のモデルカードから有効化する。

Step 2: SDK のインストール

Bash Anthropic SDK インストール 
pip install anthropic[vertex]

Step 3: API リクエストの送信 (Python SDK)

Python Anthropic SDK での呼び出し例 
import anthropic

client = anthropic.AnthropicVertex(
    region="us-east5",
    project_id="your-project-id",
)

message = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "Hello, Claude Sonnet 5!"}
    ],
)
print(message.content)

Step 3 (代替): curl コマンド

Bash curl での直接リクエスト 
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  "https://us-east5-aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/us-east5/publishers/anthropic/models/claude-sonnet-5:rawPredict" \
  -d '{
    "anthropic_version": "vertex-2023-10-16",
    "messages": [{"role": "user", "content": "Hello"}],
    "max_tokens": 1024
  }'

💡 ユースケース

🛠️ ユースケース 1: エージェント型コーディングアシスタント

シナリオ: 大規模コードベースの理解と修正を自動化するエージェントの構築

効果: 100 万トークンのコンテキストにより、大規模リポジトリ全体を把握した上でのコード修正が可能

Python Computer Use + Function Calling の組み合わせ 
import anthropic

client = anthropic.AnthropicVertex(region="us-east5", project_id="my-project")

# Computer Use と Function Calling を組み合わせたエージェント
message = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=64000,
    tools=[
        {"type": "computer_20241022", "name": "computer",
         "display_width_px": 1920, "display_height_px": 1080},
        {"type": "function", "function": {
            "name": "run_tests", "description": "Run test suite"}}
    ],
    messages=[{"role": "user",
               "content": "Fix the failing tests in the auth module"}],
)

⚡高スループット - Global エンドポイントで QPM 2,500、入力 TPM 25,000,000
🔄共有リネージクォータ - 新モデルバージョン追加時にクォータ再申請不要で運用負荷を軽減
🖼️マルチモーダル入力 - テキスト、画像、PDF をネイティブにサポート

⚠️ デメリット・制約事項

制限事項:
  • Anthropic の再販禁止ポリシーにより、特定のリセラーが管理する請求アカウントでは利用できない場合がある
  • Web Search 機能はパブリックインターネットアクセスが必要で、組織ポリシーによるデフォルト無効化あり
  • 画像の最大ファイルサイズは 5 MB、1 リクエストあたり最大 100 画像
考慮すべき点:
  • 共有リネージクォータのため、同じ Sonnet リネージの他バージョン (4.5, 4.6 など) とクォータを共有する
  • Assured Workloads 環境では追加の例外設定が必要な場合がある
  • 30 日間のログ記録 (プロンプトおよび応答) の有効化が Anthropic により推奨されている
