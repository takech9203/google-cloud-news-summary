📋 概要

Cloud SDK 573.0.0 がリリースされ、破壊的変更 1 件と多数の新機能が追加されました。最も注目すべきは Anthos Multi-Cloud における認証情報取得コマンドの統一です。

本リリースでは、AI/ML、データ分析、インフラストラクチャの各領域で重要な機能追加が行われています。Vertex AI のファインチューニングジョブ管理、Artifact Registry のイメージストリーミングキャッシュ、Cloud Data Lineage のコマンドラインサポートなど、CLI からの操作範囲が大幅に拡張されました。

Before / After

Before

  • attached clusters 専用コマンドで認証情報取得 (Fleet 統一管理不可)
  • Vertex AI ファインチューニングは コンソール/REST API のみ
  • Cloud Data Lineage は API 呼び出しが必要
  • Artifact Registry キャッシュ管理の CLI なし

After

  • Fleet memberships で全クラスタ統一管理
  • gcloud ai tuning-jobs で CLI 管理
  • gcloud datalineage で CLI 直接操作
  • BigLake Iceberg カタログ GA で本番運用可能

Breaking Change: コマンド移行

Anthos Multi-Cloud: gcloud container attached clusters get-credentials の非推奨化

Fleet memberships コマンドへの移行が必要です。既存のスクリプトや CI/CD パイプラインで使用している場合は早急に対応してください。

移行パス

非推奨
gcloud container attached clusters get-credentials CLUSTER
→
推奨
gcloud container fleet memberships get-credentials MEMBERSHIP
Connect Gateway を通じて、Fleet に登録された全クラスタ (GKE, EKS, AKS) へ統一的な認証情報取得を提供。--location フラグで位置指定が可能です。
Bash 
# 旧コマンド (非推奨)
# gcloud container attached clusters get-credentials my-cluster

# 新コマンド (推奨)
gcloud container fleet memberships get-credentials my-cluster --location=global

# リージョン指定の場合
gcloud container fleet memberships get-credentials my-cluster --location=us-central1

ユースケース

Anthos Multi-Cloud 環境の移行対応

シナリオ: AWS 上の EKS クラスタを Anthos で管理しており、CI/CD パイプラインで gcloud container attached clusters get-credentials を使用してデプロイを行っている。

Bash 
# CI/CD パイプライン内の更新
# Before (非推奨)
# gcloud container attached clusters get-credentials my-eks-cluster --location=us-west1

# After (推奨)
gcloud container fleet memberships get-credentials my-eks-cluster \
  --location=us-west1
kubectl get pods -n production

効果: GKE, EKS, AKS 全てのクラスタに同一コマンド体系で認証情報取得が可能。スクリプトの保守性が向上。

Vertex AI ファインチューニングの自動化

シナリオ: データサイエンスチームが定期的に新データセットで Gemini モデルをファインチューニングしており、ジョブ管理を自動化したい。

Bash 
# ファインチューニングジョブの作成と監視を自動化
gcloud ai tuning-jobs list --region=us-central1 --filter="state=JOB_STATE_RUNNING"

効果: コンソール不要で CLI からジョブ管理が可能。自動化パイプラインへの組み込みが容易に。
