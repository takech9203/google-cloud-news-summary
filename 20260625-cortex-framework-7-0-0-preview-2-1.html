🔧 Cortex Framework 7.0.0-preview.2.1

tableSettings パス解決の修正

Cortex Framework Public Preview Bugfix
2026-06-25
Google Cloud

📋 概要

Google Cloud Cortex Framework 7.0.0-preview.2.1 がリリースされました。 これは 2026-06-24 にリリースされた 7.0.0-preview.2 に対するマイナーバグフィックスリリースであり、 設定ファイル (config/config.yaml) 内の tableSettings プロパティにおける パス解決の不具合が修正されています。

tableSettings は、Data Foundation モジュールおよび Data Product モジュールのテーブル構成 (マテリアライゼーション方式、パーティショニング、クラスタリングなど) を定義する table_settings.yaml ファイルへのパスを指定するプロパティです。

🔄 Before / After 比較

❌ Before (v7.0.0-preview.2)

  • tableSettings でカスタムパスを指定した場合にパス解決が正しく行われないケースがあった
  • カスタムの table_settings.yaml を使用するマルチインスタンスデプロイで設定ファイルが正しく読み込まれない可能性

✅ After (v7.0.0-preview.2.1)

  • tableSettings のパス解決ロジックが修正され、カスタムパスの指定が期待通りに動作
  • カスタム構成ディレクトリに配置した table_settings.yaml が正しく参照される

💡 フォールバック動作: tableSettings を省略した場合は、従来通り table_settings.default.yaml が使用されます。この動作に変更はありません。

🎯 主要修正内容

🔧 tableSettings パス解決の修正

  • config/config.yaml 内の tableSettings プロパティで指定するファイルパスの解決ロジックを修正
  • Data Foundation モジュールおよび Data Product モジュールの両方に適用
  • デフォルトパス (definitions/data_foundation/{namespace}/table_settings.default.yaml など) へのフォールバック動作には影響なし

📐 技術仕様

項目 詳細
影響を受けるプロパティ tableSettings (foundation / product モジュール)
パスの基準 config/config.yaml からの相対パス
デフォルト動作 tableSettings 省略時は table_settings.default.yaml にフォールバック
修正対象バージョン 7.0.0-preview.2

tableSettings の構成例

YAML config/config.yaml 
data:
  modules:
    foundation:
      - moduleId: erp
        type: cortex.sap
        tableSettings: "config/cortex/data_foundation/sap/table_settings.yaml"

    product:
      - moduleId: accounts_payable
        type: cortex.accounts_payable
        tableSettings: "config/cortex/data_product/accounts_payable/table_settings.yaml"

🚀 対応手順

以下の手順で最新バージョンに更新してください:

  1. Cortex Framework リポジトリを最新 (7.0.0-preview.2.1) に更新する
  2. カスタム tableSettings パスを使用している場合は、設定ファイルが正しく読み込まれることを確認する
Bash リポジトリの更新とデプロイ 
# リポジトリの更新
git pull origin main

# ビルド・デプロイの再実行
uv run cortex-build-and-deploy
