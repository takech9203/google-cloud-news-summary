📱 CCAI Platform: Mobile SDK for iOS v2.15.4

CCaaS CCAI Platform Patch
2026-05-13

📋 概要

Google Cloud の Contact Center AI Platform (CCAI Platform) の iOS 向け Mobile SDK がバージョン 2.15.4 にアップデートされた。本パッチは安定性の向上を目的としたバグ修正リリースであり、新機能の追加は含まれない。

主な修正内容として、iOS アプリが通話切断時にクラッシュする問題の解消、および Twilio Voice SDK と Twilio Chat SDK の更新が含まれる。

⚠️ 対象者: CCAI Platform の Mobile SDK を利用してカスタマーサポート機能を iOS アプリに組み込んでいる開発者

🔄 Before / After

❌ Before (v2.15.3 以前)

  • iOS アプリが VoIP 通話の切断処理中にクラッシュする不具合が発生
  • Twilio Voice SDK および Chat SDK が旧バージョンのまま

✅ After (v2.15.4)

  • 切断時のクラッシュ問題が解消、通話終了時の安定性が向上
  • Twilio Voice SDK および Chat SDK が最新バージョンに更新、セキュリティ改善

🔧 修正内容

🛠️ 切断時クラッシュの修正

iOS アプリが VoIP 通話の切断処理中にクラッシュする問題を修正。通話終了時のリソース解放処理が正常に完了するようになった。

📦 Twilio SDK の更新

Twilio Voice SDK および Chat SDK を最新バージョンに更新。基盤通信ライブラリのセキュリティ修正と安定性改善を反映。

⚙️ 設定方法

📝 前提条件:
  • CCAI Platform Mobile SDK が既にプロジェクトに統合されていること
  • CocoaPods、Swift Package Manager、または Carthage による依存関係管理を使用していること

CocoaPods を使用する場合

Ruby 
# Podfile
pod 'UJET', :podspec => 'https://sdk.ujet.co/ios/2.15.4/ujet.podspec'
Bash 
pod update UJET

Swift Package Manager を使用する場合

Xcode のパッケージ依存関係で CCAI Platform iOS SDK パッケージを最新バージョン (2.15.4) に更新する。
