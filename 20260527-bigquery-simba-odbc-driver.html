🔌 BigQuery: Simba ODBC ドライバー更新版リリース

BigQuery GA v3.1.6.3037
2026-05-27

📋 概要

Google Cloud は、BigQuery 向け Simba ODBC ドライバーの更新版 (v3.1.6.3037) をリリースしました。Simba ODBC ドライバーは、ODBC インターフェースを通じて、レガシーアプリケーションやエンタープライズツール (Microsoft Excel、Tableau、Power BI など) から BigQuery へのシームレスな接続を実現するコネクタです。

insightsoftware 社が開発し、Google Cloud Ready - BigQuery パートナーとして認定されています。ドライバー自体は無償提供です。

🏗️ アーキテクチャ図

Simba ODBC ドライバーは、クライアントアプリケーションと BigQuery の間に位置し、ODBC 標準インターフェースを BigQuery REST API 呼び出しに変換します。大規模なデータ読み取りには BigQuery Storage Read API (High-Throughput API) を利用して高速なデータ転送を実現します。

⚙️ 設定方法

前提条件

💡 必要な準備:
  • Google Cloud プロジェクトが作成済みであること
  • BigQuery API が有効化されていること
  • 適切な IAM ロール (BigQuery User 以上) が付与されていること
  • High-Throughput API を使用する場合は roles/bigquery.readSessionUser ロールが必要

DSN 設定 (Windows)

INI 
[ODBC Data Sources]
BigQuery_DSN=Simba ODBC Driver for Google BigQuery

[BigQuery_DSN]

OAuthMechanism=0
ProjectId=your-project-id
KeyFilePath=C:\path\to\service-account-key.json
DefaultDataset=your_dataset

DSN 設定 (Linux/macOS)

INI 
# odbc.ini
[BigQuery_DSN]
Driver=Simba ODBC Driver for Google BigQuery
OAuthMechanism=0
ProjectId=your-project-id
KeyFilePath=/path/to/service-account-key.json
DefaultDataset=your_dataset

# odbcinst.ini
[Simba ODBC Driver for Google BigQuery]
Driver=/opt/simba/googlebigqueryodbc/lib/64/libgooglebigqueryodbc_sb64.so

Bash 
# isql コマンドで接続テスト (unixODBC)

High-Throughput API の有効化 (オプション)

Bash 
# 必要な IAM ロールの付与
gcloud projects add-iam-policy-binding PROJECT_ID \
  --member="serviceAccount:SA_EMAIL" \
  --role="roles/bigquery.readSessionUser"

⚠️ デメリット・制約事項

知っておくべき制限:
  • BigQuery のデータロード/エクスポート機能はドライバー経由では利用不可
  • DML (INSERT/UPDATE/DELETE) には BigQuery 固有の制限が適用
  • BigQuery 専用 - 他の Google Cloud サービスには使用できない
  • パラメータ化クエリはクエリ検証のみ
💡 考慮すべき点:
  • ドライバー更新時は既存 DSN 設定の動作確認テストを推奨
  • High-Throughput API は追加の IAM ロール付与と Storage Read API 料金が発生
  • 32-bit アプリケーション使用時は 32-bit 版ドライバーの明示的インストールが必要

💼 ユースケース

📊 ユースケース 1: Excel から BigQuery への直接接続

シナリオ: 財務部門のアナリストが、BigQuery に格納された売上データを Excel のピボットテーブルで分析。プログラミング不要で使い慣れた Excel から直接アクセス。

効果: データエンジニアに依頼せず、アナリスト自身がリアルタイムに BigQuery のデータを分析可能。レポート作成時間を大幅に短縮。

📈 ユースケース 2: Tableau での大規模データ可視化

シナリオ: データ可視化チームが、数十億行のログデータを Tableau で可視化。High-Throughput API を活用して高速にデータを取得。

効果: BigQuery Storage Read API により大規模データセットの読み取り速度が大幅向上。ダッシュボードの初期表示時間を短縮。

🔄 ユースケース 3: レガシーシステムからの段階的移行

シナリオ: オンプレミス SQL Server のレガシーアプリケーションを BigQuery に段階的に移行。アプリケーションコード変更なしで ODBC 接続先のみ切り替え。

効果: アプリケーションのリファクタリングなしに BigQuery へ切り替え可能。リスクを最小化しつつクラウド移行を推進。

🌍 利用可能リージョン

Simba ODBC ドライバーはクライアントサイドにインストールするソフトウェアであるため、リージョン制限はありません。BigQuery のデータセットが存在する任意のリージョンおよびマルチリージョン (US、EU) に対して接続可能です。

💡 Private Service Connect を使用する場合: 対応リージョンのカスタムエンドポイントを指定する必要があります。
