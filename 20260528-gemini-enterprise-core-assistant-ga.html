Gemini Enterprise: Core Assistant GA

Core Assistant の一般提供開始と Trace/Metrics 機能のプレビューリリース

GA Preview
2026-05-28

📋 概要

Google は Gemini Enterprise において、Core Assistant の一般提供 (GA) を開始しました。Core Assistant は Google が提供する「Made by Google」ルートエージェントであり、ユーザーが Gemini Enterprise アプリで特定のエージェントを指定せずに対話する際のデフォルトハンドラーとして機能します。

さらに、新しいオブザーバビリティ (可観測性) 機能として Traces タブ と Metrics タブ が Public Preview として追加されました。

🤖 対象ユーザー: Gemini Enterprise を利用してエージェントベースの AI アプリケーションを構築・運用している組織の管理者と開発者。Gemini Enterprise Frontline Edition では利用不可。

🔄 Before / After

❌ Before (アップデート前)

  • 統合的な可観測性ツールが Gemini Enterprise 内に組み込まれていなかった
  • エージェント未指定時のデフォルト応答ハンドリングが限定的
  • 運用状態のリアルタイム監視に外部ツールの別途構築が必要

✅ After (アップデート後)

  • Core Assistant が設定不要で即座にルートエージェントとして機能
  • Traces タブで OpenTelemetry ベースのスパン可視化 (30日間保持)
  • Metrics タブが追加課金なしでデフォルト有効

⚡ 主要機能

🤖 Core Assistant (一般提供)

✓Google マネージドのルートエージェント - 設定不要で即座に利用可能
✓ユーザーが特定エージェントを指定しない場合にデフォルトで応答
✓Gemini Enterprise アプリに自動プロビジョニング
✓Google Cloud コンソールから確認可能
✗構成の編集やダッシュボードのカスタマイズは不可

🔍 Traces タブ (Public Preview)

✓トレースレコードの時系列サマリー提供
✓Agent to Tool / Invoke Agent / Agent to Model の親子スパン詳細
✓実行フロー、入力、出力、レイテンシーを検査可能
✓DAG (有向非巡回グラフ) とタイムライン表示
✓データ保持: 30日間
⚠️ 注意: OpenTelemetry トレースの有効化が必要 (デフォルト OFF)

📈 Metrics タブ (Public Preview)

✓デフォルトで有効 - 手動設定不要
✓セッション数、エージェント呼び出し回数、トラフィック表示
✓ツールコール数、エラーレート表示
✓接続ツールのレイテンシーメトリクス
✓データ保持: 42日間 (6週間)
✓追加課金なし

📋 前提条件:
  • Gemini Enterprise アプリが構成済み
  • Gemini Enterprise Admin ロール (discoveryengine.agentspaceAdmin) または Gemini Enterprise User ロール
  • Traces 使用時: Cloud Trace User ロール (roles/cloudtrace.user)

✅ メリット

ビジネス面

✓即時の運用可視化: Metrics がデフォルトで有効なため、導入コストゼロでエージェントの運用状態を把握可能
✓追加課金なしのモニタリング: 既存の Gemini Enterprise ライセンスに含まれる
✓障害対応の迅速化: Traces により MTTR を短縮
✓運用の標準化: Google マネージドのルートエージェントで一貫したユーザー体験を提供

技術面

✓OpenTelemetry 標準準拠: ベンダーニュートラルなトレーシング標準、既存ツールとの統合容易
✓ゼロコンフィグのメトリクス: 手動設定なしでセッション数、レイテンシー、エラーレートを自動収集
✓詳細なスパン分析: Agent to Tool、Agent to Model などスパンタイプごとに実行フローを可視化
✓長期データ保持: Traces 30日 / Metrics 42日のデータ保持でトレンド分析可能

⚠️ デメリット・制約事項

制限事項:
  • Core Assistant の設定やダッシュボードはカスタマイズ不可 (完全に Google マネージド)
  • Gemini Enterprise Frontline Edition では利用不可
  • Traces 機能は OpenTelemetry の有効化が必須 (デフォルト OFF)
  • Preview 機能のため SLA 対象外 (Pre-GA Offerings Terms に準拠)
  • Traces データ保持は 30 日間に制限 (長期保存は別途エクスポートが必要)
💡 考慮すべき点:
  • Preview 機能は将来的に仕様変更やサポート制限がある可能性
  • OpenTelemetry トレース有効化でテレメトリデータ送信量が増加し、Cloud Trace コストに影響する場合あり
  • Core Assistant はルートエージェントとして動作するため、カスタムエージェントとの優先順位設定に注意
  • プロンプト/レスポンスデータは Trace スパンには直接保存されず、Cloud Logging/Cloud Storage に別途保存 (IAM 制御が必要)

🌍 利用可能リージョン

Core Assistant は Gemini Enterprise が利用可能な全リージョンで自動的にプロビジョニングされます。具体的な対応リージョンについては Gemini Enterprise のドキュメント を参照してください。

🔗 関連サービス・機能

→Gemini Enterprise Agent Platform: エージェントの構築・デプロイ・管理プラットフォーム。Core Assistant はそのルートエージェント
→Cloud Trace: OpenTelemetry トレースデータの保存・分析基盤。Traces 機能のバックエンド
→Cloud Logging: エージェントのプロンプトとレスポンスのログ保存先
→OpenTelemetry: CNCF のオブザーバビリティフレームワーク。トレース標準として採用
→Agent Registry: Gemini Enterprise Agent Platform でエージェントを登録・管理するレジストリ

📝 まとめ

Gemini Enterprise Core Assistant の GA リリースにより、ユーザーは設定不要でインテリジェントなルートエージェント機能を利用できるようになりました。

Public Preview の Traces と Metrics 機能は、追加コストなしでエージェントの実行フローと運用状態を可視化し、AI エージェントプラットフォームの本格運用に必要な監視基盤を提供します。

💡 推奨アクション: Gemini Enterprise を利用している組織は、まず Metrics タブの確認から始め、詳細なデバッグが必要な場合には OpenTelemetry トレースを有効化することを推奨します。
