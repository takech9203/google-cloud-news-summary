📝 概要

Looker 26.24 のリリースが発表された。Looker (original) インスタンスへのロールアウトは 2026 年 11 月 8 日 (日) に開始され、最終デプロイとダウンロード提供は 2026 年 12 月 8 日 (火) に完了予定。Looker (Google Cloud core) 向けのロールアウトは別途アナウンスされる。

最大のトピックは Filters as tiles (タイルとしてのフィルター) の一般提供 (GA) 開始。ダッシュボードのフィルターを上部フィルターバーだけでなく、キャンバス上にタイルとして自由に配置できるようになり、関連ビジュアライゼーションの隣に置くことで文脈に沿った直感的なフィルタリング体験を提供できる。さらに、KPI ツールチップ、スケジュール配信、API エラーハンドリング、アクセシビリティ、Conversational Analytics など幅広い領域で 35 件以上の品質改善が行われている。

❌ アップデート前の課題

  • Filters as tiles は Preview 機能で、本番利用には Pre-GA 提供条件が適用
  • KPI ビジュアライゼーションのカスタムツールチップで値フォーマット・配置設定が効かず、comparison 系 Liquid 変数も保存不可
  • ファイル名にスペースがあると Google Sheets に重複スプレッドシート作成、PDF / HTML が破損して配信されるなど配信の不具合
  • 一部 API が不正リクエストに HTTP 422/400 ではなく HTTP 500 を返却
  • モデルセットマッチングでアンダースコアがワイルドカード扱いされ、類似名モデルの接続に意図しないセルフサービスアクセスが許可され得た

✅ アップデート後の改善

  • Filters as tiles が GA となり、フィルターをキャンバス上のタイルとして正式利用可能に
  • KPI ツールチップ関連の 4 件を修正し、フォーマット・配置・Liquid 変数が期待通り動作
  • 配信の信頼性が向上: ファイル名の扱い、権限チェック、配信ファイルの破損、DST (夏時間) 変更への追従を改善
  • API が適切な 4xx ステータスコード (422 / 400) を返却するように修正
  • セキュリティ修正 (モデルセットマッチング、非管理者による他ユーザー開発プロジェクト削除) を適用

🧩 主要機能: Filters as tiles の GA

1️⃣ フィルターのキャンバス配置

  • ダッシュボードフィルターを上部フィルターバーからキャンバス上のタイルとして配置可能
  • フィルターバーからドラッグ、または「Send to dashboard」で移動し、「Send to filter bar」でバーに戻せる
  • フィルタータイルは他のタイルと同様にドラッグで配置変更できる

2️⃣ 配置と適用範囲の独立性

  • フィルターの配置場所 (フィルターバー / キャンバス) は、どのタイルに適用されるかには影響しない
  • 1 つのフィルターはダッシュボード上に 1 回だけ表示される (複製すると別 ID の新しいフィルターが作成される)

3️⃣ タイル単位のフィルターコンテキスト表示

  • 閲覧者は「Show Filters」アイコンから、タイルに適用中のフィルター (Vis Filters / Dashboard Filters / Query Filters) を一覧できる
  • ダッシュボード設定「Tile filter information」で表示範囲 (Show all / Hide query filters / Do not show) を制御できる

4️⃣ LookML ダッシュボード対応

  • LookML ダッシュボードでも elements セクションでフィルター要素をタイルとして配置できる
  • filter context 設定パラメータでタイル上の適用フィルター表示を制御できる

🔧 修正内容 (テーマ別・35 件以上)

📈 KPI ビジュアライゼーションとツールチップ 4 件

  • カスタムツールチップが Value Format / Comparison Value Format や左右中央の配置設定を適用しない問題を修正
  • comparison 系 Liquid 変数 (comparison_value など) がツールチップエディタで保存できない問題を修正
  • 長いタイルノート展開時に KPI 値・比較値・スパークラインと重なる問題を修正 (タイル半分の範囲でスクロール表示)

📬 スケジュール配信 4 件

  • ファイル名のスペースで Google Sheets の重複スプレッドシート作成、Google Drive でのアンダースコア置換を修正
  • 所有者が Development Mode 有効かつ develop 権限なしの場合に配信が失敗する問題を修正
  • 単一カラムのダッシュボード PDF 破損、Workflow Agent の HTML 未整形配信を修正 (Slack / Drive / Cloud Storage / Azure / Dropbox)
  • スケジュールトリガーとテーブル計算のタイムゾーン評価を最近の DST (夏時間) 変更に追従

🔒 API とセキュリティ 6 件

  • dashboard_filters への不正属性で HTTP 500 ではなく HTTP 422 を返すように修正
  • GET /auth の不正な redirect_uri で HTTP 400 を返すように修正
  • POST /api/token の Content-Type なしリクエストが HTTP 500 になる問題を修正
  • モデルセットマッチングのアンダースコアがワイルドカード扱いされる問題を修正
  • 非管理者が他ユーザーの未デプロイ開発プロジェクトを API 経由で削除できる問題を修正
  • API での Admin ユーザーのロール更新が失敗することがある問題を修正

🗄️ データベース接続と認証 3 件

  • OAuth 認証への切り替え時に古い設定フィールドが残り接続エラーになる問題を修正 (既存切り替え済み接続は再保存が必要)
  • Databricks の OAuth リフレッシュトークンがクライアント側で 7 日で期限切れ扱いされる問題を修正
  • プロジェクトスコープ接続でのビジュアルモデリングキャンバス作成失敗を修正

📊 チャートとダッシュボード UI 9 件

  • Show Percent of Previous の矢印・ラベルがバーに重なる問題を修正
  • Chart Config Override の Sankey チャートがエラーで失敗する問題を修正
  • Series Positioning の切り替え (Stacked → Overlay / Grouped) で描画が更新されない問題を修正
  • マルチセレクトフィルターのドロップダウン再オープン、タグリストフィルターの横方向リサイズを修正
  • 数値パラメータフィルターの tier 誤分類、XLS アップロード不可、タイルノート内リンクのクリック不可などを修正
  • お気に入り登録/解除で最終アクセス時刻が更新され Unused Content リストから誤除外される問題を修正

🤖 Conversational Analytics と System Activity 5 件

  • Workflow Agent 実行のダッシュボード会話への誤カウント、Engagement タブの Agent フィルター不具合を修正
  • Top Agents / Agents Not Used in Last 30 Days タイルで Agent ID と併せてエージェント名を表示
  • Agent ID リンクの HTTP 404 遷移を修正
  • Code Interpreter 設定の上書き・即時反映されない・無効化が効かない問題を修正

♿ アクセシビリティと管理機能 4 件

  • スクリーンリーダーが Yes/No・グループフィルターの名前/ラベルを読み上げない問題を修正
  • 1 系列 200 以上のデータポイントでスクリーンリーダーが読み上げない問題を修正
  • SAML / OIDC 設定の IdP グループロールマッピングでロールがソート・検索可能に
  • 大規模 Git リポジトリでのレガシー Marketplace プラグイン更新タイムアウトを修正

🎯 ユースケース

📊 ユースケース 1: セクション別フィルターを持つ運用ダッシュボード

シナリオ: 売上セクションと在庫セクションを持つダッシュボードで、各セクションに関係するフィルターをそのセクションの先頭に配置したい。

効果: Filters as tiles により、フィルターを対象タイル群の直前に配置でき、閲覧者はどのフィルターがどのビジュアライゼーションに影響するかを直感的に理解できる。「Show Filters」でタイルごとの適用フィルターも確認できる。

📬 ユースケース 2: 定期レポートの配信運用の安定化

シナリオ: ファイル名にスペースを含むレポートを Google Sheets へ定期配信しており、毎回重複スプレッドシートが作成されて運用負荷になっていた。

効果: 26.24 への更新により、既存スプレッドシートが正しく上書きされるようになり、重複ファイルの手動削除が不要になる。
