📋 概要

Google SecOps Marketplace において、7 つのサードパーティインテグレーションが同時にアップデートされた。新機能の追加 (Wiz、SentinelOne Singularity Operations Center、Proofpoint Email Protection) と既存インテグレーションの改善 (Azure Monitor、QRadar、Jira、Google Chronicle) が含まれる。

SOC チームの脅威検知・対応ワークフローを強化する内容となっており、特にインシデントレスポンスの自動化を大幅に進化させる。

❌ アップデート前の課題

  • Wiz Blue Agent Analysis を SecOps 内で直接取得不可
  • SentinelOne Singularity Operations Center との統合なし
  • Proofpoint 隔離メールのダウンロード自動化不可
  • QRadar のタイムスタンプ追跡が不正確
  • Jira でカスタム JQL / 日付範囲フィルタ不可
  • Chronicle の Wiz Defend マッピングが未最適化

✅ アップデート後の改善

  • Blue Agent Analysis を SOAR プレイブック内で自動取得
  • Singularity Operations Center との統合が実現
  • 隔離メールのダウンロード・フォレンジック自動化
  • last_persisted_time で確実な変更追跡
  • Created Before / Custom JQL で高度検索可能
  • Wiz Defend 検出の適切な処理・マッピング

🆕 新機能 (Features)

🔍 Wiz v14.0 - "Get Blue Agent Analysis" アクション追加

→Wiz のランタイムセンサー (Blue Agent) による脅威分析結果をプレイブック内から直接取得可能に
→プロセス実行、ネットワーク接続、ファイル操作などのコンテキスト情報を SOAR ワークフローに統合
→インシデント調査時に Wiz コンソールへの切り替えが不要になり、対応速度が向上

🛡️ SentinelOne Singularity Operations Center v1.0 - 新規インテグレーション

→SentinelOne の統合運用センターとの初の直接統合
→既存の SentinelOne / SentinelOneV2 とは異なり、運用センターレベルの統合管理機能に対応
→複数サイト・テナントにまたがるセキュリティイベントの統合的な管理・対応が可能

📧 Proofpoint Email Protection v10.0 - "Download Quarantined Email" アクション追加

→隔離されたメールのコンテンツを直接ダウンロードする機能を追加
→既存の Search / Move / Delete / Resubmit に加え、フォレンジック分析用のダウンロード機能が利用可能
→マルウェア分析ツールへの自動転送やメール本文の証拠保全をプレイブックで自動化

🔄 既存インテグレーションの改善 (Changes)

☁️ Azure Monitor v5.0 - ドキュメントリンク更新

→インテグレーションのドキュメントリンクが最新のものに更新、設定手順へのアクセスが改善

📋 QRadar v69.0 - タイムスタンプフィルタリング改善

→QRadar Offenses Connector で変更追跡用のタイムスタンプが last_persisted_time に変更
→オフェンスの更新・変更がより正確に検出、取りこぼしリスクが低減
→特に高負荷環境でのオフェンス同期の信頼性が向上

🎫 Jira v60.0 - 検索フィルタリング強化

→「List Issues」アクションに「Created Before」日付フィルタパラメータを追加
→Custom JQL クエリパラメータのサポート追加、任意の JQL 式でイシュー検索が可能に
→セキュリティインシデントの時系列分析や複雑な条件でのチケット検索を自動化

📰 Google Chronicle v90.0 - Wiz Defend 検出処理とオントロジーマッピング改善

→Chronicle Alerts Connector で Wiz Defend の検出結果の処理ロジックを更新
→オントロジーマッピングが改善、Wiz Defend からのアラートが Chronicle SIEM 内でより正確に分類・表示

⚠️ デメリット・制約事項

制限事項:
  • SentinelOne Singularity Operations Center v1.0 は初期リリースのため、利用可能なアクション数が限定的な可能性あり
  • QRadar コネクタのタイムスタンプ変更により、既存のカスタムフィルタリングロジックに影響の可能性
  • オントロジーマッピングの Override を選択した場合、既存のカスタムマッピングが失われる
💡 推奨事項:
  • アップデート前に、既存プレイブックとの互換性をテスト環境で確認
  • QRadar v69.0 へのアップデート時は、既存のオフェンスコネクタ設定の動作確認が必要
  • Chronicle v90.0 のオントロジーマッピング変更が既存の検出ルールに影響する可能性を検証

💡 ユースケース

🔍 ユースケース 1: Wiz + SecOps によるランタイム脅威自動調査

シナリオ: Wiz がクラウドワークロード上でランタイムの不審な挙動を検出した際、SecOps プレイブックが自動的に Blue Agent Analysis を取得してコンテキストを補完し、重要度に応じてエスカレーションまたは自動対処を行う。

効果: アナリストが Wiz コンソールに切り替えることなく、SecOps 内で完結した脅威調査が可能になり、MTTR が大幅に短縮される。

📧 ユースケース 2: フィッシングメールの自動フォレンジック分析

シナリオ: Proofpoint がフィッシングメールを隔離した際、SecOps プレイブックが自動的にメールをダウンロードし、添付ファイルをサンドボックスに送信してマルウェア分析を実施。結果に基づいて IOC を Chronicle SIEM に登録する。

効果: メールセキュリティインシデントの証拠収集から IOC 登録までの一連のフローが自動化され、手動作業が排除される。

🎫 ユースケース 3: Jira を活用したセキュリティインシデント管理の高度化

シナリオ: セキュリティインシデント発生時に Custom JQL を使用して関連チケットを横断検索し、過去の類似インシデントの対応履歴を自動取得してアナリストに提示する。

効果: 過去のインシデント対応のナレッジが自動的に活用され、一貫性のある対応と学習効果の向上が実現される。

💰 料金

Google SecOps Marketplace のインテグレーション利用自体には追加料金は発生しない。Google SecOps プラットフォームの利用料金に含まれる。
