🎬 Gemini Omni 1.2 Flash が GA に

テキスト・画像・動画から同期音声付き HD 動画を生成するオムニモーダルモデル
📅 リリース日: 2026-11-05

📋 概要

オムニモーダル基盤モデル Gemini Omni 1.2 Flash (gemini-omni-1.2-flash) が 一般提供 (GA) になりました。テキスト・画像・動画の入力を処理し、Interactions API を通じて テキストおよび同期音声付きの高解像度動画を生成します。

今回の GA では、単体の動画アップスケーリング (task: "upscale")、最大 15 秒への動画生成・編集時間の拡張、 参照画像を使った動画編集・拡張、seed 指定による決定論的な生成、課金ラベルの付与が追加されました。 消費オプションは Standard PayGo と Provisioned Throughput の両方に対応します。

❌ Before (アップデート前の課題)

  • Gemini Omni Flash 系は Preview 提供のみで本番利用不可 (初代 gemini-omni-flash-preview は 2026-11-06 廃止予定)
  • 高解像度化は生成時の resolution 指定のみで、後からのアップスケール不可
  • 生成・編集できる動画は 3〜10 秒に制限
  • 参照画像は動画生成のみ対応、編集・拡張では使えない
  • seed 指定や課金ラベル付与に非対応

✅ After (アップデート後の改善)

  • gemini-omni-1.2-flash が GA となり本番ワークロードで利用可能
  • task: "upscale" で 360p → 720p/1080p、720p → 1080p/4K に単体アップスケール
  • 各生成・編集タスクで最大 15 秒に拡張 (フレーム補間・拡張は最大 10 秒)
  • 編集・拡張時に最大 2 枚の参照画像を併用可能
  • seed による再現性確保とカスタム課金ラベルに対応
  • Standard PayGo + Provisioned Throughput の両消費オプション

テキスト・画像・動画のマルチモーダル入力を Interactions API 経由で Gemini Omni 1.2 Flash に渡し、 テキストと同期音声付き HD 動画を生成します。生成済みの動画は task: "upscale" で最大 4K まで単体アップスケールできます。

⚡ 主要機能

1️⃣ 単体の動画アップスケーリング (Standalone video upscaling)

→task: "upscale" の指定で、過去に生成した動画を単体でアップスケール可能
→360p → 720p / 1080p、720p → 1080p / 4K に変換
→低解像度でドラフトを量産し、採用カットのみを高解像度化するワークフローが実現

2️⃣ 動画生成・編集時間の拡張 (最大 15 秒)

→text-to-video、image-to-video、reference-to-video、動画編集で最大 15 秒に対応
→最初と最後のフレーム補間・動画拡張は最大 10 秒
→従来モデル (Gemini Omni 1.1 Flash Preview) の出力は 3〜10 秒だった

3️⃣ 参照画像を使った動画編集・拡張 (Reference-guided editing and extension)

→動画の編集・拡張時に、入力動画と合わせて最大 2 枚の参照画像を指定可能
→被写体やスタイルを参照画像で指示しながら、一貫性を保った編集・継続生成ができる

4️⃣ 決定論的な生成と課金ラベル

→seed 指定で再現性のある動画出力を取得
→Interactions API リクエストへのカスタムラベル付与で、チーム別・用途別のコスト配賦が可能

5️⃣ Standard PayGo と Provisioned Throughput

→Standard Pay-as-you-go (PayGo) による従量課金での利用
→Provisioned Throughput (1 GSU あたり 685 トークン/秒) でスループットを事前購入

📡 Interactions API のタスク構成

Interactions API では generation_config.video_config.task で動画タスクを指定します。 アップスケーリングでは task: "upscale" を使用します。

JSON アップスケーリングのリクエスト例 
{
  "model": "gemini-omni-1.2-flash",
  "input": [
    { "type": "video", "uri": "gs://video-bucket/input/draft_720p.mp4", "mime_type": "video/mp4" }
  ],
  "response_format": [
    {
      "type": "video",
      "delivery": "uri",
      "resolution": "4k",
      "gcs_uri": "gs://video-bucket/output/"
    }
  ],
  "generation_config": {
    "video_config": {
      "task": "upscale"
    }
  }
}

ステップ 1: Interactions API で動画を生成する

Bash text-to-video で 720p 動画を生成 
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "model": "gemini-omni-1.2-flash",
    "input": "A drone shot of a mountain landscape at sunrise.",
    "response_format": [
      { "type": "video", "delivery": "uri", "resolution": "720p", "gcs_uri": "gs://video-bucket/output/" }
    ]
  }' \
  "https://aiplatform.googleapis.com/v1beta1/projects/PROJECT_ID/locations/global/interactions"
💡 ヒント: resolution と duration を明示的に指定すると、 Provisioned Throughput 利用時のリクエストサイズ推定が正確になり、PayGo への不要なスピルオーバーを防げます。

ステップ 2: 生成済み動画をアップスケールする

Bash 720p の動画を 4K にアップスケール 
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "model": "gemini-omni-1.2-flash",
    "input": [
      { "type": "video", "uri": "gs://video-bucket/output/draft_720p.mp4", "mime_type": "video/mp4" }
    ],
    "response_format": [
      { "type": "video", "delivery": "uri", "resolution": "4k", "gcs_uri": "gs://video-bucket/output/" }
    ],
    "generation_config": { "video_config": { "task": "upscale" } }
  }' \
  "https://aiplatform.googleapis.com/v1beta1/projects/PROJECT_ID/locations/global/interactions"

task: "upscale" を指定して 720p の動画を 4K にアップスケールします。詳細な手順は公式ドキュメントの「Upscale videos」を参照してください。

💡 メリット

💼 ビジネス面

✓本番利用が可能に: GA 昇格により本番ワークロードでの動画生成パイプラインを構築できる
✓コスト効率の高い制作フロー: 低解像度でドラフトを量産し、採用カットのみを 1080p / 4K にアップスケール
✓コスト配賦の可視化: カスタム課金ラベルでチーム別・プロジェクト別のコスト管理が容易に
✓柔軟な調達オプション: 変動ワークロードは PayGo、安定トラフィックは Provisioned Throughput と使い分け

⚙️ 技術面

✓単一モデルでのオムニモーダル処理: 入力から同期音声付き動画出力まで 1 モデル・1 API で完結
✓再現性の確保: seed 指定で同じ入力から同じ出力が得られ、テストや A/B 比較が容易
✓一貫性のある編集: 最大 2 枚の参照画像で被写体・スタイルの一貫性を維持
✓より長い尺の生成: 最大 15 秒でショート広告や SNS クリップを 1 回の生成でカバー

⚠️ デメリット・制約事項

🚧 制限事項

✗最初と最後のフレーム補間と動画拡張は最大 10 秒まで (15 秒対応は生成・編集タスクのみ)
✗アップスケーリングの変換パスは「360p → 720p / 1080p」「720p → 1080p / 4K」に限定
✗編集・拡張時に指定できる参照画像は最大 2 枚

🤔 考慮すべき点

⚠️ Provisioned Throughput のクォータ適用ウィンドウ: Gemini Omni モデルは購入 GSU 数に応じたクォータ適用ウィンドウ (quota enforcement window) が設定され、 小規模な GSU 購入ではウィンドウが長くなります (従来モデルの例では 1 GSU で 2,000 秒)。 高頻度に動画を生成する場合は GSU 数の増加を検討してください。
⚠️ PayGo へのスピルオーバー: 長尺・高解像度 (特に 4K) のリクエストは 1 つのウィンドウに収まらない場合、PayGo へスピルオーバーする可能性があります。 duration と resolution の明示的な指定を推奨します。
🚨 旧 Preview モデルの廃止: gemini-omni-flash-preview は 2026 年 11 月 6 日に廃止予定です。 利用中の場合は GA モデル (gemini-omni-1.2-flash) への移行計画が必要です。

💰 料金

Gemini Omni 1.2 Flash は以下の 2 つの消費オプションで利用できます。

💳 Standard Pay-as-you-go (PayGo)

使用量に応じた従量課金。変動の大きいワークロードや検証フェーズに適しています。

📦 Provisioned Throughput

1 GSU あたり 685 トークン/秒のスループットを事前購入。安定した本番トラフィックに適しています。

💡 具体的な単価: Gemini Enterprise Agent Platform の料金ページ を参照してください。

🌏 利用可能リージョン

従来の Gemini Omni Flash 系モデルは global リージョンで提供されています。 Gemini Omni 1.2 Flash の最新の提供状況は モデルの利用可能リージョン を参照してください。

🔗 関連サービス・機能

🔌 Interactions API

Gemini Omni モデルで動画生成・編集を行うための API。ステートフルなマルチターン編集 (previous_interaction_id) や非同期実行 (background: true) に対応。

🪣 Cloud Storage

入力動画の読み込み (gs:// URI) と生成動画の出力先 (gcs_uri) として利用。

📦 Provisioned Throughput

本番ワークロード向けにスループット (GSU) を事前購入する仕組み。GSU 見積もりツールが Google Cloud コンソールで利用可能。

🔏 Content Credentials (C2PA)

Gemini Omni 系モデルの生成動画に対応するコンテンツ来歴情報。
