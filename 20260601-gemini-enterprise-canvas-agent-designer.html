📋 概要

Gemini Enterprise に 2 つの重要なアップデートが同時リリースされました。Agent Designer の Gemini 3.5 Flash 自動移行と、Canvas によるインタラクティブなドキュメント・スライド作成ツールの Public Preview 提供開始です。

🤖 Canvas とは: Gemini Enterprise ウェブアプリ内の専用ツール。チャットとサイドバイサイドで AI 生成ドキュメントやプレゼンテーションを作成・編集でき、Google Workspace / Microsoft Office / PDF にエクスポート可能。

❌ Before (アップデート前)

  • Agent Designer は Gemini 3.1 Pro で動作、最新の推論能力を活用不可
  • ドキュメント作成には外部アプリへの切り替えが必要
  • AI の回答を構造化ドキュメントに変換するプロセスが手動で煩雑

✅ After (アップデート後)

  • Gemini 3.5 Flash の高度な推論・エージェンティック能力を自動利用
  • Canvas で画面を離れずに AI 生成ドキュメント・スライド作成
  • 複数フォーマットへワンクリックエクスポート
  • AI によるトーン調整・部分的リライトなどインタラクティブ編集

⚙️ 設定方法

前提条件

✓Gemini Enterprise (Business / Standard / Plus) ライセンス保有
✓管理者が Canvas 機能を有効化済み (Canvas 利用の場合)
✓Google Drive データストア接続済み (Docs/Slides エクスポートの場合)

Step 1: Canvas の有効化 (管理者)

管理コンソール操作 
1. Google Cloud Console > Gemini Enterprise > Apps に移動
2. 対象アプリを選択
3. Web app feature management を開く
4. "Enable Canvas" トグルを ON に変更
5. 保存

Step 2: Canvas でドキュメントを作成 (ユーザー)

ユーザー操作 
1. Gemini Enterprise ウェブアプリにサインイン
2. 新しいチャットを開始
3. "Tools" をクリック、または "/" を入力してショートカットリスト表示
4. "Canvas (Preview)" を選択
5. ドキュメント作成のプロンプトを入力して送信
6. 右側の Canvas エディタでドキュメントが表示される

Step 3: Agent Designer でモデル変更 (オプション)

💡 ヒント: Gemini 3.5 Flash 以外のモデルを使用したい場合のみ必要。会話型チャットまたはフロービルダーでエージェント設定を編集できます。
フロービルダーでの変更 
1. Agent Designer キャンバスの "Flow" タブをクリック
2. メインエージェントノードをクリック
3. "Gemini model" フィールドを変更
4. "Update" をクリックして保存

⚠️ 制限事項・注意点

⚠️ 制限事項:
  • Canvas は Public Preview (Pre-GA 提供条件、サポート限定的)
  • Canvas はウェブアプリのみ対応 (モバイル非対応)
  • Canvas 対応リージョン: Global, US, EU のみ
  • スライド更新は毎回新規アーティファクト生成 (バージョニングなし)
  • Canvas はアクティブセッション中のコンテンツ編集のみサポート
⚠️ 考慮すべき点:
  • Agent Designer のモデル自動移行で既存エージェントの動作が変わる可能性 (テスト推奨)
  • デフォルト思考レベルが medium に変更 (以前の high 依存エージェントは確認要)
  • Canvas クォータは通常チャットと共有 (頻繁利用でチャット利用量に影響)
  • Google Docs/Slides エクスポートには Drive データストア接続 + Workspace ライセンスが必要
