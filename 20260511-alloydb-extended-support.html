AlloyDB for PostgreSQL: Extended Support

AlloyDB for PostgreSQL Announcement
2026-05-11

📋 概要

AlloyDB for PostgreSQL が、PostgreSQL コミュニティによって End-of-Life (EOL) に達したメジャーバージョンを実行するクラスタに対して、Extended Support (延長サポート) を提供開始。レギュラーサポート終了後に追加で 3年間 のサポートを提供し、メジャーバージョンアップグレードの計画と実行に十分な時間的猶予を与えます。

⚡ 主要機能

🔄 自動登録

PostgreSQL メジャーバージョンが AlloyDB の EOL 日 (コミュニティ EOL の3ヶ月後) に達すると自動的に登録。追加設定不要。3ヶ月前から事前通知あり。

🔒 セキュリティ/バグ修正の継続

Critical/High 重大度の CVE パッチ、AlloyDB 管理コードのバグ修正、SLA カバレッジを維持。

➕ 新規クラスタ作成サポート

Extended Support 期間中のメジャーバージョンでも新しい AlloyDB クラスタを作成可能。既存ワークフローに支障なし。

🚪 オプトアウト (脱退) 機能

いつでもメジャーバージョンアップグレードで脱退可能。In-place またはデータ移行の2つの方法から選択。

⏰ 終了後の自動アップグレード

3年間の期間終了後、デフォルトのメジャーバージョンに自動アップグレード。12ヶ月前に事前通知。

Extended Support からのオプトアウト (アップグレード)

Bash 
# ステップ 1: 現在のバージョンを確認
gcloud alloydb clusters describe CLUSTER_ID --region=REGION

# ステップ 2: In-place Major Version Upgrade の実行
gcloud alloydb clusters upgrade CLUSTER_ID \
  --region=REGION \
  --version=POSTGRES_18 \
  --async
⚠️ 注意: アップグレード前にクラスタのクローンを作成してテストすることを推奨。プライマリインスタンスのダウンタイムは通常20分~1時間。全体のアップグレード時間はデータベースサイズに依存 (40分~48時間)。

✓リスク軽減 - 急ぎのアップグレードによる障害リスクを低減
✓コンプライアンス維持 - セキュリティ要件を満たし続ける

🔧 技術面

✓柔軟なアップグレードパス (In-place / データ移行)
✓複数バージョンスキップ (例: PG14 → PG18)
✓自動フェイルオーバー継続 (高可用性構成)

⚠️ デメリット・制約事項

!追加コスト: 通常のクラスタ料金に加えて Extended Support 料金が発生 (CUD 適用不可)
!新機能制限: Regular Support 終了後に実装された新機能は利用不可
!強制アップグレード: 3年後にデフォルトバージョンへ自動アップグレードが実行される
!意図しない課金: 自動登録のため、事前通知 (3ヶ月前) を見逃すと意図せず追加料金が発生
!コスト最適化: 長期間の Extended Support より早めのアップグレードがコスト効率的な場合あり

💡 ユースケース

🏦 ユースケース 1: エンタープライズ基幹システムの段階的アップグレード

シナリオ: 大手金融機関が AlloyDB (PostgreSQL 14) で基幹取引システムを運用。数百のアプリケーションの互換性テストと段階的移行計画が必要。

効果: Extended Support により3年間の猶予が確保され、四半期ごとのテストサイクルに合わせた段階的アップグレードを安全に実行可能。

🌐 ユースケース 2: マルチリージョン環境での計画的ローリングアップグレード

シナリオ: グローバル EC サイトが複数リージョンで AlloyDB クラスタを運用。各リージョンを順番にアップグレードしてリスクを最小化したい。

効果: リージョンごとのスケジュールアップグレードが可能。問題発生時のロールバック計画を含む段階的展開を実現。

🔌 ユースケース 3: サードパーティ製品の互換性確認待ち

シナリオ: SaaS プロバイダがサードパーティ拡張機能や ORM フレームワークの新バージョン対応完了を待つ必要がある。

効果: サードパーティのアップデートサイクルに合わせたアップグレードスケジュールを設定可能。

💰 料金情報

💡 料金に関する注意:
  • Extended Support は有料サービス (通常クラスタ料金 + 追加料金)
  • 追加課金を回避するには Extended Support 開始前にアップグレードすることを推奨
  • CUD (Committed Use Discounts) は Extended Support 追加料金に適用不可
  • 詳細な料金: AlloyDB for PostgreSQL 料金ページ

🔗 関連サービス・機能

Database Migration Service (DMS)

AlloyDB へのデータ移行やメジャーバージョンアップグレード時のデータ移行に利用可能。Quick-start migrations 機能を提供。

AlloyDB In-place Major Version Upgrade

クラスタ名、IP アドレス、DB フラグなどの設定を維持したままバージョンアップグレードが可能。

AlloyDB Omni

オンプレミスやマルチクラウド環境で AlloyDB を実行。Extended Support のタイムラインは異なる場合あり。

Cloud Monitoring / Cloud Logging

Extended Support 期間中のクラスタ健全性監視やアップグレード計画の策定に活用。
