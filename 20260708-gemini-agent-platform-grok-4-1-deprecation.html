Grok 4.1 モデルファミリーの非推奨化

Gemini Enterprise Agent Platform Deprecated
2026-07-08
Shutdown: 2026-08-20

📋 概要

Gemini Enterprise Agent Platform 上で提供されていた xAI の Grok 4.1 モデルファミリー (xai/grok-4.1-fast-reasoning および xai/grok-4.1-fast-non-reasoning) が非推奨となり、2026年8月20日にシャットダウンされることが発表されました。

シャットダウン後、Model as a Service (MaaS) エンドポイントへの Grok 4.1 モデル ID を使用した API リクエストは 400 エラーを返すようになります。

⚠️ 重要: Grok 4.1 Fast は 2026年4月7日にリリースされたが、わずか約3か月で非推奨に。移行猶予期間は約43日間のみ。

🔑 非推奨化対象モデル

xai/grok-4.1-fast-reasoning

ツールコール機能に優れたコスト効率重視の推論モデル。Function Calling (Preview) をサポートし、Web データや社内ナレッジベースの検索タスクに最適化。

xai/grok-4.1-fast-non-reasoning

低レイテンシに最適化されたノンシンキングモデル。要約やカテゴリ分類などの大量処理タスクに使用。

⚠️ シャットダウン後の影響: aiplatform.googleapis.com エンドポイントで Grok 4.1 モデル ID を使用した場合、400 エラーが返され、既存アプリケーションが即座に動作停止する可能性があります。

✅ 移行のメリット

ビジネス面

→サービス継続性の確保: 早期移行で 8月20日のサービス停止による業務影響を回避
→品質向上: Grok 4.20 は業界最低レベルのハルシネーション率を実現し、出力の信頼性が向上

技術面

→コンテキスト長の大幅拡大: 128K → 2M トークンで大規模ドキュメント処理や長時間エージェントセッションが可能に
→GA レベルの安定性: Function Calling / Structured Output も GA サポート
→Output TPM の倍増: 40,000 → 80,000 TPM でスループット向上

⚠️ デメリット・制約事項

制限事項

❌移行猶予期間が約43日間と比較的短い
❌QPM が 160 → 100 に減少 (高頻度リクエストのワークロードに制約)
❌Input TPM が 880,000 → 540,000 に減少 (入力トークン量の多いアプリに注意)

考慮すべき点

💡モデルの出力特性が異なるため、プロンプトの調整やテストが必要な場合がある
💡Grok 4.3 は Preview のため、本番環境では Grok 4.20 (GA) を推奨
💡コスト構造が変わる可能性 - 料金ページで最新の料金を確認すること

💡 ユースケース

🔍 ユースケース 1: 検索タスクの移行

シナリオ: Grok 4.1 Fast (Reasoning) を Web データや社内ナレッジベースの検索タスクに使用しているケース

効果: コンテキスト長の拡大 (128K → 2M) により、より多くの検索結果をコンテキストに含められるようになる。Grok 4.20 (Reasoning) はドキュメント理解と長期間のエージェントツールコールに優れる。

📦 ユースケース 2: 高ボリュームタスクの移行

シナリオ: Grok 4.1 Fast (Non-reasoning) を要約やカテゴリ分類などの大量処理に使用しているケース

効果: Grok 4.20 (Non-reasoning) への移行で、低ハルシネーション率による分類精度の向上が期待できる。ただし QPM 制限が 160 → 100 に減少するため、レート制限対策が必要な場合がある。
