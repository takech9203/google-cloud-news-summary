📋 概要

Google SecOps (旧 Chronicle SOAR) の Marketplace において、11 のサードパーティインテグレーションが同時にアップデートされました。新しいアクションの追加、エラーハンドリングの改善、ウィジェットのレンダリング修正、認証方式の追加など多岐にわたる更新です。

これらの更新は、セキュリティオペレーションセンター (SOC) のアナリストが日常的に使用するプレイブックの信頼性と効率性を向上させ、インシデント対応ワークフロー全体の品質改善に寄与します。

🔄 Before / After

❌ Before (課題)

  • Cortex XDR でファイルダウンロードに手動操作が必要
  • CyberArk PAM のパスワード変更がプレイブックから実行不可
  • CrowdStrike Falcon で複数アラート ID の同期が不正確
  • VirusTotal Widgets のキャッシュレンダリングに不具合
  • FireEye Helix は API キー認証のみ対応

✅ After (改善)

  • Cortex XDR から直接ファイルダウンロードを自動化
  • CyberArk PAM のパスワードローテーションをプレイブックに組込可能
  • CrowdStrike Falcon のアラート同期が正確に動作
  • VirusTotal / GTI ウィジェット表示が安定・高速化
  • FireEye Helix で Trellix IAM OAuth 認証をサポート

🆕 新機能の追加

新機能 Palo Alto Cortex XDR v30.0 - Download File

エンドポイントからファイルをダウンロードする新しいアクションが追加されました。インシデント調査時にマルウェア検体やログファイルの取得を自動化し、フォレンジック調査のワークフローを効率化します。

新機能 CyberArk PAM v11.0 - Change Account Password

特権アカウントのパスワードを変更する新しいアクションが追加されました。インシデント発生時の緊急パスワードローテーションをプレイブックから自動実行可能です。既存の Get Account Password Value、List Accounts、Ping アクションに加えて利用可能。

新機能 FireEye Helix v20.0 - Trellix IAM OAuth 認証

従来の API キー認証に加えて、Trellix IAM OAuth 認証方式が追加されました。組織の ID 管理ポリシーに準拠した認証が可能になります。

⚙️ 同期・エラーハンドリングの改善

改善 CrowdStrike Falcon v77.0

複数のアラート ID が単一の SecOps アラートにマッピングされる場合の同期ロジックを更新。エラーハンドリングの全般的な改善により、Sync Alerts ジョブの信頼性が向上しました。

改善 Azure Active Directory v29.0

Enrich User アクションでのサインインアクティビティ取得時のエラーハンドリングを更新。サインイン情報が取得できない場合のフォールバック処理が改善されました。

修正 Siemplify v110.0

Create Gemini Case Summary アクションの結果処理ロジックを更新。バックスラッシュのエスケープ処理を修正し、サマリー生成の正確性が向上しました。

🖥️ ウィジェット・UI の改善

修正 VirusTotal V3 v41.0

Predefined Widgets のキャッシュフォールバックレンダリングを修正。対象アクション: Enrich Hash、Enrich IOC、Enrich IP、Enrich URL、Get Domain Details。キャッシュされたウィジェットデータの表示が正しく機能するようになりました。

改善 Google Threat Intelligence v16.0

Predefined Widgets のローディングパフォーマンスを最適化。対象アクション: Enrich Entities、Enrich IOCs。Case Wall でのウィジェット表示速度が向上しました。

💡 Predefined Widgets について: Google SecOps の Marketplace インテグレーションに付属する事前定義されたウィジェット。Widget Theme は Light / Dark / Chronicle の 3 種類から選択可能。

🔧 インフラストラクチャ・設定の改善

リファクタリング Google Cloud Compute v19.0

以下のアクションのコードがリファクタリングされ、保守性と安定性が向上:

  • Add IP To Firewall Rule
  • Remove External IP Addresses
  • Execute VM Patch Job
  • Update Firewall Rule

変更 EmailV2 v42.0

Generic IMAP Email Connector のデフォルト値を更新。IMAP サーバーアドレス、ポート、ユーザー名、パスワードのデフォルト値が変更されました。

変更 Secret Manager v2.0

Ping アクションの説明文を更新。機能的な変更はありません。

⚠️ 注意事項・制約

確認が必要なポイント:
  • EmailV2 v42.0: IMAP コネクタのデフォルト値が変更。既存設定がデフォルト値に依存している場合は確認が必要
  • FireEye Helix v20.0: OAuth 認証を使用する場合は、Trellix IAM の事前設定が必要
  • CrowdStrike Falcon v77.0: 同期ロジック変更により、既存のアラートマッピングの動作が変わる可能性あり

💡 ユースケース

🔬 ユースケース 1: マルウェア感染インシデントの自動フォレンジック

シナリオ: エンドポイントでマルウェアが検出された際、Palo Alto Cortex XDR から疑わしいファイルを自動ダウンロードし、VirusTotal V3 で解析するプレイブック

効果: Download File (v30.0) と Enrich Hash ウィジェット修正 (v41.0) の組み合わせにより、検体取得から解析結果の可視化までをシームレスに実行。初動対応を高速化。

🔑 ユースケース 2: 侵害時の緊急パスワードローテーション

シナリオ: アカウント侵害が確認された場合、CyberArk PAM を通じて関連する特権アカウントのパスワードを即座に変更するプレイブック

効果: Change Account Password (v11.0) により、侵害検出から特権アカウントの保護までの時間を大幅に短縮。CrowdStrike Falcon (v77.0) の改善されたアラート同期と組み合わせることで、検出から対応までの一貫した自動化を実現。

🔔 ユースケース 3: マルチソースアラートの統合管理

シナリオ: CrowdStrike Falcon で複数のアラート ID が 1 つのインシデントに関連付けられている場合に、Google SecOps 上で正確に追跡する運用

効果: v77.0 の同期ロジック改善により、複数のアラート ID が単一の SecOps アラートに正しくマッピングされ、アラートの見落としや重複管理の問題が解消。
