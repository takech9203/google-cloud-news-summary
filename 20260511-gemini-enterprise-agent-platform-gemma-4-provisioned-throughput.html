📋 概要

Gemini Enterprise Agent Platform において、Google のオープンモデル Gemma 4 26B A4B IT に対して Provisioned Throughput の購入が可能になりました。

GSU (Generative Service Unit) 単位でスループットを事前に確保することで、オンデマンド課金では得られないスループットの安定性と予測可能なコスト管理を実現できます。

🤖 Gemma 4 とは: Google が開発したオープンモデル。Mixture of Experts (MoE) アーキテクチャを活用し、26B パラメータ中 4B のみをアクティブ化する高効率な設計です。テキスト、ドキュメント、画像をマルチモーダルに入力可能。

⭐ 主要機能

⚡ Provisioned Throughput for Gemma 4

モデル ID: gemma-4-26b-a4b-it-maas

GSU あたり 6,725 tokens/sec のスループット保証。最小購入 1 GSU から。

📊 バーンダウンレート

入力テキスト: 1 token = 1 token

出力テキスト: 1 token = 4 tokens としてカウント

出力トークンは入力の 4 倍コストでスループット消費

🚦 トラフィック制御

dedicated - PT のみ使用

shared - pay-as-you-go のみ

未設定時 - PT 優先 + 自動スピルオーバー

📅 柔軟な契約期間

1 週間 / 1 ヶ月 / 3 ヶ月 / 1 年から選択可能。オーダーが Active になった後に課金開始。

💻 API リクエスト例

Provisioned Throughput を使用した API リクエストの実装例です。

Python 
from google import genai
from google.genai.types import HttpOptions

client = genai.Client(
    http_options=HttpOptions(
        api_version="v1",
        headers={
            "X-Vertex-AI-LLM-Request-Type": "dedicated"
        },
    )
)

response = client.models.generate_content(
    model="gemma-4-26b-a4b-it-maas",
    contents="AIの仕組みを説明してください",
)
print(response.text)
Bash 
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  -H "X-Vertex-AI-LLM-Request-Type: dedicated" \
  "https://aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/global/publishers/google/models/gemma-4-26b-a4b-it-maas:generateContent" \
  -d '{"contents": [{"role": "user", "parts": [{"text": "Hello."}]}]}'

📋 オーダー作成手順

1.Google Cloud Console の Provisioned Throughput ページに移動
2."New order" をクリック
3.オーダー名を入力
4.モデルとして gemma-4-26b-a4b-it-maas を選択
5.リージョンを選択
6.必要な GSU 数を設定
7.契約期間 (1 週間/1 ヶ月/3 ヶ月/1 年) を選択
8.確認フィールドに CONFIRM と入力し送信

Step 2: API リクエストの送信

オーダーが Active ステータスになった後、API リクエストを送信できます。ヘッダー X-Vertex-AI-LLM-Request-Type でトラフィック制御を行います。

🎯 ユースケース

📄 ユースケース 1: 大規模ドキュメント処理パイプライン

シナリオ: 企業が毎日数千件のドキュメントを Gemma 4 で分類・要約する処理パイプラインを運用。安定したスループットが必要。

効果: Provisioned Throughput により、ピーク時間帯でも安定した処理速度を維持し、SLA を満たすことが可能。

🔍 ユースケース 2: マルチモーダル画像分析アプリケーション

シナリオ: 製造業の品質管理システムで、製品画像を Gemma 4 のマルチモーダル機能で分析し、欠陥を検出。

効果: 画像とテキストの両方を入力可能。Provisioned Throughput により、製造ラインの速度に合わせたリアルタイム処理を保証。

💵 料金情報

Provisioned Throughput の料金は GSU 単位 で計算され、契約期間に応じた料金が適用されます。Gemma 4 の Provisioned Throughput は Google モデルと同じ SKU で課金されます。

📄 詳細: Gemini Enterprise Agent Platform の料金ページを参照してください。
