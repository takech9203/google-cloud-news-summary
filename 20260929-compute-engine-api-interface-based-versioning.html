インターフェースベースバージョニング (IBV) GA

日付ベース API バージョン 2026-09-01 (GA) / 2026-10-01-preview (Preview) の提供開始
リリース日: 2026-09-29

📝 概要

Compute Engine API の インターフェースベースバージョニング (IBV) が一般提供 (GA) になりました。 リクエストで日付ベースの API バージョン (例: 2026-09-01) を指定することで、 API の変更を自分のスケジュールで採用できます。 従来のチャネルベースバージョニング (CBV: v1 / beta / alpha) は引き続き利用可能で、既存の実装には影響しません。

→API バージョン 2026-09-01 (GA / 安定版): aggregatedList がスコープ到達不能時にデフォルトで部分的な結果 (partial results) を返却。returnPartialSuccess パラメータは aggregatedList / list から廃止。
→API バージョン 2026-10-01-preview (Preview): projects.get / regions.get / regions.list のレスポンスから quotas フィールドを削除。クォータ管理は Cloud Quotas API へ。

❌ Before (アップデート前の課題)

✗CBV では v1 / beta / alpha が長期間存続しインプレース更新されるため、API の挙動やレスポンスペイロードが意図しないタイミングで変化する可能性
✗破壊的変更への追従タイミングを利用者側でコントロールする仕組みがない
✗aggregatedList の部分結果はオプトイン (returnPartialSuccess デフォルト false) で、一部スコープへの到達失敗が全体の失敗につながり得た

✅ After (アップデート後の改善)

✓日付ベースのバージョン指定で、API とリクエスト/レスポンスペイロードの挙動が 指定バージョンに準拠することを保証
✓新機能へのアップグレードを 利用者自身のスケジュール で実施可能
✓2026-09-01 では aggregatedList がデフォルトで部分結果を返し、可用性が向上
✓安定版は標準の Google Cloud 非推奨ポリシーのもとで永続的に維持され、本番システムの信頼性を確保

IBV では、クライアントが X-Goog-Api-Version ヘッダーまたは $apiVersion クエリパラメータで日付ベースのバージョンを指定し、 指定がない場合は従来の CBV v1 エンドポイントの挙動となります。

⚙️ 主要機能

1️⃣ インターフェースベースバージョニング (IBV) の GA GA

→個々のインターフェース・メソッド・リソースがバージョニングされ、段階的かつ独立して進化できる方式
→$apiVersion クエリパラメータまたは X-Goog-Api-Version ヘッダーで対象バージョンを指定 (AIP-184 に準拠)
→IBV は CBV に取って代わる (supersede) 位置づけだが、既存の CBV 実装は影響を受けず継続利用可能
→バージョン未指定のリクエストは CBV v1 エンドポイントの挙動がデフォルト
→Google Cloud コンソールでの有効化作業は不要 (Compute Engine API でデフォルト有効)

2️⃣ API バージョン 2026-09-01 GA / 安定版

→スコープに到達できない場合、aggregatedList メソッドが デフォルトで部分的な結果を返す
→returnPartialSuccess クエリパラメータは aggregatedList / list メソッドから廃止
→安定版は AIP-180 で定義される厳格な互換性を維持。同一バージョンの新しい安定版リリースが既存機能を破壊したりコードの書き換えを要求したりしない

3️⃣ API バージョン 2026-10-01-preview Preview

→projects.get / regions.get / regions.list のレスポンスから quotas フィールドを削除
→クォータ情報の表示・管理には Cloud Quotas API を使用
→プレビュー版は最新の安定版のすべての機能 + 新たに追加された実験的機能を含む

バージョン種別特徴
✅ 安定版 (Stable)YYYY-MM-DD 形式。AIP-180 に基づく厳格な互換性を維持。長期サポートされ、日常的なタスクには単一の安定版の利用で十分

👍 メリット

💼 ビジネス面

✓変更採用の主導権: どのバージョンでリクエストを処理するかを利用者が選択でき、新機能へのアップグレードを自社のリリース計画にあわせて実施可能
✓本番システムの安定稼働: 安定版は長期間サポートされ、実行中のアプリケーションを意図しない API 変更から保護

🔧 技術面

✓挙動の予測可能性: API の挙動とペイロードが指定バージョンに準拠することを保証
✓部分結果によるレジリエンス向上: 一部スコープに到達できなくても aggregatedList が取得可能な結果を返し、全体失敗を回避
✓移行の強制なし: 既存の CBV v1 リクエストはこれまでどおり動作し、段階的な移行が可能

⚠️ 制限事項・考慮点

✗CBV (v1) のまま利用を続ける場合、IBV API の新機能にはアクセス不可
✗プレビュー版は過去・将来リリースとの互換性が保証されず、安定版への昇格時に機能が変更・削除される可能性
✗2026-09-01 では returnPartialSuccess が aggregatedList / list で利用不可となり、依存コードは修正が必要
✗2026-10-01-preview では projects.get / regions.get / regions.list に quotas が含まれず、Cloud Quotas API への移行が必要
!シェルで $apiVersion を使う場合、$ がシェル変数として展開されるため、ダブルクォート内では %24 への URL エンコードを推奨
!プレビュー版はミッションクリティカルな本番環境での使用は非推奨
!安定版は四半期ごとのリリースが計画されており、継続的なバージョン追従の運用プロセスの検討が必要

🛡️ ユースケース 1: 本番ワークロードを API 変更から保護しつつ計画的に移行

シナリオ: Compute Engine API を直接呼び出す社内のインフラ自動化ツールを運用しており、API の挙動変更によるリグレッションを避けたい。

Bash すべての API 呼び出しに安定版バージョンを明示 
# すべての API 呼び出しに安定版バージョンを明示
curl -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "X-Goog-Api-Version: 2026-09-01" \
  "https://compute.googleapis.com/compute/v1/projects/PROJECT_ID/aggregated/instances"

✨ 効果: API の挙動が指定バージョンに固定され、新バージョンへの移行はテストを経て任意のタイミングで実施できる。

🌍 ユースケース 2: マルチリージョン環境でのインベントリ収集の耐障害性向上

シナリオ: aggregatedList で全リージョンの VM インベントリを定期収集しているが、一部スコープへの到達失敗で収集ジョブ全体が失敗することがあった。

✨ 効果: API バージョン 2026-09-01 ではスコープ到達不能時にデフォルトで部分結果が返るため、returnPartialSuccess を個別指定することなく、到達可能なスコープの結果で処理を継続できる。

📏 ユースケース 3: クォータ管理の Cloud Quotas API への移行検証

シナリオ: regions.get のレスポンスに含まれる quotas フィールドでリージョンクォータを監視しているが、将来の API 変更に備えたい。

✨ 効果: 2026-10-01-preview を検証環境で試用し、quotas フィールドが削除された状態での動作を確認したうえで、クォータ参照を Cloud Quotas API ベースの実装に移行できる。

🔗 関連サービス・機能

→Cloud Quotas API: API バージョン 2026-10-01-preview で quotas フィールドが削除されたことに伴う、クォータ情報の表示・管理の移行先
→Cloud Client Libraries: 各リリースが特定の日付ベース API バージョンに対応し、REST 呼び出しの構築・パースを抽象化
→gcloud CLI: 安定版コマンドと gcloud preview compute グループで安定版/プレビュー版 API に対応
→Terraform (Google Cloud Provider): API バージョニングを抽象化し、プレビュー機能は google-beta プロバイダーで提供
→Cloud Audit Logs: リクエストで指定した API バージョンが監査ログに記録される
