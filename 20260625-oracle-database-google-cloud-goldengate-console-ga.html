🗄️ Oracle Database@Google Cloud:
GoldenGate コンソール管理機能が GA

Oracle Database GoldenGate GA
リリース日: 2026-06-25
Oracle Database@Google Cloud

📋 概要

Oracle Database@Google Cloud において、GoldenGate のデプロイメント、接続、接続割り当ての管理が Google Cloud コンソールから直接行える機能が正式に GA となりました。

Oracle GoldenGate は、リアルタイムのデータ統合およびレプリケーションを実現するサービスで、異なるクラウド環境やオンプレミス環境間でデータの移動・変換・同期を低レイテンシで行います。今回のアップデートにより、GUI からの直感的な管理が可能になり、運用効率が大幅に向上します。

Before / After 比較

❌ Before (これまで)

  • gcloud CLI / REST API のみで管理
  • GUI ベースの操作ができなかった
  • 状態確認にコマンド実行が必要
  • リソース間の関連性把握に複数コマンドが必要

✅ After (今後)

  • Cloud コンソールから視覚的に確認可能
  • 接続情報をブラウザから直接閲覧
  • デプロイメントと接続の割り当て関係を一覧で確認
  • リソース間の依存関係を容易に把握可能

🏗️ アーキテクチャ図

Google Cloud コンソールが GoldenGate の各リソース (デプロイメント、接続、割り当て) を統合的に管理するインターフェースを提供し、CLI や API と並ぶ管理手段として機能します。

⚙️ 主要機能

📦 デプロイメント管理 (Manage Deployments)

  • デプロイメントの一覧表示と詳細情報の確認
  • ステータス (実行中、停止中) の視覚的な確認
  • CPU コア数、メモリ、ストレージ、ネットワーク帯域幅の確認
  • 環境タイプ (開発/テスト、本番) やライセンスモデルの確認
  • オートスケーリング設定の確認

🔗 接続管理 (Manage Connections)

  • GoldenGate 接続の一覧表示と詳細情報の確認
  • 接続先データベースの情報確認
  • 接続のステータス (Available 等) の確認
  • ネットワーク設定とセキュリティ構成の確認

🔄 割り当て管理 (Manage Assignments)

  • 接続割り当て (Connection Assignments) の一覧表示と詳細確認
  • デプロイメントと接続の紐付け関係の視覚的な確認
  • 割り当てのテスト結果の確認

🛠️ 設定方法

前提条件

💡 事前準備:
  • Oracle Database@Google Cloud 環境のセットアップが完了していること
  • ODB Network が作成されていること (GoldenGate デプロイメントにはクライアントサブネットが 1 つ必要)
  • 適切な IAM ロールが付与されていること

GoldenGate デプロイメントの作成 (gcloud CLI)

Bash 
# GoldenGate デプロイメントの作成
gcloud oracle-database goldengate-deployments create DEPLOYMENT_ID \
  --project=PROJECT_ID \
  --location=REGION \
  --display-name="DEPLOYMENT_NAME" \
  --gcp-oracle-zone=GCP_ORACLE_ZONE \
  --odb-subnet=projects/ODB_NETWORK_PROJECT_ID/locations/ODB_NETWORK_REGION/odbNetworks/ODB_NETWORK_ID/odbSubnets/ODB_SUBNET_ID \
  --properties-license-model=license-included \
  --properties-environment-type=PRODUCTION \
  --properties-deployment-type=DATABASE_ORACLE \
  --properties-cpu-core-count=4 \
  --ogg-data-deployment=mydeployment \
  --ogg-data-admin-username=admin \
  --ogg-data-admin-password-secret-version=projects/PROJECT_ID/secrets/SECRET_ID/versions/1

接続と割り当ての確認 (CLI)

Bash 
# 接続の一覧確認
gcloud oracle-database goldengate-connections list \
  --project=PROJECT_ID \
  --location=REGION

# 割り当ての一覧確認
gcloud oracle-database goldengate-connection-assignments list \
  --project=PROJECT_ID \
  --location=REGION
💡 ヒント: 作成後、コンソールの Oracle Database > GoldenGate セクションからデプロイメント、接続、割り当てが全て視覚的に確認できます。

✅ メリット

💼 ビジネス面

  • 運用効率の向上: GUI ベースの管理により学習コスト低減、オペレーション迅速化
  • 可視性の向上: データレプリケーション状態を一目で把握、問題対応時間短縮
  • ガバナンス強化: リソース間の関連性を視覚確認、構成管理が容易に

🔧 技術面

  • 統合管理: コンソール、gcloud CLI、REST API の 3 つの管理手段が揃う
  • IAM 統合: ロールベースアクセス制御ときめ細かなアクセス管理
  • Secret Manager 連携: 管理者パスワードの安全な管理、設定状況の確認

⚠️ デメリット・制約事項

制限事項:
  • コンソールからの確認 (閲覧) が主な機能。一部の高度な設定変更は引き続き CLI や API が必要
  • GoldenGate リソースは ODB Network と同じリージョン・ゾーンに作成する必要がある
  • CPU コアは最大 24 コアまでの割り当て制限
考慮すべき点:
  • Extract、Replicat、Transform の詳細設定は OCI コンソールでの管理が引き続き必要な場合がある
  • 接続を削除すると関連する接続割り当ても同時に削除される (依存関係に注意)
  • Shared VPC 環境ではホストプロジェクトの ID を正しく指定する必要がある
