📌 概要

Google Cloud CCaaS の バージョン 6.13 が正式リリース されました。2026-09-16 のプレリリースノートの内容がそのまま正式版として提供され、通話ルーティング・キュー制御、レポーティング、エージェントデスクトップ、Salesforce / Kustomer などの CRM 統合、Web SDK のアクセシビリティにまたがる 約 36 件の既知の問題の修正 で構成されます (新機能追加はなし)。適用タイミングは各組織のデプロイメントスケジュール (Rapid / Regular / Critical) に依存します。

同日リリースの Advanced reporting dashboards 6.4 は新機能を含むアップデートです。Real-time Agent Monitoring への 「Active Call ID(s)」列、チームフィルタの改善 (Agent Teams への改名と Queue Teams の追加)、Connected Calls / Chats への累計時間列、Calls Queued の 「Projecting」列、そして全ダッシュボードと Explore の フランス語 (カナダ) 対応 が含まれます。

🎯 対象ユーザー: CCaaS を運用するすべての組織、特にリアルタイムダッシュボードでオペレーションを監視するスーパーバイザー・コンタクトセンター管理者。

❌ Before (アップデート前の課題)

  • ✗ライブモニタリング中にエージェントのアクティブな通話を特定するには複数のステップが必要
  • ✗「Teams」フィルタがエージェント側かキュー側か分かりにくく、キュー割り当てチームでの絞り込みも不可
  • ✗Connected Calls / Chats に接続後の累計時間 (通話・保留・チャット) の列がなく、長時間化セッションを把握しにくい
  • ✗キュー内通話がエージェントに投影 (projecting) されているかをダッシュボードで確認できない
  • ✗ダッシュボードと Explore はフランス語 (カナダ) 非対応
  • ✗CCaaS 本体に通話終了後の「通話中」状態残留、コールスパイク時のキャパシティ制限バイパス、レポートからの通話欠落など多数の既知の問題

✅ After (アップデート後の改善)

  • ✓「Active Call ID(s)」列で connecting / connected / reconnecting の通話 ID を一目で特定 (複数はカンマ区切り)
  • ✓「Agent Teams」に明確化 + Real-time Queued - Calls/Chats に「Queue Teams」フィルタを追加
  • ✓Total Consumer Talk Time / Total Hold Time / Total Consumer Chat Time 列を追加
  • ✓「Projecting」列でルーティングエンジン (deltacast) の投影状況を確認可能に
  • ✓全 advanced reporting ダッシュボードと Explore がフランス語 (カナダ) で利用可能に
  • ✓6.13 正式リリースで約 36 件の修正がデプロイスケジュールに沿って各インスタンスへ展開

🔧 1. Google Cloud CCaaS 6.13 正式リリース

バージョン 6.13 は 約 36 件の既知の問題の修正 で構成され、内容は 2026-09-16 のプレリリースノートと同一です。インスタンスへの適用時期は、選択しているデプロイメントスケジュールに依存します。

🗂️ 主な修正カテゴリ

カテゴリ 主な修正
🎧 エージェント状態管理 通話終了後も「通話中」扱いになり Available への変更や新規着信が妨げられる問題 / エージェント間転送の不応答時の状態残留 / エージェントアダプターのブランク化で新規コールが届かない問題
🔀 キュー・ルーティング コールスパイク時のキャパシティ制限バイパス / ミスドオファー通話のキュー内スタック (multicast フォールバック無効時) / エージェント優先度オーバーライドのルーティング不良
📊 レポーティング All Call History / Voice Inbound (IVR) History からのデフレクト通話・ボイスメール前切断通話の欠落 / Agent Activity Timeline の誤記録 / 重複「chat finished」イベント・「応答済み」と「放棄」の二重報告
☁️ Salesforce 統合 click-to-dial の誤ったケース関連付け・所有権再割り当て / 重複アカウント作成 / OAuth Refresh Token Rotation 強制組織での CRM 接続断
🌐 Web SDK・その他 プレチャット・チャット画面の WAI-ARIA キーボードナビゲーション / スクリーンリーダー対応 / Kustomer の発信者情報非表示 / メールアカウントの再接続不能 / Agent Assist の誤検知アラート
💡 補足: 各修正の詳細は 2026-09-16 のプレリリースノート解説レポートを参照。6.13 に CCaaS 本体への新機能追加は含まれません。

📊 2. Advanced reporting dashboards 6.4 (新機能)

🧑‍💼 Real-time Agent Monitoring: Active Call ID(s) 列

→Live Agent Data テーブルに Active Call ID(s) 列を追加
→接続中 (connecting)・接続済み (connected)・再接続中 (reconnecting) の通話 ID を表示
→複数同時通話はカンマ区切りのリストで表示
→ライブモニタリング中のアクティブ通話特定のステップ数を削減

👥 チームフィルタリングの改善

→「Teams」→「Agent Teams」に改名: エージェント側チームでのフィルタであることを明確化 (Real-time Queue Monitoring - Calls/Chats、Real-time Connected - Calls/Chats)
→「Queue Teams」フィルタを追加: Real-time Queued - Calls/Chats で、キューに割り当てられたチームによりキュー内インタラクションを絞り込み可能に

⏱️ Connected Calls / Chats: 累計時間列の追加

→Total Consumer Talk Time: 通話が最初に仮想 / 人間のエージェントに接続してからの累計時間 (Connected Calls テーブル)
→Total Hold Time: 現在進行中の保留も含む累計保留時間 (Connected Calls テーブル)
→Total Consumer Chat Time: チャットが最初に仮想 / 人間のエージェントに接続してからの累計時間 (Connected Chats テーブル)

📡 Calls Queued: Projecting 列

→Call Queued テーブルに Projecting 列を追加
→ルーティングエンジン (deltacast) がキュー内通話を利用可能なエージェントに投影中かどうかを表示

🇨🇦 フランス語 (カナダ) 対応

→すべての advanced reporting ダッシュボードと Explore がフランス語 (カナダ) で利用可能に
→CCAI Platform ポータルのプロファイル言語でフランス語 (カナダ) を選択すると適用
→管理者向けに Admin > Change Language に Français (CAN) オプションを追加

🩹 ダッシュボード関連の不具合修正

  • ✓タイル間で数値フォーマットが不整合になる問題を修正
  • ✓言語切替後に列ヘッダー・フィルタラベル・タイルタイトルが即座に切り替わらない問題を修正
  • ✓Queue Group Performance - All の Productive Agents 列がキューグループ設定に応じた値を表示しない問題を修正
  • ✓Call Queue Metrics (Historical) Explore で Agent Name を表示列に含めずフィルタすると 0 行が返る問題を修正
  • ✓Custom After Hours Deflection でサブメニュー宛の通話が All Queued Interactions レポートで親メニューに誤帰属される問題を修正
  • ✓Agent Performance、Real-time Agent Monitoring、All Interactions - Calls/Chats の Direction フィルタの有効性を修正
  • ✓Queue Performance - Calls でショートアバンダン存在時に Avg Queue Time が真の平均ではなく合計を表示する問題を修正
  • ✓Individual Call/Chat History Report 生成時にチームフィルタが適用されず管理外キューのデータが含まれる問題を修正
  • ✓複数のダッシュボード指標・ラベルのフランス語 (カナダ) 翻訳の不正確・不完全・欠落を修正
  • ✓自動応答検出ミス後にキューへ戻された発信者が Total Queued Now に含まれない問題、Current Max/Avg Queue Wait Time の誤計測を修正
  • ✓ダッシュボード下部にグレーのバーが表示され全体を表示できない問題を修正

🛠️ 設定方法

✅ 前提条件

  • ✓CCAI Platform (Google Cloud CCaaS) インスタンスが稼働しており、advanced reporting ダッシュボードにアクセスできること
  • ✓CCaaS 6.13 の修正内容の適用は、インスタンスのデプロイメントスケジュール (Rapid / Regular / Critical) に沿って自動的に行われる

📝 手順

  1. デプロイメントスケジュールの確認
    1. Google Cloud コンソールでインスタンスを含むプロジェクトを選択
    2. ナビゲーションメニューで CCAI Platform をクリック
    3. インスタンス一覧の Schedule 列でデプロイメントスケジュールを確認

    → 6.13 が自社インスタンスへ適用されるおおよそのタイミングを把握できます。

  2. 新しいダッシュボード項目の確認
    1. CCAI Platform ポータルで Dashboard > Advanced Reporting をクリック
    2. Agent Monitoring を開き、Live Agent Data テーブルの Active Call ID(s) 列を確認
    3. Real-time Calls - Calls Connected / Calls Queued などで新しい列 (Total Consumer Talk Time、Total Hold Time、Projecting) とフィルタ (Agent Teams、Queue Teams) を確認
  3. フランス語 (カナダ) 表示の設定 (必要な場合)
    1. ユーザー個人: CCAI Platform ポータルのプロファイル言語でフランス語 (カナダ) を選択
    2. 管理者: Admin > Change Language で Français (CAN) を選択

⚖️ メリットと考慮すべき点

💼 ビジネス面のメリット

  • ✓スーパーバイザーの監視効率向上: Active Call ID(s) 列でアクティブ通話特定のステップが減り、バージインやエスカレーション対応までの時間を短縮
  • ✓カナダ市場・多言語環境への対応: ケベック州などフランス語話者のスーパーバイザー・管理者がダッシュボードと Explore を母語で利用可能
  • ✓レポート精度の信頼性向上: Avg Queue Time の誤計算やチームフィルタ不具合の修正で、KPI 測定と要員計画の判断材料の正確性が向上

🔧 技術面のメリット

  • ✓キュー滞留の可視化: Projecting 列でルーティング詰まりの切り分けが容易に
  • ✓長時間セッションの検知: Total Talk / Hold / Chat Time で接続中セッションの長時間化や過剰な保留をリアルタイム検知
  • ✓フィルタセマンティクスの明確化: Agent Teams と Queue Teams の区別で誤ったフィルタリングを防止
  • ✓CCaaS 本体の運用品質向上: エージェント状態管理・ルーティング・CRM 統合の既知の問題修正が本番環境に展開

⚠️ デメリット・制約事項

  • ✗6.13 の適用タイミングはインスタンスのデプロイメントスケジュールに依存。Critical スケジュールの本番インスタンスでは Rapid の更新から通常 1 週間以内 (遅延の可能性あり) に適用
  • ✗6.13 は既知の問題の修正のみで構成され、CCaaS 本体への新機能追加は含まれない
  • ✗「Teams」→「Agent Teams」の改名により、フィルタ名を前提とした運用手順書やトレーニング資料の更新が必要になる場合がある
⚠️ 運用チェック: 既知の問題への回避策 (ワークアラウンド) を運用に組み込んでいる場合は、6.13 適用後に回避策が不要になるかを検証しましょう。

💡 ユースケース

1️⃣ ライブモニタリングからの迅速なバージイン

🎬 シナリオ: スーパーバイザーが Real-time Agent Monitoring ダッシュボードで特定エージェントの対応状況を監視しており、支援が必要な通話をすぐに特定したい。

🛠️ 実装例: Live Agent Data テーブルの Active Call ID(s) 列で対象エージェントのアクティブな通話 ID を直接確認し、該当の通話に対してモニタリングやバージ (介入) を行う。

✨ 効果: 通話 ID の特定に要していた複数ステップが不要になり、介入までのリードタイムが短縮される。

2️⃣ キュー滞留のトラブルシューティング

🎬 シナリオ: 特定のキューで待ち時間が伸びており、ルーティングが機能しているのかキャパシティ不足なのかを切り分けたい。

🛠️ 実装例: Real-time Calls - Calls Queued ダッシュボードで Queue Teams フィルタで対象キューに絞り込み、Projecting 列でルーティングエンジンが通話をエージェントに投影中かどうかを確認する。

✨ 効果: 「ルーティングが動いていない」のか「投影先のエージェントが不足している」のかを即座に判別でき、対処 (要員追加、キュー設定見直し) の判断が速くなる。

3️⃣ フランス語 (カナダ) 拠点でのダッシュボード運用

🎬 シナリオ: カナダ・ケベック州のコンタクトセンター拠点で、フランス語話者のスーパーバイザーがダッシュボードを利用する。

🛠️ 実装例: 各ユーザーのプロファイル言語をフランス語 (カナダ) に設定するか、管理者が Admin > Change Language で Français (CAN) を選択する。

✨ 効果: すべての advanced reporting ダッシュボードと Explore が母語で表示され、監視・分析業務の習熟コストが下がる。

💰 料金・利用可能リージョン

✅ 追加料金なし: 今回のアップデート (6.13 の修正、Advanced reporting dashboards 6.4) に伴う追加料金は発表されていません。

CCaaS インスタンスの課金は、インスタンスに割り当てられた課金モデルに基づく月次課金です。テレフォニー料金は従量課金です。

課金モデル 内容
Concurrent agents 月内に同時サインインしたエージェントロールユーザーの最大数
Named agents 月内にエージェントロールを持ったユーザーの最大数
Minutes used エージェントロールユーザーがサインインしていた分数

🌍 CCaaS (CCAI Platform) が利用可能な国と Google Cloud リージョンは ロケーションページ を参照してください。
