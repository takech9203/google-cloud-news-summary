📋 概要

Gemini Enterprise Agent Platform の Provisioned Throughput が、教師ありファインチューニング済み Gemini 3 モデルの推論をサポート。ファインチューニング済みモデルのエンドポイントに対しても、ベースモデルと同一の Provisioned Throughput クォータを使用してスループットを確保できるようになりました。

🤖 重要な変更点: Gemini 3 以降では、ファインチューニング済みモデルの推論にはベースモデルと比較して高いバーンダウンレートが適用されます。このプレミアムは、ファインチューニング推論の料金プレミアムに比例します。

Before / After

❌ Before (課題)

  • ファインチューニング済みモデルに Provisioned Throughput によるスループット保証ができなかった
  • 本番環境では pay-as-you-go に依存する必要があった
  • スループットが他のワークロードの影響を受ける可能性があった

✅ After (改善)

  • ベースモデルとファインチューニング済みモデルの両方に Provisioned Throughput を適用可能
  • 同一クォータで一元管理でき、運用が簡素化
  • X-Vertex-AI-LLM-Request-Type ヘッダーで柔軟なトラフィック制御が可能

⚡ 主要機能

🔗 共有クォータモデル

ファインチューニング済みモデルのエンドポイントと対応するベースモデルが同一の Provisioned Throughput クォータにカウントされます。

例: gemini-3.1-flash-lite 向けに購入した Provisioned Throughput は、そのプロジェクト内で作成された同モデルのファインチューニング版からのリクエストも優先処理します。

📊 差別化バーンダウンレート (Gemini 3 以降)

ファインチューニング済み推論のバーンダウンレートがベースモデルより高く設定されます。

例: ファインチューニング推論がベースモデルの 50% 増の料金の場合、バーンダウンレートも 50% 増 (1 input text token = 1.5 tokens)

🔀 トラフィック制御

X-Vertex-AI-LLM-Request-Type HTTP ヘッダーでリクエストごとのトラフィック制御が可能:

  • dedicated: Provisioned Throughput のみ使用 (超過時は 429 エラー)
  • shared: pay-as-you-go のみ使用 (Provisioned Throughput をバイパス)
  • デフォルト: 超過分は自動的に pay-as-you-go にスピルオーバー

⚠️ 制約事項・注意点

重要: Preview ステータスであり、SLA の対象外です。
  • ファインチューニング済みモデルの推論はベースモデルより高いバーンダウンレートが適用され、同じ GSU 数でも実効スループットが低下
  • Provisioned Throughput はモデルエイリアスでは使用不可 - 具体的なモデルバージョン ID を指定する必要あり
  • バッチ予測 (batch prediction) はサポートされない
  • Vertex AI Agents や Agent Search から呼び出されるモデルには適用されない
  • Provisioned Throughput は途中キャンセル不可のコミットメント契約
  • プレミアム率は料金ページで確認し、正確な GSU 必要量を算出する必要あり

💡 ユースケース

🏦 ユースケース 1: 金融機関のカスタマイズ済みチャットボット

シナリオ: 銀行が Gemini 3.1 Flash-Lite をファインチューニングして、社内用語や規制要件に対応したチャットボットを運用。毎秒 50 リクエストの安定スループットが必要。

効果: Provisioned Throughput により応答レイテンシの安定化とコストの固定化を実現。高いバーンダウンレートを考慮した GSU 購入で、ピーク時もスループットを保証。

🏢 ユースケース 2: SaaS プロバイダーのマルチテナント推論

シナリオ: SaaS プロバイダーがテナントごとにファインチューニングした Gemini 3 モデルを使用。ベースモデルの汎用リクエストとファインチューニング版の特化リクエストが混在。

効果: 同一 Provisioned Throughput クォータでベースモデルとファインチューニング版を管理でき、リソース効率が向上。ヘッダーによる制御で重要テナントを優先処理。

💰 料金情報

Provisioned Throughput は GSU 単位の固定費サブスクリプションで提供されます。ファインチューニング済みモデルの推論は、ベースモデルの料金プレミアムに比例した高いバーンダウンレートが適用されます。
