📋 概要

Google Cloud は、Gemini Enterprise Agent Platform の Model-as-a-Service (MaaS) で提供されている16のオープンモデルエンドポイントの廃止を発表しました。

対象エンドポイントは 2026年7月21日 付で非推奨 (Deprecated) となり、2026年10月21日 に完全廃止 (Retired) されます。廃止後は API リクエストが 400 エラーを返します。

影響範囲: DeepSeek、GLM (ZAI.org)、OpenAI gpt-oss、Moonshot AI (Kimi)、Meta Llama、MiniMax、Multilingual E5 (Embedding)、Qwen の各ファミリーにわたる16モデルが対象です。

Before / After

❌ Before (課題)

✗多数のオープンモデルが並行提供され、バージョン管理の複雑性が増加
✗旧バージョンの継続提供により、セキュリティパッチ適用が遅延
✗最新モデルへの移行インセンティブが不足

✅ After (改善)

✓モデルポートフォリオ整理によりサポート品質が向上
✓新モデルへの移行で推論精度・レイテンシが改善
✓インフラリソースの効率的活用でサービス安定性が向上

📅 廃止タイムライン

2026-07-21 - 廃止予告 (Deprecated)
公式に非推奨化。移行猶予期間が開始されます。既存エンドポイントは引き続き動作します。
2026-07-21 ~ 2026-10-20 - 移行期間
既存エンドポイントは動作を継続。この間に移行計画を策定・実行してください。
2026-10-21 - 完全廃止 (Retired)
API リクエストが 400 エラーを返却。対象モデルへのアクセスが完全に遮断されます。

📝 まとめ

Gemini Enterprise Agent Platform の16のオープンモデルエンドポイントが 2026年10月21日に廃止されます。

全ての影響を受けるユーザーは、3ヶ月の猶予期間内に後継モデルまたは代替モデルへの移行を完了する必要があります。移行前に必ずプロンプトの互換性テストと性能評価を実施し、本番環境への影響を最小限に抑えることを推奨します。

優先対応が必要なケース

→Llama 3.3 ユーザー: Llama 4 ファミリーへ移行
→DeepSeek ユーザー: 最新バージョンまたは Gemini モデルへ移行
→E5 埋め込みユーザー: Gemini Embedding 2 へ移行 (ベクトルDB再インデックス必須)
