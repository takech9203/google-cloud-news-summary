☁️ 概要

Google Cloud Contact Center as a Service (CCaaS) の Advanced Reporting ダッシュボード に対する包括的な機能強化が実施されました。リアルタイムモニタリング機能の拡充、キューパフォーマンスの可視性向上、CSAT スコアへのダイレクトアクセス、リピートコンタクト追跡機能が新たに追加されています。

🚀 主要機能 (新規追加)

🔗 子キューフィルタオプション

Queue Name フィルタを持つすべてのダッシュボードに「Child Queues」チェックボックスが追加。親キュー選択時に子キューのデータを一括で含めることが可能に。

✓ 階層型キュー構成での運用効率が大幅向上

📡 Agent & Queue Status (Live) 新メトリクス

リアルタイムでエージェントの稼働状況とキュー負荷を即座に把握可能。

✓ In Call: 通話中のエージェント数
✓ Available / Waiting: 待機中エージェント数
✓ Contacts in Queue: キュー待機コール数

🔗 CSAT ダッシュボード CRM ダイレクトリンク

CSAT Interactions テーブルの Session ID 横に CRM 内の CSAT スコアへの直接リンクが表示。手動検索の手間を排除。

📊 Real-time Queue Monitoring 新タイル

✓ Total Rolled Over Pending Callbacks
✓ Total Rolled Over Completed Callbacks
✓ Avg CSAT Calls: リアルタイム平均 CSAT

⚙️ Queue Performance 機能拡張

Interaction Type フィルタとカラムの追加、Rolled Over Callbacks メトリクスタイルの追加。インタラクション種別ごとのパフォーマンス分析が可能に。

🔁 Queue Summary Table リピートコンタクト

✓ Total Repeat Contacts: リピートコンタクト総数
✓ Repeat Contact %: FCR の間接指標として活用可能

⚠️ デメリット・制約事項

⚠️ 制限事項:
  • Advanced Reporting は対応リージョン (7 リージョン) でのみ利用可能
  • 有効化するとレガシーダッシュボードは利用不可に
  • Agent ロールのユーザーはダッシュボードにアクセス不可
  • Queue Performance ダッシュボードの日付範囲は最大 45 日間
  • ダッシュボードのリフレッシュ間隔はデフォルト 60 秒
💡 考慮すべき点:
  • Advanced Reporting の有効化/無効化はカスタムロールの権限設定に影響する可能性あり
  • CRM ダイレクトリンクは CRM 側の設定が正しく構成されている必要あり
  • Rolled Over Callbacks メトリクスはコールバック機能を利用している環境でのみ有用

🎯 ユースケース

🏢 ユースケース 1: 大規模コンタクトセンターのリアルタイム監視

シナリオ: 複数の製品ラインにまたがる階層型キュー構成 (親キュー: 製品カテゴリ、子キュー: 言語別) を持つエンタープライズコンタクトセンターで、製品カテゴリ全体のリアルタイム状況を把握したい。

効果: 子キューフィルタで配下のすべての言語別キューのデータが統合表示。Agent & Queue Status (Live) の新メトリクスと組み合わせ、製品カテゴリ全体のエージェント稼働率とキュー負荷をリアルタイムで監視し、エージェントの再配置を迅速に判断できる。

😊 ユースケース 2: 顧客体験品質の継続的改善

シナリオ: CSAT スコアが低下している傾向を検知し、根本原因を特定して改善アクションにつなげたい。

効果: Avg CSAT Calls メトリクスでリアルタイムの CSAT トレンドを監視し、スコアが低下した Session ID から CRM ダイレクトリンクで即座に詳細を確認。Repeat Contact % で低 FCR ケースを特定し、エージェントトレーニングやプロセス改善に活用。

📞 ユースケース 3: コールバック運用の最適化

シナリオ: コールバック機能を利用しているが、ロールオーバーされるコールバックが増加しており SLA に影響している。

効果: Total Rolled Over Pending/Completed Callbacks をリアルタイムで監視し、滞留状況を可視化。Interaction Type フィルタでコールバックのみを抽出してパフォーマンスを分析し、スタッフ配置やコールバック枠の調整で SLA 遵守率を改善。
