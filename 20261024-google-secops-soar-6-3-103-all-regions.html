🛡️ Google SecOps SOAR
Release 6.3.103 が全リージョンで利用可能に

📅 リリース日: 2026-10-24
Google SecOps SOAR 全リージョン展開完了 Announcement

📝 概要

2026 年 10 月 24 日、Google SecOps SOAR の Release 6.3.103 が全リージョンで利用可能になりました。 本リリースは 2026 年 10 月 18 日に第 1 段階のリージョン (日本、インド、オーストラリア、カナダ、ドイツ、スイス) へのロールアウトが開始されており、 今回の発表により第 2 段階のリージョン (US / EU マルチリージョンなど) を含むすべてのリージョンへの展開が完了しました。

Release 6.3.103 には、アラートグルーピングに関する新機能と API の非推奨化が含まれています。 第 2 段階リージョンを利用しているユーザーも、本日以降これらの変更が適用された環境を利用できます。

❌ Before (アップデート前の課題)
  • Release 6.3.103 の新機能 (クローズ済みケースの再オープン設定など) は、10 月 18 日以降、第 1 段階のリージョンでのみ利用可能だった
  • 第 2 段階のリージョン (Singapore、Qatar、Saudi Arabia、Israel、UK、Italy、EU マルチリージョン、US マルチリージョン) のユーザーは利用できなかった
✅ After (アップデート後の改善)
  • Release 6.3.103 がすべてのリージョンで利用可能になり、リージョン間の機能差が解消された
  • 全リージョンのユーザーが Source Grouping Identifier によるグルーピング時のケース再オープン設定を利用できるようになった

🔧 Release 6.3.103 に含まれる変更

1️⃣ クローズ済みケースの再オープン設定 新機能

✓Source Grouping Identifier によるアラートグルーピング時に、クローズ済みケースを再オープンするかどうかを指定できるようになった
✓このオプションを有効にすると、過去にクローズされたケースと同じ Source Grouping Identifier を持つ新しいアラートを受信した際に、Google SecOps がそのケースを再オープンする
→詳細: Configure alert grouping

2️⃣ ListCaseEvents API エンドポイントの非推奨化 Deprecated

✗2026 年 10 月 12 日付けで ListCaseEvents API エンドポイントが非推奨となった
✓代わりに ListCaseEvidenceData API エンドポイントの使用が推奨される
🚫 ListCaseEvents
非推奨 (2026-10-12)
→
✅ ListCaseEvidenceData
推奨 (Chronicle API)

⚠️ 考慮すべき点

🔄 API 移行: ListCaseEvents API を利用している場合は、ListCaseEvidenceData API への移行を計画する必要があります。
💡 運用フローへの影響: クローズ済みケースの再オープンはオプション設定です。有効化するとクローズ済みケースの運用フロー (メトリクス、SLA 管理など) に影響する可能性があるため、アラートグルーピング設定を確認のうえ適用を判断することが推奨されます。
📦 次バージョン: 次バージョンの Release 6.3.104 は 2026 年 10 月 25 日に第 1 段階リージョンへのロールアウトが開始されています (別レポート参照)。
