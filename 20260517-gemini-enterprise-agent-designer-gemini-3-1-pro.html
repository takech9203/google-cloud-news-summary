🤖 Agent Designer デフォルトモデル変更

Gemini Enterprise Limited Availability GA SLO
2026-05-17

📋 概要

Gemini Enterprise の Agent Designer において、US / Global リージョンで新規作成されるエージェントのデフォルトモデルが Gemini 3.1 Pro に変更されました。さらに、既存エージェントも自動移行が実施され、より高度な推論能力とエージェント機能を即座に活用できるようになります。

🧠 ポイント: Gemini 3.1 Pro は Limited Availability ステータスですが、GA レベルの SLO が適用されるため、本番環境での利用に適した信頼性が担保されています。

  • SWE・エージェント性能が標準レベル

✅ After

  • US/Global で自動的に Gemini 3.1 Pro を使用
  • 既存エージェントも自動移行でパフォーマンス向上
  • GA SLO で本番ワークロードに対応
  • 必要なら 2.5 Pro/Flash に手動で戻せる柔軟性

⚡ 主要機能

🆕 新規エージェントのデフォルトモデル変更

US および Global リージョンで Agent Designer から作成される新規エージェントのデフォルトモデルが Gemini 3.1 Pro に変更。他のリージョンのデフォルト設定は変更なし。

🔄 既存エージェントの自動移行

US/Global リージョンで Gemini 2.5 Pro または 2.5 Flash を使用していた既存エージェントが Gemini 3.1 Pro に自動移行。ユーザーの操作なしで移行が完了。

↩️ 手動ロールバック機能

エージェント設定から Gemini 2.5 Pro または 2.5 Flash に手動で戻すことが可能。Agent Designer の Flow タブまたは Chat ペインからモデル変更を実行可能。

🛡️ GA SLO 付き Limited Availability

Gemini 3.1 Pro は Limited Availability ステータスだが、General Availability レベルの SLO が適用。本番環境での信頼性が保証される。

⚠️ 制約事項・注意点

制限事項:
  • Gemini 3.1 Pro が利用可能なリージョンは現時点で US と Global のみ
  • Limited Availability のため全ユーザーに即時提供されるわけではない
  • 既存エージェントの自動移行はオプトアウト不可 (移行後に手動で戻す必要あり)
  • Gemini Live API は Gemini 3.1 Pro では非対応
  • Content Credentials (C2PA) は非対応
💡 考慮すべき点:
  • 自動移行により既存のプロンプトやワークフローの動作が変わる可能性がある
  • Gemini 3.1 Pro はコンパクトで直接的な回答を優先するため出力スタイルが異なる場合がある
  • モデル変更後は Preview タブで動作確認を推奨
  • 料金体系が異なる場合があるためコストの確認が必要
