Contact Center as a Service (CCaaS) Fixed (バグ修正)

📞 CCaaS 2026 年 9 月バグ修正リリース

音声・チャット・メール・レポーティング・エージェントデスクトップの安定性改善
リリース日: 2026-09-11

📋 概要

Google Cloud Contact Center as a Service (CCaaS) で、多数の不具合を修正する大規模なバグ修正リリースが公開されました。音声通話のルーティング・キャパシティ管理、エージェントデスクトップ (コールアダプター / チャットアダプター)、メールチャネル (IMAP 接続)、レポーティング・データエクスポート、Web SDK まで、コンタクトセンター運用のほぼ全領域にわたる約 40 件の問題が解消されています。

特に影響が大きいのは、IMAP 接続拒否による数時間規模のメールボックスダウンタイム、コールボリューム急増時のキャパシティ保護の迂回、1 分未満の推定待ち時間がゼロに切り捨てられオーバーキャパシティアクションが作動しない問題の修正です。可用性・SLA 管理・レポーティング精度に直結するため、CCaaS 運用組織の管理者や Solutions Architect は内容の把握が推奨されます。

❌ Before: アップデート前の課題

  • 通話がアップロード完了前に終了すると SmartAction が誤って「failed」と記録
  • 大規模チーム + カスタムロール環境でアウトバウンド番号リストの読み込みがタイムアウト・遅延
  • 1 分未満の推定待ち時間がゼロに切り捨てられ、オーバーキャパシティアクションが作動しない
  • コールボリューム急増がキャパシティ保護を迂回し、エージェント可用性が最小値を下回る
  • 断続的な IMAP 接続拒否で取得ワーカーがバックオフループに入り、数時間のメールボックスダウンタイム
  • 手動ラップアップが無関係な直近の通話に誤帰属され、Timeline・Raw エクスポートの精度が低下
  • 完了したコール転送がキュー滞在時間レコードを重複生成し、キューボリューム・SLA が過大報告

✅ After: アップデート後の改善

  • SmartAction ステータス・ラップアップ帰属・キュー滞在時間の記録が正確になり、SLA メトリクスの信頼性が向上
  • 待ち時間の丸め処理とキャパシティ保護が修正され、オーバーキャパシティアクションが設計どおり機能
  • IMAP・Twilio ICE トークン・チャット Webhook など一時的な接続エラーへの耐性が改善し、チャネル可用性が向上
  • 「[object Object]」表示・ナビバー重なり・読み込み表示などデスクトップの表示不具合が解消
  • 非効率なデータベースクエリによる高 CPU 使用率が解消され、全チャネルのパフォーマンスが改善

今回の修正は音声ルーティング、エージェントデスクトップ、メール・チャットチャネル、レポーティングの 4 領域に大別され、いずれもコンタクトセンターの可用性と SLA メトリクスの精度向上に寄与します。

🔧 主要な修正内容 (領域別)

📞 音声通話・ルーティング・キャパシティ管理 10 件

  • 1 分未満の推定待ち時間がゼロに切り捨てられ、オーバーキャパシティアクションが正確にトリガーされない問題
  • コールボリューム急増がチームのキャパシティ保護を迂回し、エージェント可用性が設定した最小値を下回る問題
  • 応答済みの音声通話が、エンドユーザー切断後に要求していない 2 回目のコールバックをトリガーする問題
  • 通話の「エージェントレグ」が接続中のままタイムアウトまで停滞し、サイレントに失敗する問題
  • オーバーキャパシティ時の電話デフレクションがエージェント直接着信で作動せず、エラー表示や無期限の待機が発生する問題
  • プライマリキューが最小可用性しきい値を下回っていても、セカンダリキューの通話がエージェントに割り当てられる問題
  • クロスランゲージ転送後、デフレクション音声が転送元キューの言語で再生される問題
  • 高キャパシティリダイレクト中にボイスメールが保存されない問題
  • Twilio ICE トークン取得時の一時的な接続エラーで、通話セットアップが失敗・遅延する問題
  • DAP ルックアップ中の一時的なネットワーク障害で、着信がデフォルトキューにルーティングされたりチャットが開始できない問題

🖥️ エージェントデスクトップ・アダプター 9 件

  • ネストされたカスタムデータがセッションデータフィードで「[object Object]」と表示される問題
  • 「Previous Interactions」ページでナビゲーションバーがサマリーテキストに重なり、スクロール時に固定されない問題
  • チャット割り当て時に、トランスクリプトではなく読み込みインジケーターが表示され続ける問題
  • 切断された通話後に、必須ディスポジションのプロンプトが表示されない問題
  • 接続中にキャンセルしたアウトバウンドコールが「不明な失敗」として記録される問題
  • ボイスメールの巻き戻し・早送りボタンで最初から再生されてしまう問題
  • 設定が不完全な場合に通話コントロールボタンが更新・描画されない問題
  • 通話開始時にセンチメントバナーが即座に表示されない問題
  • フランス語 (カナダ) の通話履歴でキュー名が英語表示される問題

📧 メール・チャットチャネル 5 件

  • 断続的な IMAP 接続拒否で取得ワーカーが長時間のバックオフループに入り、数時間のメールボックスダウンタイムが発生する問題
  • チャット Webhook 配信中の一時的な接続断による不要な遅延
  • チーム所属の更新や直接キュー割り当てで資格を得たエージェントに、待機中のチャットが即座に提供されない問題
  • Web SDK チャットウィジェット内で静的テキストがキーボードフォーカスを受け取り、キーボード・スクリーンリーダー操作を妨げる問題
  • デプロイ中の一時的なアセットエラーが CDN にキャッシュされ、Web SDK の初期化が失敗する問題

📊 レポーティング・データエクスポート・監査 7 件

  • 手動ラップアップセッションが Agent Activity Timeline と Raw エクスポートで無関係な直近の通話に誤帰属される問題
  • 完了したコール転送がキュー滞在時間レコードを重複生成し、キューボリュームと SLA メトリクスが過大報告される問題
  • 仮想エージェントから人間へのエスカレーションのキャンセル時に、負のキュー滞在時間や不正確な SLA が報告される問題
  • 仮想エージェントのエスカレーションがボイスメールにデフレクトされた場合、インバウンド通話の録音がエクスポートされない問題
  • 外部 CRM 統合のないインスタンスで、カスタムフォームの回答が外部ストレージにエクスポートされない問題
  • API クライアントやバックグラウンドジョブからの変更で監査ログレコードが生成されない問題
  • レポーティングメトリクスで作業時間と待機時間の期間が重複する問題

⚙️ 管理ポータル・その他 8 件

  • 写真・動画アップロード完了前に通話が終了した場合、SmartAction が誤って「failed」と記録される問題
  • 大規模チーム + カスタムロール環境でアウトバウンド番号リストの読み込みがタイムアウト・遅延する問題
  • 「SLA thresholds for queues」ダイアログで保存したキュー名が保持されない問題
  • 「Languages」ダイアログの音声アップロードオプションが保存後に Text-to-speech に切り替わる問題
  • キューの作成・更新が失敗しタイムアウトエラーが返される問題
  • 仮想エージェントの音声通話がラップアップ中にセッションエラーをトリガーする問題
  • Vonage BYOC 通話で Agent Assist のリアルタイム文字起こしが開始されない問題
  • 非効率なデータベースクエリによる高 CPU 使用率と全チャネルのパフォーマンス低下
💡 補足: 修正の全リストは 公式リリースノート を参照してください。

🎯 メリット

💼 ビジネス面

  • SLA・レポーティングの信頼性向上: キュー滞在時間の重複・負の値、ラップアップ誤帰属、作業/待機時間の重複が解消され、意思決定の精度が向上
  • 顧客体験の改善: 二重コールバック、無期限の待機、ボイスメール未保存、多言語環境の誤アナウンスが解消
  • メールチャネルの可用性向上: 数時間規模のメールボックスダウンタイムが解消され、SLA 遵守が容易に

🛠️ 技術面

  • 一時的な障害への耐性強化: IMAP、Twilio ICE トークン、チャット Webhook、DAP ルックアップのリトライ・フォールバックが安定化
  • キャパシティ保護の正常化: オーバーキャパシティアクションと最小可用性しきい値が設計どおりに機能
  • コンプライアンス対応の強化: API・バックグラウンドジョブ経由の変更でも監査ログが生成され、監査証跡の網羅性が向上
  • アクセシビリティ改善: Web SDK のキーボードフォーカス問題が修正され、スクリーンリーダー操作が改善

⚠️ デメリット・制約事項 (考慮すべき点)

⚠️ 既存の回避策との干渉: 本リリースはマネージドサービス側で適用されるため、ユーザー側での適用作業は不要です。ただし、修正された動作 (オーバーキャパシティアクションのトリガー条件、キュー割り当てロジックなど) が従来の回避策と干渉しないか確認することが望ましいです。
📈 レポーティング値の不連続: キュー滞在時間の重複記録や負の値が修正されたことで、修正前後でキューボリュームや SLA の値に不連続が生じる可能性があります。過去データとのトレンド比較時には注意してください。
❓ 詳細情報の確認: 個別の修正の適用タイミングや詳細な技術的背景は Release Notes に記載されていないため、影響が疑われる場合はサポートへの確認を推奨します。

💡 ユースケース

📊 ユースケース 1: SLA レポートの再検証

シナリオ: コール転送を多用するコンタクトセンターで、キューボリュームと SLA メトリクスが実感より高く報告されていた。

効果: 完了した転送によるキュー滞在時間レコードの重複生成が修正され、レポートが実態を正しく反映。修正日以降のデータで SLA しきい値やスタッフィング計画を再検証することで、過大報告に基づいていた運用判断を是正できる。

📧 ユースケース 2: メールチャネルの安定運用

シナリオ: IMAP ベースのメール連携で、断続的な接続拒否をきっかけに数時間メールが取得されない障害が発生していた。

効果: メール取得ワーカーの過剰なバックオフループが修正され、一時的な IMAP 接続拒否から迅速に回復。ダウンタイム監視アラートの誤検知・実障害の双方が減少する。

💰 料金

本リリースはバグ修正であり、料金体系への変更はありません。CCaaS の料金の詳細は 料金ページ を参照してください。

🔗 関連サービス・機能

🖥️ CCAI Platform (Agent Desktop) 今回多数の修正が入ったエージェント向けインターフェース。コールアダプター、チャットアダプター、セッションデータフィードなどのパネルで構成。
🤖 Agent Assist Vonage BYOC 通話でのリアルタイム文字起こし開始の問題が修正され、BYOC 環境でのエージェント支援が安定化。
💬 Dialogflow / 仮想エージェント 人間エージェントへのエスカレーションに関する SLA メトリクスや、ラップアップ時のセッションエラーが修正。
📜 Cloud Audit Logs API クライアントやバックグラウンドジョブ経由の変更でも監査ログレコードが生成されるように。

📝 まとめ

✅ 約 40 件の問題を一括解消する大規模バグ修正リリース

音声ルーティング・キャパシティ管理・エージェントデスクトップ・メールチャネル・レポーティングにわたる修正が含まれます。特にキュー滞在時間の重複記録や負の値の修正はレポーティング値に不連続を生む可能性があるため、SLA レポートやダッシュボードを運用しているチームは修正日以降のデータを基準に指標を再確認することを推奨します。また、これまで回避策を講じていた問題 (二重コールバック、IMAP ダウンタイムなど) については、回避策の撤去可否を検討してください。
