📋 概要

Google Cloud は、リソースベースの確約利用割引 (CUD) レコメンデーション機能を GPU、Local SSD ディスク、プレミアム OS ライセンスに対して一般提供 (GA) として拡張しました。 過去の使用量データに基づいた最適なコミットメント購入の推奨を自動的に受け取ることができます。

対象ユーザー: Compute Engine で GPU (A2, G2, N1+GPU)、Local SSD、またはプレミアム OS ライセンス (SLES/RHEL) を定常的に利用している FinOps 担当者、クラウドアーキテクト、インフラ管理者

🔄 Before / After

❌ Before (アップデート前)

  • GPU / Local SSD / OS ライセンスの CUD レコメンデーションが未提供
  • 最適なコミットメント購入量を手動で分析する必要あり
  • 損益分岐点の計算を自身で実施
  • リソースベース CUD は vCPU とメモリのみに限定

✅ After (アップデート後)

  • GPU / Local SSD / OS ライセンスに対して自動レコメンデーション生成
  • FinOps Hub ダッシュボードから推奨購入量と節約額を直接確認
  • 安定使用量モデルと最適節約モデルの 2 種類を提供
  • 過去 30 日間の使用履歴に基づくデータドリブンな推奨

⚡ 主要機能

🖥️ GPU 向け CUD レコメンデーション

  • A2 (Accelerator-optimized)、G2/G4 (Graphics-optimized)、N1+GPU に対応
  • 最大 55% (一部タイプは最大 65%) の割引
  • リザベーションの作成・アタッチが必須

💾 Local SSD 向け CUD レコメンデーション

  • C3, C3D, C4, C4A, C4D, N1, N2, N2D, C2, C2D, H4D, Z3 など多数対応
  • 最大 55% の割引
  • 大部分でリザベーションのアタッチ必須 (Titanium SSD は例外)

📋 プレミアム OS ライセンス向け

  • SLES: 最大 79% 割引
  • SLES for SAP: 最大 63% 割引
  • RHEL: 最大 20% 割引
  • ハードウェアコミットメントとは別に購入可能

📈 レコメンデーション計算モデル

  • 安定使用量モデル: 30 日間の連続稼働リソースに基づく定常ワークロード向け
  • 最適節約モデル: バースト利用含め純節約額を最大化 (損益分岐点考慮)

Step 1: FinOps Hub でレコメンデーションを確認

Google Cloud コンソール > Billing > FinOps Hub > 「Potential savings/month」チャートから「View all recommendations」をクリック

Step 2: レコメンデーションの詳細確認とシナリオモデリング

個別のレコメンデーションをクリック > 「Create a scenario」でカバー率やコミットメント期間を調整し、最適な購入量をシミュレーション

Step 3: コミットメントの購入

レコメンデーションに基づいてコミットメントを購入。GPU の場合はリザベーションの同時作成が必須。

Bash 
# gcloud CLI でリソースベースコミットメントを購入する例 (GPU)
gcloud compute commitments create my-gpu-commitment \
    --region=us-central1 \
    --plan=36-month \
    --resources=type=nvidia-tesla-a100,amount=4 \
    --reservations-from-file=reservations.yaml

✅ メリット

ビジネス面

💰GPU ワークロードのコスト最適化: AI/ML トレーニングやレンダリングなど GPU 集約型ワークロードで最大 65% のコスト削減が可能
🤖FinOps の自動化: 手動分析なしに最適なコミットメント購入量の推奨を受けられ、意思決定の迅速化と精度向上に寄与
📋OS ライセンスコストの大幅削減: SLES 環境で最大 79% の削減が可能。SAP on Google Cloud のような大規模環境で特にインパクト大

技術面

📈データドリブンな最適化: 過去 30 日間の実使用データに基づく 2 種類の計算モデルにより、ワークロード特性に合った推奨を提供
🔄シナリオモデリング対応: カバー率や期間を変更した場合の節約額をシミュレーション可能で、複数パターンの比較検討が容易
🌐CUD シェアリングとの連携: Billing Account 配下の全プロジェクトでコミットメントを共有可能、組織全体での最適化

⚠️ 制限事項・注意点

制限事項:
  • ❌A3 Ultra、A4、A4X、A4X Max マシンシリーズには未対応
  • ❌Cloud TPU に対する CUD レコメンデーションは利用不可
  • ❌Compute Engine SKU を使用するリソースのみが対象 (CE, GKE, Spark, Airflow 1, Vertex AI の VM)
  • ❌コミットメント購入後のキャンセルは不可
💡 考慮すべき点:
  • GPU コミットメントにはリザベーション (ゾーン単位の容量確保) が必須
  • 使用量が減少した場合でも月額課金が継続
  • レコメンデーション生成には最低 30 日間の使用履歴が必要
  • CUD シェアリングの設定状況 (2026/6/16 以降作成のアカウントはデフォルト有効) を確認

🎯 ユースケース

🤖 ユースケース 1: AI/ML トレーニング環境のコスト最適化

シナリオ: 機械学習チームが A2 インスタンス (NVIDIA A100 GPU) を常時 4 台以上使用してモデルトレーニングを実施。オンデマンド価格で課金中。

効果: CUD レコメンデーションにより安定使用量を特定し、3 年コミットメントで最大 65% のコスト削減。月額数千ドル単位の節約。

📋 ユースケース 2: SAP on Google Cloud の OS ライセンスコスト削減

シナリオ: SAP HANA 環境で SLES for SAP ライセンスを大量に使用。各 VM のライセンス費用がオンデマンド価格で積み上がっている。

効果: OS ライセンスの CUD レコメンデーションに基づき SLES for SAP コミットメントを購入し、最大 63% の削減を実現。

💾 ユースケース 3: ハイパフォーマンスデータベースの Local SSD コスト最適化

シナリオ: リアルタイムデータ処理基盤として N2 インスタンスに Local SSD を多数アタッチし、低レイテンシストレージを常時利用。

効果: Local SSD 向け CUD レコメンデーションに基づき 1 年 or 3 年コミットメントで最大 55% のストレージコスト削減。
