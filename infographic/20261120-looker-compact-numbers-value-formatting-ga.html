📈 Looker: コンパクト数値表示と
基本値フォーマットが GA

リリース日: 2026-11-20

📝 概要

Looker 26.20 以降のデフォルト Explore インターフェースで、 コンパクト数値表示 (Compact numbers) と 基本値フォーマット (basic value formatting) が GA (一般提供) になりました。 Looker (Google Cloud core) と Looker (original) の両方が対象です。

これまで数値の表示形式調整には Excel スタイルのフォーマット文字列 (例: 0.0,," M") の記述が必要でしたが、 今後は GUI のプリセットを選ぶだけで見やすい数値表示を実現できます。 フォーマット構文に馴染みのないビジネスユーザーやアナリストにも優しい、アクセシビリティの高いアップデートです。

🔴 Before: アップデート前の課題
  • 表示形式の変更には Excel スタイルのフォーマット文字列 (例: #,##0.00、0.000,," M") の記述が必須
  • 「1.85K」「2.3M」のような省略表記にも専用の構文知識が必要
  • 構文を知らないビジネスユーザーは LookML 開発者に value_format の定義を依頼するか、デフォルト表示のまま利用
🟢 After: アップデート後の改善
  • Compact numbers を有効にするだけで K / M / B / T の標準接尾辞で省略表記
  • Decimal precision で小数点以下の桁数 (Default、0、1〜8) を選択可能
  • Display format で Default / Number / Percent / Financial のプリセットを選択可能
  • 高度なケースは「Switch to advanced formatting」で従来の Excel スタイル文字列にも切り替え可能

従来は Excel スタイルのフォーマット文字列の記述が必須でしたが、GA 後はデフォルト Explore インターフェースの Style タブから GUI プリセットで値フォーマットを設定でき、必要に応じて高度なフォーマット文字列にも切り替えられます。

⚙️ 主要機能

1️⃣ Compact numbers (コンパクト数値表示)

1,000 以上の数値を標準的なメトリック接尾辞 K (千) / M (百万) / B (十億) / T (兆) で省略表記。 デフォルトでは無効 (オプトイン)。有効時、Decimal precision が Default なら小数点以下 2 桁 (例: 1,845 → 1.85K)、0 を選択すると整数に丸め (例: 2K)。

2️⃣ Decimal precision (小数精度)

表示する小数点以下の桁数を Default、0、または 1〜8 から選択。 フォーマット文字列を書かずに桁数だけを調整可能。

3️⃣ Display format (表示形式プリセット)

Default (データソースのデフォルト) / Number (桁区切り付き数値) / Percent (% 付き) / Financial (ローカライズされた通貨記号、例: $) から選択。

4️⃣ 高度なフォーマットへの切り替え

「Switch to advanced formatting」で従来どおり Excel スタイルのカスタムフォーマット文字列 (Custom Format Rule) を入力可能。「Switch to basic formatting」で基本コントロールに戻れる (基本フォーマットの選択はカスタムフォーマットルールを上書き)。

🛠️ 設定方法

💡 前提条件: ① インスタンスが Looker 26.20 以降を使用していること / ② デフォルト Explore インターフェース (新しい Explore エクスペリエンス) を使用していること
  1. Style タブを開く — Explore で可視化を表示し、Configure パネルの Style タブを開く。 チャートタイプに応じて該当セクション (Style / Values / Series) を展開。 縦棒・横棒・折れ線・散布図・面・ウォーターフォールの場合は Value Labels を有効化。
  2. 基本フォーマットを設定 — Value format セクション (テーブルチャートは Format セクション) で、 Compact numbers / Decimal precision / Display format を設定。
  3. (任意) 高度なフォーマットへ切り替え — Excel スタイル文字列が必要なら Switch to advanced formatting をクリックし、Custom Format Rule に入力。 Switch to basic formatting で基本コントロールに戻る。
設定例 経営ダッシュボードの KPI 表示 (単一値チャート) 
# Explore → Configure パネル → Style タブ → Style セクション
Compact numbers: 有効       # 1,845,000,000 → 1.8B
Decimal precision: 1        # 小数点以下 1 桁
Display format: Financial   # 通貨記号付き → $1.8B

⚖️ メリットと制約事項

✅ メリット

✓セルフサービス分析の裾野拡大: フォーマット構文を知らないビジネスユーザーでも、見やすい数値表示を自分で設定できる
✓レポート品質の向上: 大きな数値のコンパクト表記により、ダッシュボードや単一値チャートの可読性が向上
✓LookML 開発者への依頼削減: 表示形式の微調整のために value_format の変更を開発者に依頼する必要が減る
✓後方互換性の確保: 高度なケースでは従来の Excel スタイルフォーマット文字列へいつでも切り替え可能
✓設定の簡素化: GUI プリセットにより設定ミス (フォーマット文字列の構文エラー) を防止

⚠️ 制限事項

✗Looker 26.20 以降のデフォルト Explore インターフェースでのみ利用可能 (クラシック Explore では従来どおり Value Format フィールドに文字列を入力)
✗カスタムフォーマットは type: number のディメンションまたはメジャーに対してのみサポート
✗基本フォーマットのオプションを選択すると、カスタムフォーマットルール (高度なフォーマット) の設定は上書きされる
⚠️ 考慮すべき点: LookML の value_format / value_format_name や、インスタンス・ユーザー単位の Number format 設定 (ロケール別の桁区切り) と併用する場合は、適用の重なり方を確認すること。 また、Compact numbers はデフォルトで無効のため、利用するにはチャートごとに有効化が必要。

🎯 ユースケース

💼 ユースケース 1: 経営ダッシュボードの KPI 表示

シナリオ: 売上高やユーザー数など桁数の大きい KPI を単一値チャートで表示する際、「1,845,000,000」のような生の数値では瞬時に規模を把握しにくい。

設定: Compact numbers: 有効 / Decimal precision: 1 / Display format: Financial

効果: 「$1.8B」のような簡潔な表示になり、経営層が一目で規模を把握できる。フォーマット文字列の知識は不要。

📈 ユースケース 2: アナリストによる割合指標のアドホック分析

シナリオ: コンバージョン率や成長率などの割合指標を折れ線チャートで可視化する際、これまでは 0.00% のようなフォーマット文字列を都度入力していた。

効果: Display format で Percent を選択し、Decimal precision で桁数を選ぶだけで統一的なパーセント表示が可能になり、アドホック分析のスピードが向上する。

🔗 関連サービス・機能

📐 LookML value_format / value_format_name パラメータ

モデル側で定義する従来の値フォーマット方法。基本フォーマットはこれを補完する UI レイヤーの機能。

🧮 テーブル計算・カスタムフィールド

作成・編集時に Format ドロップダウンでカスタムフォーマットを指定可能。

🌐 Number format 設定 (ローカライズ)

インスタンス・ユーザー単位で桁区切り記号 (1,234.56 / 1.234,56 / 1 234,56) を設定する機能。他のフォーマット設定の上に適用される。

📊 Looker Studio

同じく Google Cloud の BI ツールで、コンパクト数値などの表示オプションを提供。ツール間で一貫した数値表現を実現しやすくなる。

✨ まとめ

✅ ポイント: Looker のデフォルト Explore インターフェースで、Excel スタイルのフォーマット文字列を書かずに コンパクト数値表示・小数精度・表示形式を GUI で設定可能になりました。 ビジネスユーザーのセルフサービス分析を後押しする改善です。 Looker 26.20 以降のインスタンスを利用している場合は、ダッシュボードや Explore の数値表示設定を この基本フォーマットに置き換えることを検討してください。
