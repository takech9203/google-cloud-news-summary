🖥️ GDC for bare metal
1.33.1100-gke.72 リリース

csi-snapshot-validation-webhook の削除と Critical 3 件を含む脆弱性修正
📅 リリース日: 2026-08-04

📝 概要

Google Distributed Cloud (software only) for bare metal のパッチバージョン 1.33.1100-gke.72 がダウンロード可能になりました。 本バージョンは Kubernetes v1.33.11-gke.100 上で動作します。 オンプレミスのベアメタル環境で GKE Enterprise クラスタを運用しているユーザー向けの メンテナンスリリースであり、コンポーネントの近代化とセキュリティ修正が中心です。

→非推奨の csi-snapshot-validation-webhook コンポーネントを削除。バリデーションは CRD 内の CEL (Common Expression Language) ルールによる Kubernetes ネイティブ処理に移行
→Critical 3 件 (CVE-2025-22871、CVE-2026-33815、CVE-2026-33816) を含む多数の脆弱性 (CVE) を修正
⚠️ 注意: GKE On-Prem API クライアント (Google Cloud コンソール、gcloud CLI、Terraform) での インストール・アップグレードにこのバージョンが利用可能になるまで、リリース後 約 7〜14 日かかります。
🕐 Before (〜1.33.1000)
  • VolumeSnapshot などのバリデーションに専用 Webhook コンポーネント (csi-snapshot-validation-webhook) をクラスタ内で稼働させる必要があった
  • Webhook ベースのバリデーションは追加の Pod・証明書管理などの運用対象コンポーネントを増やす要因だった (過去に証明書ローテーション対応などの保守が実施)
  • 1.33.1000-gke.59 以前には Critical 3 件を含む未修正の脆弱性が存在した
✅ After (1.33.1100-gke.72)
  • 非推奨 Webhook が削除され、CRD に組み込まれた CEL ルールによるネイティブバリデーションに移行。クラスタ内の運用コンポーネントが削減
  • バリデーションが API サーバー側 (CRD の CEL ルール) で完結し、Webhook 呼び出しに依存しない構成に
  • Critical / High / Medium / Low 各重要度の脆弱性が修正され、セキュリティ体制が強化

📸 ボリュームスナップショットのリソース構成

CEL ルールによるバリデーション対象となるリソース (snapshot.storage.k8s.io API グループ) は以下のとおりです。

リソース役割
VolumeSnapshotClassスナップショットの CSI ドライバと deletionPolicy を定義
VolumeSnapshot既存 PersistentVolumeClaim のスナップショット取得リクエスト
VolumeSnapshotContentストレージシステム上の実スナップショットとのバインディングを保持
