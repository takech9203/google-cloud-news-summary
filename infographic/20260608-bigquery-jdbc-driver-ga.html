BigQuery GA Java Open Source

📋 概要

Google が開発したオープンソースの JDBC ドライバー が一般提供 (GA) となった。Java アプリケーションから標準的な JDBC インターフェースを通じて BigQuery に接続し、クエリの実行やデータ操作が可能になる。

従来のサードパーティ製 Simba JDBC ドライバーに代わり、Google が直接開発・メンテナンスするオープンソースドライバーとして、BigQuery の最新機能への迅速な対応、Maven Central からの容易な導入、Storage Read API による高スループット読み取りなど多くの利点を提供する。

✅ 対象ユーザー: 既存の Java/JDBC エコシステムを活用して BigQuery と統合したい開発者、BI ツール管理者、データエンジニア

🔄 Before / After

❌ Before (従来)

  • サードパーティ製 Simba JDBC ドライバーに依存
  • BigQuery ロード/エクスポート機能が未サポート
  • Google 製ドライバーは Preview 段階 (SLA なし)
  • 新機能への対応にタイムラグ

✅ After (今回のアップデート)

  • Google 製ドライバーが GA (SLA 保証)
  • Maven Central から簡単導入
  • Storage Read API で高速読み取り
  • オープンソースで透明性確保
  • 接続プーリング・バルクインサート対応

⚡ 主要機能

📐 標準 JDBC インターフェース準拠

✓DriverManager / DataSource による接続
✓PreparedStatement パラメータ化クエリ
✓ResultSet 標準データ取得
✓executeBatch バルクインサート

🔐 多様な認証方式

✓サービスアカウント (キーファイル)
✓Google ユーザーアカウント
✓Application Default Credentials
✓Workload Identity Federation
✓リフレッシュ/アクセストークン

🚀 高スループット読み取り

EnableHighThroughputAPI プロパティで有効化。Storage Read API を利用して大量データの読み取りパフォーマンスを大幅に向上。アクティベーション閾値のカスタマイズも可能。

📝 Storage Write API バルクインサート

EnableWriteAPI プロパティで有効化。executeBatch メソッドとの組み合わせで大量データの効率的な書き込みを実現。

🌐 オープンソース

Google が開発・メンテナンス。Maven Central で公開 (com.google.cloud:google-cloud-bigquery-jdbc)。Shaded Uber JAR も利用可能。

ステップ 1: 依存関係の追加

Maven

  <groupId>com.google.cloud</groupId>

  <version>0.3.0</version>
</dependency>
Gradle

    implementation("com.google.cloud:google-cloud-bigquery-jdbc:0.3.0")
}

ステップ 2: 接続の確立

Java 
import java.sql.Connection;
import java.sql.DriverManager;

private static Connection getConnection() {
    String url = "jdbc:bigquery://https://www.googleapis.com/bigquery/v2:443;"
        + "ProjectId=my-project;"
        + "OAuthType=3;"; // Application Default Credentials
    Connection connection = DriverManager.getConnection(url);
    return connection;
}
Java (DataSource) 
import com.google.cloud.bigquery.jdbc.DataSource;
import java.sql.Connection;

private static Connection getConnection() throws SQLException {
    DataSource ds = new DataSource();
    ds.setURL("jdbc:bigquery://https://www.googleapis.com/bigquery/v2:443;");
    ds.setAuthType(3); // Application Default Credentials
    ds.setProjectId("my-project");
    ds.setEnableHighThroughputAPI(true);
    return ds.getConnection();
}

ステップ 3: クエリの実行

Java 
import java.sql.ResultSet;
import java.sql.Statement;

Statement statement = connection.createStatement();
ResultSet resultSet = statement.executeQuery(
    "SELECT name, age FROM `my-project.my_dataset.my_table` LIMIT 100"
);

while (resultSet.next()) {
    String name = resultSet.getString("name");
    long age = resultSet.getLong("age");
    System.out.println(name + ": " + age);
}

💡 ユースケース

🔗 ユースケース 1: 既存 Java アプリケーションの BigQuery 統合

RDBMS を使用している既存の Java アプリケーションで、分析クエリを BigQuery に移行。既存の DAO レイヤーを大幅に書き換えることなく、BigQuery の分析能力を活用できる。

Java 
String bqUrl = "jdbc:bigquery://https://www.googleapis.com/bigquery/v2:443;"
    + "ProjectId=analytics-project;"
    + "OAuthType=3;"
    + "DefaultDataset=sales_data;";

Connection conn = DriverManager.getConnection(bqUrl);
PreparedStatement ps = conn.prepareStatement(
    "SELECT region, SUM(revenue) as total FROM sales WHERE date = ? GROUP BY region"
);
ps.setDate(1, java.sql.Date.valueOf("2026-06-01"));
ResultSet rs = ps.executeQuery();

📊 ユースケース 2: BI ツール・レポーティングツールとの接続

JDBC 接続をサポートする BI ツール (JasperReports、BIRT、DBeaver など) から BigQuery のデータにアクセス。JDBC ドライバーの JAR を追加するだけで、GUI ベースのクエリ作成やレポート生成が可能に。

📦 ユースケース 3: バルクデータ投入パイプライン

Java バッチ処理で大量のデータを BigQuery にロード。Storage Write API を活用し、数千件単位のバッチインサートを効率的に実行。

Java 
DataSource ds = new DataSource();
ds.setURL("jdbc:bigquery://https://www.googleapis.com/bigquery/v2:443;");
ds.setProjectId("etl-project");
ds.setAuthType(3);
ds.setEnableWriteAPI(true);

Connection conn = ds.getConnection();
PreparedStatement ps = conn.prepareStatement(
    "INSERT INTO `etl-project.warehouse.events` (event_id, timestamp, payload) VALUES (?, ?, ?)"
);

for (Event event : events) {
    ps.setString(1, event.getId());
    ps.setTimestamp(2, event.getTimestamp());
    ps.setString(3, event.getPayload());
    ps.addBatch();
}
ps.executeBatch();

💼 ビジネス面

✓標準準拠: java.sql で既存コード移行容易
✓柔軟な配布: Maven / Gradle / Uber JAR
✓豊富な認証: ADC, SA, WIF 対応

⚠️ デメリット・制約事項

制限事項:
  • BigQuery 専用ドライバー (他の Google Cloud サービスやデータベースには使用不可)
  • INTERVAL データ型は Storage Read API 使用時にサポートされない
  • BigQuery の DML に関するすべての制限事項が適用される
💡 考慮すべき点:
  • Simba ドライバーからの移行時は接続文字列フォーマットが異なるため設定変更が必要
  • High Throughput API 使用時は roles/bigquery.readSessionUser ロールが追加で必要
  • ドライバーのバージョン管理と依存関係の競合に注意

💰 料金情報

JDBC ドライバー自体は無料でダウンロード・使用可能。追加ライセンスも不要。ドライバーを通じた BigQuery の利用には標準の BigQuery 料金が適用される。

項目 料金体系
JDBC ドライバー無料
BigQuery クエリ (オンデマンド)$7.50 / TB (スキャンデータ量)
BigQuery Storage Read API$1.10 / TB (読み取りデータ量)
BigQuery ストレージ$0.02 / GB / 月 (アクティブ)

🔗 関連サービス

→BigQuery Storage Read API: High Throughput API として JDBC ドライバーから利用可能。大量データの読み取り高速化
→BigQuery Storage Write API: バルクインサート時に使用。大量書き込みのパフォーマンス向上
→Simba ODBC/JDBC ドライバー: 従来のサードパーティ製ドライバー。非 Java アプリでは引き続き ODBC を使用
→Cloud IAM: 認証・認可の基盤。サービスアカウント、Workload Identity Federation による安全なアクセス制御
