ドライバ バージョン 580.x.x が利用可能に

Cloud Run NVIDIA L4 GPU Feature AI 推論
📅 リリース日: 2026-08-11

📌 概要

Cloud Run の NVIDIA L4 GPU 向けに、NVIDIA ドライバ バージョン 580.x.x が利用可能になりました。サービス (services)、ジョブ (jobs)、ワーカープール (worker pools) の 3 つのリソースタイプすべてで利用できます。

Cloud Run の GPU はフルマネージドで提供され、ドライバやライブラリの追加インストールは不要です。ドライバ 580.x.x は CUDA 13.0 に対応する世代であり、L4 GPU でもより新しい CUDA 環境を前提とした LLM 推論、動画トランスコード、3D レンダリングなどの AI/計算集約型ワークロードを実行しやすくなります。

❌ Before (アップデート前の課題)

✗L4 GPU に提供されるドライバは 535.x.x (CUDA 12.2) のみで、より新しいドライバを選ぶ手段がなかった
✗CUDA 12.2 より新しい CUDA を使うには、フォワード互換パッケージ入りの NVIDIA ベースイメージに依存するか、手動インストールして LD_LIBRARY_PATH に追加する必要があった
✗新しい CUDA ツールキットを前提とするフレームワーク・ライブラリの利用にひと手間かかっていた

✅ After (アップデート後の改善)

✓L4 GPU で NVIDIA ドライバ 580.x.x が利用可能になり、新しいドライバ環境でワークロードを実行できる
✓サービス・ジョブ・ワーカープールの 3 リソースタイプすべてで一貫して利用可能
✓RTX PRO 6000 Blackwell GPU (580.x.x) とドライバ世代を統一でき、GPU タイプをまたぐコンテナイメージの共通化が容易に

🔧 主要機能

1️⃣ NVIDIA L4 GPU 向けドライバ 580.x.x の提供

→L4 GPU インスタンスで NVIDIA ドライバ バージョン 580.x.x が利用可能に
→ドライバ 580.x.x は CUDA 13.0 に対応する世代 (RTX PRO 6000 Blackwell GPU の「580.x.x (13.0)」という表記より)
→従来の L4 GPU のドライバは 535.x.x (CUDA 12.2)

2️⃣ 3 つのリソースタイプすべてで利用可能

→🌐 サービス: HTTP リクエスト駆動の推論エンドポイントなど
→⚙️ ジョブ: バッチ推論やモデルのファインチューニングなどのバッチ処理
→👷 ワーカープール: Pub/Sub などからのプル型処理を行う常駐ワーカー

3️⃣ フルマネージドなドライバ提供 (従来どおり)

→ドライバはプリインストールされ、利用者によるインストール作業は不要
→ドライバ ライブラリは /usr/local/nvidia/lib64 にマウントされ、LD_LIBRARY_PATH に自動的に追加される
→ドライバがプリインストールされた GPU インスタンスは約 5 秒で起動

1

L4 GPU 付きサービスのデプロイ

BashL4 GPU 付きサービスをデプロイ
gcloud run deploy SERVICE \
  --image IMAGE_URL \
  --cpu 8 \
  --memory 32Gi \
  --gpu 1 \
  --gpu-type nvidia-l4 \
  --region us-central1

ドライバは Cloud Run 側で管理されるため、コンテナイメージにドライバを含める必要はありません。

2

ジョブ / ワーカープールでの利用

Bashジョブとワーカープールでの GPU 指定
# ジョブの場合
gcloud run jobs update JOB_NAME --gpu 1 --gpu-type nvidia-l4

# ワーカープールの場合
gcloud run worker-pools update WORKER_POOL \
  --gpu 1 \
  --gpu-type nvidia-l4

ジョブとワーカープールでも同じ GPU タイプ指定 (nvidia-l4) で L4 GPU を利用できます。

3

ドライバ バージョンの確認

Bashコンテナ内で実行 (例: 起動スクリプトやジョブ内)
nvidia-smi

コンテナ内から nvidia-smi を実行すると、割り当てられたドライバ バージョンを確認できます。

⚠️ デメリット・制約事項

🚫 制限事項

✗L4 GPU は 1 インスタンスあたり 1 基のみ構成可能
✗L4 GPU の最小構成は 4 CPU / 16 GiB メモリ
✗GPU インスタンス数はサービスの最大インスタンス数設定と、プロジェクト・リージョンごとの GPU クォータの両方で制限される
✗L4 GPU の利用可能リージョンは限定されている (下記「利用可能リージョン」参照)

🤔 考慮すべき点

⚠️ ドキュメントの記載とのずれに注意: 公式ドキュメント (2026-08-12 時点) では L4 の「現行ドライバ バージョン」は 535.x.x (12.2) と記載されており、580.x.x はリリースノートで「利用可能」とアナウンスされた段階です。アプリケーションが特定のドライバ/CUDA バージョンに依存する場合は、nvidia-smi で実際に割り当てられたバージョンを確認してください。
!コンテナ内のコード (CUDA ツールキットやフレームワーク) は、提供されるドライバ バージョンと互換である必要がある。NVIDIA の互換性マトリクスで確認すること
!ワーカープールの GPU は自動スケーリングされず、プロセスが動作していなくてもインスタンス稼働中は GPU 課金が発生する

💰 料金

ドライバ バージョンの違いによる追加料金はなく、L4 GPU の利用料金は従来どおり GPU 秒単位で課金されます。GPU はインスタンスのライフサイクル全体にわたって課金されます。CPU・メモリの料金が別途発生します。
