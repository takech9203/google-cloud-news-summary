🗄️ AlloyDB for PostgreSQL
Advanced Query Insights の設定変更が再起動不要に

📅 リリース日: 2026-10-30 | PostgreSQL 18 以降と互換性のあるクラスタが対象
AlloyDB for PostgreSQL Advanced Query Insights Fixed

📌 概要

PostgreSQL 18 以降と互換性のある AlloyDB クラスタでは、 Advanced Query Insights (高度なクエリインサイト) の有効化や設定編集 (クエリ長の変更、アクティブクエリ分析の有効化など) を保存しても、 インスタンスの再起動が不要になりました。

Advanced Query Insights は、標準の Query Insights に加えて、待機イベント分析・アクティブクエリ分析・クエリプランのサンプリング・インデックスアドバイザーなどの高度な診断機能を提供します。 これまでは設定変更時に再起動が必要で、可観測性の向上とサービス継続性のトレードオフが発生していましたが、今回の修正によりダウンタイムなしで可観測性機能を調整できるようになりました。

❌ Before: アップデート前の課題

  • Advanced Query Insights の有効化・設定編集 (クエリ長の変更、アクティブクエリ分析の有効化など) の保存時にインスタンスの再起動が必要だった
  • 再起動に伴う接続断を避けるため、設定変更をメンテナンスウィンドウまで延期する運用が必要だった
  • パフォーマンス問題の発生中に可観測性機能を有効化したくても、再起動の影響を考慮して躊躇するケースがあった

✅ After: アップデート後の改善

  • PostgreSQL 18 以降のクラスタでは、有効化・設定編集が再起動なしで反映されるように
  • サービス稼働中に、ダウンタイムを気にせず可観測性設定を調整可能に
  • 障害調査の最中でも、アクティブクエリ分析などの診断機能を即座に有効化可能に
⚠️ 注意: PostgreSQL 17 以前と互換性のあるクラスタでは、引き続き設定変更の保存時にインスタンスの再起動が必要です。

PostgreSQL 17 以前のクラスタでは設定保存時に再起動 (接続断) が発生しますが、PostgreSQL 18 以降のクラスタでは設定が再起動なしで即時反映されます。

⚡ 主要機能 (PostgreSQL 18 以降)

1️⃣ 再起動不要での Advanced Query Insights の有効化

→Google Cloud コンソールの「クエリ分析情報 (Query insights)」から「Enable advanced query insights features for AlloyDB」を選択して保存しても再起動は不要
→有効化時のデフォルト動作として、待機イベント分析とアクティブクエリ分析がオンになり、クエリ長が 4500 バイト → 100000 バイトに引き上げ

2️⃣ 再起動不要でのクエリ長の変更

→コンソールではクエリ長を 256 バイト〜最大 100 KB まで変更可能 (gcloud では 1024〜100000 バイト、デフォルト 10240 バイト)
→従来はクエリ長の変更に再起動が必要だったが、PostgreSQL 18 以降では不要に

3️⃣ 再起動不要でのアクティブクエリ分析の有効化

→実行中のクエリをトランザクション開始時刻順に Query Insights ページで監視可能
→実行時間の長い上位 50 件のトランザクションの表示や、クエリ・トランザクションの終了 (terminate) 操作に対応

🛠️ 設定方法

✅ 前提条件

✓Google Cloud プロジェクトで AlloyDB for PostgreSQL へのアクセスが有効であること
✓再起動不要の恩恵を受けるには、クラスタが PostgreSQL 18 以降と互換性があること
✓設定編集に必要な IAM 権限 (AlloyDB インスタンスの更新権限) を持っていること

(PG 18+ は再起動不要)
💡 ポイント: 「Enable advanced query insights features for AlloyDB」チェックボックスを選択し、必要に応じて「Active query analysis」やクエリ長を設定します。PostgreSQL 18 以降は再起動不要。PostgreSQL 17 以前では「Confirm and restart」の確認が表示されます。

⌨️ ステップ 2: gcloud CLI で設定する場合

Bash gcloud で Advanced Query Insights を有効化 
gcloud alloydb instances update INSTANCE \
  --cluster=CLUSTER \
  --project=PROJECT \
  --region=REGION \
  --observability-config-enabled \
  --observability-config-track-active-queries \
  --observability-config-max-query-string-length=QUERY_LENGTH

--observability-config-enabled で Advanced Query Insights を有効化し、--observability-config-track-active-queries でアクティブクエリの追跡を有効化します。QUERY_LENGTH は 1024〜100000 バイトの範囲で指定します (デフォルト 10240 バイト)。

📄 ステップ 3: Terraform で設定する場合

HCL Terraform での observability_config 設定 
observability_config {
  enabled = true
}

Terraform では observability_config ブロックの enabled フィールドを true に設定します。

🎯 メリット

💼 ビジネス面

✓ダウンタイムの排除: PostgreSQL 18 以降では可観測性設定の変更にメンテナンスウィンドウの調整が不要になり、運用負荷が低減
✓迅速なトラブルシューティング: 本番環境で問題が発生した際、再起動の影響を懸念することなく診断機能を即座に有効化できる

⚙️ 技術面

✓可観測性の段階的な調整: クエリ長やアクティブクエリ分析などの設定を、稼働中のワークロードに影響を与えずに試行・調整できる
✓アクティブクエリ監視の即時利用: 有効化後すぐに、実行時間の長い上位 50 件のトランザクションの監視や接続の終了操作が可能

⚠️ デメリット・制約事項

🚧 制限事項

✗PostgreSQL 17 以前と互換性のあるクラスタでは、引き続き設定変更の保存時にインスタンスの再起動が必要
✗アクティブクエリの表示は、実行中のクエリが多い場合、データ収集のメモリ上限により一部のみ表示されることがある

🤔 考慮すべき点

  • クエリ長を長くすると、より多くのメモリが必要になる
  • クエリプランのサンプリングレートを上げるとデータポイントは増えるが、パフォーマンスに悪影響を与える可能性がある
  • Advanced Query Insights 有効化によるデータ保存量の増加は、追加料金が発生する可能性がある
  • クエリコメントの保存を有効にする場合、コメントに機密情報が含まれるならユーザーアクセスに注意が必要

💡 ユースケース

🚨 ユースケース 1: 本番障害発生中のアクティブクエリ分析の即時有効化

シナリオ: 本番の AlloyDB (PostgreSQL 18) でレイテンシの急上昇が発生。原因特定のためにアクティブクエリ分析を有効化したいが、従来は再起動が必要なため躊躇していた。

Bash 障害調査中にアクティブクエリ分析を即時有効化 
gcloud alloydb instances update prod-instance \
  --cluster=prod-cluster \
  --project=my-project \
  --region=us-central1 \
  --observability-config-enabled \
  --observability-config-track-active-queries
✅ 効果: 再起動なしで即座にアクティブクエリ分析が有効になり、実行時間の長いトランザクションを特定して、必要に応じて問題のある接続を終了できる。

📈 ユースケース 2: 分析ワークロード向けのクエリ長の拡大

シナリオ: 長大な分析クエリを実行する環境で、デフォルトのクエリ長では SQL 全文が確認できない。PostgreSQL 18 のクラスタでクエリ長を 100 KB に拡大したい。

✅ 効果: 再起動によるサービス影響なしにクエリ長を変更でき、長い分析クエリの全文とクエリプランを確認して性能問題の根本原因を特定できる。

💰 料金

本アップデート (再起動不要化) 自体に追加料金はありません。 ただし、Advanced Query Insights の有効化によりデータ保存量が増加した場合、追加料金が発生する可能性があります。詳細は料金ページを参照してください。
