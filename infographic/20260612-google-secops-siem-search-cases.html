📋 概要

Google SecOps の SIEM Search に、ケースおよびケース履歴の検索機能が正式に追加されました。セキュリティアナリストは単一の SIEM Search インターフェースから UDM イベント、エンティティ、ケース、ケース履歴を横断的に検索できるようになります。

SIEM（Security Information and Event Management）と SOAR（Security Orchestration, Automation, and Response）のデータを統合的に検索・相関分析することで、インシデント対応のワークフローが大幅に効率化されます。

Before / After

❌ Before (従来)

  • SIEM Search は UDM イベントとアラートの検索に限定
  • ケースデータへのアクセスには SOAR Search や別のケース管理画面への切り替えが必要
  • 複数ツール間でコンテキストスイッチが頻繁に発生
  • 異なるインターフェースからの情報を手動で突き合わせる必要あり

✅ After (新機能)

  • 単一の SIEM Search から UDM、エンティティ、ケース、ケース履歴を統合検索
  • ケース詳細とセキュリティデータを直接相関可能
  • コンテキストスイッチ削減でインシデント対応加速
  • YARA-L 2.0 構文で高度なクエリ・統計分析・エクスポートに対応

クエリ例

YARA-L 2.0 
# オープン中のケースを検索
case.status = "OPENED"

# 特定のアクティビティタイプを含むケースを検索
case.wall_activities.activity_type = "CASE_ALERT_DATA"

# アラートとエンティティが関連付けられたケースを検索
case.alerts.metadata.id != "" AND case.alerts.entities.name != ""

# ケース履歴で優先度変更を検索
case_history.case_activity = "PRIORITY_CHANGE" AND case_history.assignee.name != ""

# ケース履歴で情報優先度のエントリを検索
case_history.priority = "PRIORITY_INFO"

⚠️ 制限事項

制限項目 詳細
アラート・壁アクティビティ・タスク ケース検索結果からケースページへピボット後のみ表示可能
ケース管理操作 Search インターフェース内での編集・変更は不可 (読み取り専用)
クロスリソース結合 ケースとケース履歴間、または同一リソースタイプ内の結合は非対応
活動ヒートマップ ケースおよびケース履歴検索では利用不可
カスタムフィールド ケースおよびケース履歴検索では非対応
💡 考慮すべき点:
  • カスタムフィールドに依存したワークフローには影響がある
  • ケース ID で直接アクセスする場合は従来の方法を併用する必要がある
  • Prevalence (普及率) や活動ヒートマップはケース検索結果では利用不可

🎯 ユースケース

🚨 ユースケース 1: トリアージとケース優先度付け

シナリオ: SOC チームが大量のオープンケースの中から重要度の高いインシデントを迅速に特定し、対応優先順位を決定する。

YARA-L 2.0 
# 特定のアラートとエンティティが関連付けられたオープンケースを検索
case.status = "OPENED" AND case.alerts.metadata.id != "" AND case.alerts.entities.name != ""

効果: ステータス、アクティビティ、関連アラートに基づいてケースを効率的に特定・優先付け。最も重要なインシデントに即座にフォーカスできる。

🕵️ ユースケース 2: エンティティのタイムライン調査

シナリオ: 特定のユーザーアカウントに関連する不審なアクティビティが検出され、そのエンティティに関連するケース履歴とセキュリティイベントを時系列で追跡する。

YARA-L 2.0 
# 特定のアサイニーに関連するケース履歴の優先度変更を追跡
case_history.case_activity = "PRIORITY_CHANGE" AND case_history.assignee.name != ""

効果: ケースデータとセキュリティテレメトリの相関で、インシデントの包括的なタイムラインを構築し、深い洞察に基づいた判断が可能になる。

📉 ユースケース 3: ケースデータの統計分析とレポーティング

シナリオ: セキュリティマネージャーが特定期間のケース傾向を分析し、SOC チームのパフォーマンス指標やインシデント傾向レポートを作成する。
