☁️ Cloud SDK: gcloud CLI 594.0.1
パッチリリース (General bug fixes)

Cloud SDK (Google Cloud CLI) GA パッチリリース
📅 リリース日: 2026-11-21

📋 概要

2026 年 11 月 21 日、Google Cloud CLI (gcloud) バージョン 594.0.1 がリリースされた。 公式リリースノートの記載は 「General bug fixes (一般的なバグ修正)」のみで、 新機能の追加や Breaking Changes は含まれていないパッチリリースである。修正されたバグの具体的な内容は公表されていない。

本リリースは、2026 年 11 月 17 日の 594.0.0 に続くパッチである。594.0.0 には gcloud auth、gcloud billing accounts、gcloud compute shared-vpc の各コマンド群におけるフラグと位置引数の優先順位に関する 3 件の Breaking Changes が含まれていた。 594.0.1 にはこれらを元に戻す記載はないため、594.0.0 の動作変更はそのまま有効である。

シナリオ: 594.0.0 の Breaking Changes の影響調査のためにアップグレードを保留していた CI/CD 環境やローカル環境で、バグ修正済みの 594.0.1 を適用する。

Bash影響確認 + アップデートの実装例
# 影響を受けるコマンドパターンをスクリプトから検索 (594.0.0 の Breaking Changes 対応)
grep -rnE "gcloud (auth (print-access-token|print-identity-token|login|application-default login|activate-service-account)|billing accounts (get-iam-policy|set-iam-policy|add-iam-policy-binding|remove-iam-policy-binding)|compute shared-vpc)" .

# 問題がなければ 594.0.1 へ更新
gcloud components update

効果: Breaking Changes の影響確認と、バグ修正済みパッチの適用を 1 回のアップグレードで完了できる。
