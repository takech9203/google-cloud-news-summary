🛡️ Google SecOps Public Preview

⚙️ Consolidated Settings and Navigation
統合された設定メニューと新しい左ナビゲーション

📅 リリース日: 2026-11-04

📋 概要

Google SecOps (旧 Chronicle) で、これまで別々に存在していた SIEM Settings と SOAR Settings が単一の「Settings」メニューに統合され、Public Preview として提供開始。設定項目は 5 つの機能カテゴリに再編され、プラットフォーム左側のナビゲーションメニューも刷新されます。

SIEM (Chronicle SIEM) と SOAR (旧 Siemplify) の製品統合の経緯から生じていた「2 つの製品の寄せ集め」感を解消し、機能ベース (何をしたいか) で設定を探せる一貫した管理体験を実現。権限制御も強化され、各設定ページは必要な権限を持つユーザーにのみ表示されます。

🛠️ Administration 🔐 Access Management 🔍 Investigation 🚨 Detection 🗄️ Data Management

❌ Before: 分離された設定メニュー

  • SIEM 系設定 (フィード、フォワーダー、パーサー、データ保持など) と SOAR 系設定 (ケースステージ、環境、SOC ロールなど) が 別々のメニューに分散
  • 目的の設定がどちらのメニューにあるかを覚えておく必要があった
  • 製品 (SIEM / SOAR) 単位の分類のため、業務目的ベースで設定を横断的に探すのが困難
  • Cloud IAM Viewer / Editor は SOAR 設定ページを参照できず、確認にも管理者相当の関与が必要なケースがあった

✅ After: 統合された Settings メニュー

  • 単一の「Settings」メニューに統合され、5 カテゴリから機能ベースで設定を探せる
  • 左ナビゲーションも刷新され、Your Workdesk、Cases、Investigation、Detection、Automation などの業務フローに沿った構造に
  • 各設定ページは必要な権限を持つユーザーにのみ表示 (権限に応じた出し分け)
  • Cloud IAM Viewer / Editor が一部の SOAR 設定ページを読み取り専用モードで閲覧可能に

従来は SIEM と SOAR で分かれていた設定メニューが単一の Settings メニューに統合され、5 つの機能カテゴリに再編されます。各設定ページは権限を持つユーザーにのみ表示されます。

🚀 主要機能

1️⃣ 設定メニューの統合 (SIEM Settings + SOAR Settings → Settings)

→従来の「SIEM Settings」と「SOAR Settings」が廃止され、単一の「Settings」メニューに一本化
→製品単位ではなく機能・業務目的単位の 5 カテゴリに再分類: Administration / Access Management / Investigation / Detection / Data Management

2️⃣ 左ナビゲーションメニューの刷新

→業務フローに沿った構造に整理: Your Workdesk、Cases、Investigation (SIEM Search / SOAR Search / Data Tables)、Detection (Rules & Detections / Alerts & IoCs / Emerging Threats / Risk Analytics / Reference Lists)、Automation (Playbooks / Integrations Setup / Jobs Scheduler / IDE)、Dashboards & Reports、Content Hub

3️⃣ 権限ベースの設定ページ表示

→各設定ページは、該当ページの操作に必要な権限を持つユーザーにのみ表示
→不要な設定項目が見えなくなることで、誤操作リスクの低減と UI のシンプル化を両立

4️⃣ Cloud IAM Viewer / Editor の読み取り専用アクセス

→Cloud IAM の Viewer / Editor 権限を持つユーザーが、一部の SOAR 設定ページを読み取り専用モードで閲覧可能に
→設定内容の確認・監査目的のアクセスに、管理者権限の付与が不要に

5️⃣ ドキュメントの更新

→公式ドキュメントが新しいナビゲーションパスを反映して更新済み
→新ナビゲーションでの各機能の場所は「Navigate the Google SecOps platform」ページに一覧表として整理

📝 手順詳細

  1. Public Preview Features ページを開く: 本機能はオプトイン方式の Public Preview。未オプトインの場合は SIEM Settings > Public Preview から開く (オプトイン後は Settings > Administration > Public Preview に配置)
  2. 機能を有効化する: 対象機能 (Consolidated Settings and Navigation) の行で「Preview Status」トグルをオンにし、確認ダイアログで「Enable」をクリック
💡 ヒント: 有効化後に問題があった場合、管理者はトグルをオフにして即座に無効化し、フィードバックを提供できます。
⚠️ 注意: FedRAMP や HIPAA などのコンプライアンス管理対象テナントでは、Public Preview Features ページでの機能のオン / オフ切り替えは利用できず、Google SecOps サポートへの依頼が必要です。

💡 メリット

💼 ビジネス面

✓運用効率の向上: 業務目的ベースの 5 カテゴリ整理により、目的の設定への到達時間が短縮され、SOC 運用のオーバーヘッドが削減
✓オンボーディングの容易化: SIEM と SOAR の製品史を知らなくても設定を探せるため、新任の管理者・アナリストの学習コストが低下
✓監査・ガバナンスの強化: Cloud IAM Viewer / Editor による読み取り専用アクセスで、監査担当者に過剰な権限を付与せずに設定内容を確認してもらえる

⚙️ 技術面

✓権限ベースの UI 出し分け: 必要な権限を持つユーザーにのみ設定ページが表示され、最小権限の原則に沿った運用がしやすい
✓SIEM / SOAR の統合体験: 単一プラットフォームとしての一貫したナビゲーションで、SIEM 検索から SOAR ケース管理までの画面遷移が自然に
✓ドキュメントとの整合: 公式ドキュメントが新ナビゲーションに合わせて更新済みで、手順書と実画面の乖離が生じにくい

⚠️ デメリット・制約事項

🚧 制限事項

✗Public Preview 段階の機能であり、Pre-GA Offerings Terms が適用される (サポートが限定的な場合や、GA までに変更が入る可能性がある)
✗コンプライアンス管理対象テナント (FedRAMP、HIPAA など) では、セルフサービスでの有効化が不可。サポート経由での対応が必要

🤔 考慮すべき点

✗既存の社内手順書・Runbook・トレーニング資料の記載 (「SIEM Settings > ...」「SOAR Settings > ...」) を新パスに更新する必要がある
✗オプトイン方式のため、チーム内で有効化のタイミングを調整しないと、ユーザーごとに見えている画面構造が異なり混乱を招く可能性
✗権限ベースの表示制御により、従来見えていた設定ページが見えなくなるユーザーが発生し得るため、ロール設計の確認が推奨

🎯 ユースケース

📥 ユースケース 1: SOC 管理者による設定作業の効率化

シナリオ: SIEM のフィード設定と SOAR のコネクタ設定を両方管理している SOC 管理者が、データ取り込みに関する設定を一括で見直したい。

新しい配置 
Settings > Data Management 配下で完結:
- Feeds (SIEM フィード)
- Forwarders (SIEM フォワーダー)
- Parsers (パーサー管理)
- Connectors (SOAR コネクタ)
- SOAR Webhooks (SOAR Webhook)
- Data Export (BigQuery エクスポート)
✅ 効果: 従来は SIEM Settings と SOAR Settings を行き来する必要があったデータ取り込み関連の設定が、Data Management カテゴリに集約され、一箇所で確認・変更できる。

🔍 ユースケース 2: 監査担当者への読み取り専用アクセス付与

シナリオ: 内部監査チームが SOAR の SLA 設定やアクセス管理設定の内容を定期的に確認する必要があるが、変更権限は付与したくない。

✅ 効果: Cloud IAM の Viewer 権限を付与するだけで、監査担当者は対象の SOAR 設定ページを読み取り専用モードで閲覧でき、管理者が画面キャプチャを提供するなどの手間が不要になる。

🔗 関連サービス・機能

🔐 Cloud IAM

Viewer / Editor ロールによる SOAR 設定ページの読み取り専用閲覧が可能に。Google SecOps の機能アクセス制御の基盤。

📊 Google SecOps SIEM

フィード、パーサー、データ保持などの SIEM 設定が新しい Settings メニューの Data Management / Administration カテゴリに再配置。

🤖 Google SecOps SOAR

ケースステージ、環境、SOC ロール、コネクタなどの SOAR 設定が機能ベースのカテゴリに再配置。

🗄️ BigQuery

Settings > Data Management > Data Export から Google SecOps データの BigQuery エクスポートを設定可能。

✨ Gemini (Agentic SOC)

Settings > Investigation > Gemini Investigations からセキュリティトークンや Triage and Investigation エージェントを管理。

📌 まとめ

Google SecOps の設定メニューと左ナビゲーションが統合され、SIEM / SOAR という製品の区分ではなく業務目的ベースで設定を探せるようになる、プラットフォーム統合の節目となるアップデートです。

Public Preview のオプトイン方式のため、まずは検証環境や合意の取れたチームで有効化し、社内手順書のナビゲーションパス更新とロール設計の確認を進めることを推奨します。
