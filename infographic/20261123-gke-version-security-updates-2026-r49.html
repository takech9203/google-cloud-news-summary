🚢 GKE 2026-R49 バージョン & セキュリティアップデート

各リリースチャネルへの新パッチ提供と Container-Optimized OS の累積セキュリティ修正
📅 リリース日: 2026-11-23

📋 概要

GKE 2026-R49 リリースとして、Rapid / Regular / Extended / No channel の各リリースチャネルに新しいクラスタバージョンが提供された。 Rapid チャネルには 1.34.13 〜 1.37.2 の 4 つのマイナーバージョン系列の最新パッチが追加され、Alpha クラスタ向けには 1.38.0-gke.5273000+preview が新たに利用可能になった (旧ビルド 1.38.0-gke.4162000+preview は提供終了)。 なお、Stable チャネルへの新規リリースはない。

セキュリティ面では、更新された Container-Optimized OS (COS) イメージを使用する新しい GKE バージョンが含まれる。 更新イメージは累積的であり、前回の GKE リリース以降に公開されたすべての COS セキュリティ修正を取り込んでいる。 対象は GKE 1.32.13 〜 1.38.0+preview で、COS 121 / 125 / 129 / dev-138 の各系列が更新されている。

❌ Before (アップデート前の課題)

  • 以前の GKE ノードが使用する COS イメージには、前回リリース以降に公開されたセキュリティ修正が未適用
  • Rapid チャネルで 1.34.13 / 1.35.10 / 1.36.6 / 1.37.2 系の最新パッチが利用不可
  • Alpha クラスタでの Kubernetes 1.38 系検証は旧ビルド (1.38.0-gke.4162000+preview) に依存

✅ After (アップデート後の改善)

  • 更新 COS イメージ (cos-121 / cos-125 / cos-129 / cos-dev-138) により累積的なセキュリティ修正を適用可能に
  • Rapid / Regular / Extended / No channel で新パッチが利用可能になり、クラスタ作成・アップグレードの選択肢が拡大
  • Alpha 1.38.0-gke.5273000+preview により次期マイナーバージョンを最新ビルドで早期検証可能
💡 ポイント: 本アップデートは GKE を利用するすべてのユーザーに影響する定期バージョンアップデート。特に COS セキュリティ修正を取り込むためのノードアップグレードは、すべての本番環境クラスタで推奨される。

ステップ 1: 利用可能なバージョンを確認

Bash 各チャネルの利用可能バージョンを確認 
# 各チャネルで利用可能なバージョンとデフォルトバージョンを確認
gcloud container get-server-config \
  --zone=asia-northeast1-a \
  --format="yaml(channels)"

ロールアウトはリリースノート公開時点で進行中のため、ゾーンによってはまだ新バージョンが表示されない場合がある。

ステップ 2: クラスタのコントロールプレーンをアップグレード

Bash コントロールプレーンのアップグレード 
# コントロールプレーンを指定バージョンにアップグレード
gcloud container clusters upgrade my-cluster \
  --zone=asia-northeast1-a \
  --master \
  --cluster-version=1.36.5-gke.2262000

コントロールプレーンのアップグレードは数分から数十分かかる。アップグレード中もワークロードは引き続き実行される。

ステップ 3: ノードプールをアップグレード (COS セキュリティ修正の適用)

Bash ノードプールのアップグレード 
# ノードプールを指定バージョンにアップグレード
gcloud container clusters upgrade my-cluster \
  --zone=asia-northeast1-a \
  --node-pool=default-pool \
  --cluster-version=1.36.5-gke.2262000
✅ 重要: COS イメージのセキュリティ修正はノードのアップグレードによって適用される。サージアップグレード方式で実行され、ワークロードの可用性が維持される。

⚖️ メリットと制約事項

👍 メリット

💼 ビジネス面

✓セキュリティリスクの低減: 累積的な COS セキュリティ修正により既知の脆弱性リスクが軽減。コンプライアンス要件の充足にも重要
✓運用の安定性向上: 各チャネルで検証済みのパッチバージョンが提供され、安定した運用が可能

🔧 技術面

✓最新 Kubernetes パッチへのアクセス: Rapid で 1.37.2 までの最新パッチを早期検証可能
✓次期バージョンの早期検証: Alpha 1.38.0-gke.5273000+preview で 1.38 系の新機能を評価可能
✓長期サポート環境への修正提供: Extended の 1.32.13 / 1.33.13 で古いバージョン環境にも修正が届く

⚠️ デメリット・制約事項

🚧 制限事項

✗ロールアウトは進行中で、全ゾーンで利用可能になるまで数日かかる場合がある
✗Stable チャネルは今回新規リリースがなく、新パッチを取得できない
✗Alpha (1.38.0+preview) は Alpha クラスタ専用で本番環境には使用不可。旧 Alpha ビルドは提供終了
✗No channel は非推奨 (deprecated)

🤔 考慮すべき点

!COS セキュリティ修正はノードイメージに含まれるためノードプールのアップグレードが必要。コントロールプレーンのみでは適用されない
!解消された CVE は対応する COS イメージのセキュリティリリースノートで確認が必要
!コントロールプレーンとノードのバージョンスキューは許容範囲内に保つことを推奨
!メンテナンスウィンドウ/除外の設定により自動アップグレードのタイミングが影響を受ける

🎯 ユースケース

1️⃣ 本番環境へのセキュリティパッチ適用

シナリオ: Regular チャネルを使用している本番クラスタで、更新された COS イメージのセキュリティ修正を早期に適用したい。

Bash Regular チャネル本番クラスタのアップグレード 
# 現在のクラスタバージョンを確認
gcloud container clusters describe my-prod-cluster \
  --zone=asia-northeast1-a \
  --format="value(currentMasterVersion,currentNodeVersion)"

# Regular チャネルの新パッチバージョンにコントロールプレーンをアップグレード
gcloud container clusters upgrade my-prod-cluster \
  --zone=asia-northeast1-a \
  --master \
  --cluster-version=1.35.9-gke.1673000

# ノードプールもアップグレードして COS セキュリティ修正を適用
gcloud container clusters upgrade my-prod-cluster \
  --zone=asia-northeast1-a \
  --node-pool=default-pool

効果: 更新された COS イメージの累積セキュリティ修正が適用され、既知の脆弱性に対するリスクが解消される。

2️⃣ Kubernetes 1.37 / 1.38 の早期検証

シナリオ: 開発環境で Kubernetes 1.37 系の最新パッチや 1.38 系の新機能を検証し、本番環境への移行計画を立てたい。

Bash 検証用クラスタの作成 
# Rapid チャネルで 1.37.2 のクラスタを新規作成
gcloud container clusters create dev-cluster-137 \
  --zone=asia-northeast1-a \
  --release-channel=rapid \
  --cluster-version=1.37.2-gke.1606000 \
  --num-nodes=3

# Alpha クラスタで 1.38.0+preview を検証 (本番利用不可)
gcloud container clusters create alpha-cluster-138 \
  --zone=asia-northeast1-a \
  --enable-kubernetes-alpha \
  --cluster-version=1.38.0-gke.5273000+preview \
  --num-nodes=3

効果: 最新の Kubernetes バージョンを早期に評価でき、本番環境への移行に向けた互換性テストを実施できる。

3️⃣ Extended チャネル環境のセキュリティ維持

シナリオ: アプリケーションの互換性要件により 1.32 / 1.33 系を継続利用している環境で、セキュリティ修正を取り込みたい。

効果: Extended チャネルの 1.32.13-gke.3169000 / 1.33.13-gke.2480000 (cos-121-18867-652-49 使用) へのアップグレードにより、古いマイナーバージョンのまま最新のセキュリティ修正を適用できる。

💰 料金

GKE の料金はクラスタモード (Autopilot / Standard) によって異なる。バージョンアップデート自体に追加料金は発生しない。

🔗 関連サービス・機能

🖥️ Container-Optimized OS: GKE ノードで使用される OS イメージ。セキュリティ修正は COS イメージの更新として提供される
📡 GKE リリースチャネル: Rapid / Regular / Stable / Extended の各チャネルにより、安定性と新機能提供のバランスを選択できる

📝 まとめ

GKE 2026-R49 は、Rapid / Regular / Extended / No channel への新パッチバージョン提供と、COS イメージ (cos-121 / cos-125 / cos-129 / cos-dev-138) の累積セキュリティ修正を含む定期アップデートである。

✅ 推奨アクション: セキュリティ修正はノードアップグレードによって適用されるため、コントロールプレーンだけでなくノードプールの計画的なアップグレードが重要。各チャネルの特性と自組織の運用要件を踏まえ、早期のパッチ適用を推奨する。
