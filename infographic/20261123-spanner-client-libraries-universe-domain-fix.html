📝 概要

Spanner の Python クライアントライブラリ google-cloud-spanner 3.72.1 と Go クライアントライブラリ cloud.google.com/go/spanner v1.96.2 が 2026 年 11 月 22 日にリリースされ、11 月 23 日付の Google Cloud Release Notes に掲載されました。 いずれも新機能を含まない小規模なバグ修正リリースで、修正内容は共通して 組み込みメトリクスのエクスポーターが universe domain などのクライアント設定を尊重する ことです。

Spanner クライアントライブラリには、RPC のレイテンシなどを自動的に Cloud Monitoring にエクスポートする 組み込みのクライアントサイドメトリクス機能があります (Go 1.71.0 以降、Python 3.60.0 以降)。 一方、Google Cloud には標準の googleapis.com とは別の「ユニバース」 (独立した自己完結型クラウド環境。universe domain で識別) が存在します。 今回の修正により、標準以外の universe domain やカスタムの client_options を設定しているクライアントでも、 メトリクスエクスポーターがその設定に従って動作するようになりました。

❌ Before: アップデート前の課題
  • Python: メトリクスエクスポーターが、Spanner クライアントに設定した universe_domain と client_options を尊重していなかった
  • Go: メトリクスエクスポーターが、設定した universe domain (GOOGLE_CLOUD_UNIVERSE_DOMAIN) を尊重していなかった
  • 標準以外のユニバースで利用する場合、メトリクスエクスポートがクライアント本体と異なる設定で動作する可能性があった
✅ After: アップデート後の改善
  • Python 3.72.1: エクスポーターが universe_domain と client_options を尊重 (#19172)
  • Go v1.96.2: エクスポーターが universe domain (GOOGLE_CLOUD_UNIVERSE_DOMAIN) を尊重 (#20953 / #20956)
  • universe domain 利用環境でも、データアクセスとメトリクスエクスポートが一貫した設定で動作
💡 ポイント: 標準の Google Cloud (googleapis.com) のみを利用しているユーザーへの影響は限定的ですが、 universe domain を設定して利用している環境や、client_options でエンドポイント等をカスタマイズしている Python ユーザーにとっては重要な修正です。

背景: 組み込みクライアントサイドメトリクスと universe domain

📊 クライアントサイドメトリクス

Spanner クライアントライブラリは、リクエストがアプリケーションを出てからレスポンスを受け取るまでのレイテンシ情報 (operation_latencies、attempt_latencies、GFE/AFE レイテンシなど) を spanner.googleapis.com/client/* という名前空間で Cloud Monitoring に自動エクスポートします。 Go は 1.71.0 以降、Python は 3.60.0 以降でサポートされています。

🌐 ユニバース (universe)

Google Cloud のリソース階層の最上位概念で、独自のネットワークを持つ自己完結型クラウドです。 標準の Google Cloud に加え、同じ技術を基盤としつつ単一の管轄区域内・パートナー運営のデータセンターで稼働するユニバース (Google Cloud Dedicated プログラム) が存在し、強力なデータ主権・運用主権の保証を提供します。 クライアントライブラリでは universe domain の設定によって接続先ユニバースを切り替えます。

組み込みメトリクスの前提条件とオプトアウト

組み込みメトリクスの利用には Cloud Monitoring API の有効化と、サービスアカウントへの Monitoring Metric Writer (roles/monitoring.metricWriter) ロールの付与が必要です。 OpenTelemetry で独自にメトリクスを収集している場合などは、以下のようにオプトアウトできます。

Python 
# Python
spanner_client = spanner.Client(disable_builtin_metrics=True)
Go 
// Go
client, err := spanner.NewClientWithConfig(ctx, database, spanner.ClientConfig{
    DisableNativeMetrics: true,
})

⚠️ デメリット・制約事項

考慮すべき点
•バグ修正のみのリリースであり、新機能は含まれない
•標準の Google Cloud (googleapis.com) のみを既定設定で利用している場合、実質的な挙動の変化はほぼない
