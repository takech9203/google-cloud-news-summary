🎥 Gemini Enterprise: 動画生成が Omni 1.2 Flash にアップグレード

Gemini Enterprise GA (一般提供) Veo 3.1 を置き換え
リリース日: 2026-11-06

📋 概要

Gemini Enterprise の Web アプリにおける動画生成機能のバックエンドモデルが Gemini Omni 1.2 Flash (GA) にアップグレードされました。 global リージョンでの動画生成において Veo 3.1 を置き換え、 映像の明瞭さ (clarity) と指示追従性 (instruction following) が向上しています。

利用には管理者が Web アプリの機能管理設定で 「Enable video generation」 をオンにする必要があります。 有効化後、エンドユーザーはチャットボックスの Tools > Create videos から自然言語プロンプトで短い動画を生成し、 フォローアッププロンプトで結果を改善できます。

❌ Before (アップデート前の課題)

  • 動画生成のバックエンドは Veo 3.1 を使用
  • 動画生成専用モデルの Veo 3.1 は、映像の明瞭さと複雑な指示への追従に改善の余地があった

✅ After (アップデート後の改善)

  • global リージョンのバックエンドが GA モデルの Gemini Omni 1.2 Flash に置き換え
  • 映像の明瞭さ (clarity) が向上
  • 指示追従性 (instruction following) が向上し、意図した動画を得やすく
  • ユーザー操作 (Tools > Create videos) は変わらず、設定済みならそのまま新モデルの恩恵を享受
🤖 対象読者: Gemini Enterprise を全社導入している企業の管理者 (機能の有効化判断) と、 プレゼン資料・社内コミュニケーション・マーケティング素材などで動画生成を活用するエンドユーザー。 Gemini Omni 1.2 Flash モデル自体の GA (Agent Platform の Interactions API 経由での利用) は別レポート参照。

Gemini Enterprise Web アプリの動画生成バックエンドが Veo 3.1 から Gemini Omni 1.2 Flash に置き換わりました。 管理者が機能を有効化すると、ユーザーはチャットから動画を生成し、Library で閲覧・検索・ダウンロードできます。

⚡ 主要機能

🔄 1. 動画生成モデルの Omni 1.2 Flash への置き換え

global リージョンの動画生成において、Gemini Omni 1.2 Flash (GA) が Veo 3.1 を置き換え。 映像の明瞭さ (clarity) と指示追従性 (instruction following) が向上。

💬 2. チャットからの動画生成 (Tools > Create videos)

チャットボックスの「Tools > Create videos」を選択し、生成したい動画を自然言語で記述してプロンプトを送信。 アシスタントの応答後、フォローアッププロンプトで結果を改善 (refine) できる。

📚 3. Library での生成コンテンツ管理

過去のチャットで生成した画像・動画を Library で一覧表示し、「Images」「Videos」でフィルタリング可能。 生成元のチャットを開く、ダウンロードするなどの操作が可能。 自然言語で生成済みコンテンツを検索できる (検索結果は最大 10 件の画像・動画を表示)。

🔐 4. 管理者による機能制御 (Enable video generation)

動画生成の利用には、管理者が Web アプリの Feature Management で「Enable video generation」をオンにする必要がある。 有効化すると、ユーザーは Web アプリで動画を生成できるようになる。

🛠️ 設定方法

前提条件

✓Gemini Enterprise Admin IAM ロール (roles/discoveryengine.agentspaceAdmin)
✓既存の Gemini Enterprise Web アプリ

ステップ 1: 管理者が動画生成を有効化する

  1. Google Cloud コンソールで Gemini Enterprise ページに移動
  2. 設定するアプリの名前をクリック
  3. Configurations > Feature Management タブをクリック
  4. Enable video generation をオンにする

ステップ 2: ユーザーが動画を生成する

  1. Gemini Enterprise Web アプリのチャットボックスで Tools > Create videos をクリック
  2. 作成したい動画の内容を記述してプロンプトを送信
  3. 応答を受け取った後、フォローアッププロンプトで結果を改善
  4. 生成した動画は Library から閲覧・検索・ダウンロード

✓GA モデルへの移行: バックエンドが GA の Gemini Omni 1.2 Flash となり、Google の最新オムニモーダルモデルの改善 (明瞭さ・指示追従性) を Web アプリから利用できる

⚠️ デメリット・制約事項

🚧 制限事項

✗動画生成は global リージョンでのみ利用可能 (US/EU マルチリージョンおよび CA, IN, JP, SG, UK の国内リージョンでは利用不可)
✗管理者が「Enable video generation」をオンにしない限り、ユーザーは動画生成を利用できない
✗Library の自然言語検索の結果に表示されるのは最大 10 件の画像・動画

🤔 考慮すべき点

⚠️プロジェクトが月間の支出上限 (monthly spend cap) に達した場合、またはプールされたクォータ上限を超過し管理者が超過利用 (overages) を有効にしていない場合、「Usage limit reached」エラーが表示され動画生成が制限される (他の機能は残りのクォータの範囲で利用可能)
⚠️データレジデンシー (DRZ) 要件が厳しい組織では、動画生成が global リージョン限定である点を確認した上で有効化を判断する必要がある
⚠️Veo 3.1 の出力に合わせてプロンプトをチューニングしていた場合、モデル置き換えにより生成結果の傾向が変わる可能性があるため、主要なユースケースでの再検証を推奨

🎯 ユースケース

📣 ユースケース 1: マーケティングチームによる動画素材のドラフト作成

シナリオ: マーケティング担当者がキャンペーン企画の初期段階で、コンセプトを伝える短い動画イメージを素早く作成したい。

実装例 
1. 管理者が Feature Management で Enable video generation をオン
2. 担当者が Tools > Create videos で「新製品のコンセプトを伝える、
   明るいトーンのオフィスシーンの短い動画」といったプロンプトを送信
3. フォローアッププロンプトでトーンや被写体を調整
4. Library から動画をダウンロードして企画資料に添付

効果: 指示追従性が向上した Omni 1.2 Flash により、意図に沿った動画ドラフトを少ない反復で取得でき、 外部制作への依頼前のコンセプト検証を高速化できる。

♻️ ユースケース 2: 生成済み動画資産の再利用

シナリオ: 過去のチャットで生成した動画を、別のプロジェクトで再利用したい。

効果: Library の自然言語検索で「過去に作ったオフィスシーンの動画」のように検索し、 該当動画をダウンロードまたは生成元チャットから再編集できるため、同じ素材を一から作り直す手間を削減できる。
