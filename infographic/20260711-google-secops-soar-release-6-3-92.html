📋 概要

Google SecOps SOAR Release 6.3.92 が全リージョンで利用可能になりました。本リリースには Publisher Agent Version 2.7.0 が含まれ、Publisher の高可用性 (HA) サポートと GCOM インフラストラクチャ移行済みエージェントでのファイル転送機能が追加されました。

🔄 Before / After 比較

❌ Before (アップデート前)

  • Publisher Agent に高可用性の仕組みがなく、障害時に通信が途絶するリスク
  • GCOM 移行済みエージェントでファイルのアップロード/ダウンロード不可
  • Remote Agent HA のみで Publisher 側の冗長化サポートが不足

✅ After (アップデート後)

  • Publisher Agent レベルでの高可用性 (Primary/Secondary 構成)
  • プレイブック/SDK を使用したファイル転送が可能に
  • エンドツーエンドの冗長構成 (Remote Agent + Publisher HA)

🚀 主要機能

🔁

Publisher Agent 高可用性 (HA)

Publisher Agent レベルでのアプリケーション高可用性を追加。Primary 障害時に Secondary が自動的にタスクを引き継ぎ、Remote Agent HA と組み合わせてエンドツーエンドの冗長構成が可能。

📁

ファイル転送サポート (GCOM)

プレイブックおよび SDK を使用して、GCOM インフラ移行済みリモートエージェント経由でファイルのアップロード/ダウンロードが可能に。インシデント対応の自動化を支援。

🐛

バグ修正

内部およびカスタマーバグ修正を含み、プラットフォーム全体の安定性が向上。既知の不具合に対する修正を実施。

⚠️ 制約事項・考慮点

制限事項
! ファイル転送機能は GCOM インフラストラクチャに移行済みのエージェントのみが対象
! Publisher HA の詳細な設定手順は公式ドキュメントで別途確認が必要
! SOAR から Google Cloud への移行 (Stage 2) が未完了の場合、一部機能に制限がある可能性
💡 考慮すべき点
  • GCOM インフラへの移行が未完了の場合、ファイル転送機能は利用不可。移行計画の策定が必要
  • SOAR 移行 Stage 2 の期限は 2026 年 9 月 30 日 に延長されているが、早期の移行完了を推奨
  • Publisher Agent のアップデートは段階的に展開されるため、リージョン間でタイミングにずれあり

💡 ユースケース

🔍 ユースケース 1: インシデント対応時の自動エビデンス収集

シナリオ: セキュリティインシデント発生時に、リモートサイトのサーバーからログファイルやメモリダンプを自動的に収集する。

効果: ファイル転送機能により、アナリストが手動でリモート接続する必要がなくなり、初動対応時間が短縮。プレイブックに組み込むことで、アラート発生と同時に証拠保全を開始可能。

🏢 ユースケース 2: 高可用性 MSSP 環境での運用

シナリオ: 複数のクライアント環境を管理する MSSP が、Publisher 障害によるサービス中断を防止したい。

効果: Publisher HA により、Primary Publisher の障害時にも Secondary が自動的にタスクを引き継ぎ、クライアント環境との通信を維持。Remote Agent HA と組み合わせることで、エンドツーエンドの耐障害性を確保。
