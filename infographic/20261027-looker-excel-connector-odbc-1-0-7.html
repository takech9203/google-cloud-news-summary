📊 Looker-Excel Connector
ODBC ドライバー 1.0.7 リリース

リリース日: 2026-10-27
☁️ Looker Feature (新バージョン提供開始) Windows 64-bit / 32-bit

📝 概要

Looker-Excel Connector で使用する ODBC ドライバーの最新バージョン 1.0.7 がダウンロード可能になりました。 Looker-Excel Connector は、Looker の Explore で作成したクエリを Microsoft Excel が認識できる形式 (ODC ファイル) としてエクスポートし、 Windows 版 Excel から Looker のガバナンスが効いたデータに直接アクセスできるようにする機能です。

ODBC ドライバーは利用する各ユーザーのローカルマシンにインストールするソフトウェアで、ODBC 互換クライアント (Excel など) から Looker インスタンスをあたかも SQL データベースのように扱えるようにします。Excel で日常的にデータ分析を行うビジネスユーザーが、 Looker のセマンティックレイヤーを経由した一貫性のあるデータを Excel 上で利用するための基盤コンポーネントです。

💡 ポイント: バージョン 1.0.7 での個別の変更点 (修正内容・改善点) は Release Notes には記載されていないため、 詳細は Looker-Excel Connector のドキュメントを参照してください。

Excel は、ローカルにインストールした ODBC ドライバーと DSN を介して Looker インスタンスに接続し、 Explore からエクスポートした ODC ファイルを開くことで LookML モデル経由のデータを取得します。

⚡ 主要機能

🔌 ODBC ドライバー 1.0.7 の提供開始

→Looker-Excel Connector 用 ODBC ドライバーの最新バージョンがダウンロード可能に
→Windows 64-bit / 32-bit の両アーキテクチャ向けインストーラーを提供

📊 Looker-Excel Connector の役割

→Explore のギアメニューの「Open in Excel」オプションから、クエリを ODC ファイルとしてエクスポート
→ODBC ドライバーがインストールされていれば、ODC ファイルを Windows 版 Excel で直接開ける
→初回オープン時に DSN (Data Source Name) を作成し、Looker インスタンス情報と認証資格情報を保存

1

ODBC ドライバー 1.0.7 のダウンロードとインストール

Looker-Excel Connector ドキュメントから、 使用する Windows のアーキテクチャ (64-bit / 32-bit) に対応した最新インストーラーをダウンロードし、画面の指示に従ってインストールします。 「Windows によって PC が保護されました」ダイアログが表示された場合は「詳細情報」→「実行」を選択します。

2

DSN の作成

インストール後、初めて ODC ファイルを開くと、Windows が DSN の作成を求めます。 DSN には Looker インスタンス情報と認証資格情報が保存され、以降 Excel などの ODBC クライアントから再利用できます。
