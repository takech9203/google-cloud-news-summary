💰 Cloud Billing: Cost estimator agent
AI エージェントのコスト見積もり

リリース日: 2026-11-10
Cloud Billing Preview FinOps Gemini Enterprise Agent Platform

📌 概要

Google Cloud コンソールの Billing セクション内で直接コスト見積もりができる新機能が登場。 第一弾の Cost estimator agent (コスト見積もりエージェント) が Preview で利用可能になり、 Gemini Enterprise Agent Platform で構築する AI エージェントのコストを、 リファレンスアーキテクチャに基づいて高レベルで見積もれます。

AI エージェントのコスト見積もりは従来のインフラサイジングと異なり、次の 3 領域の考慮が必要です。

🔤 1. トークン使用量 入出力トークン数、コンテキストキャッシュによる削減
🔁 2. デプロイパターンごとの挙動 オーケストレーターがサブエージェントやツールを呼び出す頻度
🏗️ 3. 支援インフラ 検索グラウンディング、ランタイム、セッション、Model Armor、評価、オブザーバビリティ
💡 ポイント: 自然言語でビジネスニーズを記述するだけでこれらをまとめてモデル化し、月額の想定支出を算出。 計算自体は Google Cloud の料金エンジンが決定論的に実行し、Billing アカウントの価格表 (契約 SKU 価格・割引、契約外は公開定価) を適用。 AI が価格を推測したり合計を計算することはありません。主な対象は FinOps 担当者、アーキテクト、エージェント開発者です。

😣 Before: アップデート前の課題

  • トークン数・キャッシュ率・ツール呼び出し頻度など多数の変動要素があり、Pricing Calculator では SKU を 1 つずつ特定して積み上げる必要があった
  • 構築前に、どのコンポーネント (ランタイム、セッション、Model Armor など) が課金対象かを把握しづらかった
  • 契約価格 (割引) の反映には価格表を見ながら手計算が必要だった

😊 After: アップデート後の改善

  • 自然言語の記述だけで 4 種類のリファレンスアーキテクチャから最適案を提案、サンプル初期値を自動入力
  • 自身の Billing アカウントの契約 SKU 価格・割引を自動適用 (契約外 SKU は公開定価)
  • 月額合計・内訳に加え SKU レベルの CSV をエクスポートでき、予算設定や財務承認にそのまま活用可能

⚡ 主要機能

💬 1. 自然言語によるコストモデリング

「5,000 人の社内ユーザーをサポートする人事ヘルプデスクエージェントのコストを見積もりたい」のような自由記述プロンプト、 またはスターター プロンプトから開始。SKU のリストではなくビジネスニーズから出発し、 エージェントがユースケースを 4 つのリファレンスアーキテクチャのいずれかにマッチングして、含まれるコンポーネントを説明したうえで確認を求めます。

📝 2. リファレンスアーキテクチャに基づくプリフィル

確認後、コア構成フォームにトークン数・セッション数・ランタイムなどのサンプル開始値とプロンプト内の数値が自動入力。 トラフィックドライバー (ユーザー数、セッション数、ターン数、ツール呼び出し数) やコンポーネント詳細 (モデル、トークン数、キャッシュ率、検索ティア) をフォーム直接編集またはチャットで調整できます。

⚙️ 3. Billing アカウント価格表による決定論的な計算

見積もりは Google Cloud の料金エンジンが Cloud Billing アカウントの価格表を使って決定論的に計算。 契約 SKU 価格・割引を適用し、契約外 SKU は公開定価を使用。AI エージェントが SKU 価格を推測したり、合計を独自に計算したりすることはありません。

📄 4. SKU レベルの CSV エクスポート

「Generate estimate」で月額見積もり合計とコンポーネント別内訳を表示し、cost_estimate.csv をダウンロード可能。 CSV にはコンポーネント/アイテム、プロダクト、表示名、SKU ID、リージョン、使用量単位、ベースコスト、定価コスト、見積もりコスト、通貨が含まれます。

🚀 設定方法

前提条件

✓Cloud Billing アカウントに対して Billing Account Viewer または Billing Account Administrator (相当のカスタムロール) が付与されていること
✓見積もり対象が Gemini Enterprise Agent Platform で構築するエージェントであること (その他のサービスは Pricing Calculator を使用)

ステップ 1: Cost estimator agent にアクセス

  1. Google Cloud コンソールで Billing の Overview ページに移動
  2. 対象の Cloud Billing アカウントを選択
  3. Billing ナビゲーションメニューの Cost optimization セクションで Cost estimation を選択

ステップ 2: エージェントを記述して見積もりを生成

  1. カスタムプロンプトまたはスターター プロンプトを入力
  2. エージェントが提案するサンプルアーキテクチャを確認・承認
  3. プリフィルされた構成フォームのトラフィック入力とコンポーネント詳細を、想定使用量に合わせて編集 (フォーム直接編集またはチャットで指示)
  4. Generate estimate をクリックして月額見積もりと内訳を取得し、必要に応じて Download CSV で SKU レベルの詳細をダウンロード

✅ メリット

💼 ビジネス面

📋 構築前の財務承認が容易に 構築前に具体的な月額ベースラインを提示でき、支出上限の設定、予算・アラート作成、プロジェクトクォータ割り当て、ローンチの財務承認に活用可能
💲 契約価格を反映した現実的な見積もり 自社 Billing アカウントの契約 SKU 価格と割引が自動適用され、公開定価ベースの概算より実態に近い計画が可能

🛠️ 技術面

🧩 AI エージェント特有のコスト構造をカバー トークン、キャッシュ率、ツール呼び出し、グラウンディング、ランタイム、Model Armor、オブザーバビリティまで網羅的にモデル化
⚙️ 決定論的な価格計算 価格計算は料金エンジンが実行し LLM が価格を推測しないため、見積もり数値に再現性と信頼性がある
📐 リファレンスアーキテクチャによる設計ガイド 4 つのサンプルアーキテクチャが課金対象コンポーネントの全体像を示し、アーキテクチャ検討の出発点としても有用

⚠️ デメリット・制約事項

制限事項

✗Preview 段階であり、Pre-GA Offerings Terms が適用される (サポートが限定される可能性がある)
✗現時点の見積もり対象は Gemini Enterprise Agent Platform で構築するエージェントのみ (組み込みの Agent Search と Google Cloud Observability コンポーネントを含む)
✗BigQuery、Cloud SQL、GKE、Cloud Storage など他のサービスの見積もりは引き続き Pricing Calculator を使用

考慮すべき点

⚠️ 注意: 見積もりはあくまで計画用の非拘束的な予測であり、固定の月額価格や支出上限を保証するものではありません。 実際の課金は 100% 従量制 (メーター計測) で、プロンプトの長文化、推論ループやツールリトライの増加、キャッシュヒット率の低下、 想定超のトラフィックなどでコストは見積もりを上回り得ます。
✗プリフィルされる初期値はサンプルのプレースホルダーであり、実際の想定使用量に合わせた調整が前提
✓見積もり後は Cloud Billing の予算・アラートや支出上限を併せて設定し、実際の消費を継続的に監視することを推奨

💲 料金

Cost estimator agent は Google Cloud コンソールの Billing セクション内の機能として提供されます。 生成される見積もり額は、利用者の Cloud Billing アカウントの価格表 (契約 SKU 価格・割引、契約外 SKU は公開定価) に基づいて計算されます。

💡 補足: 見積もりは非拘束的な計画用の予測であり、実際の請求は従量制の実測使用量のみに基づきます。 Agent Platform 関連の個別料金は Google Cloud Pricing Calculator および各サービスの料金ページを参照してください。
