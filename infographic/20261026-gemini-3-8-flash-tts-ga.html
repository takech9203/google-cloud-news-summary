Gemini Enterprise Agent Platform GA (一般提供)

🎙️ Gemini 3.8 Flash TTS / Flash-Lite TTS が一般提供 (GA) に

リリース日: 2026-10-26
Google Cloud Release Notes

📌 概要

Google Cloud は、Gemini Enterprise Agent Platform のテキスト読み上げ (TTS) モデル Gemini 3.8 Flash TTS (gemini-3.8-flash-tts) と Gemini 3.8 Flash-Lite TTS (gemini-3.8-flash-lite-tts) の 一般提供 (GA) を発表しました。global に加え、 us / eu マルチリージョンで利用できます。

両モデルは、構造化されたスピーカー/スタイルメタデータ (speech_metadata)、 インラインボーカルタグ (<laugh>、<sigh>、<short pause> など)、 マルチスピーカーダイアログ、ストリーミングをサポート。テキストを一言一句正確に読み上げる (verbatim recitation) 用途に最適化されており、ナレーション、オーディオブック、音声エージェントの応答などに適しています。

❌ アップデート前の課題

  • 2026-09-28 のリリース以降 Preview (Pre-GA Offerings Terms 適用) で、本番利用には規約上の制約を考慮する必要があった
  • 提供ロケーションは global のみで、us / eu マルチリージョンでのデータ処理要件に対応できなかった
  • 旧世代 gemini-3.1-flash-tts-preview はスタイル指示をテキストに埋め込む形式 (例: "Say cheerfully: Hello!") のため、指示文がそのまま読み上げられるリスクがあった

✅ アップデート後の改善

  • 両モデルが GA となり、本番・商用ワークロードで安心して利用可能に
  • global に加え、us / eu マルチリージョンで利用可能に
  • 構造化メタデータ (speech_metadata)、インラインボーカルタグ、マルチスピーカーダイアログ、ストリーミングが GA 機能として利用可能に
💡 ポイント: 忠実度重視の Flash TTS と、スループット/コスト効率重視の Flash-Lite TTS を、同一のリクエストスキーマのままモデル ID の変更だけで使い分けられます。 なお、Voice design / Voice replication は引き続き Preview です。

アプリケーションは Gemini Enterprise API の generateContent / streamGenerateContent を通じて、 テキストと構造化メタデータを 2 つの GA モデルのいずれかに送信し、WAV またはストリーミング PCM として音声を受け取ります。

⚙️ 主要機能

📝 構造化されたスピーカー/スタイルメタデータ (speech_metadata)

入力テキストは一言一句読み上げる「台本」として扱われ、話し方の指示は各 part に付与する speech_metadata (speaker、style) で構造的に指定。 例: "speech_metadata": {"style": "cheerful and friendly"}。 スタイル指示文が誤って読み上げられる問題を構造的に回避できます。

😄 インラインボーカルタグ

<laugh>、<sigh>、<cough>、<breath>、 <short pause> などの山括弧タグをトランスクリプト内に記述し、瞬間的な非言語音声イベントを挿入できます。

👥 マルチスピーカーダイアログ

複数の話者による対話音声を 1 回のリクエストで生成可能。マルチスピーカーリクエストでは、 各ターンの speech_metadata に設定済みスピーカーのいずれかを明示します。

📡 ストリーミング

streamGenerateContent によるストリーミング生成をサポートし、 リアルタイム性が求められる音声エージェントなどに対応します。

🎤 豊富なボイスオプション

30 のプレビルトボイス、2,000 以上の Extended Voice Library のボイスを利用可能。 Voice design (ボイス作成) / Voice replication (ボイス複製) で作成したボイス (voice_... ID) も利用できます (両機能は引き続き Preview)。

🚀 設定方法

前提条件

✓プロジェクトを設定し、Gemini Enterprise API を有効化する
✓開発環境に Application Default Credentials を構成する
✓Python を使用する場合: pip install --upgrade "google-genai>=2.25.0"

ステップ 1: Python SDK でシングルスピーカー音声を生成

Python シングルスピーカー音声の生成 
from google import genai

client = genai.Client(enterprise=True, project="PROJECT_ID", location="global")

response = client.models.generate_content(
    model="gemini-3.8-flash-tts",
    contents=[{
        "role": "user",
        "parts": [{
            "text": "Have a wonderful day!",
            "speech_metadata": {"style": "cheerful and friendly"},
        }],
    }],
    config={
        "response_modalities": ["AUDIO"],
        "speech_config": {"voice_config": {"voice": "Kore"}},
    },
)

# 単発リクエストのレスポンスはデフォルトで完全な WAV ファイル
with open("out.wav", "wb") as f:
    f.write(response.candidates[0].content.parts[0].inline_data.data)

テキスト本文は台本として扱われ、スタイルは speech_metadata で指定します。

ステップ 2: REST API での呼び出し

Bash curl による generateContent 呼び出し 
curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  https://aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/global/publishers/google/models/gemini-3.8-flash-tts:generateContent \
  -d '{
    "contents": [{
      "role": "user",
      "parts": [{
        "text": "Have a wonderful day!",
        "speechMetadata": {"style": "cheerful and friendly"}
      }]
    }],
    "generationConfig": {
      "responseModalities": ["AUDIO"],
      "speechConfig": {"voiceConfig": {"voice": "Kore"}}
    }
  }' | jq -r '.candidates[0].content.parts[0].inlineData.data' | base64 --decode > out.wav
💡 ヒント: Flash-Lite TTS を使う場合はモデル ID を gemini-3.8-flash-lite-tts に変更するだけです。

⚠️ デメリット・制約事項

制限事項

✗Voice design と Voice replication は引き続き Preview 提供 (Pre-GA Offerings Terms が適用される)
✗入力トークン上限は 8,192、出力トークン上限は 16,384
✗Gemini Live API、Count Tokens API、Chat Completions API には非対応 (GenerateContent API を使用)
✗sampleRate フィールドは無視される (Linear PCM / WAV は 24 kHz、μ-law / A-law は 8 kHz 固定。別のサンプルレートが必要な場合はクライアント側でリサンプリング)

考慮すべき点

⚠️ 旧モデルからの移行時の注意 (gemini-3.1-flash-tts-preview 以前):
  • インラインのスタイル指示文 (例: "Say cheerfully: ...") は読み上げられる可能性があるため、speech_metadata に移動する
  • 単発リクエストのデフォルト出力が raw PCM から WAV (RIFF ヘッダー付き) に変わったため、手動で WAV ヘッダーを付与していたコードは修正が必要
  • マルチスピーカーリクエストでは全ターンで speaker の明示が必須
  • 対応言語数がモデルにより異なる (Flash: 130 言語、Flash-Lite: 101 言語)

🎯 ユースケース

📚 ユースケース 1: オーディオブック・スタジオ品質ナレーションの制作

シナリオ: 出版社がオーディオブックを大量制作したい。長時間のナレーションでも声質やトーンが一貫し、 笑い声やため息などの演技表現も必要。

Python ナレーション生成の実装例 
response = client.models.generate_content(
    model="gemini-3.8-flash-tts",
    contents=[{
        "role": "user",
        "parts": [{
            "text": "それは、忘れられない夏の日のことでした。<short pause> 彼は静かに扉を開けたのです。",
            "speech_metadata": {"style": "calm, storytelling narration"},
        }],
    }],
    config={
        "response_modalities": ["AUDIO"],
        "speech_config": {"voice_config": {"voice": "Kore"}},
    },
)

効果: Flash TTS の長時間マルチターン安定性により、声の同一性・音色・ルームトーンを維持したまま 長編ナレーションを生成できる。
