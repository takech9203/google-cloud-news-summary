📝 概要

CCAI Platform の advanced reporting dashboards 6.16 のプレリリースノートが公開されました。 本リリースは新機能の追加ではなく、修正 (Fixed) に特化した内容です。 中心となるのはフィルタープロンプトの大規模な改善で、全ダッシュボードで一貫した動作となり、 各ドロップダウンが設定済みの値の完全なリストを表示するようになります。

⚠️ プレリリースノートについて: 正式リリース前の事前公開情報です。リリース時に内容が変更される可能性があり、リリース時のバージョンは 6.16 より大きくなる可能性があります。

🔧 主要な修正内容

⚡ 1. パフォーマンスの修正

Real-time Agent Monitoring ダッシュボードの Agent Performance タイルが、自動更新時に冗長なデータベースクエリを実行していた問題を修正。自動更新が効率化されます。

🔍 2. フィルタープロンプトの一貫性向上と完全なリスト表示

  • リストベースのフィルターが初回クリックで検索可能なリストを直接開くように変更
  • 空または部分的だった Agent Name、Agent Email、Agent Custom ID、Agent Teams、Location、Language、Answered By、Projection Result のドロップダウンが完全なリストを表示
  • Disposition Codes / Disposition List フィルターがインスタンスに設定されたコードを表示
  • Agent Teams / Team Name フィルターが、エージェントに割り当てられたいずれかのチームでマッチ
  • 名前変更 (Queue Group、Queue、Agent Team、Disposition Code、Location、Role、Skill) が 30 分以内に反映
  • ライブ Queued の Projecting フィルターがクリア可能に (選択肢は Yes のみ)
  • 定義済み値リストのないフィールド (電話番号、ID など) は演算子付きプレーンテキストボックスで直接入力可能
  • Call Status / Deflection Type フィルターが、以前欠落していた値を表示

📡 3. データ表示の修正

  • Channel が、以前空白だったインタラクションタイプ (internal、API-initiated、campaign、UCaaS、callback、extension calls) について、ライブの Voice / Chat ダッシュボードおよび履歴 Chat ダッシュボードで値を報告
  • Agent Audit ダッシュボードの Change Details テーブルがタイムスタンプ列を表示し、正しくソート

🚨 4. 仕様変更 (既存運用に影響する可能性あり)

  • 消費者電話番号フィルターが複数値ではなく単一値のみを受け付けるように変更。複数の番号を渡す保存済みフィルターやリンクは 1 つの番号のみ適用
  • Missed Interactions ダッシュボードで Activity Status → Projection Result に名称変更
  • Actor 値を標準化。旧表記を使用していた保存済みフィルター、Look、スケジュールは再選択が必要

💡 メリット

💼 ビジネス面

✓ レポート作成の効率化: フィルターが完全なリストを表示するため、目的のエージェント・チーム・ディスポジションコードを確実に絞り込め、分析作業の手戻りが減る
✓ 運用変更の反映が迅速に: 構成変更が 30 分以内にフィルターへ反映され、組織変更直後でも最新の構成でレポートを作成できる

⚙️ 技術面

✓ ダッシュボードの負荷軽減: 冗長な DB クエリが解消され、Real-time Agent Monitoring の自動更新が効率化
✓ データの網羅性・一貫性向上: Channel 値の補完、欠落していたフィルター値の表示、Actor 値の標準化により、ダッシュボード間の突き合わせや集計の信頼性が向上

⚠️ デメリット・制約事項

🚧 制限事項

✗ プレリリースノートである点に注意: 次期アップデートの予定であり、正式リリース時に変更される可能性がある。リリース時のバージョンは 6.16 より大きくなる可能性がある
✗ 消費者電話番号フィルターは単一値のみを受け付ける。複数の番号を渡していた保存済みフィルターやリンクは 1 つの番号のみ適用
✗ ライブ Queued ダッシュボードの Projecting フィルターの選択肢は Yes のみ

🤔 考慮すべき点

🚨 Actor 値の標準化は破壊的変更: 旧表記の Actor 値を使用していた保存済みフィルター、Look、スケジュールは、リリース後に再選択 (再設定) が必要です。
✗ Missed Interactions の Activity Status を参照していた運用手順やドキュメントは、Projection Result への名称変更に合わせた更新が必要
✗ Channel 値が新たに報告されるインタラクションタイプにより、Channel ベースの集計値が従来と変わる可能性があるため、既存レポートとの比較時に注意

📌 まとめ

CCAI Platform の advanced reporting dashboards 6.16 プレリリースノートは、フィルター動作の統一、空白データの補完、パフォーマンス改善を中心とした修正リリースの予告です。

多くはレポート作成体験を改善するものですが、Actor 値の標準化、消費者電話番号フィルターの単一値化、Activity Status の名称変更は既存の保存済みフィルター・Look・スケジュールに影響します。レポーティングを運用するチームは、正式リリース前に影響を受ける資産を棚卸しし、リリース後に速やかに再設定できるよう準備しておくことを推奨します。
