📋 概要

Google Cloud は、既存の Gemini Enterprise Standard / Plus サブスクリプションにバンドルされている Gemini Code Assist のエンタイトルメント (利用権) を 2027 年 3 月 31 日で終了すると発表しました。 この日以降、既存サブスクリプションからエンタイトルメントが削除されます。 終了日までの Gemini Code Assist のサポートは Gemini 3.x モデルファミリーのみに限定されます。

これに先立ち、2026 年 10 月 9 日以降に購入された新規 Gemini Enterprise サブスクリプションには、すでに Gemini Code Assist のエンタイトルメントが含まれていません。 同日より Gemini Code Assist Standard / Enterprise の新規販売自体も終了しており、今回の発表は Gemini Code Assist 全体のサンセット (段階的終了) 計画の一環です。

開発者ワークフローの移行先として、エージェント型コーディング支援は Google Antigravity で提供されます。 Antigravity は Gemini Enterprise の各エディションに含まれており、追加のサブスクリプションなしで利用できます。

❌ Before (アップデート前の課題)

  • Gemini Enterprise Standard / Plus に Gemini Code Assist がバンドルされ、開発者向け AI 支援は Code Assist (IDE 拡張・Gemini CLI) 経由で提供
  • Gemini Code Assist と後継の Antigravity という 2 系統の開発者向け AI ツールが併存し、移行時期が不明確

✅ After (アップデート後の変更)

  • 既存サブスクリプションの Code Assist エンタイトルメントは 2027/3/31 で終了し、以降削除される
  • 終了日までのサポートは Gemini 3.x モデルファミリーのみ
  • 2026/10/9 以降の新規サブスクリプションには Code Assist エンタイトルメントを含まない
  • エージェント型コーディング支援は Google Antigravity (アプリ / CLI / IDE 拡張) に一本化

既存の Gemini Enterprise サブスクリプションは 2027 年 3 月 31 日まで Gemini Code Assist を利用できますが (Gemini 3.x モデルのみ)、 それ以降は Gemini Enterprise に含まれる Google Antigravity がエージェント型コーディング支援の提供手段となります。

📅 サンセットのタイムライン

2026 年 10 月 9 日 (発効済み)
Gemini Code Assist Standard / Enterprise の新規サブスクリプション購入終了。新規 Gemini Enterprise サブスクリプションに Code Assist エンタイトルメントが含まれなくなる
2027 年 1 月 31 日
Gemini Code Assist の年間サブスクリプションの自動更新終了。既存サブスクリプションへの追加ライセンス購入も終了
⚠️ 2027 年 3 月 31 日 (今回の発表)
既存の Gemini Enterprise Standard / Plus サブスクリプションの Gemini Code Assist エンタイトルメント終了
2027 年 12 月 31 日
Gemini Code Assist の月間サブスクリプションの自動更新終了

💡 主要なポイント

1️⃣ 既存 Gemini Enterprise サブスクリプションへの影響

→Standard / Plus にバンドルされた Code Assist エンタイトルメントは 2027 年 3 月 31 日まで維持
→この日以降、エンタイトルメントは既存サブスクリプションから削除される

2️⃣ モデルサポートの限定

→2027 年 3 月 31 日までの Gemini Code Assist のサポートは Gemini 3.x モデルファミリーのみに限定

3️⃣ 移行先は Google Antigravity

→エージェント型コーディング支援は Google Antigravity で提供。Gemini Enterprise エディションに含まれる
→Antigravity アプリ (デスクトップ)、Antigravity CLI、IDE 拡張機能 (VS Code、Visual Studio、JetBrains 系 IDE、Zed、Xcode など) が利用可能
→Gemini CLI から Antigravity CLI への移行ガイドが提供されている

4️⃣ 単体の Gemini Code Assist サブスクリプションへの影響

→既存の Code Assist サブスクリプションは契約期間の終了まで利用可能
→年間サブスクリプションは 2027/1/31、月間サブスクリプションは 2027/12/31 まで自動更新可能

🚀 移行先: Gemini Enterprise の AI developer tools

Standard、Plus、Standard Emerging Market、Pay-as-you-go の各エディションの有効な非トライアルサブスクリプションで、以下のツールが利用可能です。

ツール説明

ステップ 1: サブスクリプションの移行計画を立てる

Gemini Code Assist を単体サブスクリプションで利用している場合は、最終更新日または契約終了日より前に Gemini Enterprise への移行を計画します。 Gemini Enterprise バンドルで利用している場合は、2027 年 3 月 31 日のエンタイトルメント終了までに Antigravity への移行を完了させます。

ステップ 2: Antigravity のセットアップ

開発者のワークフローに応じて、Antigravity アプリ、Antigravity CLI、または各 IDE 向けの Antigravity 拡張機能を導入します。 エンタープライズ利用では IDE 拡張機能から「Sign in with Gemini Enterprise」を選択し、企業 ID (BYOID、Workforce Identity Federation を含む) で認証後、 対象の Google Cloud プロジェクトとリージョンを選択します。

ステップ 3: Gemini CLI からの移行

Gemini CLI を利用している場合は、公式の移行ガイド (Antigravity CLI migration guide) に従って Antigravity CLI へ移行します。

⚠️ デメリット・制約事項

🚫 制限事項

✗2027 年 3 月 31 日以降、既存の Gemini Enterprise Standard / Plus サブスクリプションから Gemini Code Assist エンタイトルメントが削除され、利用できなくなる
✗終了日までの Gemini Code Assist のモデルサポートは Gemini 3.x モデルファミリーのみ
✗2027 年 1 月 31 日以降、Gemini Code Assist の追加ライセンス購入は不可
✗Antigravity in Gemini Enterprise は現時点で以下のコンプライアンス認証・セキュリティ管理を未サポート: Access Transparency (AXT)、FedRAMP (Moderate / High)、IL4 / IL5、ISO 認証 (ISO 27001、ISO 42001 を含む)、ITAR、SOC 1 / 2 / 3

🤔 考慮すべき点

⚡Gemini Code Assist を前提とした開発者ワークフロー (IDE 拡張機能、Gemini CLI) は、エンタイトルメント終了前に Antigravity への移行テストを行うことが推奨される
⚡コンプライアンス要件 (FedRAMP、ISO、SOC など) がある組織は、Antigravity の現時点でのコンプライアンス制限を確認したうえで移行計画を立てる必要がある
⚡Android Studio はサードパーティ ID プロバイダをサポートしていないため、該当構成のユーザーは Android Studio での AI developer tools 機能を利用できない
⚡Antigravity の一部マルチエージェント機能 (/boost、/teamwork-preview) はトークン使用量とコストが増加する可能性があり、管理者が組織単位で有効/無効を制御できる

🎯 まとめ

Gemini Enterprise Standard / Plus にバンドルされていた Gemini Code Assist エンタイトルメントは 2027 年 3 月 31 日で終了し、開発者向けエージェント型コーディング支援は Gemini Enterprise に含まれる Google Antigravity に一本化されます。 Gemini Code Assist を利用中の組織は、終了日までのモデルサポートが Gemini 3.x ファミリーに限定される点にも留意しつつ、 Antigravity (アプリ / CLI / IDE 拡張機能) への移行検証とコンプライアンス要件の確認を早期に開始することを推奨します。
