📋 概要

Google Cloud CCAI Platform の高度なレポートダッシュボード (Advanced Reporting Dashboards) について、 バージョン 6.24 のプレリリースノートが公開されました。今回は新機能の追加ではなく、 レポーティング機能の不具合修正 (Fixed) が中心です。ダッシュボードの表示崩れ、ダウンロードレポートのデータ欠落、 多言語環境 (フランス語・スペイン語・カナダフランス語) での翻訳不備、長期間指定時の通話ディスポジション空白表示など、 コンタクトセンターの運用レポートの正確性に直結する 7 件の問題が修正されます。

🔄 Before / After

❌ アップデート前の課題

  • ワイドスクリーンで Dashboard Reports セレクタ内の通話・チャットタイプ名が途中で切れて表示
  • 全エージェント対象の Individual Call/Chat History レポートで、アクティブなエージェントが 1 名以下の場合に未割り当ての通話・チャット (放棄・デフレクト・期限切れ) が欠落
  • Interactions Detail by Agent レポートで、キューを経由しないアウトバウンド通話が欠落
  • Real-time Queue Monitoring / Campaign ダッシュボードで、フランス語・スペイン語のインタラクションに英語のキュー名を誤表示
  • 「ラップアップ」「保留」指標のカナダフランス語 (fr_CA) 翻訳が一貫せず不正確
  • スペイン語チャットキューに英語名を誤表示
  • 46〜365 日の日付範囲で通話ディスポジションフィールドが空白に

✅ アップデート後の改善

  • ワイドスクリーンでもセレクタの通話・チャットタイプ名が切れずに表示
  • All Call History / All Chat History ファイルが常に含まれ、未割り当ての通話・チャットが漏れなく出力
  • Interactions Detail by Agent レポートにキューなしのアウトバウンド通話が含まれる
  • フランス語・スペイン語環境でキュー名がローカライズされた名前で正しく表示
  • fr_CA のラップアップ・保留指標の翻訳が統一され、正確に
  • スペイン語チャットキュー名が正しく表示
  • 46〜365 日の日付範囲でも通話ディスポジションが正しく表示

🔧 修正内容 (Fixed) の詳細

🖥️ 1. Dashboard Reports セレクタの表示崩れ修正

ワイドスクリーンディスプレイで、通話タイプ・チャットタイプ名がセレクタ内で途切れて表示される問題を修正。

📞 2. Individual Call/Chat History レポートのデータ欠落修正

全エージェント対象で実行した際、選択期間にアクティビティのあったエージェントが 1 名または 0 名の場合に、エージェント未割り当ての通話・チャット (放棄、デフレクト、期限切れなど) が欠落する問題を修正。修正後は All Call History / All Chat History ファイルが常にレポートに含まれる。

📤 3. Interactions Detail by Agent レポートの欠落修正

全エージェント対象で生成した際に、キューを経由せず発信されたアウトバウンド通話が欠落する問題を修正。

🌐 4. 多言語環境でのキュー名表示の修正

Real-time Queue Monitoring および Campaign ダッシュボードで、フランス語・スペイン語のインタラクションに英語のキュー名が表示される問題を修正。スペイン語チャットキューに英語名が表示される問題も修正。

🍁 5. カナダフランス語 (fr_CA) 翻訳の修正

高度なレポートにおける「wrap-up (ラップアップ)」「hold (保留)」指標の翻訳が一貫せず不正確だった問題を修正。

📅 6. 長期間の日付範囲でのディスポジション表示の修正

46 日〜365 日の日付範囲を指定すると、通話ディスポジション (対応結果) フィールドが空白になる問題を修正。四半期・年次レベルの分析が可能に。

🔗 関連サービス・機能

📊 高度なレポートダッシュボード (Advanced Reporting Dashboards)

Looker ベースのダッシュボード群。Real-time Queue Monitoring、Campaign、Agent Performance などのダッシュボードを提供し、カスタムダッシュボードや Looks の作成も可能。

📄 標準レポート (Standard Reports)

Report Builder から CSV 形式でダウンロードするレポート機能。今回修正対象の Individual Call/Chat History レポートはこの機能に含まれる。

📣 アウトバウンドキャンペーン (Campaigns)

Campaign ダッシュボードで通話結果やキャンペーンボリュームを監視する機能。今回の多言語キュー名表示の修正対象。
