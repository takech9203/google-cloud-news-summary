☁️ Cloud Asset Inventory ✨ Gemini for Google Cloud Feature
📅 リリース日: 2026-11-08

🔍 Gemini for Google Cloud の Topic リソースタイプが
Cloud Asset Inventory 検索 API で利用可能に

cloudaicompanion.googleapis.com/Topic が SearchAllResources / SearchAllIamPolicies の検索対象に追加

📋 概要

Cloud Asset Inventory の検索 API (SearchAllResources および SearchAllIamPolicies) で、 Gemini for Google Cloud (Cloud AI Companion API: cloudaicompanion.googleapis.com) の Topic リソースタイプが一般公開されました。

組織・フォルダ・プロジェクトのスコープで Topic リソースを横断検索でき、Topic に付与された IAM 許可ポリシー (topicAdmin / topicReader などのロールバインディング) も棚卸しできるようになります。

💡 このアップデートの価値: Gemini for Google Cloud の利用が組織内で拡大する中、クラウド管理者やセキュリティチームが 「どのプロジェクトにどんな Gemini 関連リソースが存在し、誰がアクセスできるのか」を統一的なインターフェースで可視化できます。

❌ Before (アップデート前の課題)

  • Topic リソースは検索 API の対象外で、組織横断で存在を把握するには個別のプロジェクト・API を直接確認する必要があった
  • Topic リソースに付与された IAM ポリシーを組織全体で棚卸しする統一的な手段がなかった

✅ After (アップデート後の改善)

  • gcloud asset search-all-resources やコンソールから、組織・フォルダ・プロジェクトのスコープで Topic リソースを横断検索可能に
  • gcloud asset search-all-iam-policies で、Topic の IAM 許可ポリシー (プリンシパル、ロール) を検索・監査可能に

Cloud Asset Inventory の 2 つの検索 API から、新たに Gemini for Google Cloud の Topic リソースと その IAM ポリシーを横断検索できるようになった構成を示しています。

⚙️ 主要機能

1️⃣ SearchAllResources での Topic リソース検索

→cloudaicompanion.googleapis.com/Topic を指定スコープ (プロジェクト / フォルダ / 組織) 内で検索可能
→--asset-types フラグでこのリソースタイプに絞り込んだ検索が可能

2️⃣ SearchAllIamPolicies での IAM ポリシー検索

→Topic リソースに直接付与された IAM 許可ポリシーを検索可能
→Topic 向けの IAM ロール (roles/cloudaicompanion.topicAdmin、roles/cloudaicompanion.topicReader) のバインディング状況を監査できる

🔧 技術仕様

📊 検索 API の概要

項目詳細
対象リソースタイプcloudaicompanion.googleapis.com/Topic
対象 APISearchAllResources、SearchAllIamPolicies
検索スコーププロジェクト、フォルダ、組織
必要な権限 (リソース検索)cloudasset.assets.searchAllResources
必要な権限 (IAM ポリシー検索)cloudasset.assets.searchAllIamPolicies
前提条件検索を実行するプロジェクトで Cloud Asset Inventory API (cloudasset.googleapis.com) を有効化

💻 検索コマンド例

Bash gcloud asset 検索コマンド 
# 組織内の Gemini for Google Cloud Topic リソースを検索
gcloud asset search-all-resources \
  --scope=organizations/ORGANIZATION_ID \
  --asset-types=cloudaicompanion.googleapis.com/Topic

# Topic リソースに付与された IAM 許可ポリシーを検索
gcloud asset search-all-iam-policies \
  --scope=organizations/ORGANIZATION_ID \
  --asset-types=cloudaicompanion.googleapis.com/Topic

👍 メリット

💼 ビジネス面

✓ガバナンスの強化: 組織内で利用が広がる Gemini for Google Cloud 関連リソースを一元的に把握でき、シャドー利用の発見やコンプライアンス対応に役立つ
✓監査の効率化: Topic リソースへのアクセス権限 (誰がどのロールを持つか) を 1 つのクエリで棚卸しできる

🛠️ 技術面

✓統一インターフェース: 他の Google Cloud リソースと同じ検索 API・クエリ構文・コンソール UI で扱える
✓自動化への組み込み: 既存の Cloud Asset Inventory ベースの棚卸しスクリプトや監査パイプラインに、資産タイプを追加するだけで対応できる

⚠️ デメリット・制約事項

考慮すべき点
▲検索 API はメタデータのインデックスを対象とするため、リソースの変更が検索結果に反映されるまでにタイムラグが生じる場合がある
▲検索可能な属性はリソースタイプごとに異なるため、詳細は公式ドキュメントのサポート対象アセットタイプ一覧で確認が必要

🎯 ユースケース

📦 ユースケース 1: 組織全体での Gemini 関連リソースの棚卸し

シナリオ: セキュリティチームが、組織内のどのプロジェクトで Gemini for Google Cloud の Topic リソースが作成されているかを定期的に把握したい。

Bash 実装例 
gcloud asset search-all-resources \
  --scope=organizations/ORGANIZATION_ID \
  --asset-types=cloudaicompanion.googleapis.com/Topic \
  --format="table(name, project, location)"

効果: プロジェクトを個別に調べることなく、組織全体の Topic リソースを一覧化できる。

🔑 ユースケース 2: Topic リソースへのアクセス権限の監査

シナリオ: 監査担当者が、Topic リソースに対して管理者権限 (roles/cloudaicompanion.topicAdmin) を持つプリンシパルを確認したい。

効果: SearchAllIamPolicies にロールを条件として指定することで、過剰な権限付与を早期に検出できる。

🔗 関連サービス・機能

✨ Gemini for Google Cloud (Cloud AI Companion API)
今回検索対象に追加された Topic リソースを提供するサービス。cloudaicompanion.googleapis.com エンドポイントで提供される。
🔐 IAM
Topic リソース向けのロール (roles/cloudaicompanion.topicAdmin、roles/cloudaicompanion.topicReader) のバインディングが SearchAllIamPolicies の検索対象となる。
🛡️ Security Command Center
Cloud Asset Inventory のデータを活用した資産の可視化・セキュリティ監視と補完関係にある。

📝 まとめ

✅ ポイント: Gemini for Google Cloud の Topic リソースが Cloud Asset Inventory の検索 API に対応したことで、 組織横断でのリソース把握と IAM 権限監査が容易になりました。
💡 推奨アクション: Gemini for Google Cloud を利用している組織では、既存の資産棚卸し・監査プロセスの 対象アセットタイプに cloudaicompanion.googleapis.com/Topic を追加することを推奨します。
