📋 概要

Google Cloud CCaaS の次期バージョン (6.13 になる見込み) のプレリリースノートが公開されました。 プレリリースノートは、次期バージョンで提供予定の変更内容を事前に知らせるもので、コンタクトセンター管理者は リリース前に影響範囲を評価し、運用チームへの周知やテスト計画を準備できます。

今回は新機能の追加ではなく、既知の問題の修正 (Fixed) のみ約 36 件で構成されています。 通話ルーティング・キュー制御、レポーティング・データエクスポート、エージェントデスクトップ、 Salesforce / Kustomer などの CRM 統合、Web SDK のアクセシビリティまで、CCaaS の広範な領域をカバーしています。

🔄 Before / After

❌ Before (修正対象の既知の問題)

  • 最初のメッセージ前に終了したチャットで、セッションメタデータとデータフィードが外部ストレージに出力されない
  • 通話終了後もエージェントが「通話中」と誤認識され、Available への変更や新規コールの着信が妨げられる
  • コールスパイク時にキャパシティ制限がバイパスされ、エージェント可用性が必要最低水準を下回る
  • All Call History / Voice Inbound (IVR) History から、デフレクトされた通話やボイスメール前切断の通話が欠落
  • Salesforce click-to-dial が誤ったケースに関連付き、重複アカウントが作成される

✅ After (6.13 で修正予定)

  • チャット・通話のセッションデータ、履歴レポート、Agent Activity Timeline の記録精度が改善
  • エージェント状態管理 (通話終了後のステータス、転送不応答時のアクティブ状態残留) が正しく動作
  • キュー・ルーティングの信頼性 (キャパシティ制限、multicast フォールバック無効時のスタック、優先度オーバーライド) が向上
  • Salesforce / Kustomer 統合の発信者情報表示、ケース関連付け、OAuth Refresh Token Rotation 対応が改善
  • Web SDK のキーボードナビゲーション (WAI-ARIA) とスクリーンリーダー対応が改善

🔧 修正内容の詳細

通話ルーティング・キュー制御 📞 コールの接続・振り分けの信頼性向上
  • モバイルインバウンドコールの接続失敗: エージェント側レッグは接続する一方、エンドユーザー側レッグが Unknown error で失敗する問題を修正
  • エージェント間転送での状態残留: 受信側エージェントが応答しなかった場合、通話終了後も無期限に「通話中 (アクティブ)」として扱われる問題を修正
  • 通話終了後のエージェント状態の誤認識: Available への変更を妨げ、新規コールの着信をサイレントにブロックする問題を修正
  • コールスパイク時のキャパシティ制限バイパス: コール急増時に制限がバイパスされ、エージェント可用性が必要最低水準を下回る問題を修正
  • ミスドオファーによるキュー内スタック: 応答されなかった通話がキュー内に永久にスタックする問題を修正 (multicast フォールバック無効のキューで発生)
  • エージェント優先度オーバーライドのルーティング不良: 最上位ランクのエージェントへ正しくルーティングされない問題を修正
  • 超過容量デフレクションの不発火: アウトバウンドコールをキューにウォーム転送した際に over-capacity デフレクションがトリガーされない問題を修正
  • SIP リダイレクト時のカスタムヘッダー欠落: 超過容量キューが SIP URI にリダイレクトする際、カスタム SIP ヘッダーが含まれない問題を修正
  • キュー内アナウンス間隔の短縮: 数分に設定した間隔が約 60 秒に誤って短縮される問題を修正
  • 通話終了処理の遅延によるタイムアウト: 終了した通話の処理遅延がタイムアウトエラーを引き起こす問題を修正
レポーティング・データエクスポート 📈 レポート・記録の精度改善
  • セッションメタデータ・データフィードの欠落: 最初のメッセージ前に終了したチャットで、外部ストレージからファイルが欠落する問題を修正
  • デフレクトされた通話の欠落: All Call History / Voice Inbound (IVR) History レポートから欠落する問題を修正
  • ボイスメール前切断の通話の欠落: ボイスメールを残す前に発信者が切断した通話がレポートから欠落する問題を修正
  • キャンセルされたアウトバウンドコールの欠落: 接続前にキャンセルされた手動・カスケードコールがチームフィルター適用時の Call History から欠落する問題を修正
  • Agent Activity Timeline の誤記録 (マイク障害): 応答できなかった通話が「picked up」として誤記録される問題を修正
  • ログイン・ログアウトの誤帰属: 手動のログイン・ログアウトが該当エージェントではなく System に帰属される問題を修正
  • 「chat finished」イベントの重複: エンドユーザー離脱とエージェントのチャット終了がほぼ同時に発生した場合の重複報告を修正
  • 矛盾したイベント記録: エスカレーションされた音声通話が「応答済み」と「放棄」の両方として報告される問題を修正
  • 録音の音声欠落: 通話中のバーチャルタスクアシスタント実行時に、エージェント音声の一部が録音から欠落する問題を修正
エージェントデスクトップ・アダプター 🖥️ エージェント UI の安定化
  • ライブデータの消失: エージェントデスクトップでライブコール・チャットのデータが失われる問題を修正
  • Dismiss ボタンの 409 エラー: メッセージ送信後も Dismiss ボタンが有効なまま残り、クリックすると 409 エラーになる問題を修正
  • アダプターの空白化: 着信通知直後にエンドユーザーが切断すると、アダプターが空白になり新規コールが届かなくなる問題を修正
  • 「connecting」状態のスタック: 接続に失敗した通話がコールアダプター上で無音のままスタックする問題を修正
  • ラップアップパネルのフリーズ: ネットワーク再接続後、送信完了済みにもかかわらずディスポジションパネルがフリーズする問題を修正
  • キュー一覧の古い情報: エージェントの選択言語と一致しないキューに通話が配置される可能性があった問題を修正
  • 転送メニューの言語不整合: 通話転送・ボイスメール転送メニューが選択言語ではなく英語で表示される問題を修正
  • アイコンの表示不良: Agents > Filter Settings ページの上下矢印アイコンが不適切なスケールで描画される問題を修正
CRM 統合 🔗 Salesforce / Kustomer 連携の改善
  • Kustomer: 発信者情報の非表示: 直通インバウンドコールで、発信者情報が Incoming call ページに表示されない問題を修正
  • Salesforce: click-to-dial のケース関連付け不良: 発信元のケースではなく直近のオープンケースに誤って関連付けられる問題を修正
  • Salesforce: ケースの誤リンク・所有権再割り当て: 同一電話番号に紐づく他のケースへ誤ってリンクされる問題を修正
  • Salesforce: 重複アカウントの作成: 着信コールが既存アカウントにリンクされず、重複アカウントが作成される問題を修正
  • Salesforce: OAuth Refresh Token Rotation 環境での接続断: Rotation を強制する組織で CRM 接続がドロップする問題を修正
その他 🧩 メール / Agent Assist / Web SDK
  • メールアカウントの再接続不能: 一時的な認証失敗の後、メールアカウントが無期限に切断されたままになる問題を修正
  • Agent Assist の誤検知アラート: 通話中の長い無音による接続タイムアウトが誤検知エラーアラートをトリガーする問題を修正
  • Web SDK: WAI-ARIA 準拠: プレチャット・チャット画面のメニューがキーボードナビゲーション標準に準拠していなかった問題を修正
  • Web SDK: スクリーンリーダー対応: チャット画面の Text size オプションの目的を識別できなかった問題を修正
