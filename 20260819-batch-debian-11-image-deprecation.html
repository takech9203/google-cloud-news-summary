⚠️ Batch: Debian 11 OS イメージファミリーの開発終了

☁️ Batch Deprecated (非推奨) 🗓️ 2026-08-31 サポート終了
リリース日: 2026-08-19

📌 概要

Google Cloud Batch の Debian 11 OS イメージファミリーが開発終了 (end of development) となりました。 これは Compute Engine の Debian 11 イメージが 2026 年 8 月 31 日に EOS (サポート終了) を迎えることに伴う措置で、 batch-debian-11-official プレフィックスを持つすべてのイメージバージョンは同日までのみサポートされます。

Batch Debian (batch-debian プレフィックス) はスクリプト runnable を含むジョブのデフォルトイメージのため、 Debian 11 を明示指定しているジョブだけでなく、デフォルトイメージに依存しているジョブも影響を受ける可能性があります。 移行先として batch-debian-12-official (Debian 12 bookworm ベース) が利用可能です。

❌ アップデート前の課題

  • Batch Debian 11 (batch-debian-11-official) がスクリプトジョブ用イメージファミリーとして提供されてきた
  • ベース OS の Debian 11 (bullseye) が 2026-08-31 に EOS を迎え、以降はセキュリティ更新・イメージ更新が提供されない
  • EOS 後の OS を使い続けると、脆弱性対応や不具合修正が受けられず運用リスクが増大

✅ アップデート後の改善

  • サポート終了日 (2026-08-31) と移行手順が公式に明示された
  • デフォルトイメージ (batch-debian) 使用のジョブは Batch 側で Debian 12 へ段階的に自動移行 → 多くの場合ユーザー側の変更不要
  • 移行先の batch-debian-12-official は 2028-06-30 まで EOS 予定なし (Compute Engine)

ジョブ定義でのイメージ指定方法によって対応が分岐します。デフォルトの batch-debian プレフィックスを使用する場合は Batch が自動的に Debian 12 へ移行しますが、batch-debian-11-official を明示指定している場合は ジョブ作成時に別のイメージを指定する必要があります。

🔧 主要な変更点

1️⃣ Batch Debian 11 イメージファミリーの開発終了

→batch-debian-11-official プレフィックスを持つすべてのイメージバージョンが対象
→最終サポート期限は 2026 年 8 月 31 日 (Compute Engine Debian 11 の EOS 日と同日)
→EOS 後は Debian コミュニティおよび Google からのイメージ更新・セキュリティ修正が提供されない

2️⃣ デフォルトイメージの自動移行

→batch-debian プレフィックス (スクリプト runnable のデフォルト) を使用するジョブ定義は、Batch が自動選択するイメージが遅くとも 2026-08-31 までに段階的に Debian 12 へ移行
→2026-08-31 より前に作成されたジョブは、describe することで Debian 11 / 12 のどちらを使用しているか確認可能

3️⃣ 明示指定ジョブの移行方法

→batch-debian-11-official を指定しているジョブ定義は、ジョブ作成時に別のイメージ指定が必要
→Debian 12 へ移行する場合は batch-debian-12-official イメージファミリー、またはそのプレフィックスを持つイメージバージョンを指定

⚙️ 設定方法 (移行手順)

💡 前提条件: Batch API が有効化されたプロジェクトと、ジョブ作成に必要な IAM ロール (roles/batch.jobsEditor および roles/iam.serviceAccountUser)、gcloud CLI がインストール済みであること。

ステップ 1: 既存ジョブが使用しているイメージを確認する

Bash 使用中の OS イメージの確認 
# ジョブの詳細を表示して使用中の OS イメージを確認
gcloud batch jobs describe JOB_NAME --location LOCATION

# Batch が提供するイメージの一覧を確認 (非推奨イメージも表示する場合)
gcloud compute images list \
    --project=batch-custom-image \
    --no-standard-images \
    --show-deprecated

2026-08-31 より前に作成されたジョブについて、Debian 11 と Debian 12 のどちらを使用しているかを describe で確認できます。

ステップ 2: ジョブ定義のイメージ指定を Debian 12 に変更する

JSON ジョブ定義 (bootDisk.image を Debian 12 に変更) 
{
  "taskGroups": [
    {
      "taskSpec": {
        "runnables": [
          {
            "script": {
              "text": "echo Hello world from task ${BATCH_TASK_INDEX}."
            }
          }
        ]
      },
      "taskCount": 3,
      "parallelism": 1
    }
  ],
  "allocationPolicy": {
    "instances": [
      {
        "policy": {
          "bootDisk": {
            "image": "projects/batch-custom-image/global/images/family/batch-debian-12-official"
          }
        }
      }
    ]
  },
  "logsPolicy": {
    "destination": "CLOUD_LOGGING"
  }
}

batch-debian-11-official を指定していた箇所を batch-debian-12-official に置き換えます。

ステップ 3: 更新した定義でジョブを作成して動作確認する

Bash ジョブの作成 
gcloud batch jobs submit JOB_NAME \
    --location LOCATION \
    --config JSON_CONFIGURATION_FILE
⚠️ 注意: Debian 12 上でスクリプトや依存パッケージが問題なく動作することを、期限 (2026-08-31) 前に検証してください。

⚖️ メリットと制約事項

👍 メリット

  • 明確な移行期限の提示: サポート終了日が明示され、移行計画とテストのスケジュールを立てやすい
  • 運用リスクの低減: EOS 後の OS 継続利用によるセキュリティ・コンプライアンスリスクを回避
  • デフォルト利用者の負担軽減: batch-debian 使用ジョブは自動移行のため多くの場合コード変更不要
  • 長期サポートの確保: Debian 12 は 2028-06-30 まで EOS 予定がなく、より長いサポート期間を確保

⚠️ 制約事項・考慮点

  • batch-debian-11-official 系イメージは 2026-08-31 以降サポートされない
  • EOS を迎えた OS はイメージファミリー経由で参照できなくなり、イメージ更新も提供されない
  • Debian 11 と 12 ではパッケージバージョン (Python、glibc など) が異なるため、互換性テストが必要
  • Batch イメージベースのカスタムイメージは Debian 12 ベースで再構築が必要
  • 自動移行は「段階的」のため、移行期間中はジョブごとに describe で使用イメージの確認を推奨

🎯 ユースケース

💼 ユースケース 1: デフォルトイメージを使用するスクリプトジョブの確認

シナリオ: ジョブ定義でイメージを明示指定せず、スクリプト runnable のデフォルト (batch-debian) に依存。自動移行の対象だが、Debian 12 でスクリプトが動作するか事前に確認したい。

Bash 事前検証の実装例 
# 既存ジョブが使用しているイメージを確認
gcloud batch jobs describe my-script-job --location us-central1 \
    | grep -A 2 "bootDisk"

# Debian 12 を明示指定してテストジョブを実行
# (bootDisk.image に batch-debian-12-official を指定した JSON を使用)
gcloud batch jobs submit my-script-job-debian12-test \
    --location us-central1 \
    --config job-debian12.json

効果: 自動移行に先立って Debian 12 での動作を検証でき、移行期限直前のトラブルを回避できる。

🌙 ユースケース 2: Debian 11 を明示指定している定期バッチの移行

シナリオ: 夜間の定期データ処理ジョブで batch-debian-11-official イメージファミリーを明示指定。2026-08-31 までに移行が必須。

効果: ジョブ定義の bootDisk.image を batch-debian-12-official に変更してテスト実行することで、サポート期限後もセキュリティ更新を受けられる環境で定期処理を継続できる。

💰 料金・利用可能リージョン

💵 料金: このアップデート自体による料金への直接的な影響はありません。 Batch サービス自体には追加料金がなく、ジョブが使用する Compute Engine リソース (VM、ディスクなど) に対して課金されます。 Debian イメージのライセンスは無料 (Free) です。 Batch の料金 →
🌍 リージョン: この非推奨化は、Batch が利用可能なすべてのリージョンの Batch Debian 11 イメージに適用されます。 Batch のロケーション →

🧩 関連サービス・機能

🖥️Compute Engine: Batch ジョブの VM 実行基盤。本件は Compute Engine Debian 11 イメージの EOS (2026-08-31) に起因
📦Batch Container-Optimized OS (batch-cos): コンテナ runnable のみのジョブで使用されるデフォルトイメージ。今回の非推奨化の影響は受けない
🛠️カスタムイメージ (Compute Engine): Batch イメージをベースにカスタムイメージを構築している場合、Debian 12 ベースでの再構築が必要
🔐組織ポリシー (trusted image policy): compute.trustedImageProjects 制約で許可イメージを管理している場合、移行先イメージが許可されているか確認が必要
