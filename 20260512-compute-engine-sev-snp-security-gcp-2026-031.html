Google は、AMD ファームウェアに存在する脆弱性に対する緩和策を適用したことを発表した。 この脆弱性は、悪意のあるハイパーバイザーが AMD Secure Processor (ASP) 上で任意のコードを実行できる可能性があるもので、 Memory Mapped I/O (MMIO) の読み書き権限のエスカレーションを通じて AMD SEV-SNP ゲストの機密性と整合性を侵害する恐れがあった。

⚠️ 脆弱性の詳細

🐛 ファームウェアの保護欠如
AMD ファームウェアにおける保護機能の欠如が根本原因。悪意のあるハイパーバイザーが AMD Secure Processor (ASP) 上で任意のコードを実行可能な状態であった。
🔓 MMIO 権限エスカレーション
Memory Mapped I/O (MMIO) の読み書き権限がエスカレーションされ、本来アクセスできない領域への不正アクセスが可能に。
🛡️ SEV-SNP ゲスト侵害
上記の攻撃チェーンにより、AMD SEV-SNP で保護されたゲスト VM の機密性 (Confidentiality) と整合性 (Integrity) が侵害される可能性があった。
✅ Google による自動緩和
Google が全対象インスタンスに緩和策を自動適用。AMD アドバイザリ AMD-SB-3030 に準拠した対応が完了済み。ユーザー側でのアクション不要。
