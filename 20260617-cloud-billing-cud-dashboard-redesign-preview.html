💰 CUD ダッシュボードのリデザイン

Cloud Billing Preview
2026-06-17

📋 概要

Google Cloud は、Cloud Billing における Committed Use Discounts (CUD) ダッシュボード のリデザイン版をプレビューとして公開しました。リソースベースの CUD と支出ベースの CUD を 単一の統合ビュー で確認でき、コミットメント管理を大幅に効率化します。

Before / After 比較

❌ Before

  • リソースベース CUD と支出ベース CUD が別画面に分散
  • 全体像の把握に複数画面を行き来する必要
  • 大量コミットメントの検索・フィルタリングに時間がかかる
  • 統一的なコスト最適化戦略の策定が困難

✅ After

  • 全 CUD を単一画面で一覧表示・管理
  • ユーザビリティ向上で迅速な情報アクセス
  • スケーラビリティ改善で大規模環境にも対応
  • フィルタ・ソート設定がセッション間で保持

⚡ 主要機能

🔗 統合 CUD ビュー

リソースベース (vCPU, メモリ, GPU, Local SSD) と支出ベース (BigQuery, Cloud SQL, Spanner) の全 CUD を単一画面で表示。Aggregated View と Instance View でドリルダウン可能。

🎨 ユーザビリティ向上

プロパティベースのフィルタリング、列表示・ソート設定の永続化、サイドパネルでの詳細表示 (利用率履歴を含む) を実現。

📈 スケーラビリティ改善

大量のコミットメントを持つ Cloud Billing アカウントでもスムーズに動作。Active CUDs 列で合計数を表示し、CSV ダウンロードでオフライン分析にも対応。

🛒 アクション統合

ダッシュボードから直接 CUD 購入、推奨事項の確認・適用、自動更新設定の変更、CUD 分析レポートへのアクセスが可能。

🔧 技術仕様

CUD の種類と対象

CUD タイプ 対象 割引率
リソースベース CUD Compute Engine の vCPU, メモリ, GPU, Local SSD, ソールテナントノード 最大 55-70%
支出ベース CUD (新モデル) BigQuery, Cloud SQL, Spanner, Bigtable, AlloyDB, Dataflow, Memorystore サービスにより異なる
支出ベース CUD (レガシー) VMware Engine, NetApp Volumes サービスにより異なる

⚠️ 制約事項・注意点

⚠️ 制限事項
  • プレビュー段階 - GA 時に機能や UI が変更される可能性あり
  • CUD 購入後はキャンセル不可 (ダッシュボードのリデザインに関わらず基本制約)
  • 購入後のリージョン・期間の変更は不可
💡 考慮すべき点
  • レガシーの CSV ダウンロード形式は 2026 年 9 月 8 日 まで利用可能。それまでに新形式への移行を計画すること
  • プレビュー機能のため、本番運用ワークフローへの完全組み込み前に十分な検証を推奨

🎯 ユースケース

🏢 マルチサービス CUD ポートフォリオの管理

シナリオ: 大規模組織が Compute Engine のリソースベース CUD と、BigQuery / Cloud SQL / Spanner の支出ベース CUD を複数保有

効果: 全コミットメントを一覧表示し、期限切れ間近 (30 日以内) のコミットメントを迅速に特定。自動更新設定の確認や追加購入の推奨事項を一箇所で確認可能。

📈 CUD 利用率の最適化分析

シナリオ: FinOps チームが月次のコスト最適化レビューで CUD 利用率を確認し、過剰利用・不足利用のパターンを特定したい

効果: サイドパネルの詳細ビューから各コミットメントの過去の利用率履歴を確認。CUD 分析レポートに直接アクセスして効果を評価し、不足利用のコミットメントを特定してリソース計画改善に活用。

🔗 関連サービス・機能

→CUD 分析レポート - CUD の有効性を分析するレポート機能。ダッシュボードから直接アクセス可能
→CUD Recommender - 過去の使用パターンに基づいて追加コミットメントを推奨
→BigQuery Billing Export - CUD メタデータのエクスポートにより詳細な分析が可能
→Cost Breakdown Reports - CUD による節約額を含むコスト内訳の可視化

📝 まとめ

今回の CUD ダッシュボードのリデザインは、Google Cloud のコスト最適化管理における重要な UX 改善 です。リソースベースと支出ベースの CUD を統合的に管理できることで、特に複数サービスにまたがるコミットメントを持つ組織の FinOps 運用が大幅に効率化 されます。プレビュー段階ではありますが、早期にアクセスして新しいインターフェースに慣れておくことを推奨します。
