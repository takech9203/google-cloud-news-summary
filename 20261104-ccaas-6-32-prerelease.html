Contact Center as a Service プレリリース Fixed (不具合修正)
📅 リリース日: 2026-11-04

📋 概要

Google Cloud Contact Center as a Service (CCaaS) の次期バージョンと見込まれる 6.32 のプレリリースノートが公開されました。 本バージョンは新機能の追加ではなく、約 30 件の不具合修正 (Fixed) に特化した品質改善リリースとなる見込みです。

修正範囲は、コールルーティングとキュー管理、エージェントアダプター / デスクトップの UI と状態管理、 バーチャルエージェント (SMS / WhatsApp チャネルを含む)、アウトバウンドキャンペーンとコールバック、 Salesforce や NICE WFM などの外部連携まで多岐にわたります。

❌ Before (アップデート前の課題)

  • 放棄キューレコードの待ち時間が、最初にキューに入った時刻から誤って計算
  • ブラウザタイムアウト後の遅延接続リクエストで、インバウンドコールがキューに滞留しルーティング不能
  • 特定エージェント宛の音声転送が提示されず、発信者が無期限に保留
  • 切断などの通話関連操作に最大 72 秒かかる
  • 一時的エラー後に Agent Assist の文字起こしが恒久的に停止
  • 一時停止したキャンペーンが再開されず、失敗や参加者情報の欠落が反復

✅ After (6.32 で見込まれる改善)

  • 待ち時間・コールバック容量 (丸め誤差) などレポーティング / 容量計算の精度向上
  • ルーティング起因のスタックが解消され、インバウンドコールの取りこぼしが減少
  • アダプター / デスクトップのフリーズやステータス不具合が解消され、エージェント体験が改善
  • SMS / WhatsApp チャットの応答不能・エスカレーション不能を解消
  • Salesforce・NICE WFM・外部 DCR 連携の不整合を解消

🔧 サービスアップデートの詳細

📥 ルーティング・キュー関連の修正

  • 放棄キューレコードの待ち時間計算: 放棄した特定のキューに入った時刻から計算するよう修正
  • インバウンドコールのキュー滞留: タイムアウト後の遅延接続リクエストによるルーティング不能、再試行時の途中切断を修正
  • エージェントの状態スタック: ルーティング瞬間の放棄で projected 状態のまま受電不能になる問題、着信中の新規 deltacast オファーで誤って Unresponsive になる問題を修正
  • 音声転送: 特定エージェント宛の転送が提示も期限切れもされず、発信者が無期限保留になる問題を修正
  • ダイナミックキューと WFM 連携: スタッフィング 0 / 1 未満でも最低 1 スロット提供される問題、カスタムキュー識別子なし保存で同期がサイレント失敗する問題を修正

🖥️ エージェントアダプター / デスクトップの修正

  • 表示・UI: SmartActions / バーチャルタスクアシスタントのヘッダータイトル切り詰め、CRM 番号不一致時の誤った Not Found バナー、頭字語フィールド名の先頭文字の誤小文字化を修正
  • ステータスバー: In-email ステータスバーの白表示、ステータスバーから直接変更できない問題を修正
  • 動作・パフォーマンス: リカバリーコールで Calling のままフリーズする問題、通話関連操作に最大 72 秒かかる問題、アウトバウンド中にディレクトリへ特定エージェントが表示されない問題を修正

🤖 バーチャルエージェント・チャネルの修正

  • 資格情報とエスカレーション: 一時的なネットワークエラーで資格情報が誤って無効化される問題、SMS / WhatsApp チャットが応答不能になり人間へエスカレーションされない問題を修正
  • コールバックとルーティング: Apps API 経由の強制コールバックが元のキューへ誤ルーティングされる問題、外部 DCR 経由でカスタムパラメーターが欠落しインテントを失う問題を修正
  • Agent Assist: 一時的なネットワーク / クォータエラー後に文字起こしが恒久停止する問題を修正

📤 アウトバウンド・キャンペーンの修正

  • キャンペーン: 一時停止後に再開されず、失敗や参加者情報の欠落が繰り返される問題を修正
  • コールバックと番号検証: キャリアタイムアウトの無効番号への誤分類、新市外局番のカナダ番号が Callback call API で拒否される問題、丸め誤差によるコールバック容量の過小計算を修正
  • 発信制限: Allow unrestricted international calling 有効のエージェントに番号制限ルールが適用されない問題を修正

🔌 ポータル・外部連携の修正

  • CCaaS ポータル: スペイン語切替時に有効な IVR キューが「Setup is required」表示でグレーアウトされる問題を修正
  • Salesforce 連携: 設定無効でもバーチャルエージェントのみ対応のコールにケース・取引先責任者が誤作成される問題を修正
  • NICE WFM 連携: サブドメイン 20 文字超のインスタンスでセッションデータエクスポートが生成されない問題を修正
