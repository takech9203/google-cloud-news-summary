📞 CCaaS: HubSpot 連携機能の強化

CCaaS Feature Bug Fix
2026-05-12

🎯 概要

Google Cloud CCaaS (Contact Center AI Platform) において、HubSpot CRM との連携を大幅に強化する 3 つの新機能 がリリースされた。エージェントステータスのリアルタイム同期、通話転送時のチケットオーナー自動更新、デフォルト管理者ユーザーによるエージェント同期により、HubSpot を利用するコンタクトセンターの運用効率が大幅に向上する。

加えて、iOS アプリのクラッシュ修正や通話トランスクリプトの文字化け修正など、8 件の重要なバグフィックス も含まれている。

⚡ 主要機能

🔄 エージェントステータス継承

CCAI Platform と HubSpot 間でエージェントステータスをリアルタイムに同期。多対一のカスタムマッピングをサポートし、異なるステータス命名規則に柔軟に対応。

→Settings > Developer Settings > Agent Platform で HubSpot を選択
→Agent Status Inheritance ペインからマッピング設定
→既存の Kustomer 向け同等機能と同じアーキテクチャ

🎫 通話転送時のチケットオーナー自動更新

通話がエージェント間で転送された場合、HubSpot チケットのオーナーが自動的に新しいエージェントに更新される。追加設定不要で動作。

→インタラクションのライフサイクル全体で正確なオーナーシップ記録を維持
→HubSpot 連携が有効な環境で自動的に動作

👥 エージェント同期 (デフォルト管理者ユーザー)

HubSpot に対応するプロファイルが存在しないエージェントについても、デフォルト管理者ユーザーを使用してアカウント作成・レコード更新が可能。

→Settings > Developer Settings > CRM > Default User で設定
→エージェントアダプターに Authorize ボタンが表示

Step 1: Agent Platform の設定

Settings > Developer Settings に移動し、Agent Platform として HubSpot を選択。

Step 2: エージェントステータス継承の設定

Agent Status Inheritance ペインを開き、トグルを On に切り替え。Status Mapping セクションで HubSpot ステータスを CCAI Platform ステータスにマッピングし、Save をクリック。

Step 3: エージェント同期の設定

CRM ペインの Default User セクションでデフォルト管理者ユーザーを設定。エージェントアダプターに表示される Authorize ボタンで認証を完了。

⚠️ 制限事項・注意点

制限事項:
  • ブレンド SMS/MMS メッセージ経由のメディアファイル保存は未サポート
  • エージェントステータス同期は HubSpot を Agent Platform として選択時のみ利用可能
考慮すべき点:
  • ステータスマッピング設計には組織のワークフローに合わせた検討が必要
  • デフォルト管理者ユーザーには適切な権限設定が求められる
  • 既存の HubSpot 連携設定がある場合、新機能有効化前に互換性確認を推奨

💡 ユースケース

📊 UC1: マルチチャネルコンタクトセンターのステータス統合管理

シナリオ: 大規模コンタクトセンターで HubSpot CRM を使用。エージェントが HubSpot 側で「メール対応中」に設定した場合、CCAI Platform 側でも自動的に「取り込み中」に変更し、新規通話の着信を防止。

効果: ステータス管理の一元化により、不適切なタイミングでの着信割り当てが防止される。エージェントの操作負荷も軽減。

🎫 UC2: エスカレーション時のチケット追跡

シナリオ: 一次対応エージェントが技術的な問題を解決できず、専門チームに通話を転送。転送完了後、HubSpot チケットのオーナーが自動的に新しいエージェントに更新。

効果: SLA 管理やパフォーマンスレポートの精度が向上。手動でのチケット更新忘れによる管理上の混乱を防止。

👥 UC3: 新規エージェントの迅速なオンボーディング

シナリオ: 繁忙期に臨時エージェントを追加する必要があるが、HubSpot プロファイル作成が間に合わない。デフォルト管理者ユーザー経由で CCAI Platform からアカウント作成が可能。

効果: オンボーディング時間が短縮。HubSpot 管理者の作業待ちボトルネックが解消。
