🐍 Colab Enterprise
Python 3.13 サポート開始

Colab Enterprise Feature (GA)
リリース日: 2026-11-09
Google Cloud Release Notes

📌 概要

Colab Enterprise で Python 3.13 が利用可能になり、最新の Python バージョンとして位置づけられました。 「Latest」設定のランタイムテンプレート (デフォルトランタイムテンプレートを含む) から作成される新規ランタイムは、今後 Python 3.13 を使用します。

データサイエンティストや ML エンジニアは、パフォーマンス改善や最新の言語機能を含む Python 3.13 をマネージドなノートブック環境でそのまま利用できます。 既存のランタイムは現在の Python バージョンを維持するため、稼働中のワークロードへの影響はありません。

❌ Before (アップデート前)
  • 利用できる最新の Python は 3.12 までで、Python 3.13 の新機能やパフォーマンス改善をマネージド環境で利用できなかった
  • Python 3.13 前提のライブラリやコードの検証には、Colab Enterprise 以外の環境が必要だった
✅ After (アップデート後)
  • 「Latest」設定のテンプレート (デフォルト含む) から作成されるランタイムが自動的に Python 3.13 を使用
  • テンプレートの設定変更なしで、新規ランタイムが最新バージョンを利用可能
  • 既存ランタイムはバージョン維持で既存ワークロードの互換性を保持
⚠️ 移行計画の推奨: Python 3.10 は 2026 年 2 月 23 日にパッチ・サポート終了、2026 年 8 月 17 日に提供終了予定。古いバージョンを使用しているユーザーは移行計画の検討が推奨されます。

「Latest」設定のランタイムテンプレートから作成される新規ランタイムは Python 3.13 を使用し、既存ランタイムは現在のバージョンを維持します。

⚡ 主要機能

1️⃣ Python 3.13 の提供開始
→Colab Enterprise で利用可能な最新の Python バージョンが 3.13 になった
→「Latest」設定のランタイムテンプレートから作成される新規ランタイムは Python 3.13 を使用する
2️⃣ デフォルトランタイムテンプレートへの自動適用
→デフォルトランタイムテンプレートは最新の Python バージョンを使用するよう構成されているため、新規デフォルトランタイムは Python 3.13 を使用する
→⚠️ 注意: 2025 年 5 月以前に作成されたデフォルトランタイムテンプレートは Python 3.10 に固定されている場合がある。最新バージョンを使うにはテンプレートを削除して再作成する
3️⃣ 既存ランタイムの互換性維持
→既存ランタイムの Python バージョンは自動的に変更されない
→既存ランタイムのバージョン変更はサポートされておらず、必要な場合は目的のバージョンを使用するテンプレートから新しいランタイムを作成する

💡 サポート終了後の挙動:
  • パッチ・サポート終了後: そのバージョンでの新規テンプレート作成が不可になり、既存テンプレートは最新バージョンへ自動アップグレードされる。ランタイムは最終アップグレード (またはアップグレードがない場合は作成) から 6 か月後に停止する
  • 提供終了後: そのバージョンは Colab Enterprise で利用できなくなり、残存するテンプレートは最新バージョンへ自動アップグレードされる

🔌 REST API によるテンプレートの Python バージョン変更

HTTP / JSON notebookRuntimeTemplates の PATCH リクエスト 
PATCH https://REGION-aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/REGION/notebookRuntimeTemplates/TEMPLATE_ID?updateMask=software_config.colab_image.release_name

{
  "softwareConfig": {
    "colabImage": {
      "releaseName": "RELEASE_NAME"
    }
  }
}
→RELEASE_NAME にはイメージのリリース名 (例: Python 3.11 の場合 py311) を指定する
→「Latest」に設定するには RELEASE_NAME を空にする

既存ランタイムで Python 3.13 を使いたい場合は、Latest 設定 (または Python 3.13 指定) のテンプレートから新しいランタイムを作成し、ノートブックの接続先を切り替えます。

ステップ 3 (必要な場合): 古いデフォルトランタイムテンプレートの再作成

2025 年 5 月以前に作成されたデフォルトランタイムテンプレート (Python 3.10 固定の可能性あり) を最新バージョンに更新するには、デフォルトランタイムテンプレートを削除します。 次回デフォルトランタイム作成時に、最新 Python バージョンを使用するテンプレートが自動で再作成されます。

💡 メリット

💼 ビジネス面
  • 移行作業の最小化: 「Latest」設定のテンプレートを使っていれば、設定変更なしで新規ランタイムが自動的に Python 3.13 を使用
  • 既存ワークロードの安全性: 既存ランタイムはバージョンを維持するため、稼働中の分析・ML ワークロードが突然壊れるリスクがない
🔧 技術面
  • 最新の言語機能の利用: Python 3.13 の新機能やパフォーマンス改善をマネージドノートブック環境で利用できる
  • ライブラリ互換性の検証環境: Python 3.13 対応ライブラリの動作検証を Colab Enterprise 上で実施できる

⚠️ デメリット・制約事項

🚫 制限事項

✗既存ランタイムの Python バージョン変更はサポートされていない (新規ランタイムの作成が必要)
✗2025 年 5 月以前に作成されたデフォルトランタイムテンプレートは Python 3.10 に固定されている場合があり、最新化にはテンプレートの削除・再作成が必要

🤔 考慮すべき点

⚠️「Latest」設定のテンプレートでは、新規ランタイムの Python バージョンが予告なく上がるため、依存ライブラリの Python 3.13 対応状況を確認しておく必要がある
⚠️再現性が重要なワークロードでは、Latest ではなく特定の Python バージョン (リリース名) を固定したテンプレートの利用を検討する
⚠️Python 3.10 は 2026 年 2 月 23 日にパッチ・サポート終了、2026 年 8 月 17 日に提供終了となるため、該当テンプレート・ランタイムの移行計画が必要

♻️ ユースケース 2: Python 3.10 テンプレートのサポート終了対応

シナリオ: 2025 年 5 月以前から Colab Enterprise を利用しており、Python 3.10 固定のデフォルトランタイムテンプレートが残っている。2026 年 2 月のサポート終了前に最新化したい。

効果: デフォルトランタイムテンプレートを削除して再作成することで、以降のデフォルトランタイムが Python 3.13 を使用するようになり、サポート終了に伴う自動アップグレードやランタイム停止のリスクを回避できる。

💰 料金

✅ 追加料金なし: Python 3.13 サポート自体に追加料金はありません。

Colab Enterprise の料金は従来どおり、ランタイムが使用するコンピューティングリソース (Compute Engine 料金) と Colab Enterprise の管理手数料に基づいて課金されます。 詳細は Colab Enterprise の料金ページ を参照してください。

🌏 利用可能リージョン

Colab Enterprise が利用可能なすべてのリージョンで Python 3.13 を利用できます。 対応リージョンの一覧は Colab Enterprise のロケーション を参照してください。

🔗 関連サービス・機能

🤖 Vertex AI (Agent Platform)

Colab Enterprise の API は Vertex AI / Agent Platform API のサブセットであり、ランタイムテンプレートは notebookRuntimeTemplates リソースとして管理される

📊 BigQuery

BigQuery エディタからノートブックを作成して Colab Enterprise ランタイム上で実行でき、新規ランタイムは Python 3.13 を使用する

🖥️ Compute Engine

ランタイムの基盤となる VM リソース。予約 (Reservations) を利用してランタイム用リソースを確保することも可能

🏗️ Terraform

ランタイムおよびランタイムテンプレートの管理を Terraform リソースで自動化できる

📝 まとめ

Colab Enterprise で Python 3.13 が最新バージョンとして利用可能になり、「Latest」設定のテンプレート (デフォルトテンプレート含む) から作成される新規ランタイムは自動的に Python 3.13 を使用します。 既存ランタイムへの影響はありませんが、依存ライブラリの Python 3.13 対応確認と、サポート終了が近い Python 3.10 テンプレートの移行計画を進めることを推奨します。
