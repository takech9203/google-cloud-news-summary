📋 概要

Google Cloud は 2026 年 10 月 14 日、Application Integration に関するセキュリティ情報 GCP-2026-068 を公開しました。2026 年 8 月 27 日より前のバージョンにおいて、 AuthConfig (認証プロファイル) の検証処理とインテグレーション実行ランタイムに Incorrect Authorization (不適切な認可) の脆弱性が存在していました。 この脆弱性には CVE-2026-85298 が割り当てられ、重大度は Critical (重大) と評価されています。

悪用された場合、認証済みのユーザーが権限を昇格させ、Google Cloud プロジェクト内のサービスアカウントになりすますことが可能でした。 AuthConfig はサービスアカウントや OAuth 2.0、JWT などの認証情報を保持してタスク実行時に利用される仕組みであるため、 認可検証の不備は本来許可されていないサービスアカウント権限での操作につながる恐れがありました。

✅ 対応状況: この脆弱性は 2026 年 8 月 27 日にパッチ適用済みであり、ユーザー側での対応は不要です。 Application Integration はフルマネージドサービスのため、修正はサービス側で自動的に展開されています。

🔓 アップデート前の課題 (脆弱性の内容)

  • 2026 年 8 月 27 日より前のバージョンでは、AuthConfig の検証処理とインテグレーション実行ランタイムに不適切な認可 (Incorrect Authorization) の欠陥が存在
  • 認証済みユーザーが本来の権限を超えて権限昇格を行い、プロジェクト内のサービスアカウントになりすますことが可能だった
  • 重大度は Critical。サービスアカウントの権限を介したプロジェクト内リソースへの不正アクセスにつながる恐れ

🔒 アップデート後の改善 (修正内容)

  • 2026 年 8 月 27 日にサービス側でパッチが適用され、脆弱性は解消済み
  • フルマネージドサービスのため、ユーザー側での対応 (アップグレードや設定変更) は一切不要
  • AuthConfig の検証と実行ランタイムにおける認可チェックが是正され、意図しないサービスアカウントのなりすましを防止

🔑 AuthConfig (認証プロファイル) について

AuthConfig は、Application Integration のタスクが外部アプリケーションやサービス、データソースに接続する際の 認証情報を保存・管理する仕組みです。以下の認証タイプをサポートしています。

  • 🎫 Auth token (Basic / Bearer / MAC)
  • 🪪 Google OIDC ID Token (サービスアカウントベース)
  • 🔏 JSON Web Token (JWT)
  • 🔐 OAuth 2.0 (認可コード / クライアントクレデンシャル / リソースオーナーパスワード)
  • 📜 SSL/TLS クライアント証明書
  • 🤖 サービスアカウント
💡 補足: AuthConfig の管理には roles/integrations.integrationAdmin または roles/integrations.integrationEditor などの IAM ロールが必要です。

✅ 推奨される対応

🎯 必須の対応: なし。 本脆弱性は 2026 年 8 月 27 日にサービス側でパッチが適用済みであり、ユーザー側での対応は不要です。

🔎 推奨されるセキュリティレビュー (任意)

本件を機に、以下の確認を行うことを推奨します。

1. AuthConfig の棚卸し

Application Integration の「Auth Profiles」ページで、使用中の認証プロファイルと、紐づくサービスアカウントの権限を確認する

2. 最小権限の確認

認証プロファイルで使用するサービスアカウントに過剰な権限 (特に roles/owner や roles/editor などの広範なロール) が付与されていないか確認する

3. 監査ログの確認

必要に応じて Cloud Audit Logs でサービスアカウントの利用状況に不審なアクティビティがないか確認する

4. セキュリティ情報の購読

Google Cloud セキュリティ速報の XML フィード (google-cloud-security-bulletins.xml) を購読し、今後の情報を迅速に把握する
