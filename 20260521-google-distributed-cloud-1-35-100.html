VMware / Bare Metal パッチリリース - クラスタヘルスチェック修正およびセキュリティ脆弱性修正

2026-05-21
Google Distributed Cloud Fixed

📋 概要

Google Distributed Cloud (software only) for VMware および Bare Metal のバージョン 1.35.100-gke.72 がリリースされた。本リリースは Kubernetes v1.35.3-gke.400 上で動作し、重要なバグ修正とセキュリティ脆弱性修正を含むパッチリリースである。

🔄 Before / After 比較

❌ アップデート前の課題

  • Advanced Admin クラスタから Non-Advanced ユーザークラスタへの gkectl diagnose cluster でエラー発生
  • クラスタ健全性確認に代替手段が必要で運用効率低下
  • セキュリティ脆弱性が残存し攻撃面が存在

✅ アップデート後の改善

  • Non-Advanced ユーザークラスタへのヘルスチェック・診断が正常動作
  • gkectl diagnose cluster による統一的な監視が復旧
  • セキュリティ脆弱性修正によりセキュリティ態勢が強化

🛠️ 設定方法

💡 前提条件: gkectl 1.35.100-gke.72 インストール済み / Admin クラスタ kubeconfig へのアクセス / cgroupsv2 が有効な OS イメージ

ステップ 1: バージョンのダウンロード (VMware)

Bash 
# gkectl のアップグレード
gsutil cp gs://gke-on-prem-release/gkectl/1.35.100-gke.72/gkectl ./
chmod +x gkectl

ステップ 2: クラスタのアップグレード (VMware)

Bash 
# Admin クラスタのアップグレード
gkectl upgrade admin \
  --kubeconfig=ADMIN_CLUSTER_KUBECONFIG \
  --config=ADMIN_CLUSTER_CONFIG

# User クラスタのアップグレード
gkectl upgrade cluster \
  --kubeconfig=ADMIN_CLUSTER_KUBECONFIG \
  --config=USER_CLUSTER_CONFIG

ステップ 3: クラスタのアップグレード (Bare Metal)

Bash 
# クラスタのアップグレード
bmctl upgrade cluster \
  --cluster=CLUSTER_NAME \
  --kubeconfig=ADMIN_KUBECONFIG

ステップ 4: ヘルスチェックの実行確認

Bash 
# VMware: 修正後のヘルスチェック確認
gkectl diagnose cluster \
  --kubeconfig=ADMIN_CLUSTER_KUBECONFIG \
  --cluster-name=USER_CLUSTER_NAME

# Bare Metal: ヘルスチェック確認
bmctl check cluster \
  --cluster=CLUSTER_NAME \
  --kubeconfig=ADMIN_KUBECONFIG

⚠️ デメリット・制約事項

⚠️ 制限事項:
  • リリース後約 7-14 日間は GKE On-Prem API クライアント (コンソール、gcloud CLI、Terraform) から利用不可
  • cgroupsv2 が必須 - cgroupsv1 環境ではアップグレード不可
  • サードパーティストレージベンダー利用時は GDC Ready パートナーのドキュメントで互換性確認が必要
🚨 考慮すべき点:
  • Non-Advanced クラスタは将来的に Advanced への移行が必須 - 計画的な移行を検討
  • Bare Metal: Ansible 2.18 使用のため、ターゲットノードに Python 3.9 が必要 (RHEL 8.10 以降)
  • Ubuntu 使用時: 24.04 へのアップグレードが含まれるため、アプリケーション互換性を事前確認

💡 ユースケース

🏢 ユースケース 1: マルチテナントオンプレミス環境での診断

シナリオ: Advanced Admin クラスタで複数のユーザークラスタ (一部は Non-Advanced) を管理し、定期的なヘルスチェックを自動化している環境

Bash 
#!/bin/bash
# 全ユーザークラスタの定期診断スクリプト
ADMIN_KUBECONFIG="/path/to/admin-kubeconfig"

for cluster in $(gkectl list clusters --kubeconfig=$ADMIN_KUBECONFIG -o name); do
  echo "Diagnosing cluster: $cluster"
  gkectl diagnose cluster \
    --kubeconfig=$ADMIN_KUBECONFIG \
    --cluster-name=$cluster
done

効果: Non-Advanced を含む全クラスタの診断が正常実行され、インシデント検知の網羅性が回復

🏦 ユースケース 2: セキュリティコンプライアンス対応

シナリオ: 金融・医療等の規制環境でオンプレミス Kubernetes クラスタを運用しており、脆弱性パッチの迅速な適用が求められる

効果: Vulnerability fixes に記載された脆弱性が修正され、セキュリティ監査への対応が容易に
