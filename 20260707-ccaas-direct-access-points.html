📋 概要

Google Cloud CCaaS (CCAI Platform) に、チャットチャネル向けの Direct Access Points (DAP) 機能が追加されました。API レスポンスの Key-Value ペアに基づいて、チャット会話を特定のキューに直接ルーティングすることが可能になります。

従来は IVR (音声)、Web SDK、Mobile SDK でのみ利用可能だった DAP が、チャットチャネルにも拡張されたことで、コンタクトセンターの運用効率が大幅に向上します。

🔄 Before / After

❌ Before (従来)

  • チャットで DAP が利用不可
  • 全チャットがデフォルトのキューツリーを通過
  • API 起点チャットも直接ルーティング不可
  • 顧客属性に基づく即時振り分けが困難

✅ After (今回)

  • チャットで API Response DAP が利用可能
  • デフォルトルーティングをバイパス可能
  • API レスポンスで特定キューに直接ルーティング
  • 複数 Key-Value ペアの AND 条件設定

🏗️ アーキテクチャ図

API レスポンスの Key-Value ペアが DAP の条件に一致した場合、チャットはデフォルトのキューツリーを経由せず、指定されたキューに直接ルーティングされます。

💻 ルーティングロジック例

条件は複雑なものから順に作成する必要があります。最初にマッチした条件でルーティングが確定し、以降の条件は評価されません。

JSON 
{
  "conditions": [
    {
      "key": "customer_tier",
      "value": "enterprise"
    },
    {
      "key": "issue_type",
      "value": "billing"
    }
  ],
  "target_queue": "enterprise-billing-support"
}

🛠️ 設定方法

前提条件

→Google Cloud CCaaS (CCAI Platform) の有効なインスタンス
→API DAP 用の外部 API エンドポイント (JSON レスポンス)
→API 認証情報 (Basic 認証 / Salesforce 統合)
→管理者権限

設定手順

  1. API エンドポイントの準備 - チャットユーザー情報を受け取り JSON レスポンスを返すエンドポイントを構築
  2. DAP の作成 - CCAI Platform ポータルで Settings > Queue に移動し、チャットチャネルで API Response DAP を作成
  3. Key-Value ペアの設定 - API レスポンスの Key-Value ペアを入力し、AND 条件を設定
  4. グリーティング設定 - 必要に応じてグリーティングメッセージを設定
  5. テスト - 条件を満たすテストチャットを送信し、正しいキューにルーティングされることを確認
API Endpoint Example 
API URL: https://your-api.example.com/customer-routing
Method: POST
Response: {"customer_tier": "enterprise", "issue_type": "billing"}

⚠️ デメリット・制約事項

⚠️ 制限事項
  • プレリリース段階 - 本番環境での利用にはリリース後の確認が必要
  • API Response DAP のみがチャットに対応 (User Segment DAP、General DAP は未対応)
  • 外部 API エンドポイントの可用性がルーティングの信頼性に直結
💡 考慮すべき点
  • DAP 条件の作成順序が重要 - 複雑な条件を先に配置する必要がある
  • API レスポンスの遅延がチャット開始の待ち時間に影響する可能性
  • 既存 API DAP との重複がある場合、ルーティングルールの再構成が必要になる場合がある

🎯 ユースケース

👑 ユースケース 1: VIP 顧客の優先チャットサポート

シナリオ: EC サイトのチャットサポートで、API から顧客の購買履歴やサブスクリプションティアを取得し、VIP 顧客を専任チームのキューに直接ルーティング。

設定例 
API Response: {"customer_tier": "vip", "annual_spend": "high"}
DAP 条件: customer_tier = vip AND annual_spend = high
ターゲットキュー: VIP専任サポートキュー

効果: VIP 顧客がデフォルトのキューツリーを経由せず、即座に専任エージェントに接続。顧客満足度とリテンション率が向上。

🔧 ユースケース 2: 技術的な問題の自動エスカレーション

シナリオ: SaaS プロダクトのチャットサポートで、顧客のアカウントステータスや障害情報を API で確認し、既知の障害に該当する場合は専門の技術チームに直接ルーティング。

効果: 既知の問題に対して一次対応を経由せずに専門チームが即座に対応。解決時間の短縮と顧客満足度の向上。

🚀 ユースケース 3: オンボーディングチャットの専用キューへの振り分け

シナリオ: 新規登録ユーザーがチャットを開始した際、API でアカウント作成日を確認し、新規ユーザーをオンボーディング専門チームのキューに直接ルーティング。

効果: オンボーディング専門のエージェントが対応することで、初期の離脱率を低減し、製品の活用促進につなげる。
